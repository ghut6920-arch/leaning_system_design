# 为什么离线预测好，闭环仍可能失败

本单元要把一次闭环失败接成可核对的项目判断：评价了什么，偏差怎样传下去，哪些解释仍成立，怎样用实验帮助选择。先看对象和机制，随后看条件对照与一份完整实验示范，最后分析同一个教学案例。案例和数值均是明确假设，不是你的项目数据，也不是已运行实验。

## 把命令接回下一次输入

![策略、执行和环境组成的闭环](E:/文献资料/学习系统架构设计/learning/embodied-intelligence/questions/visible/bc-closed-loop-20261012/closed-loop-v1.png)

图中的真实状态 x_t 包括机器人和物体的位置、速度、接触等，未必直接可见。传感器将它变成观测 o_t；策略实际使用输入 h_t，可以是当前观测，也可以加历史。策略输出的是**命令 a_t**，部署接口及低层控制器将它变成**实际输入 u_t**。环境据当前状态、实际输入和扰动，产生下一状态；下一状态又形成下一次输入。箭头表示依赖与时刻连接，不自动表示每项都能直接测得。

| 同一控制时刻的对象 | 用途与关系 |
|---|---|
| x_t → o_t | `o_t=g(x_t,传感条件)`；图像不是全部物理状态 |
| o_t/历史 → h_t | 可以使用过去观测和已发动作；历史不保证足够区分所需动作 |
| h_t → a_t | `a_t=πθ(h_t)`；网络给出命令 |
| a_t/状态/时序 → u_t | `u_t=C(a_≤t,x_≤t,时序)`；包含还原、坐标、命令语义、跟踪与延迟 |
| x_t、u_t、w_t → x_(t+1) | `x_(t+1)=F(x_t,u_t,w_t)`；实际动作改变下一输入 |

图上方的状态支路提醒我们：同一个命令在不同状态下，执行和环境反应可以不同。真实状态不可观察时，记录必须说明用了什么代理，不能把图像特征直接当真实 x_t。

BC 的离线目标通常类似 `L_demo=E_(h,a*)~D[ℓ(πθ(h),a*)]`，比较示范输入上的预测与标签。闭环任务则关心 `J=E_τ[Σ c(x_t,u_t)]`、任务成功及恢复表现；这里的轨迹由策略、执行接口、环境和传感共同产生。因此，评价输入来自谁、动作造成什么、用什么标准判成功，都是模型判断的一部分。

| 观察 | 它实际回答什么 | 仍未回答什么 |
|---|---|---|
| episode 留出集动作误差低 | 相似示范输入上，预测与标签接近 | 自身动作造成的新输入上会怎样；任务容差和恢复 |
| 某些初始条件下闭环成功 | 这些条件下整条执行链完成任务 | 其他条件、扰动范围、原因和可靠性 |
| 扰动后能恢复 | 这类扰动及检查条件下存在恢复行为 | 所有扰动、所有阶段或真实机械臂稳定性 |

## 一个完整示范：同样的离线误差，反馈不同

使用一维无量纲模型，e_t 是偏离目标的数值。没有惯性、噪声、接触和约束，环境固定为 `e_(t+1)=e_t+u_t`。演示只包含 `e=0、正确动作u*=0`。取两种策略：

`u_q(e)=-(1-q)e+b`。

在演示输入 e=0 上，两种策略都输出 b，离线平方误差都是 b²。但把动作代回环境：

`e_(t+1)=e_t-(1-q)e_t+b=q e_t+b`。

这里 b 每步引入同一偏置；q 决定已有偏差怎样传到下一步。q 由所给环境和策略共同形成，不是 BC 的统一性能指标。

从 e_0=0 开始，取 b=0.01。完整短轨迹为：

| 时刻 | q=0.5 的偏差 | q=1 的偏差 | q=1.2 的偏差 |
|---|---:|---:|---:|
| 0 | 0 | 0 | 0 |
| 1 | 0.010000 | 0.010000 | 0.010000 |
| 2 | 0.015000 | 0.020000 | 0.022000 |
| 3 | 0.017500 | 0.030000 | 0.036400 |
| 4 | 0.018750 | 0.040000 | 0.053680 |
| 5 | 0.019375 | 0.050000 | 0.074416 |

例如 q=1.2 的第二步是 `1.2×0.01+0.01=0.022`；这个新偏差成为第三步的输入，又得到0.0364。相同的演示误差 0.0001，没有约束偏离输入上的反馈斜率。q=0.5 把已有偏差减半，但偏置每步仍在加入，最终趋近0.02而非零；q=1则持续积累偏置。

展开递推可得 `e_t=bΣ_(j=0)^(t-1)q^j`。q≠1 时为 `b(1-q^t)/(1-q)`，q=1 时为 tb。这是给定标量模型中的合法关系，不是根据几次数值证明真实机器人稳定。

把 b 改为0，演示输入上的误差严格为零。若外部扰动使 e_0=0.05，q=0.5 的下一偏差为0.025，q=1.2则为0.06：离线完美仍没有确定恢复反应。实际机械臂的状态、观测、低层控制和接触要复杂得多，不能把一个 q 或这张数表直接当其稳定性证明。

这些输入已经给出了完整计算。接下来要使用的是其中的关系：**原评价在何种输入上成立，部署怎样改变输入，对新输入的行为又有哪些依据。**无需另做换数字练习。
