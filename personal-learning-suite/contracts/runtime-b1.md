# B1 保存与入口接口

日期：2026-10-03；共用语义 `pl-contracts/0.1.0`；承载格式 `pl-store/0.1.0`。

依据 D01 第六、九至十一节、D00 第三、五、六、九节、D08 恢复与授权、D09 采用与执行边界，以及 N00 的 B1 清单。本文件细化承载，不另维护对象字段定义；[共用契约](shared-contracts.md)仍是唯一字段与专业责任来源。

## 当前范围

B1 使用明确标记的虚构工作区。真实课程、个人记录目录、模型与宿主身份绑定尚未选定；程序拒绝把真实个人原件或 `host_verified` 授权作为当前虚构模式的输入。`entry_actor` 只用于受控开发测试，不构成真实身份认证。

主入口可以初始化空间、读取当前合法上下文、定位恢复点、路由专业需要、暂停、限制、清理和限定导出。教学、目标设计、评分、规划和策略配置尚未实现；路由成功只返回下一职责及缺项，不启动专业 Agent，不生成活动或“已安排”回执。

## 存储与事务

本批选择 Python 标准库 SQLite 事务，替代 D01 中建议的多文件原子发布实现；这是保持原契约的本地存储适配选择。一个 `records.sqlite3` 保存对象修订、当前索引、原件文本、限制、暂停、操作回执与状态修订。没有另一份权威 `state.json`，也没有各 Skill 的数据库。个人记录仍在套件之外；本批行为测试使用临时目录，演示空间显式为虚构。

写入使用 `BEGIN IMMEDIATE`，对象、原件、有效指针、操作去重与状态修订一起提交。预期修订不符返回 conflict；校验或权限不足返回 rejected；发生保存异常返回 not_saved。不把待保存说成保存成功，错误返回不携带未采纳的完整载荷。

对象正文按 id + revision 定位，修订不可覆写；当前指针独立于历史修订。ArtifactRef 当前有限切片支持不可变的安全相对逻辑路径及 revision=1，原件文本与对象一起存在数据库。需要修订原件时使用新逻辑路径，不能改写旧路径或把旧原答当新原答。后续确实需要同路径多原件版本时再扩适配器。

专业字段由相应角色及授权约束。测试用 `import_fixture` 只能用于初始空空间，且明确要求 `synthetic_only=true`；混角色种子导入是测试初始化接口。B0 夹具保留历史标记 `synthetic=true`，演示脚本确认其来源后在内存补入接口标记，不修改原夹具。普通提交不能再调用这个例外，不能靠 `owner` 字段或角色模式获得其他专业写入权。

操作标识对应一个逻辑变更。回执只保存必要标识、修订与计数，不保存个人载荷或内容哈希。相同标识的相同重试返回原回执；同标识不同载荷拒绝。删除、暂停或限制变化须先检查，旧幂等成功不能成为再次使用失效依据的许可。

控制操作的重试按当前控制状态核对理由；若后续操作已改写同范围理由，旧操作会保守拒绝，调用方须重新读取状态并明确新的操作。B1 不保存完整控制历史来重现旧理由。

## 读取、限制、删除与导出

读取先查控制与现有合法引用；暂停可以保留读取与查看，但拒绝相应范围新提交。专业依据停用与用户暂停分开，resume 只恢复用户暂停，不解除专业限制。解除专业用途限制须有相应专业责任的恢复依据；B1 不伪造该依据。

read_context 给出当前对象和控制；read_refs 按确切 id/revision 返回获准保留的历史对象。断点或判断引用旧修订时用 read_refs，不把引用悄悄替换成最新修订，也不直接绕过组件读数据库。

删除由显式 scope_ids 进入持久控制与清理两阶段，先提交“待删除、不可使用”的范围，再清理正文、全部历史修订、原件、候选及含相同引用/原件路径的受控派生内容。第二阶段失败时返回未清理完成，第一阶段限制仍保留；重启后的读取、导出、提交和恢复不能绕过该限制。共享原件包含所删片段时，保守清理其依赖并报告影响；确认独立的对象/原件保留。此保守处置不代表已由 AG3 重新评分，后续专业恢复仍待处理。

成功删除通常增加两次 `state_revision`；清理失败时返回已保存停用门后的实际修订和 `pending_cleanup`。调用方不能假定删除失败即状态未变，应读取当前状态后以同一删除操作标识继续清理。

用户未删除关联索引时，最小失效 ID 不含正文、摘要或内容指纹。删除包含索引时同时清理相关去重回执和失效 ID；旧提交不能凭旧 CAS、空缺引用或幂等回执复活。无法对应现有合法依据的迟到结果在持久化前拒绝。该策略不承诺凭空识别用户以后重新提供的同一文字。

SQLite 使用 DELETE journal 与 secure_delete；清理受控数据库不等于操作系统、安全软件、外部备份或会话历史已经永久擦除。程序只报告受控数据库的实际处理。进入 Agent 上下文的内容仍须结束受影响任务，并在剩余合法上下文继续；B1 未实现自动终止宿主 Agent 或擦除历史。

导出默认在内存构造所选对象及其引用依赖，不自动创建外部副本。原件按完整逻辑路径导出；多个片段共用一个文件时会包含该文件的其他片段，B1 不提供片段裁剪接口。查看“只看原答”之类请求时，入口按 ArtifactRef 的定位展示请求段，不能直接把整份导出当作回答。只导出引用/摘要时明确不足独立复核。用户自行保存 stdout 或导出结果成为外部副本，当前程序不能代其清除。

## 执行边界与验收

只有本地单入口顺序调用；没有无人值守后台、真实多 Agent 身份、模型绑定或旧展示拦截。数据库事务串行化不等于同时阻止两个 Agent 向用户发言；接管与展示保障留 B6。

B1 验证保存后重新打开、CAS、幂等、授权/采用拒绝、暂停/限制、删除及关联索引、限定导出、无摘要恢复、路径边界与失败回滚。每项实际输出单独记录；B10-06/08/12 只在本存储与入口切片得到局部结果，完整专业/宿主情境尚未运行，不据此宣称 V1—V4 通过。
