## 目标与范围

让运行指令能够把可靠内容转成有用途、能理解、能实践、能调整并返回整体任务的教学。保留目标标准、学科核验、真实原答和帮助、完整产物、预算、恢复及合理控制；减少不改变教学决定的重复加载、登记和会签。

维持七 Skill、四逻辑角色，不新建掌握分、画像或第二份需求队列。原研究与正式设计作为维护源；运行规则承担实际选择。个人学习目录、通用指令、开发程序及验证输出分开。模型品牌不是接口条件；专业能力不足或必要工具缺失时明确可用范围。

## 第一阶段的具体修改

1. SK03 主入口先区分“已有活动”“有作品”“陌生／未准备单元”，明确调用 design-whole 和 Encoding 的准备规则。程序提交规则留运行参考，不把程序能保存当成已经会教。
2. design-whole 把对象、关系、条件、必要前置、整体任务和学习者起点转成可直接教的安排；引用目标、材料和计划，不再建新对象。当前可讲内容必须可定位、正确且够承担功能。
3. encoding 用内容结构决定讲解、例子、表征和学习者工作；按当前准备程度选择完整示范、部分承担、目标任务或边界。动态变化可增细、扩条件、合整体、撤支持或换形式，不能只有向下补基础。
4. c0 将教学输入与证据检查分开：可靠示范可以直接展示，其实际代做操作如实记录；资格表不会阻止提供学习必需的信息。自然关联的操作尽量形成一个工作单元；简单反馈及时给，稳定上下文复用。
5. AG1 交给 AG0 的是当前可执行材料和任务、用途、关键分支及返回位置；AG0 未拿到这些时先准备，不能仅从目标标题连续生成问题。普通范围内自己兼任可直接完成，不制造角色回执。
6. 给两个具体正常教学例作为按需参考：陌生的视频张量语义和已有基础的动态模型。示例展示内容决策，并明确它们不是用户已完成的学习。

## 第六阶段的必要情境

至少核查：陌生单元；已有复杂作品；Post 访问困难与结构障碍；自主方法选择；新旧规则条件更新；理论与实现／实验对应；缩时与局部无进展；系统参考错误；跨模型恢复。

前向输入只给实际可取得的规则、原始资料和请求；允许真实按需回源，记录其成本。不能先给理想教学方案再宣布 Skill 通过。评价具体材料、展示顺序、学习者工作、反馈和完整产物，不用标题、字数或字段匹配代替语义判断。独立复核只在有授权且可用时调用；单模型演练明确标记。

真实学习需要用户实际进入学习后才记录原答。理论、代码行为、实验解释和新的使用条件分别核验。当前帮助下完成不代表无帮助或长期保持；个人记录不复制进通用资源。日常稳定材料复用，记录准备、主动学习、阻塞等待、反馈／恢复成本，避免把首次准备免费化或重复相加。
