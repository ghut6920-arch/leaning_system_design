# 采样器独立规格 / revision 1

本文件是 AI 备课规格，尚无学习者实现、提交或运行。完整教师实现另在 `teacher_cfm.py`；审查者可以查看。已看过完整实现后，只能描述实际支持下的实现、修改或追踪，不能称首次无提示独立实现。

函数签名：`euler_sample(field, z, c, n_steps)`。输入 `z` 是有限实数 `[B,2]`，`c` 是相同 B 的整数 `[B]` 且每项为 0 或 1；`n_steps` 是正整数，bool 不作为合法步数。`field(x,t,c)` 接收当前状态 `[B,2]`、标量生成时间 t 和类标，输出相同 shape 的有限速度。输出是 t=1 的 `[B,2]` 状态，不能改变输入 z。

从 z 初始化，固定 h=1/N。对 n=0,…,N−1，查询 `field` 的时间为 n/N、状态为上一次更新所得的位置；完成 `y←y+h×velocity`。合计恰好 N 次查询与更新，不额外查询 t=1。训练端点 X₁ 不是该函数输入。检查非法 N、shape、类标及不合法场输出，给明确异常。所有同 N 的 batch 样本共享积分时间；不是一次一个样本的时间循环。

可独立自检的行为依据：恒定速度 d 将终点变成 z+d；时间依赖速度 v=t 的二维场使终点变成 `z+(N−1)/(2N)`；查询次数必须是 N，首末查询时间为 0 与 (N−1)/N；必须使用更新后的状态。对 oracle Gaussian 场，N=1 终点为各 c 的 μc，固定 c 的方差为零；这只是纯数值对照，不是要求模型直接输出目标均值。
