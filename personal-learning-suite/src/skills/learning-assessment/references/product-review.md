# 整体作品的实质评审

按需用于备课审查、复杂作品、非标准解与整体判断。依据 D02 第三／五／六／九节、D03 第五至七节、D04 第四至七节、D05 第七节 C、D06 第九节 C、D11 第六／八节；语义仍来自 [共享契约](../../../../contracts/shared-contracts.md)。下列原答均是虚构内容，自查不等于独立复核。

## 审查备课时先回用途，再看目标内产出

从原用户用途、实际内容、候选目标和成品开始，之后再看作者的通过总结。先依 [目标规则](../../learning-goals/references/goal-design.md)判断近期理解要求怎样承接用途、有理由暂缓哪些工作；再核实际材料、主要问题、参考与支持是否兑现既定要求。两种判断分别说明，不因自定目标与自定题面一致就认定用途已充分覆盖。来源本来只支持有界候选时，不替用户补造全课程要求。

检查 [材料教学功能](../../learning-materials/references/domain-checks.md)及谁承担关键操作：正确参考与完整文件不足以证明必要关系已教出，题面中的自主工作也不能由教师参考补算。指出实际缺失连接及影响，区分原目标内缺项、目标建议未充分承接用途、范围外改善和实际适配待验证。允许简单目标、纯解释和已有合格安排直接结束，不能事后添加统一训练／实现／闭卷要求。

目标选择不足交AG1回原依据修订，材料功能不足交AG2与教学方补齐；核受影响主线再交AG0。不另设会签或固定审查Agent，同模型可重新依原件核查，已见作者结论不称盲评。认知初稿及审查结论可因具体反证回改，不以多数赞同裁定。检查实例见 [备课质量实例](../../learning-teaching/references/preparation-quality-examples.md)。

交付区分目标选择、内容／材料功能、学习者工作与候选呈现的判断；实际执行、学习效果和协作净价值未观察时另列未知。设计就绪只支持在该范围试教，不形成学习者能力判断；后来的目标修订不倒判原来合法的表现。

## 从原件检查连接，再给有范围的结论

1. 明确本次决定和原有标准。取得确切要求／判据修订、原任务、允许资源、实际帮助、可靠参考和连续原件。只读摘要无法支持关键连接时回正文／代码；缺原件就限制结论，不能从教师总结补写原答。
2. 将目标的整体义务定位到产物中的实际位置。检查前提、所求结论、接口、条件／分支和整体组织；局部计算或模块各自正确还须检查能否合法连接。允许多解，不将参考步骤当唯一模板。
3. 对内容作实质核验。证明检查合法推理及覆盖全部结论；构造核可行性及所称下界；实现回规格和实际执行依据；实验／论证查比较条件、证据与竞争解释。有限运行或数值只是相应范围的辅助，不能证明一般命题。
4. 按操作解释谁完成了什么。教师提供的等式、判据、核方向、测试、完整代码分别影响相关操作；允许查基础引理不自动取消核心论证的支持。帮助之后的修订与初答分开，同一作品的多个引用仍是同一相关样本。
5. 交每项具体结论：原答中支持的位置和理由、条件与限制、未完成或相反证据。整体缺关键连接，不能由平均分补过；局部有效支持保留。参考疑误先限制用途并交 AG2，不先给学习者记错；新要求不能倒判旧答。
6. 只把会改变目标内下一决定的缺口交为同一必要需求。已有完整合法作品就直接复用／重评并明确不追加检查；未来条件未到可以结束，缺原件／核验能力则限制相应用途。教学修复沿父产物返回，计划由 SK05 取舍。

## 完整二次目标：具体评分锚点与替代解

完整任务与数学依据见 [目标实例](../../learning-goals/references/goal-worked-design.md)，评审先确认到底是公式计算、一般唯一性与构造，还是另有最小秩。以下不能作为每种目标的共同强制评分表。

| 原有目标义务 | 该作品里需看到什么 | 常见不足与返回工作 |
|---|---|---|
| 一般唯一性 | PSD／正λ等假设、公共核条件的两方向及存在性，或合法等价证明 | 只列三个数值例子：保留算例应用，回一般论证；“非严格凸”单句不足以完成不唯一方向 |
| 合法构造 | 给合法 `Q` 并证实其限制 `ker(A)` 的剩余方向，对所称全部 `b` 成立 | 仅说非零或rank1：核方向是否遗漏，返回候选检验与选择 |
| 本题最小秩 | 可行rank1构造，以及rank0不可能的理由 | 数值可逆只核具体候选，不能替代下界 |
| 一般最低秩 | 在自由选PSD设定下，`rank(Q)≥dim ker(A)` 的下界与达到界限的构造，包含满列秩0边界 | 只给具体题的rank1：保留该题，回一般限制映射及达到下界 |
| 后续时点重建（仅若目标要求） | 对应时间、实际接触／帮助条件下的合法重建原件 | 即时答对或日期过去不补足；未要求则不产生复习债务 |

**虚构原答甲：合法非模板作品。**任务取 `A=[[1,1,0],[0,1,1]]`，原答选择 `Q=diag(1,0,0)`，说明 `ker(A)=span{(1,-1,1)}`，任意非零该方向第一分量非零，故不能同时在 `ker(Q)`。用公共核判据证明对所有 `b` 唯一；由于 `Q=0` 留下该方向，秩0不可行。若原有要求只需本题的唯一性与最小秩且判据允许引用，这是一份合法完成作品，不能因参考用了投影矩阵而判错。若还要求自主重建一般唯一性证明或一般最低秩，而原答没有，保留本题构造／最小性支持，列这些义务尚未取得，不默认整份失败或自动通过。

**虚构原答乙：同为rank1，却不合法。**原答选 `Q=uuᵀ`，`u=(1,1,0)`，理由仅“非零PSD且rank1”。`n=(1,-1,1)` 满足 `An=0`、`uᵀn=0`，所以 `Qn=0`，沿 `n` 目标不变。原答可支持已展示的PSD／秩计算，当前构造未满足唯一性；若核检查成功但没有连到方向覆盖，只修这个连接，不重教全部矩阵基础。教师直接给出 `n` 或公共核条件后改好，记录为这些帮助下的修订，不能回写自主构造。

**虚构原答丙：数值候选通过，整体证明缺失。**原答给 `nnᵀ/3` 并运行一次 `b` 得到解，却没有解释为何所有 `b` 唯一、为何不能低秩，也没有一般下界。实际数值结果只核那次运行及对应计算，构造形式可另作内容核查；完整目标仍未完成。必要返回是候选可行性、下界和一般量词，不能安排十道同型数值题代替。

**虚构原答丁：简单目标已够。**如果目标仅为给定 `Q=I` 公式计算，原答按合法公式计算、条件／维度与代回正确，允许工具已知，便按该要求结束。上面的证明、最小秩和后续时点义务都不追加。

参考更正后以当时合法原答、资源和判据直接重评；甲原本完整满足当时目标，就撤销错误补课需求，不为更正系统再测一次。参考修好不补造乙／丙没有完成的推理。

## 理论、实现、测试选择与实验各查自己的工作

以 [材料实例 C](../../learning-materials/references/materials-examples.md) 的均值规格为例：完整作品需非空计算和明确空输入报错，接口返回／异常也符合约定。若代码只返回 `sum(xs)/len(xs)`，能跑 `[2,4]` 只支持该输入；如果先定规格要求显式空输入检查，则隐式除零不完成它。反之，原规格只要求报错而没有要求特定异常或显式写法，不能事后追加那项标准。

教师给过 `[2,4]`、单元素、正负数和空输入的预期，则这组运行可支持相应实现工作，不能支持自主测试选择。若完整代码来自AI、用户仅运行，可评价使用／执行和观察，不能判为自主实现。复杂系统另查真实模块接口、边界、环境及可复现执行；测试覆盖根据规格决定，不用固定样本数作保证。

真实实验若要比较某改动效果，回查基线、数据／切分、指标、随机性、运行条件、实际结果及竞争解释。只得一张损失图可评价已展示趋势；缺匹配比较条件时不能确定改动导致收益。理论推导、代码行为和实验解释可共享原件，但分别给理由与未支持范围。

评审是当前责任的专业工作，不要求每次新增表格、复制代码或等待多个角色会签。完成后用现有 Judgment／同义课程记录保存，关键原件及帮助可回查，下一教学接回父作品。
