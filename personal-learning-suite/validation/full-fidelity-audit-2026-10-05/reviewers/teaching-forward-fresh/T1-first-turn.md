这里按从下标 0 开始、数组以外的值都算 0 的完整线性卷积来示范。`x=[2,1]` 表示 `x[0]=2、x[1]=1`；`h=[3,4]` 表示 `h[0]=3、h[1]=4`。下标告诉我们数值放在哪个位置；它本身不是要相乘的数。

卷积的对象是这两串带位置的数，结果是一串新数 `y`。规则是：把 `x` 中下标为 `i` 的数与 `h` 中下标为 `j` 的数相乘，把这份贡献放到输出的 `i+j` 位置；同一位置的贡献相加。这就是公式 `y[n]=Σ_k x[k]h[n-k]` 中“两个输入下标加起来等于 n”的意思。[MIT 的离散卷积定义](https://live.ocw.mit.edu/courses/6-003-signals-and-systems-fall-2011/3c5d1ec5efbca4bcf46cdf5a1cca3518_MIT6_003F11_lec08.pdf)

这个例子只有四份可能非零的贡献：

| 输入位置 | 相乘 | 放到哪个输出位置 |
|---|---|---|
| `x[0]` 与 `h[0]` | `2×3=6` | `0+0=0` |
| `x[0]` 与 `h[1]` | `2×4=8` | `0+1=1` |
| `x[1]` 与 `h[0]` | `1×3=3` | `1+0=1` |
| `x[1]` 与 `h[1]` | `1×4=4` | `1+1=2` |

所以每个输出是：

- `y[0]=6`：只有下标组合 `(0,0)`。
- `y[1]=8+3=11`：下标组合 `(0,1)` 和 `(1,0)` 都贡献到这里。
- `y[2]=4`：只有下标组合 `(1,1)`。

得到 `y=[6,11,4]`。它有三个位置，是因为本例输入下标之和从 0 到 2。最关键的一点是：中间的 11 来自两条不同的贡献路径，它们落在同一个输出位置，所以要相加。
