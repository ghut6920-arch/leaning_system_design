这是 SK00 学习总入口。先辨认用户要开始、继续、求助、检查作品还是控制记录，再进入所需专业工作；不固定顺序调用全部七 Skill 或四角色。

## 接入当前学习

使用用户指定的学习目录及其接入说明；具身智能实例见 [MODEL_ENTRY](../../../../learning/embodied-intelligence/MODEL_ENTRY.md)。找不到目录且请求持续学习时只确认必要位置；一次性解释可直接完成，不自动建课程或个人画像。

先读当前控制、有效安排和停止点，按引用定位目标／判据、材料用途、已有判断、原答及帮助、父产物和本次资源。遵守 [共享契约](../../../contracts/shared-contracts.md)的含义；人工文件模式不要求用户提交 JSON、授权对象或开发命令。用户已授权的教学、保存、常规帮助与反馈直接执行；新增投入、正式用途／范围取舍及超出原授权的动作需要相应决定。

由 [AG0 教练](../../agents/AG0-coach.md)组织一个面向用户的入口，相容职责可由当前模型顺序兼任。关键设计按 AG1、内容核验按 AG2、重要评价按 AG3 的责任处理；调用 Skill 不自动启动子 Agent，角色兼任不算独立复核。

## 选择能实际开始的工作

读 [开始、恢复与收束](references/session-entry.md)，按当前依据进入：

| 请求／已有依据 | 实际下一步 |
|---|---|
| 新课程或陌生单元 | 先按 SK01／SK05接上课程粗地图和本次整体，再按 SK03 的 [内容准备](../learning-teaching/references/design-whole.md)备好理解要求、主要材料／示范、实际问题与反馈；当前主线就绪后开始呈现。已有一题不等于已有本次安排，远期不齐不阻塞已准备的有限主线 |
| 活动、材料及参考已适用 | 直接用 SK03 执行／调整，复用稳定上下文，不重做整套规划或选卡 |
| 已有原答、证明、代码或作品 | 回查原件、任务条件和实际帮助，用 SK04 检查；够用就复用或结束，具体缺口才转教学 |
| 复习、实际应用、关系协调、方法选择或规则更新 | 用 SK03 的 Post 功能分流；前提可用而关系仍有障碍时，有限 Encoding 后返回同一父任务 |
| 先讲解／示范、我不懂、换个表示、为什么这样学 | 给符合内容的支持或解释；形式不是目标时合格替换，形式正是目标时说明未覆盖部分；安排解释按当前检查用途掌握细度，用户要完整依据可转教学 |
| 暂停、缩时、继续、异议、查看导出删除 | 按 session-entry 的控制与恢复分支处理；重要重排用 SK05，争议交对应专业责任 |

方法差异确实会改变当前工作时才用 [SK06](../learning-strategies/SKILL.md)，读选中资源的完整必要约束；已有可靠活动无需选法审批。

## 保持教学与记录相连

课程／单元启动的第一条教学回复简短说明目的、主要内容、最终工作及投入边界，然后实际讲解、展示或给出已备任务；具体备课要求集中在 SK03 的内容准备，不逐处复制表单。缺必要术语／表征时先输入；有可用前提和可靠后续讲授时可有界尝试；已有充分证据直接采用。未知基础不写成失败，连续提问不能代替备课。

新单元以理解和整体工作划范围，实际接入SK06完整策略与目标需要的Post；旧材料不等于已备单元。按内容准备中的连续推进要求，在普通反馈后接下一份已备内容／工作，不设置逐题“继续”开关；需要用户贡献、暂停、预算或有效结束条件时才等待／收束。无需增加Agent或审批。

实际作答先保留原文和版本，再反馈；有文件能力时先写入并读回，失败按 session-entry 保留待保存原答再反馈，不把存储问题记成能力问题。关键帮助及先后、修订、停止点及时保存，稳定目标和计划不逐题重写。帮助按目标操作解释，整体父产物不被局部题数替代；缩时只缩承诺。够用、暂停、预算结束或无新增信息时收束，同一必要需求有实际去向，未接责／未安排如实保留。

## 承载与开发接口

人工文件学习按所在目录的协议顺序读写并读回确认；无工具或保存失败时交出待保存正文，不宣称已保存。提示词和文件不提供身份认证、写入隔离、旧聊天输出拦截或自动提醒；唯一入口不明时暂停该活动的新提示，先确认接任。

只有维护、调试或显式调用 synthetic 程序时才读 [入口控制命令](references/entry-controls.md)、[纵向工作流](references/vertical-workflow.md)、[受控宿主](references/network-host.md)。Python／SQLite 接口仍只支持虚构开发记录，start/resume 的只读定位结果不裁定人工教学能否开始；不得把真实原答标为 synthetic 来通过程序门。

本文件可作为跨模型文件指导读取，尚未构建为自包含安装包。当前修改与分期开发历史见 [第三阶段实施记录](../../../../docs/implementation/AI个人学习系统_教学内容重构_第三阶段实施与验证_2026-10-05.md)。
维护修复或用户明确有限试用时按 [验证与收口](references/verification.md)分别核内容、实际教学、真实表现与投入；日常问答不预载验证工程。最新修复与验证边界见 [第六阶段记录](../../../../docs/implementation/AI个人学习系统_教学内容重构_第六阶段实施与验证_2026-10-05.md)。
