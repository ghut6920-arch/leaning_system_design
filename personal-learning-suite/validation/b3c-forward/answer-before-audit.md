## 一、已有可靠活动：当前可用的是直接复用路径

在题设“已有可靠活动明确允许输入、关键工作与可靠反馈”且没有新增选法差异的范围内，直接交 SK03/当前教学入口沿该活动完成工作，`selection_needed=false`，本次新 `MethodConfig=null`。不为交付一张方法卡而重新遍历或编造候选。

保留学习者的工作：在给定 P→Q、Q→R、P 和允许教材/参考的条件下补出指定局部理由，再把它接回同一完整父推理链。复用不意味着只填空后就结束，也不意味着必须闭卷恢复前提。理由与父链须由该活动的可靠参考核验；反馈不能从原活动中省去。

此处“当前可用”只描述虚构路由。当前没有提供活动、目标、材料、父产物和预算的精确 ObjectRef，也没有访问真实暴露/帮助记录。SK03 在真实执行前应定位原活动和同一父产物、确认输入/关键操作/反馈/预算/当前限制仍相容；如已有可靠配置同样未变化，就引用它，不另建配置。本次没有执行 CLI reuse 或 inspect 来假装完成这些核查。

停止与返回：局部理由达到活动的够用条件即接回原父链；父链仍有问题时检查连接、组织或必要前置，不重复填同一理由或无限下钻。预算结束、暂停、参考争议或无新增信息时保留实际断点。充分证据只结束相应范围，不能提前报整体通过。

`omitted_parts` 与 `non_equivalence`：本次未计划完整撤支架、无相邻线索变式、结构近例独立解释或延迟保持。这里只借支架，不能称为完整 S07/X02 训练，也不能据支架下正确声称理由链独立形成、迁移或持久可用。课程本次只要求局部理由与父链连接，原卡的新例/撤提示/延迟设想不会自动成为新增必修债务。

`adjustable_parts/local_adaptations`：可调整句干、节点呈现、符号与措辞，保留同一理由连接和父链返回；新增规则、改变推理结构或显示关键答案须重核。当前实际借用只有上述支架，未把完整卡要求全部搬成任务。

## 三、查阅版本规格后更新旧实现的分支：不需要固定先闭卷

在题设只要求允许查阅条件下更新一个旧实现分支的范围内，可以直接查阅可核验的目标版本规格并修订该分支。闭卷检索没有新增必需工作，不作为必经前项。必要前提暂时访问失败时也可使用允许的可靠规格输入继续；不能因此认定能力缺口或自动增加闭卷债务。

候选方法为 `post/conditional-update` 的局部借用：“定位哪一条版本/条件依据改变哪一个分支，并保留仍正确的旧版本情境”。`post/retrieve-generate-order` 只为本次顺序理由提供条件化依据，不另追加一次检索任务。两键均为套件新增说明，资源版本 `pl-strategies/0.1.0`，没有原始 Post 卡 ID；D06 的 P 编号是验收定位，R06 的 E25/E38/E49 以及顺序条目的 E29—E34 是文献定位，不能作操作卡号或方法效用分数。完整来源与 evidence_limits 在 `load-conditional-update.json`、`load-retrieve-generate-order.json` 中保留。

这仍为待核候选：请求没有具体旧实现、目标版本、分支位置、新旧合法域、更新原因和可靠可兑现反馈。`old_new_bases_reliable/valid_old_scope_preserved/update_reason_identified` 与实际用途核验为 unknown；“允许查阅”不证明查到的是正确适用版本，未知版本不能自动取最新。若参考有未解除实质争议，先由 AG2 处理内容纠错；不能先断定旧答案错。

保留的关键工作为按规格判断本分支的条件与结果，说明更新依据以及旧规则仍有效的范围。规格可给必要前提，不能在声称独立分支判断时直接代做该关键选择；实际暴露和帮助仍未知。当前未提出持久保持目标，故不额外要求延迟、新例或神经机制状态。新旧内容可共存，即时修订不证明“旧痕迹已擦除”或再巩固完成。

SK03 定位原实现与同一父产物并准备本次分支任务；AG2 核新旧规格与适用域，AG1/SK06 确认借用配置，AG3 只依据后续实际原答、帮助与条件解释证据。已核部分足以完成当前分支就回完整实现并结束该范围；材料争议、预算结束、无新增信息或暂停时保留断点。若以后正式目标另要求无提示恢复或旧错复发已有依据，再由相应责任提出会改变决定的检查；那是条件化新需求，不是本次默认前置。
