# 全策略编译与认知主线修复

日期2026-10-06。本次执行用户要求：全部策略资源可直接读取，修复实际选法、单元规划、认知工作及连续教学。教学指导以知识关系的建立和使用为目的；增加材料篇幅、题数、文件数或忙碌程度不作为效果证明。

## 现在可用的资源

60张Encoding卡全部编译，另有4个完整Post包，共64个可读取资源键、68个确定性生成文件。入口为 [策略索引](../../personal-learning-suite/resources/strategies/strategy-index.json)，完整范围见 [资源清单](../../personal-learning-suite/resources/strategies/manifest.json)。SK06、跨模型文件入口和现有StrategyCatalog／load接口都能取得完整包，注册卡不再因未编译只返回回源位置。

每张Encoding包保留原Markdown和JSON两载体全文、文首／文尾共用约束、目的／操作／风险／深化／验收字段、原证据编号及对应研究正文。其余57张采用原文标签的确定性提取；原3张已有细化条件保留，API与协议兼容。Post保留完整设计／研究段落，未伪造原始Post卡号。原始60卡、研究、设计和来源登记未改，R09空证据及全部H性质保留。

两载体中存在引用范围／缩写与逐项列举差异。构建器只展开同家族编号缩写并去除链接目标作比较；实质正文变化仍报错，原文两份均保存。全库比较、必需字段缺失与正文约束被改写的负例已有检查。编译和可读取只说明完整资源可获得，当前任务适配与认知工作仍由教学方核对。

## 修复后的备课与执行

集中规则在 [design-whole](../../personal-learning-suite/src/skills/learning-teaching/references/design-whole.md)。SK00、SK03、SK05、目标、材料、评估、SK06及四个Agent围绕它接入：

1. **先定近期理解目标和整体工作。**单元围绕一组需要建立／使用的关系、条件与产物组织，跨轮保持。一次回复、一道题、局部正确或预算中断不自动成为新单元。预算未知可分段，课程保留粗地图，单元主线须已经准备。
2. **认知工作决定材料和任务。**明确对象、关系、条件、不变量、理由、选用、推演或整合中实际需要的部分，说明AI提供什么、学习者承担什么、参考怎么核对。目标需要的关系解释和整体使用不能全部留为未知，改数字／轴号的近例也不能自动替代它们。
3. **新单元实际接入策略。**读取SK06选法、索引及实际采用的完整Encoding包；同时判断该单元所需Post功能并读所选完整包。教师安排引用实际正文、版本／指纹、借用操作和实例化用途。稳定合格安排直接复用，纯解释不遍历库或硬加测验。直接教学也要落实认知目的、内容依据及选择理由。
4. **普通反馈后接已备下一工作。**已授权单元内，在同一回复给具体反馈，再呈现下一份材料／解释／整体任务。真正需要原答、作品、选择或可行入口信息时等待，有效停止条件成立时收束。没有逐题“继续吗”开关，也不等用户说继续才准备后续。
5. **局部补充回同一作品。**错误定位与正确局部保留；教师纠正版不归用户自主完成。用户要求推进可继续可靠教学，尚未完成的目标连接在后续原作品中自然承担，不派一串补偿微测或独立复习债务。
6. **减少无变化的文书处理。**原答和关键帮助可靠保留；稳定目标、参考和策略复用，单元断点或重要变化时再整理必要索引，不把每道题后的文书收束当成教学终点。

四个Agent仍是可由单模型顺序兼任的责任定义，没有自动启动独立Agent或加入审批。没有新建认知评分、个人数据库、必填JSON表单或改变真实运行服务API。新单元选法不等于固定卡数、固定阶段或每次使用全部库。

## 课程接入

具身目录的 [AGENTS](../../learning/embodied-intelligence/AGENTS.md)、[MODEL_ENTRY](../../learning/embodied-intelligence/MODEL_ENTRY.md)、[FRAMEWORK](../../learning/embodied-intelligence/FRAMEWORK.md)、[启动提示词](../../learning/embodied-intelligence/START_PROMPT.md)和[交互规则](../../learning/embodied-intelligence/INTERACTION.md)已同步：实际读取完整策略、以认知目标划单元、局部反馈后继续已备主线，旧局部安排缺主线时补齐所缺连接。

框架manifest覆盖公共指导、完整策略资源和五份接入指导，指纹用于换模型或维护后读取发生变化的规则。文件更新不会自动注入旧聊天上下文；原学习聊天接任时应按新版入口重读变化部分并复用真实断点。没有向其他聊天发送消息，也没有把虚构内容写成个人学习事实。

教学题面、原答、代码作品、状态、计划、成绩及学习进度保持；课程内修改的是接入指导和公共引用。原件范围核对结果见验证目录中的course-unchanged.json。

## 有实际内容的虚构走查

[完整教师安排](../../personal-learning-suite/validation/strategy-cognitive-fix-2026-10-06/example/teacher-plan.md)使用有明确数学规格的观测数组接口。单元工作是解释并组织raw→v→g→f，以及消费者条件变化后的保留／拒用。它没有真实传感器、用户表现或学习效果数据。

[首轮材料](../../personal-learning-suite/validation/strategy-cognitive-fix-2026-10-06/example/learner-input.md)连贯展示角色表、同尺寸错置对照、范围与增益处理、通道合成公式和完整代码，再让学习者追踪整个连接及条件保持下的变化。后台提前备好两种消费者变化任务与 [完整参考](../../personal-learning-suite/validation/strategy-cognitive-fix-2026-10-06/example/teacher-reference.md)，没有每个新概念一个停点。

实际借用S05／D02／X05／S09与两个Post包，完整JSON读取、资源键及指纹见 [材料与读取结果](../../personal-learning-suite/validation/strategy-cognitive-fix-2026-10-06/material-checks.json)。正确答复后的反馈直接接已有条件任务，混淆、前置不足、恢复、只解释、未知预算、暂停和已有充分作品等处理见 [课堂文本](../../personal-learning-suite/validation/strategy-cognitive-fix-2026-10-06/example/classroom-playback.md)。这些输出由当前模型顺序构造并自查，未称独立前向测试。

## 边界

本轮完成全库资源承载、文件调用与规划规则、课程接入和有限内容／程序检查。教学规则明确承担认知工作，仍需执行模型在具体内容中落实；编译器、文件指纹及程序声明检查不读取学习者内部表征，也不强制所有模型正确教学。当前虚构文本不是独立模型实验，更不是现实学习效率、保持或迁移收益的证明。真实效果需要在后续授权学习中观察，不能再次用静态通过代替课堂质量。
