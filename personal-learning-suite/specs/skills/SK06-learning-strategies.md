# SK06 learning-strategies：B0 短任务单

状态：B3c 有限开发切片已实现，未安装或执行真实学习；下文 B0 草案与预期保留为设计历史。规格修订：0.2.0；共享协议：`pl-contracts/0.1.0`。

接口按[共享契约](../../contracts/shared-contracts.md)，出处与冲突按[来源登记](../../resources/source-registry.json)。方法索引、卡包与研究条目是资源，不是新增 Skill 或 Agent。

## 负责的决定与模式

AG1 主责同一教学工作的可复用选法、组合、适配、替换及维护；AG0 按需复用已核对且当前适用配置或许可内适配；AG2／AG3 按需检查内容前提／证据用途。路线不固定模式词；只有真实选法差异、重复适配或复用维护价值才触发。

不重新诊断学习者、不替 SK03 设计当前学科内容正确性、不安排日期或创建独立复习／能力状态。SK03 决定当前学习者做什么，SK05 决定投入。调用无需“策略 Agent”；自报配置模式不取得维护通用 Skill 或专业裁决授权。

## 编写依据与接口

必读路线第五至七节、交付与维护边界；D00 规范优先／语义／控制；D01 资源与宿主边界；D07 全文；D05／D06 专项；D04 活动契约；D08 成本／需求；D09 采用；D10 异常；D11 V4 及相关 B10。按所用方法读 R01—R06 结构、完整正文和证据限制。

输入：当前要完成的工作、目标／证据／材料引用、真实帮助和允许资源、内容前提、预算与中断需求、已有活动／`MethodConfig`、实际使用反馈及当前控制／授权。

输出：带条件 `MethodConfig`、替代／不等效差异、复用／调整／合并／暂停用途／退出个人配置／保持未知意见。包含工作类型、来源原 ID 与版本、前置／排除、必须保留操作／反馈、可调整部分、组合干扰、成本／中断、停止／返回和证据／复用限制；只借用部分就记实际借用部分，不把卡片训练设想变课程额外目标。

AG1 采用可复用配置决定；SK03 确认当前内容实例、题面、参考和真实帮助，AG2 核内容，AG3 限证据。影响承诺的成本／替代附同一 `LearningNeed` 交 SK05，不新建一份债务。工作结果留未处理、限制和下一责任，配置生成／调用成功不等采用或学习已发生。

## 路径、约束和停止

常规路径：先看当前工作和已有活动是否需要重选 → 索引定位相关候选 → 读选中全文及共用约束 → 检查准入／真实差异／相互泄露／反馈 → 条件化配置与替代 → SK03 在课程内容中实例化并必要核验 → 实际版本／帮助／结果反馈 → 有价值时维护。

短路径：已有可靠活动直接教学，不遍历库；稳定适用配置直接复用；无合格卡可采用可靠直接教学或简单替代，SK06 退出配置不等 SK03 必须停教。到当前用途够用即停止选法，不固定候选数量或两三张卡。

资源约束：R02／R03 是同一 Encoding 库的两载体，不算独立证据；R03 卡字段不足以自动调度，关键条件在正文；R02 文首／文尾约束必须随卡保留。模板 H 为设计综合，R09 空证据字段不补论文也不自动禁用，但仍须内容／用途核验。R04 矩阵是非互斥导航，不评分、不固定检索在先；R06 E01—E49 是文献号，D06 P1—P5 是覆盖号，不伪装 Post 卡号。Post 新资源键注明套件新增并指原章节。索引覆盖不等全卡编译／适配／验证。

当前日常读取沿完整运行契约及条件性研究展开；原完整包与两载体保留。相同义务可共享一份规范正文，实质冲突不合并；Post混合段和研究范围/强度/反例仍必读。规则和产物同步迁移，具体读取方法见SK06的selection-adaptation，不把资源索引或自由摘要当完成读取。

异常／停止：实质来源冲突、配置失配或版本变化先限相应用途，历史事件保留当时版本；失败／超预算返回可行替代、差异和未覆盖，不删必要反馈声称等效。高能力／核验不可用保持重要未决，可靠授权工作可继续。停用通知 SK03 和必要 SK05；用户暂停即时生效。删除覆盖个人使用分析、候选／临时资源及验证摘录，终止受影响上下文，策略摘要不恢复已删原答；迟到旧配置经控制／兼容采用检查。接管不扩预算／授权，不重置暴露。

必须保留：研究建议受 D00／专项后续规范约束，不编译统一延迟、固定诊断或生物机制数值。新增实现选择：本套件结构化资源键／标签必须标新增，未知字段不得生成成已核验值；通用资源与个人记录分离。通用 Skill／角色／资源改动先形成开发维护提案、核对测试发布，学习过程不自动改已安装包。

## 加载、工具与修改范围

拟运行顺序为索引导航 → 选中完整正文＋共用约束 → 必要证据回查，只加载当前工作需要的资源；索引命中只有卡名不能执行。用户询依据、重要新主张／冲突／维护才回相关研究条目，新的外部事实另核验；不继承旧阅读声明为“已核验”。B0 只登记原资源，尚未形成运行卡包／方法导航。

需要可定位正文与版本、内容／用途核验、实际反馈引用、授权和共享提交。依赖缺失返回缺能力与可靠可用范围，不读未知旧包、不猜造约束；宿主不能隔离写入／输出则单入口顺序执行，不伪装独立审查。

本轮允许修改：本任务单；共用契约和来源登记由维护者集中改。B3c 才建立轻索引、少量完整核对卡包、Post 方法导航及最小选法适配；全库自动排名、复杂成本算法和自动研究更新延后。B0 不编译 60 卡、不生成安装 Skill。
