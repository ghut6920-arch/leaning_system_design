# B2b 有限验收

依据 N00 第十二节 B2b、D03、D04 第二／四节及 D10 领域差异。本批沿用 B0 共用对象及 B1 保存，不依赖尚未实现的 B2a 自动目标设计；测试中的目标、预算和授权是明确的人工虚构输入。

| 场景 | 可观察条件 | 验证层次 |
|---|---|---|
| 受控文本原件 | 只返回所选合法行段；缺失、越界、定位不符拒绝；公式和图未自动读清 | 实际软件行为 |
| 扫描模态缺口 | 依赖公式的用途受限；只依赖已读文字的用途保留；未读部分显式 | 字段和用途行为；无实际 OCR |
| 已足够材料 | 复用既有精确版本，无新增活动、题库、成绩或复习需求 | 实际软件行为＋Skill 前向试用 |
| 示范转独立检查 | 用途绑定变化不直接复用；当前可见标题／位置提供目标操作则受限 | 标注的操作泄露检查＋人工流程 |
| 完整参考 | 数学完整性／对象域／边界、AI 规格／环境／异常、金融单位／时点／假设、政治因果／竞争解释均显式 | 声明完整性；专业依据另核 |
| 多解／漏零解 | 参考从题干重解，原答保存；两链回查，四恢复分别保留未完成 | Skill 候选前向试用＋依赖行为 |
| 正常材料提交 | AG2 既有授权、采用、活动用途与版本相容，写入同一数据库，重开读回 | 实际软件行为 |
| 冲突／重复 | 旧状态不覆写，同逻辑操作不多建材料；权限与候选采用边界真实拒绝 | 实际软件行为 |
| 暂停／限制／删除 | 控制优先；迟到材料不复活；纠正不解除历史评分限制 | 实际软件行为的受控范围 |

实现只允许保存经本切片声明检查为 compatible 的正常用途材料；待核／有误用途由候选返回说明。相同原答不能因材料包拆分多计样本。材料准备永远不记录实际展示；被要求查看参考后实际发生的教学转换留 B3 的事件与证据解释。

执行入口为 [check_b2b.py](../scripts/check_b2b.py)，输出 [行为报告](../validation/b2b-runtime-report.json) 和 [原始输出](../validation/b2b-runtime-output.txt)。独立前向结果另记 [复核记录](../validation/b2b-review.md)。B1 回归及 B0 静态复验用于检查既有兼容性；不能借局部通过修改历史完整情境 `not_executed`。

失败修复后重跑受影响用例；通过后只因新增改变或未解疑问扩大测试。真实课程、实质 B10 异常、宿主身份／旧展示拦截与学习效果留后续批次，不将代码字段检查当作真实课程核验。
