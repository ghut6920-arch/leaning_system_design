# SK02 learning-materials：B2b 开发规格

状态：B2b 已建立开发态 SK02、AG2 运行角色和有限材料辅助接口；规格修订 0.2.0；共享协议 `pl-contracts/0.1.0`；日期 2026-10-03。尚未安装或绑定真实宿主。B0 历史 0.1.0 仅交任务单与待测预期，没有运行包，该界定保留。

接口按[共享契约](../../contracts/shared-contracts.md)，出处与冲突按[来源索引](../../resources/source-registry.json)。

## 负责的决定与模式

AG2 主责资料读取、片段与用途、必要生成材料和关键参考核验；模式按路线为读取／准备／核验／纠错。AG0 仅按需使用已核验材料的同用途等价安排；目标工作、帮助、对象域或核心条件变化须重核。

不自建教学计划、不判断用户已理解／通过；内容核验通过不等于当前任务未泄题。权限由角色绑定、`AuthorizationGrant`、工作单范围和 `ControlState` 决定，模式或高级模型不保证可靠。

## 编写依据与接口

必读路线材料角色、矩阵、加载、P-Material／P-Change；D00 语义与双链纠错／控制；D01 第六、九至十一节；D03 第三至十节；D04 第二、四节；D09 采用；D10 学科差异；D11 V1、B10-04／05／12。只核所用方法的材料／反馈要求，转译不得丢适用、排除、反馈、证据和停止约束。

输入：原资料／版本／定位、近期 `GoalSpec`、活动意图／`ActivitySpec`、允许输入与不可代做操作、已有来源／材料核验、预算／授权／限制。

输出：`SourceFragment`、`MaterialUse`、用途核验依据与限制、多解／反例及必要替代；疑误输出 `ChangeNotice` 与已知直接 `DependencyEdge`。`MaterialUse` 分当前可见输入、备用帮助和教师参考；片段分文字、公式、图表等实际读清范围与缺口。材料准备、采用和实际展示分开，真实帮助由 AG0 的 `PerformanceEvent` 记录。

AG2 采用内容核验；AG1 确认要求／关键设计影响，AG3 确认证据用途；只有承诺、依据或可执行范围改变才进入计划整合。P-Material 接收方返回匹配工作、潜在代做与实际使用部分。`WorkOrder`／`WorkResult` 留接责、未处理范围、依据、下一责任和触发，收到不等安排。

## 路径、约束和停止

常规路径：盘点资料身份与近期用途 → 读清必要上下文 → 先核已有材料足够否 → 按缺口摘录／重组／补充／生成／暂不增加 → 按学科与用途核验 → 返回可使用范围与改选信号。取得当前用途必要依据即停扩展，复杂目标仍有完整参考评审路径。

短路径：可靠旧依据与版本／条件／用途兼容，直接引用；已有输入够而缺表现，正式结果可为“暂不新增”。生成可视化、题库或外部书单不作为默认准备。

异常：读不清指明模态；参考／来源争议先限制评分与教学相关用途，按内容链和要求链回查；四项恢复分开。失败／超预算选择可靠原文、简单静态替代或暂缓，不跳必要核验；高能力不可用继续已有可靠授权部分，保留待查。暂停／删除先控制，清理个人摘录、候选、临时件和验证副本，终止受影响上下文；迟到材料不恢复已删信息。接管继承合法读范围与预算，不额外面向用户展示。

必须保留：研究支持不是答案依据；推导、测试、来源或专业核验取决于对象／后果，模型一致不替代。新增实现选择：片段／用途分成逻辑对象，共用同一状态；材料 CLI 仅为同一组件的局部入口，不另建状态控制命令体系或数据库。

## 开发态加载、工具与修改范围

入口为 [SKILL.md](../../src/skills/learning-materials/SKILL.md)，角色为 [AG2](../../src/agents/AG2-materials.md)。按模式加载 [materials-workflow.md](../../src/skills/learning-materials/references/materials-workflow.md)，按领域／对象加载 [domain-checks.md](../../src/skills/learning-materials/references/domain-checks.md)，调用辅助器时加载 [runtime.md](../../src/skills/learning-materials/references/runtime.md)。当前来源、目标用途、活动与版本由合法工作单提供；争议回原件、推导／测试和依赖链。研究主张争议才回相应研究条目，不读无关全库。

辅助器 [learning_materials.py](../../src/runtime/learning_materials.py) 的 `MaterialsService` 提供 `read_fragment/inspect_material/submit_material/trace_change`，CLI 提供 `read/inspect/submit/change`。它沿用 B1 同一 SQLite、控制、CAS、幂等、授权与采用；材料局部语义按 [materials-b2b.md](../../contracts/materials-b2b.md)。没有独立材料数据库，也没有复制维护共享字段定义。项目相对引用不是自包含安装包。

需要真实文件／公式图表读取、代码或推导核验、适当专业审查、共享受控提交；缺哪能力就限制对应用途。无法身份／写入／输出隔离则单入口顺序返回，不宣称提示词实现隔离。

本批允许修改：本规格、SK02 开发源与 references、AG2 角色及单独分配的材料辅助器／验收文件；共用字段和来源登记由维护者集中修订。B2b 是当前用途的有限切片，与 B2a 共用目标接口，不要求全课程准备完成。

## 虚构验收与交付

| 虚构输入 | 可观察通过条件 |
|---|---|
| 扫描材料文字读清，公式图未读清 | 分模态报告缺口，限制依赖公式的用途，保留可靠文字范围 |
| 合格示范材料改作自主选法检查 | 重新核可见范围与潜在泄露，不能仅沿用内容正确结论 |
| 参考消去变量漏零解，原答含合法零解 | 先限两链依赖，提供更正／多解；支持充分原答直接重评，四恢复分别可见（B10-04） |
| 当前活动已具可靠材料且预算有限 | 返回复用／暂不新增，不强制制作图或题库 |
| 完整证明／构造目标，只有数值算例 | 保留完整参考缺项与高级目标，不能将算例结果改称一般证明已核验 |
| 公式核验通过，但图映射或标题给出方法 | 图须另核；独立选择用途重新检查关键操作是否被代做 |
| 删除、暂停、旧版本或无授权的材料提交 | 先当前控制再引用／授权／采用，拒绝不相容提交，不恢复删去内容 |

当前交付为开发入口、按需资源、角色、有限辅助器与虚构验收；实际执行结果及未核边界由本批验证记录报告。读取／字段／提交检查不等于学科核验，多模态和真实身份／输出隔离仍未绑定；不借指纹或链接可打开宣称内容正确。V1—V4、真实课程试用和学习收益待后续实际记录。
