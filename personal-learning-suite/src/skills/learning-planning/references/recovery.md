# 滚动调整、积压与恢复

人工文件模式用课程的真实安排和停止记录，见 [SK05](../SKILL.md)；共享对象名称可以是同义短视图。下文 shrink、allowed_adjustments、累计时长下界等程序校验含义在实际调用 [运行接口](runtime.md)时适用，不要求文件恢复先构造机器载荷。用户缩时立即停止新增工作，原授权内可收束；重要取舍仍由相应责任决定。

恢复先读当前有效承诺、控制、目标、可靠活动及 SessionCheckpoint 的最后可信事件、父产物、帮助与下一连接。已有可靠材料和判断直接沿用；缺摘要时可从原活动／事件继续，不冷启动全课程。未保存动作和接触保持未知，只询问会改变当前决定的缺项。

生成时的prepared／拟展示快照不单独裁定当前是否已展示。用合法聊天记录、后来原答／事件或已确认交接核对最后事实；没有这些依据时保持未知，不猜补，也不因一个旧快照重复已经确认的讲解。控制中的权限／暂停限制仍生效，活动位置依据当前断点及后续事实定位。

目标内未完成连接沿同一父作品承接：指出学习者已有支持、AI代做部分和下一份已备自然工作；必要时明确暂缓条件及未覆盖影响。没有作品证据不能用“解释完了”关闭整体要求，也不把每项未知生成一条复习债务。目标只需讲解或用户已改变范围时按真实用途收束。

AG1 重要重排显式替换旧承诺，并同时处置其全部需求；同一共享预算只有一个有效安排。其他可靠目标不因局部纠错全部重做。AG0 shrink 必须在 allowed_adjustments 与有效授权中，保留原活动、目标判据、材料用途与关键设计，只减少操作／覆盖／成本。没有可反馈子范围就暂缓／停止，保留未覆盖后果与触发。

已花费声明不能回退，保存的 C0 累计时长形成下界；多个活动可能报告同一累计量，不直接相加。这里只检查显式声明，未绑定统一计时器或跨活动完整成本账本。恢复发现新执行消耗未反映在当前承诺时回交预算取舍，不再次发完整旧额度。

缩时与积压的实际取舍见 [多尺度计划实例](multi-scale-plan.md)。先扣已花费及必要收束，再选可反馈子范围；连一个可核连接也放不下就停止，保存父产物断点和已给帮助。局部完成不能关闭父作品需求，恢复接尚未完成的连接，不能只因换聊天重新讲已完成构造。只有上层方向／用途或阶段可行性受影响才改对应尺度。

积压从使用变化、错误依据撤回、证据已充分或资源减少重新处置；不全部滚到明天。仅缺未来必要条件时留触发，下次进入检查，不承诺后台提醒或已发生保持。删除／限制使相关承诺不可用时只据剩余合法记录重新确认范围，迟到稿和旧请求不复活证据；专业恢复、教学恢复与计划恢复分别成立。
