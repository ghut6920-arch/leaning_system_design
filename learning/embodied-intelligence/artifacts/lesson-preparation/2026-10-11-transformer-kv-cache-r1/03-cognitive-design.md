# 认知主线与师生分工 / revision 1

本稿在 AG2 首轮学科交接之后形成。01-disciplinary-analysis 的专业依据先回答“缓存究竟复用什么、成立靠什么、长上下文瓶颈在哪里”，本稿将其转为可跟踪的输入、剩余判断与连续作品。目标均为本次备课建议，尚未写入个人 goals。

## 单元终点

拟形成一份《长上下文推理审计与方案说明》，把一个因果 decoder 的运算、缓存状态、有效前缀、资源预算和质量证据接成同一论证。允许查看本单元公式、图、来源及教师给定的参数；可用计算器。重点为在已提供知识下解释、判断条件和选择方案，不要求闭卷背诵或独立编写完整 Transformer。

| 要建立／使用的关系 | 学习者最终工作与关键判据 | 实际材料与工作位置 |
|---|---|---|
| Query 与每个 Key 匹配，再按 softmax 权重混合 Value | 追踪一行 attention；说明重算什么、复用什么；不将 K/V 或权重当原始文本 | 04 §1–2，05 A |
| 因果依赖 → 旧逐层状态不变 → 缓存等价 | 在固定条件下串起层间理由；前缀改变时指出失效后缀；不只说“token 没变” | 04 §3–4，05 A／C |
| prefill 最后 logits → 首生成 token → 下一次 decode 输入 | 跟踪 token 与缓存长度，避免把输出 token 预先写进 cache | 04 §4，05 A |
| 历史长度 → score/读取增长；头数／字节 → 容量 | 分开 prefill、单步和生成累计成本；有单位的容量式与余量；不推断实测速度 | 04 §5–6，05 B |
| 优化改变的对象 → 语义、资源与质量条件 | 在约束下选、拒选或保留未定；不能由分页／FlashAttention 推出删历史仍精确 | 04 §7，05 B／C |
| 支持上下文长度、可运行、可靠利用信息 | 给出能区分质量与系统限制的观察；不把容量或单次检索当普遍能力 | 04 §8，05 B／C |

必要前置由材料直接提供：点积、softmax、矩阵行列含义、因果 mask、字节／GiB、token 与 logits 的对应。线性代数完整课程、GPU 环境及训练细节不设为入口门槛。若相关作品已合格，可直接审同一作品并跳过重复示范；先验未知不会自动触发基础测验。

## 连贯主线

| 路径 | 教师提供的实际输入 | 留给学习者的加工 | 接到哪里 |
|---|---|---|---|
| E1：让 attention 运算可见 | 带语义的 Q/K/V 公式与一行完整算例；旧／新分母对照 | 使用表示解释为什么权重不是可直接复用的历史缓存；不要求猜定义 | 缓存状态说明 |
| E2：从一层到多层 | 因果依赖的归纳理由、各层 KV 布局、prefill／decode 时间线与两层代码轨迹 | 根据同一模型检查 token 时序、当前位置、前缀和层间接口；在 A 中组织理由 | 完整推理审计 |
| E3：把缓存接到资源 | 分别推导逻辑容量与 dense attention 成本，给 32k 主例和优化功能对照 | 将 64k／并发约束重新计算并连接选择；指出未知项 | 方案说明 B |
| P1：关系整合 | 公式、轨迹和有效条件允许查阅，不先安排闭卷名词题 | 用一份作品把缓存等价、时序、资源与质量接通 | A＋B 同一作品 |
| P2：条件选用 | 方案的专业对象与边界已教；B 题面只给需求与日志，不给默认方案 | 决定哪些方案合适、哪些改变语义、何处信息不足，说明依据 | B 的决策与观察 |
| P3：条件更新 | C 在原作品之后给新的前缀／位置／语义条件 | 保留仍有效结论、修订失效部分并定位重算范围；不制造“你原来错了” | 原作品版本修订 |

Encoding 与 Post 共用作品，路径不是固定阶段门。A 可与连贯输入合并，B 的整体工作已涵盖相关补全时不再另出算术微题。C 的条件更新是情境变化，不预设学习者有误概念。纯讲解请求可结束；本次是备课审查，以上全为预备。

## 实际策略采用

已取得策略索引、common-constraints 和下列完整资源：Encoding 的两载体正文、研究片段与约束；Post 的顶层条件、完整 source_excerpts 和 evidence_refs。重复相同 body_sha256 的源段落按同次已读复用。资源版本均 pl-strategies/0.1.0；Encoding 源版本2.0；Post 源各按包内定位，未声明版本不补造。精确文件哈希见 method-source-fingerprints.json。

| 资源键／正文 | 本题实际借用 | 未借用与不等效处 |
|---|---|---|
| encoding/S05，R02 S05／R03 operations/14 | 04 完整数值路线与状态轨迹，步步对应输入、操作、结果；A 组织追踪 | 不用“看懂”证明独立实现；不强制紧跟换数字题、闭卷或延迟验收 |
| encoding/R04，R02 R04／R03 operations/23 | 区分缓存等价的联合条件，缓存存在并非充分保证长上下文质量；C 的接受／拒用／未定 | 不把容量、mask 或位置中的一个单项宣布为充分条件，不将现实质量二值化 |
| encoding/S09，R02 S09／R03 operations/18 | attention→逐层状态→prefill／decode→预算与质量的接口连接，B 端到端论证 | 不无限展开训练、Tokenizer、GPU 黑箱；局部正确不以加总判整体 |
| post/retrieve-relation，D06 §恢复／关系整合／最小返回等完整片段 | A／B 在允许资料下补桥、协调理论与资源；缺前提就供给 | 恢复不是本单元独立目标，不强加闭卷前测；不能把教师补桥算成原答贡献 |
| post/select-method，D06 §自主选用与迁移等完整片段 | B 根据日志、预算、语义需求比较与选用，允许拒用或信息不足 | 只支持刚学过候选中的条件选择；主题、相邻讲解已有线索，不能声称广泛无提示远迁移 |
| post/conditional-update，D06 §更新六类原因等完整片段 | C 基于确切新条件修订同一作品，保留合法旧域 | 无用户旧答时不称误概念已纠正；即时修订不证明持久更新或旧记忆擦除 |

选择这些资源是因为本主题同时需要可跟踪算法、联合条件、层间组织和条件下的工程选择。只采用 S05 会留下“算对一个 attention 行，却不知道缓存何时可用、方案能否满足需求”的缺口；再加无用途的卡不能填补这个缺口。

## 执行条件、反馈与停止

内容与参考已有原论文／固定版本文档、归纳推导及教师数值检查；针对 A／B／C 的具体答案及合法分支在 06。必须保留学习者的组织、变式判断和方案理由；审查者能看到全部参考，未来若直接看了参考则按实际帮助解释后续工作，不假装未接触。

普通原答先保存读回，反馈定位一个关键关系，随即接已备下一材料或作品段；只在确需用户贡献处等待。卡点信号与可直接用的支持见 08。局部够用回 A/B/C 同一位置，不新建补课队列。预算未给，教学可分段但不许诺分钟数；暂缓保留作品未完成的连接，标准不改。

未来收束须分开：教师解释已交付、作品关键操作由学习者完成到哪里、帮助代做哪里、目标内未完成及恢复位置。仅查容量或跑教师代码不能支持整体完成。无新增工作、用户暂停、实际预算结束或参考争议时可停止；未安排后续就写未安排，不按日期制造保持结论。
