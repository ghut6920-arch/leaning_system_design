## 本次最关键的设计

把轴布局、批帧合并、逐帧表示与信息、来源身份、时间组织和消费者用途分别说明，再接成同一条数据流。先展示完全保序的逐帧编码，再桥接原两段各四帧的作品，最后单独改变行排列条件。相同特征来自不同原帧的例子，用来说明特征数值不能替代来源记录。

原作品输入保持 BTHWC=[2,4,2,2,3]。解释小例另设两段各两帧、每帧1×1；它不改变原作品规格。接口与 toy 编码函数均为本题明示契约，不推断所有模型的格式、可逆性或效果。

修后审查没有发现尚未修复的P1/P2主线阻塞。已修视频/帧称呼重名、特征表/空间坐标符号重名，以及来源回查和编码逆推的条件口径；第一回复也补齐了必要符号释义。小例到原作品增加了时间与空间规模，但保留数据、shape、函数与契约支架，只让学习者先承担连接理由，再补整链。真实负担与教学效果尚未测量。
