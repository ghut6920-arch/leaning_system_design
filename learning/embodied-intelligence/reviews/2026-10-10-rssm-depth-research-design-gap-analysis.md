# 认知备课仍有不足：研究、设计与执行的差距分析

日期：2026-10-10。承接 [本次 RSSM 质量审查](2026-10-10-rssm-preparation-quality-review.md)及其针对追问的内容复核。任务是分析剩余不足和改进方向；本轮只新增分析及核对记录，不修改研究、正式方案、Skill、Agent、原备课或真实学习进度。

## 一、直接结论

当前不足主要发生在“把原用途变成具体认识要求，再把这些要求转成可教材料和可靠任务”的过程中。现有研究和正式方案已经明确提出中间机制、条件、合法对照、整体组织与学习者工作，足以支持对本次 RSSM 的直接补强；不能把这次遗漏主要归为研究从未讲过这些原则。

但研究与设计也不是已经完备。研究主要提供通用学习操作及其证据边界，没有形成覆盖复杂 AI 主题的学科教学知识；正式方案把专业判断分配给了相应职能，却对“怎样判定一段具体解释已经把目标关系讲透”保留了较多教师裁量。通用执行指导虽已升级，部分修复判例自身仍有隐含连接。多个执行者遵循同一尺度时，材料可以更正确、更完整，却仍留下同类内容不足。

因此需要同时做两类改进：补强从专业内容到教学解释的设计与判例；让实际备课和审查使用这些依据检查材料中的具体推理。增加策略数量、Agent 数量或同义规则，不能自动完成这两项工作。

这一归因是由原件支持的解释，不是受控实验测出的因果贡献。最新备课的参数学习到预测、分布到动作选择已实质改善，不能把剩余局部缺口重新扩大为整套系统无效。

## 三、研究的深入程度：足以修当前问题，但不等于成熟导师理论

### 1. 现有研究在关键原则上并不浅

Encoding §7–8 明确区分关系精确性、解释完整性、边界、扰动和跨表征；要求实体/过程、相互作用、状态改变、结果，以及未知和黑箱接口。Post §4–5 区分多种整合结果，说明原理与适用条件、真实方法选择和迁移不能由复述替代。这些内容已经能推出本次应补的观测来源、结构取舍和诊断性任务。

因此，“没有找到更多神经科学或元分析，所以教不出数据如何改变参数”不是当前最有依据的归因。此处需要的是把既有原则用于具体 RSSM 的概率图、训练数据和优化步骤，并取得相应领域依据。

### 2. 研究主要回答了通用操作问题，学科教学知识更薄

知道示例、比较、解释、变式和反馈可能有效，仍需要知道：某学科里哪一条认识最关键；哪些例子真正显露它；哪些推理初学者不能自行补；怎样的替代解释需要条件化处理。现有研究有负反馈等深入实例，系统也有一般证明、构造与实现判例，不能说完全没有此类资源。但复杂 AI 模型中的专业内容到教学表示，目前仍较多依赖每次模型现场判断。

这与 Shulman 区分学科知识和学科教学知识的理论框架相容：后者还涉及使特定内容可理解的表征、例子、解释，以及该主题的典型理解困难。[原论文](https://home.miracosta.edu/rfrench/documents/Shulman_1986.pdf)。它提供一种分析视角，不证明本系统增加某个模块后必然有效，也不要求另建数据库。

应补的定向研究是“如何把复杂模型的专业解释转成可教内容”，包括机制说明、设计取舍、例子辨识性与评审可靠性。新增几十个操作名或更宏观的脑机制综述，对当前隐含连接的修复价值较小。

### 3. 操作顺序与效果仍有真实研究空白

Encoding §11 的示意算法围绕缺口诊断、操作、修订和新例组织，§16 同时承认粗模型与事实预问、统一顺序、案例数量和局部返回时机尚未解决。正式 Encoding/C0 已明确允许先输入、无错误模型的正常建构与复杂跨活动工作；两者不必矛盾，但原研究的微活动算法不能机械升为课程运行顺序。

Post 明确保留检索与生成的顺序冲突、复杂整合及远迁移边界。本次没有证据表明这些未知造成了 RSSM 的具体遗漏。应在研究补充中明确算法示意的适用粒度，继续按具体目标选顺序；不能承诺仅靠研究文本就有跨学科最优自适应。

## 四、正式设计哪里还不够：专业充分性的分辨尺度仍需具体化

正式方案的责任、对象区分和内容实例化已经较完整。它们明确要求参考结构、关键连接和学科核查，却没有一个能自动判断所有学科解释是否充分的程序。这种裁量本身合理，但目前的复杂 AI 判例仍不足以稳定校准它。

本次 G1 要求结构理由及合法替代，M1 给出历史需求、分布需求和替代名单，审查即可认可基本覆盖。若用户希望进一步解释为什么在具体数据与优化条件下选 h/z 组合，还需候选结构的具体性质、取舍和条件。这不是再加“深入分析”四个字，而是把本次承诺的认识讲清：功能对应、条件比较或较深的设计论证，究竟做到哪项。

同样，“解释参数怎样由数据学习”可以被实例化为局部梯度方向，也可以要求从观测形成的推断接到该方向。新材料做了前者，后者的一部分隐含在另一节。形式上都属于机制解释，但两者在教学上承担的工作不同。

设计需要补的是这种“必要内容到何种程度”的判例和取舍方法。可以用原安排中的几句话完成，不要为每条知识另建表单、统一深度等级或固定数量的反例要求。

## 五、当前最具体的执行指导盲点：修复判例自身少了一跳

[通用质量实例 B](../../../personal-learning-suite/src/skills/learning-teaching/references/preparation-quality-examples.md)要修复“数据怎样改变预测”，却从给定 h、q=N(m,v) 开始，随后推局部 prior 参数梯度。它有效演示了参数学习，尚未显露数据怎样形成这个 q。最新 RSSM M4 也先给旧 q，再在局部更新结束后明确给 o=0。

这两处同类隐含桥是可见事实；没有据此证明新备课直接复制了该模板。重要的是：即使执行者按这个好例认真做，也可能再次交出“参数怎样变”清楚而“数据为何推动它变”较隐含的材料。不能把全部责任推给备课执行者没有读 Skill。

通用指导 A 同样有效解释历史输入与分布输出需求，但它不完整承担 RSSM 混合结构的专业优化取舍。基础功能理由与具体架构比较应分别示范，按用途调用。旧数学证明类判例有较强专业细节，也应继续保留，而非以一个新的通用模板覆盖所有内容。

推荐回修这些判例的内容，并在材料/审查规则中引用它们。规则已有的用途与功能原则无需反复复制；修订要产生实际更清楚的说明与能区分薄弱材料的检查。

## 六、为什么核查和多 Agent 仍会通过这种不足

最新交叉审查确实核了内容与教学功能，修过符号、对象混同、B3 范围和数值。它不只是文书核查，也不能归为完全没审。参数梯度、协方差、动作排序等具有明确数学锚点；结构解释和材料是否显露全部必要桥梁，判定尺度则更依赖目标措辞和读者视角。

当审查以“存在结构理由”“有局部更新”“有一般推导”“W 有新条件”为足够依据时，一段必要输入只是可以从别处推得，仍可能被专业读者自行补齐后接受。多个角色共享同一目标和尺度，不会自动发现这一差别。更多赞同或更多子 Agent 不能替代新的辨别依据。

这也是本次评估需要改进之处：最初强调了足够采用，追问后才明确区分参数更新链已经完整、观测来源仍隐含、结构理由达到基本功能但未展开更深取舍。评估者也要按具体联系报告充分性，不能只给“可试教”的总体结论。

该解释有原件支持，但未做受控因果验证。没有证据支持归因为某品牌、推理预算必然不够、AI 故意省略，或规则必然压制教学。

## 七、研究、设计、执行分别怎样改进

### 1. 研究：做有界的学科教学补充

保留原研究的证据分层，新增补充而不是重写成已验证定律。优先处理三个问题：

- **内容分析：**怎样从论文、概率图、公式与程序提取本次用途不可省略的关系；区分结构功能、选择理由、训练机制和效果证据。
- **解释与例子：**怎样发现专业读者会自行补齐、初学者却看不到的一跳；怎样选一个合法变化使目标关系变得可辨认；何时一个公式论证已经足够，不必额外造例。
- **评审校准：**两份都正确且齐全的材料，为什么一份更能承担目标；用何种可复核判例减少主观“深”的分歧。

项目 Post 研究所引的 [Gjerde 等物理实验](https://journals.aps.org/prper/pdf/10.1103/PhysRevPhysEducRes.18.010136)关注解释中的动作、目标、原理和适用条件，为具体解释内容提供局部依据。研究场景和结果不能直接外推为 RSSM 教学算法；本轮不引用其摘要效应量作为升级收益保证。

### 2. 正式方案：补内容实例化与充分性取舍的案例附录

优先落在工作包 2/3、4、Encoding 和 C0 的已有接口：用途需要的认识、必要参考关系、可见材料、学习者剩余操作和反馈保持同一条链。附录至少示范以下区别：

- 功能角色解释与有条件的结构取舍；合法替代名单与实际比较依据。
- 给定 q 的局部参数学习与数据形成 q 后产生学习信号。
- 一般公式成立、具体算例正确和该算例承担所称教学功能。
- 已给候选下的选用与无明显方法线索的判断。
- 已有完整局部与整体连接；同一主题不同合理终点。

不把这些列成所有课都必须做的固定清单。若目标只是固定 q 下求局部导数，就不因为没追溯原观测而判不合格；若目标明确是数据如何驱动学习，就应补这条来源关系。

### 3. Skill/Agent：改具体指导和实际审查方式

AG1 与 AG2 在认知初稿之后，先沿专业依据走一遍目标要求的解释，指出当前输入、变化、中间关系与结论。必要连接可由明确接口提供；允许黑箱的地方按目标保留。然后选 Encoding/Post 资源，确保卡片落实到这条关系，而不是由卡片反推全部目标。

材料成品出来后，以学习者实际可见片段检查：关键量来自哪里；必要条件是否已展示；当前这一步能否由已给内容合法推出；所称对照是否有辨别作用。它是一次有界内容检查，不需要另写一份假学习者聊天，也不能把 AI 模拟答对算学习收益。

AG3 沿原用途与资料核这些连接，再看作者总结。发现目标尺度含糊就交 AG1 具体化，材料少一跳就交 AG2 补桥。可以由同一模型顺序兼任；多 Agent 时分别委派会产生新依据的问题，不增加泛泛的“再全面审查”角色。

### 4. 当前 RSSM 内容：用少量补强兑现这些原则

| 内容 | 当前已有 | 最小补强及收益 |
|---|---|---|
| 数据→学习 | 有 M2 的 q 公式、M4 局部梯度和更新 | 在更新前明确旧 q 的观测来源；固定旧 α=1,d=2，对照 o=0 与 o=2，分别产生局部导数 8 与 0，让数据到信号可直接看见 |
| 结构选择 | 有历史/分布两种需求及替代方案 | 在同一需求下解释具体候选的条件与限制；按所用架构依据说明 h/z 路径取舍及观测入口，不声称 RSSM 唯一或普遍最优 |
| 一般神经预测边界 | 已声明非线性均值不等于分布预测 | 在需要理解此边界时，加一个小反例或相关非线性步骤；不扩成新的必修大章 |
| 方法/证据判断 | 有合法在线/离线选择及过度推断拒用 | 若近期目标要更深诊断，提供条件不全、多个解释相容的预测结果，要求指出哪项检验能区分，降低显眼措辞提供的线索 |
| 观测后的修订 | W 已备两个条件、两次规划 | 展示时先留第一次计划，再给新增观测；保持同一 W，兑现已设计的时间顺序 |

上述观测对照是局部固定 q/h 的两个场景，导数为 0 不意味着完整神经目标所有梯度为 0。当前核心更新到未来的计算链已经正确且连贯，不需要重新制作全部材料。

旧稿用于解释平均 h 漏 KL 的数值反例有价值。最新测试明确要求全新设计、不得读旧记录，因此不能将未复用旧例判成执行违规。以后正式准备允许复用时，保留已核好例，并审查它仍承担原功能，减少反复生成带来的质量波动。

## 八、怎样验证改进真的修到内容

先验证备课质量，再根据需要验证教学和学习效果。第一步可做小规模的有区别材料审查：保持同一用途，提供几份都能算对的候选，审查者须定位不同内容缺口，而不是按文件数、卡号或公式长度选优。

| 候选情境 | 内容检查应给出的区别 |
|---|---|
| 完整 ELBO 与固定参数 loss，却承诺解释数据如何学习 | 定位缺参数变化及预测连接；不能被公式完整掩盖 |
| 有局部梯度与预测改变，但 q 的数据来源隐含 | 在“数据驱动学习”的目标下指出起始桥；在仅求该局部导数的目标下可合格 |
| 有组件职责和替代名单，却承诺深入结构取舍 | 指出具体性质/条件比较未充分承担；若只要基本接口解释则可结束 |
| 成本与方差都正确，候选方差相同 | 可以承担绝对成本；不能冒称已经展示不确定性改变排序；一般公式论证若已承担目标可保留 |
| 深教师参考、但学习者只抄完整结论 | 保留讲解资格，不宣布自主工作已准备；按原目标另留必要连接 |
| 简单解释请求，内容已经充分 | 合格结束，不强加证明、训练、闭卷或保持任务 |

候选判据应先依据专业内容确定；审查尽量先不看作者评分和版本标签，再核分歧。它检验内容评审的辨别力，不是学习实验。只让同一生成者写几个明显错误再自己选正确，仍不足以证明稳定可靠。

内容和执行路径够用后，按工作包 10 观察真实材料使用、帮助与整体作品；如果目标需要保持或更广应用，再取得对应证据。没有实际学习表现时，不用这类未知替代已经能判断的内容不足，也不宣称升级已证明学习收益。

## 九、优先级与归因的限度

**先修通用判例和当前材料的必要桥，再补正式设计附录；定向研究为这两项提供更好的依据与分歧处理，最后用有辨别力的内容检查和真实使用校准。**已有原则、策略库和职责边界大体保留。较大的运行架构、API、schema、Agent 扩容或全库重编译，目前没有对应缺陷依据。

目前最有依据的归因是：通用原则已到位，专业内容的教学实例化和充分性判定还不够稳定；已有执行指导也存在具体隐含桥。研究在学科教学与跨领域调度效果上有待深化，正式设计在该专业判断的案例和尺度上需要补强。不能由此推断所有研究都不深入，或者只修一个局部例子就保证任何模型、任何领域都能充分教学。
