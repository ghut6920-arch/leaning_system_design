# B0 来源与依赖基线

版本：0.1.0。登记日期：2026-10-02。这里保存开发输入的身份、结构核对与依赖状态。

`source-registry.json` 登记 N00 路线文档、D00—D11 正式设计及 R01—R06 研究／方法来源，共 19 份。每项包含相对套件根路径、原文声明版本、用途层级、章节行号或 JSON pointer、非个人文件 SHA256、实际读取核对范围及优先规则。

路径基准是 `personal-learning-suite/`，所以原件路径为 `../原文件名`。原件继续留在项目根，未复制、修订或修复链接。此登记用于当前开发工作区；发布可分发套件前还需映射实际资源位置，不能让其他机器依赖原作者的绝对路径。文件指纹只检测变化，不能证明内容、论文或学习收益可靠。个人记录不在此目录，不应通过指纹留下可重建内容。

## 本地实测事实

- R02／R03 各有 60 张卡，O、S、R、D、I、X 六类各 10 卡；全部 ID、顺序、名称、分类及每卡证据 ID 集合一致。分类用于检索，不代表六阶段或六 Agent。
- R03 每卡恰有 `id`、`name`、`category`、`content_markdown`、`template_status`、`evidence_ids` 六字段。60 条模板状态相同，均标 H 设计综合；正文均有“深化任务（H）”及“约束与验收”。卡片字段未提供已经结构化的前置、预算、停止或评分数据库。
- 唯一空 `evidence_ids` 是 Encoding 卡 R09「重要性标准分解与条件排名」。保留设计综合性质，不补造引用、不因空字段自动禁用；实际采用仍需内容及用途核验。
- R03 的 `/sources` 有 46 键，卡片实际引用其中 38 个不同键，无未知引用键。它们主要提供来源定位，不能替代研究条件与核查边界。
- 去除 Markdown 链接目标后，32 卡正文一致，另 28 卡只出现证据编号压缩写法差异；逐行差异未发现实质操作差异。R02 和 R03 是同一套方法的两个载体，不能算两份独立证据。
- R02 文首共同约定及末尾“添加例子与停止的规则”不在单卡 JSON 内。B3c 的选中卡包必须附带适用共用约束，不能只读标题或只复制单卡字段。
- R04 有 7×7 非互斥匹配矩阵、5 行结果倒推导航、6 种组合及 3 项使用边界，无稳定策略 ID。矩阵符号表达任务匹配，不是效应量、排名或固定先检索流程。
- R05 有 15 个编号章节；R06 的 E01—E49 共 49 个条目，编号连续。这些 E 编号属于文献，不是 Post 操作卡。声明来源中不存在现成 Post JSON 卡库。

上述结构核对及载体比较已经执行。研究效果、课程适用性和论文外部核验均未执行；D 系列在资源登记子任务中完成的是元信息与章节定位盘点，完整语义核对情况需结合其他 B0 交付，不将自动解码全文称为完整审查。各项实际范围在 `read_check_scope` 中逐源记录。

## 优先规则与命名空间

D00 是统一共同规范。N00 的四角色、七 Skill 包装及实施路线在显式修订范围内优先于 D01 的旧包装；对应专业行为按其正式专项及 D00 执行。研究／实践库是候选方法及边界依据，不能将早期固定两三卡、强制先诊断、统一延迟检查或生物机制推测编译为硬流程。D07 中“工作包 7 尚未形成”属于历史阶段说明，不视为依赖缺失。

引用时区分来源号、Encoding 卡号与文献号，例如来源 `R02` 和 Encoding 卡 `R02` 是两个命名空间。JSON 卡片按实际 `id` 查找数组下标，随后定位完整 `content_markdown`；卡 ID 不是 JSON 数组下标。

## 下一批次的依赖状态

`runtime-dependencies.json` 分开以下状态：

| 层级 | B0 状态 | 进入后续工作的条件 |
|---|---|---|
| 设计来源 | `available_design_source` | 可读取、定位和检测变化；不等于运行资源已核验 |
| 索引／选中卡包／Post 方法说明／方法配置 | `pending_b3c` | 按实例必要范围转译、保留完整条件、原文核对、虚构任务检查 |
| 记录组件与 Skill／Agent 运行能力 | `pending_later_phase` | B1—B6 实现并检查可观察行为 |
| 宿主、模型、工具、真实记录目录与技术控制 | `host_unbound` | 明确真实绑定与能力边界；未满足并行展示控制时保留串行范围 |
| 真实课程、用途、预算、可靠参考与个人记录 | `awaiting_real_input` | 来自真实输入与合法记录，字段当前为 null |

登记中列出的旧本地 `outputs` 链接仅保留原定位和候选当前来源映射，状态为待 B3c 处理；原文没有改动，旧路径是否存在未检查，外部文献没有重新核验。HTTPS URL 中名称为 `outputs` 的正常网页路径不属于此问题。

B0 没有生成 60 卡运行索引、卡包、Post 新卡号或安装 Skill，也没有创建真实学习状态。方法配置需要合法运行资源与当前任务条件，未知值保持未知。稳定且可靠的活动可在其授权范围内直接教学，不能为了展示选法能力强迫每题加载全库。
