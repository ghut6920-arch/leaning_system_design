# 动作条件 RSSM：备课审查入口

日期：2026-10-09（Asia/Shanghai）。版本：revision2。状态：review_only / prepared，不是正式学习活动。

本次依据用户指定的主题独立备课：部分可观测环境中的动作条件 RSSM，从序列变分推断到多步预测与闭环规划。用户要求先交完整备课成品供审查，并明确不开展正式教学、不修改真实学习进度。目标和判据均为本次设计建议，没有登记为已采用的个人目标；没有学习者原答、运行或能力判断。

本次实际使用多 agent：认知设计先确定知识关系、关键工作和策略；来源核验并行检查学科事实；材料设计在认知设计交接后开始；审查在材料成品形成后进行。所有 agent 使用同一宿主和模型体系，审查是另一 agent 对原件的核查，没有盲评或模型独立性的承诺。面向用户的入口只有当前聊天。
