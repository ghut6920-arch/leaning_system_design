## 已修复的实际发现

| 发现 | 最终处理及核对 |
|---|---|
| known 条件携带 null 仍被接受 | Fact 与条件值检查拒绝，加入行为回归 |
| verification=list、unresolved_items=int 引发异常 | 结构化拒绝或未决，程序不再崩溃；回归覆盖 |
| 等价映射交换实现与解释能力 | 保留要求只能逐项自身映射，交换映射重核；回归覆盖 |
| 修订报告已重核但候选仍称首版无历史 | 真正修订将比较结果写入候选 version_compatibility；复用及缩时整个原目标保持不变 |
| 未决作用域使用不存在的要求 ID | 返回 invalid 并指明作用域问题，不能保留全部可靠范围掩盖错误 |
| 解释专属未核来源进入总来源聚合后阻断实现 | 按逐要求／判据／前置的实际关联限制，未关联来源才按共用依赖处理 |
| 最终重放误把读清范围和核验范围要求为相同文本，并拒绝已有文字条件 | 二者保持不同语义；接受非空文字或说明列表；新增真实关系回归，原独立输入无需改写 |
| 缩时交接称候选为正式目标 | 明确原目标规范可仍为候选，采用状态继续由授权决定 |

独立代码复核提供了可复现问题；修补后由根代理和独立测试开发代理实际复验，没有声称原复核代理完成了整份最终代码批准。

## 独立前向试用

[原始独立试用](b2a-forward/b2a-forward-review.md)从异或正文、目录和个人配置校验用途形成两个 `user_purpose` 要求，保留四项未决。用户只有 3 分钟且请求先看示范后，目标、判据和 `not_required` 时间要求不变；没有原答、表现、掌握结论或有效计划。

原始语义候选、输入、CLI stdout 和局限说明保留原文。修补后的[最终重放](b2a-forward-final.json)使用完全相同的两份输入，六项观察检查通过：仍为 partial 候选且无错误、保留两项语言无关要求、整个目标未变、不作判断／采用、只交候选计划处理。最终重放由根代理执行，不能当作新的独立语义试用。

stdout 不包含完整来源包，交付须携带合法输入来源或精确共享引用；结构化预算与示范请求仍需原会话变更视图。辅助程序不处理真实示范显示、材料用途核验或计划接责。本批按接口明确保留这些边界，不以“complete”越过它们。
