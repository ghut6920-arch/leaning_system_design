# AI 个人学习系统：工作包 2 与 3 联合设计提示词

我正在建立一个面向个人长期使用的 AI 学习系统。工作包 1“整体学习流程与概念架构 v0”已经完成。本轮请联合设计工作包 2“课程要求—能力目标—验收证据”和工作包 3“学习者状态、诊断与证据更新”，分别对应 v0 中的 B1、B2。

我希望解决的核心问题是：**AI 收到我上传的课程与学习材料后，怎样结合材料内容、我的学习用途和实际表现，判断要学到什么程度、当前从哪里开始、哪些地方需要补充或验证，并据此决定后续学习内容怎样展开；随着学习发生，又怎样持续修正这些判断。**

本轮交付这部分的联合顶层设计，达到可以继续展开材料组织、教学活动和学习计划的深度。请作出明确但可修订的设计选择，解释依据与关键取舍。重点是让目标、证据、判断和后续安排真正衔接起来。

请依据项目文件的实际内容开展设计：

- `AI个人学习系统_整体学习流程与概念架构_v0.md`：当前架构、已确认需求与边界。
- `AI个人学习系统_设计流程与工作包.md`：工作包 2、3 的定义及相邻工作的范围。
- `AI个人学习系统_架构设计提示词_GPT6Astra.md`：原始需求背景，其中要求重新交付 v0 的旧任务不再适用。
- `01_Encoding研究报告.md`、`02_Encoding微操作与提问库.md`、`04_Encoding策略库.json`、`Post-Encoding-Dynamics-深度增量研究.md`、`Retrieval-Integration-快速矩阵.md`、`post-encoding证据台账与参考文献.md`：研究依据、候选方法和证据边界。

文件中提及但未提供的材料不视为已读。已有研究框架和操作库是设计资源，不必逐项变成模块、步骤或量表。若同时提供本轮配套的顶层设计分析，可将它作为可讨论的建议，不必照搬其结构或结论。

系统面向人工智能、数学、金融、政治等科目，以课程资料为起点，结合阅读与合适的学习活动。既有方向是高能力 Agent 负责关键评估、规划与教学设计，中等能力 Agent 承担主要交互、制作与执行；具体责任划分仍由实际决策需要推导。时间不足时，独立掌握优先，可以缩小覆盖范围，用户保有对目标和投入的决定权。

下面的问题表达希望设计能够解决的事情，不是固定目录或运行顺序。你可以重组、合并、补充或质疑其划分：

- **材料怎样成为学习目标与验收依据？**不同资料提供的信息、不足和冲突如何影响目标范围、深度、前置关系与判据？怎样确定有用的目标粒度，既能指导局部学习，又保留综合能力要求？
- **系统怎样逐步了解学习者？**在自述、历史记录和新表现有限的情况下，哪些信息足以支持当前决策，哪些需要进一步了解？怎样开展适量的冷启动与局部诊断，并处理同一表现的不同解释？
- **目标和学习者证据怎样共同决定内容展开？**什么判断会改变近期的范围、起点、顺序、重点、材料需求、帮助程度与后续检查？怎样形成能供教学继续使用的依据，并保留执行中的适应空间？
- **判断怎样随学习和材料变化而更新？**教学中、撤除帮助后、延迟及新情境的表现怎样回流？证据不足、相互冲突、适用条件变化，或材料与评分被纠正时，系统怎样修订结论及后续安排？
- **这部分与其他工作怎样接起来？**工作包 4 的材料组织、5—6 的教学与策略、7—8 的计划与协作，需要从本轮得到什么，又会返回什么？哪些交接必须现在明确，哪些细节适合留待后续？

设计应延续 v0 对证据含义的区分：材料内容、用户自述、实际表现、表现条件、诊断假设与教学安排各有不同作用；有提示完成、即时独立完成、延迟保持和新情境应用支持的结论也不同。少量问答只支持相应任务范围内的判断，不能据此形成稳定的一般认知能力标签。系统应允许未知，保留合理的替代解释，并能够依据新证据撤销原判断。

请保持充分的设计自由度。具体架构、概念划分、表示方式、诊断方法和展开机制由你论证。v0 是当前起点，其中可修订的设计选择也可以被挑战；若需要调整，说明理由和影响。希望得到有实际判断力的方案，而不是照着材料堆叠概念，或把“因材施教”留成无法检查的原则。

本轮以工作包 2、3 为中心，相邻工作只展开到足以使主流程成立的程度。需要的细节可以深入，但不要求代码、技术选型、完整题库或逐轮教学脚本。目标粒度、评估题量、状态维度、阈值、模块和 Agent 数量都没有预设答案；示例参数应说明其假设性质。

最终请交付一份连贯、可审查的中文设计方案。表达结构由你选择，应让读者看清主要流程与信息关系、关键判断如何成立、这些判断怎样影响后续学习，以及尚未解决的问题。重要选择给出理由与代价，区分项目依据、设计推论和待验证假设，并为关键依据提供可定位的出处。

请用少量有区分力的具体情境检验方案，展示同一材料面对不同学习者表现时，安排为何不同，以及新证据或错误怎样改变原判断。当前没有真实课程或学习者记录的部分，可用明确标注的假设情境继续设计；不要据此虚构我的能力，也不要把纸上走查当作学习成效验证。补充信息按其对关键取舍的影响提出，不必先进行全面访谈。

完成时，我应能沿着“这份材料支持什么目标—目前有什么证据—还不知道什么—为什么这样展开后续学习—什么情况会改变安排”检查整个方案，并知道接下来的工作可以据此继续设计。
