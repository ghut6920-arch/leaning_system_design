# 教学与长期计划：研究、设计到可加载规则的内容兑现审查

日期：2026-10-04。只读审查源文件；本报告不修改 Skill、Agent、个人记录或研究结论。审查对象是模型读取当前规则后，能否完成研究与设计中要求的专业教学决定；不是要求 Python 自动讲课，也不以文档篇幅作为失败证据。

## 判断

**SK03 需要重编正向教学准备的核心与路由，保留其证据、帮助、局部返回及停止规则；SK05 适合补充四层计划与真实取舍，不需要整体推翻；AG0/AG1 保留简短职责与权限边界，但需清理历史批次混排并明确未准备单元的入口。**

设计源并没有规定“初学先连续问问题”。C0 设计允许先解释、定义、示范，Encoding 设计明确允许完整讲解作为纯教学输入，再按目标选择必要学习者工作。现行规则也允许这样做，因此“先讲解不合法”不是当前 Skill 的要求。真正不足是：普通入口常假设已有可靠活动，陌生单元的内容分析、材料需求、起点理由与讲解/示范/练习之间如何合成为一份可教方案，主要依赖模型自行补齐。

**Post-Encoding 不宜判为整体内容缺失。** 初看精简引用会低估它：四份 compiled 资源直接内嵌恢复、五类整合、选法、条件更新、反馈、时间及组合设计原文，不只是来源链接。应修复的是从当前任务到必要资源的稳定加载、学科实例化和正常前向验证。资源可用不等于每次普通教学一定加载，也不等于真实学习效果已经验证。

本报告使用五类：**保留完整**（当前可加载规则可指导该决定）、**指导不足**（有义务/原则或深层资源，但普通路径缺少必要的决定桥梁）、**缺失**（在已读活跃路径找不到该内容）、**明确延后**（原实现明确不承诺）、**实际执行违背**（需真实执行证据）。本子审查没有读取 WM 聊天原件，不据此认定某次教学实际违背。

## 纸上前向用例

以下是本次审查的设计检验，不是实际教学或学习者新表现，不写入个人记录。它们将“规则是否能提出合理决定”和“学习是否发生”分开。

### 用例 A：初学概念与代码，不先索要未知定义

条件：学习者第一次接触视频张量，当前目标仅为理解轴的语义并能区分“重新解释形状”与“交换轴”；允许阅读代码及运行小例。当前没有可定位的已有表现。可靠材料应覆盖元素与索引映射、形状规则、操作语义；不能只把某一段现成代码成功执行当内容核验。

合理准备：先明确本次用途“看懂视频数据如何进入模型”；给一个带标签的小张量与 `batch/time/channel/height/width` 对应，示范一个完整的小索引变换。初始讲解解释轴名、每个数字指什么、改变哪一轴会改变什么，必要时给表格/逐元素代码轨迹。随后保留一个尚未代做的语义映射工作让学习者完成；当前目标若只要求读懂示范，可以在有限边界下结束，而不是强加独立代码目标。

若目标确实要求能自行选择操作，再给没有暗示操作名称的新场景，让学习者解释需要保留的元素身份与目标轴顺序，选择并执行。形状一致但语义错位时反馈到索引映射，不能再连问“rank是多少/维度几个”冒充深学习。缺 API 记忆可供文档；输入和索引关系仍不理解才做最小局部建模，然后回原数据处理代码。已有合格代码与解释者可以直接复用，跳过冗余示范。

现行 T 能维护支持与目标边界、父代码与局部返回；不足是普通入口没有稳定生成“用途→结构关系→必要材料→示范/可视化→未代做工作”的准备桥梁。设计源 C0:85–95、Encoding:184–207 和 R/Encoding:121、133、148 提供这些条件，应该编入必要入口而不是指望每次翻整套原文。这是 SK03 核心重编的具体失败预演，并非证明用户已经在此用例失败。

### 用例 B：后续恢复，访问失败与结构误解必须分流

条件：原任务合并 20 人均值 60、30 人均值 80 的成绩，问每人的平均并说明人数作用。允许定义与计算器；先前确实学过相关关系。本次仅看到“我不记得公式”，不能立即判定模型丢失。

分支一：提供原允许的“平均=总分/人数”定义或定位线索后，学习者自行得到两组总分、总人数和 72，并解释贡献。可以完成当前恢复工作，保存实际帮助；不要重启整章 Encoding，不把它记为无提示公式恢复。若既有目标不要求闭卷，不能因此新建闭卷欠账。

分支二：已经提供总分 1200、2400，仍写 `(1200+2400)/2`。这才有可定位的关系障碍候选；排除题意/单位读取或笔误所需的信息若不会改变下一帮助，就直接说明“3600 是全部学生的总分，除以 2 是两组总分的平均”，留给学习者用总人数修订。必要时用极小人数的可枚举例重建“人均”的语义，局部够用立即回原题。不能要求不断自行发现尚未具备的关系。

如果目标还要求自主选择，则后续混合任务必须包含人数相等、政策赋等权、人数未知等真实条件变化；学习者可以选择简单平均/人数加权/信息不足。不是将所有例子都命名“加权平均训练”。如果父题仍失败，重查整体映射与题意，不无限下钻算术。

此例当前 post-encoding.md:7 与 c0.md:35 已足以给出核心分流，B4-forward:18 还提供结构障碍的实际候选输出；选择与五类整合在 compiled Post 资源可取得。因此这部分应保留并补反向成功例，不能整体重做为固定问答流程。

### 用例 C：计划缩时仍能保持理论整体义务

条件：当前承诺 60 分钟，有一个一般证明目标及近期真实代码使用任务，用户只剩 25 分钟。先确认该时段仍包括恢复、反馈与收束；不能将25分钟全部承诺为新学习。

若证明主线的连接已经形成且现在继续收益高，可在保留完整证明目标与断点下缩本次展开，延后可自然使用覆盖的重复检查；若近期代码工作卡在条件选择，则可优先该选择工作，并明确证明主线这次不做的影响。两路线均须解释真实放弃项；不把“高优先级”当理由。若只有已核验算例，完整一般证明仍未就绪，不能通过减少判据承诺证明完成。

当前 SK05 足以避免费用/收束归零与伪排期；课程剩余量、阶段依赖、周内竞争以及真实期限是否仍可达的重新估计需要四层计划规则补齐。源 WP7:35–50、87、99–104 已有依据；修复应补这段内容，不另造普遍复习频率。
