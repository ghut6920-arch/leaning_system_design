# 材料工作流

依据 D03 第三至十节、D04 第二／四节和 D00 第八／九节。对象、Fact 状态、授权与采用字段只按 [共享契约](../../../../contracts/shared-contracts.md)，本文件不另定义 schema。先读当前模式；疑误出现时再读纠错部分。

## 读取：忠实片段与缺口

先区分大纲、要求、正文、作业和解答，盘点可访问范围；目录只提供候选范围。围绕近期用途精读必要前后文，片段边界由完整含义决定。无法理解局部时扩大到其定义／前提／证明，而不把局部完成称为全文核验。

`SourceFragment` 必须能回看来源身份、声明版本、定位和实际读取范围。文字、公式、图表、脚注／附件分别保留读清范围和未读部分。公式中的负号、指数、量词、对象域，表格的表头／单位，跨页证明的假设都可能改变结论。文件可打开、文字成功抽取或目录命中只证明相应访问／抽取动作。

完整含义应保留以下关系，按当前材料选择：

| 对象 | 不可截掉的上下文 |
|---|---|
| 定义／命题／公式 | 对象域、符号、量词、条件与结论 |
| 证明／推导 | 所求结论、前提、合法步骤、调用依据及有意省略处 |
| 例题／参考 | 完整题干、限制、方法选择点、答案和核验依据；展示可分开 |
| 图表／模拟 | 坐标、单位、图例、映射、参数范围、近似与模型假设 |
| 代码／实验 | 规格、输入输出、环境、数据／实验条件和解释范围 |
| 论述／案例 | 主张、证据、推理、情境、竞争解释，事实与价值前提 |

局部不清而不影响当前用途，可返回可靠部分和限制。缺失可能改变命题／答案时，暂停依赖它的事实讲授和评分参考，回原件、同版本可靠文本或补必要页。独立可核验的替代须标明自身来源；不能补写缺页后冒充原文，也不能把补足内容当作已解决原教材写法争议。读取失败不诊断成学习者能力缺口。

## 准备：六种正式结果

从当前目标／活动取得要支持的工作与允许资源，检查已有原文、备用材料和旧核验是否仍兼容。起点、预算或暴露未知时保留未知；只问会改变当前选择的缺项。可靠性和用途必要条件先于形式偏好，再比较必要性、前置负担、相对已有材料的增量和制作／核验／学习总负担。

| 结果 | 采用条件 | 交付中说明 |
|---|---|---|
| 直接用原材料 | 完整、可读，足以支持当前工作 | 位置、关注点、前置、用途和旧核验适用范围 |
| 重组原材料 | 信息齐全但分散或指代不清 | 移到一起的片段、原位置及新增连接判断 |
| 补局部桥接说明 | 缺符号／术语／一步推导／映射连接 | 补哪处、解释与新增命题的区别及依据 |
| 引入外部来源 | 缺关键依据、合格例子或必要视角 | 缺口、来源／版本、与原材料的关系及检索停止点 |
| 生成局部材料 | 特定对照／变式／表征／任务有价值且可核验 | 目标关系、不变条件、变化维度、核验办法及用途 |
| 暂不新增或暂缓相关部分 | 输入够而缺表现，或关键依据／预算不足 | 下一责任与触发、可继续范围和未覆盖影响 |

新生成前先确认可行核验路径，产物未核保持候选。改造例题同时准备题干、可接受解及核验依据，但不用一起展示。外部检索取得用途所需依据便停；不默认重写全章、做题库或加可视化。偏好可决定可逆形式选择，单次“看不懂”或成功不能固化为学习类型。

## 形式与功能：把材料准备成能使用的内容

转译自 D03 第六节，结合 D05 第四／五节和 R01 的任务条件。先说明当前缺的是对象、关系、步骤、条件、转换还是整体组织，再选择承担该功能的实际片段。表中是候选用途，不是每单元都要制作的清单。

| 形式 | 承担的教学功能 | 留给学习者的具体工作 | 适用与核验要点 |
|---|---|---|---|
| 必要定义、短说明、任务框架 | 建立对象含义、用途和关系的初步入口 | 用已给信息定位对象，接上当前任务；无需空白建全章地图 | 缺对象时及时给；核对象域、指代、条件，不把目录当框架讲解 |
| 公式与推导 | 显示数量关系、条件和合法连接 | 解释／完成对应步骤、检查条件或选择公式 | 保留量词与假设；代回检验候选，完整性另须推导 |
| 完整例题、部分范例 | 让陌生的步骤组织可见，再按表现移交工作 | 在完整示范后承担未给的连接、步骤或选择 | 题干、理由、结论连贯；完整参考先核，展示过的方法按帮助解释 |
| 近例、非例、条件对照 | 辨认决定适用性的条件 | 接受、拒用或指出信息不足，并说清改变的条件 | 控制无关差异；非例应真的违反指定条件，不只换数字 |
| 图、关系表、坐标图 | 显示结构、变化或两种表示的对应 | 追踪变量、预测变化、解释映射或自行转换 | 轴、刻度、单位、方向、范围与公式对应；若构图正是目标，成图不能代替其工作 |
| 动画／交互 | 暴露静态形式难以保留的过程或可操纵条件 | 在允许参数内作预测、操作并核对变化 | 确有增量才制作；检查实际成品的参数、约束、边界和行为，核公式不等于核交互 |
| 代码、轨迹、规格与小型数据 | 把算法条件接到实现与可观察行为 | 解释状态、补实现、选择测试或解释结果 | 输入输出、环境、预期及异常行为明确；运行、理论、测试选择和实验解释分别核 |
| 原始论述、证据片段、竞争案例 | 保留主张与论据之间的连接 | 比较证据、推理、替代解释与结论边界 | 保留情境、事实／价值前提；不按是否同意参考立场评分 |
| 完整证明／综合作品及局部支架 | 维持整体约束和接口，修复局部后返回 | 组织完整论证或端到端产物 | 局部支持指回父产物；完整核验不能换成几道小题或孤立运行结果 |

选择后必须交出实际内容或确切可访问位置，并说明“现在看什么→用它做什么→怎样核对→缺哪项时补什么”。只有“需要一张图／应有范例”的声明仍是待准备。新手缺对象时先给足够定义和示范；已有必要前提时允许有界尝试；原作品足够时直接审查。可靠性规则不能被用来无限推迟必要教学输入。

开始课程／单元时，这项交付覆盖 [本次已选主线](../../learning-teaching/references/design-whole.md)的核心输入、示范及主要问题参考，不只覆盖第一道小题。按目标要建立／使用的知识关系选择材料，题面、合法答案及反馈依据一起准备，按节奏分开展示。没有图或代码需要时不额外制作；已经选作主线必需的成品则在呈现前实际核验，不用形式名称或生成计划代替。

信息相同的两种表示仍可能承担不同工作。例如公式便于计算，坐标图使极值与零点的空间对应可观察；转换本身是目标时，图不因信息等价而被删为冗余。按 R02／R03 的 S02、S03、X06 使用时保留语义对应、意义单元和全局连接，按当前缺口选必要操作；不机械分屏、不默认增加表征数量，也不以“图已给出”推为用户建立了映射。卡片的中文模板与顺序属于设计，研究家族支持不证明本次材料有效。

具体起点、呈现边界和实际核验见 [材料实例](materials-examples.md)。

## 核验：内容与用途分别判断

读取 [领域与对象核验](domain-checks.md)。对重要材料表达“查了什么—依据在哪—支持何范围—没查什么—因此可怎样用”，保留核验责任、版本和局限。核验是专业工作，辅助检查器不能替代来源对照、合法推导、测试或适当专业审查。

用途资格至少检查：题意和条件是否充分，参考是否可评分、多解是否完整，材料是否支持目标操作，是否增加无关前置，是否代做须由学习者完成的关键工作，所需允许资源／暴露条件是否成立。AG2 交出可行性与限制；AG1 维护目标及关键活动设计，AG3 判断实际表现的证据用途。

`MaterialUse` 的三部分承担不同呈现功能，无需三套重复内容：

| 部分 | 处理 |
|---|---|
| 当前可见输入 | 本次必要题面、对象／规则说明、框架或示范，以及学习者工作和限制；采用理由若泄露待查方法则延后 |
| 备用帮助 | 符号释义、局部推导、例题或边界说明，仅按需要调用，注明会代做哪些操作 |
| 教师参考 | 位置、完整核验、答案／多解与评分边界，不随当前任务自动展开 |

独立并非闭卷：允许公式／文档／计算器时，可提供它们，关键判断仍须由学习者完成。按目标逐项检查文字、标题、颜色、编号、箭头、默认值和折叠位置是否给出方法、关系、条件或构图答案；不能给媒体固定帮助等级。用户要求完整参考时可转教学，实际展示交 AG0 记录并由 AG3 限定后续结论。未显示记录不能证明用户从未见过。

复用内容核验不等于复用用途资格。字体调整可只检查呈现；含义、对象域、关键假设、答案、图映射、软件／数据版本或目标用途改变时，重核受影响部分。新任务按与已有暴露的实质差异判断，生成日期或换数字不能证明“未练迁移”。接收方返回用途匹配、潜在代做、实际采用范围及缺项；返稿不等于已展示或已安排。

交 SK03 时把这三部分接到当前活动：当前入口已落实的片段／成品、尚未展示的支持及调用信号、教师正确性锚点、学习者剩余操作和必要返回点。AG1／AG0 确认当前用途与预算；兼任可在同一可执行视图中直接完成，不另造材料审批队列。输入不足先落实缺项，输入足够后就交给学习者工作，不继续堆摘要。

## 复杂整体参考

目标需要完整证明、存在性／构造／最小性、代码系统或开放论证时，保留完整题面和可核验参考，不因精简上下文退化为几个算例、术语解释或局部通过率。准备阶段可分段，但要有整体约束、关键接口、多解／反例、可接受替代路线和最终整体评审路径。

证明检查合法推导、存在性及覆盖全部结论；构造还需验证可行性和所称最优／最小下界。实现检查整体规格、模块接口、测试与解释范围，正常输入通过不能覆盖全部条件。开放论证保留证据与竞争解释，正确的“信息不足”也可在参考范围中。需要专业能力而暂不可得时，保留高级目标、返回当前可用子范围与未决参考，不能暗降目标后称已核验。

修复材料须保留父活动、父产物定位、卡点、局部够用条件与返回连接；局部核验合格后回同一整体产物。复杂任务参考按需回 D05／D06 对应完整案例，不能只加载摘要中的结论；这些设计案例不是实际课程教材或未暴露测试题。

## 纠错：两链回查与四面恢复

用户质疑、新合法解、参考与原答冲突或来源疑误都是核验入口。先定位同一主张和条件：区分术语映射、不同定义域／假设、时点／版本差异、同条件事实矛盾和解释／价值分歧。课程参考有错时分开课程评分要求与学科事实，不按日期、权威或模型投票裁定。

1. 立即限制具体受影响内容及用途并保留原答；不等待完整重评或新版计划。实质争议时通知相应职责，已能确认无关范围继续。
2. 回原位置、重推、测试或补来源，建立更正依据和未解决范围。纠正对象保持版本可追溯，不能改写历史原答和帮助条件。
3. 沿实际依赖回查两条链：**来源／规则 → 派生解释、图、题目与参考 → 使用事件／评分 → 能力判断 → 补缺、跳过与计划**；以及 **来源／规则 → 目标／前置／判据 → 任务／材料／评价 → 判断与安排**。AG2 查自己的材料及已知使用处，其他责任方补各自直接依赖。
4. 输出 `ChangeNotice`、已知直接 `DependencyEdge` 和 `unchecked_scope`。依赖来自实际引用，主题相近不等于依赖；未找到也不等于无影响。不能排除的关键依赖受限，明确下一责任与触发。
5. 按四个恢复面返回：AG2 核更正材料用途；AG3 用当时原答／帮助／判据重评历史判断；AG0 修复已发生的教学误导；AG1 重审要求并处理错误补课／跳过／承诺。各自有依据才恢复，材料恢复不自动解除另外三面。

原答充分时支持直接重评，不要求默认重考；原答不足只由 AG3 提出能改变结论的必要补证。更正答案不能凭空补出未展示的推理能力，新加目标要求不能倒判旧原答。已知错误若用于辨错，须重新设计用途、备可靠更正依据和相应授权，不能换成“反例”标签继续使用。

## 控制、停止与交接

按照共享控制先删除／暂停／限制，再身份职责／授权，再来源与目标／活动／预算／帮助版本兼容，再专业采用。无当前授权只交候选。范围内的可靠同用途等价替换可依已有授权直接完成，重要来源争议或实质设计变化交相应角色，不能靠模式名取得决定权。

当前用途已有充分依据且学习者仍有明确工作时交付，不扩全课程。预算耗尽时选合格原文、简单静态替代或暂缓；必要核验不能跳。失败交“缺项—影响用途—可靠部分／替代—责任及触发”，不无限委派或反复索要完整方案。`WorkResult` 保留处理与未处理范围、依据、采用需要与下一责任；无接责由发送方跟进。

暂停不等于专业限制解除；恢复重读当前目标、材料用途、帮助、父产物、停止原因及预算。删除先停用再清个人摘录、候选、临时件和验证副本，结束已含删除内容的受影响任务，以剩余合法上下文继续。通用材料不得藏个人原答或影子暴露结论。迟到结果先查当前控制，不能恢复已删信息；磁盘清理不承诺宿主历史和外部副本已擦除。
