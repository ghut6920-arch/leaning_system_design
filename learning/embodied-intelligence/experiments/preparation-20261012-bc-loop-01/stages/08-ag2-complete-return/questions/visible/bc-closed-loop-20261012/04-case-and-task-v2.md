# 教学案例：拾取、对准槽口并放置

**以下规格、数值和观察全部是明确构造的教学假设，未实际运行，不是论文实验或你的项目记录。**暂不执行实验，可查阅前面三份材料与来源。

## 已有资料

策略输入为当前RGB图像与当前关节位置，不含显式速度/接触输入。输出是标定还原后的绝对关节目标，低层采用位置控制。同一个保存输入上的标签、归一化还原与命令含义检查正确；整段在线执行、观测同步和时序尚未审计。

示范主要是无扰动的成功轨迹。验证集按episode划分，输入仍来自相同初始分布，标签MSE较低；这里没有给出MSE单位与各阶段误差，不能把“低”当任务容差已验证。

使用一个冻结checkpoint，来自一次训练；训练种子未保留。36个仿真初始配置/环境种子，在两条件下逐一配对，物体、槽口、任务标准和低层参数保持。两个条件均完成拾取并进入对准阶段。在对准阶段，两个条件都从配对完整快照按相同流程重置，速度均为0，夹持相对位姿与低层设置相同。标准条件保留原横向位置；扰动条件仅将末端与被夹物体横向偏8 mm，关节按合法逆解同步设置，相对夹持位姿保持，未发生碰撞或落物。这样，两条件没有同时改变速度初始化；干预差异是上述横向状态偏移及维持该状态合法所需的关节对应。

成功标准为：在同一限定episode时域内完成放置，物体中心距目标不超过5 mm且保持两个评价采样，过程中无掉落/禁用碰撞。这个标准只用于本案例。

|---|---:|---|
| 标准条件 | 28/36 | 36个配对配置；均已成功拾取 |
| 横向状态扰动 | 12/36 | 相同配置/环境种子；只按上列规格改变阶段状态 |

没有给出每对成败的对应表、全部轨迹或统计区间。分母36是教学数据规格，不是你的实验预算；一次训练的环境重复也不是多个训练种子的验证。两组观察表示这些构造条件下存在差异，不指定唯一机制。

在评价结果揭晓前预先选的8个扰动快照上，专家重新控制，6个完成任务，2个失败。没有提供全部失败的可恢复性、专家动作序列或与策略完全同步的观测。因此，部分状态可恢复，但不能说36个扰动条件全部可恢复。
