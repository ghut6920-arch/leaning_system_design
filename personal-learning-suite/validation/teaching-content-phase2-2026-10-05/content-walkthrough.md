# 第二阶段：单模型内容走查

2026-10-05。执行者是本次修订的同一模型，已读研究、设计与修订指令，因此这是知情内容演练，不是盲测、独立模型发现能力或用户学习实验。以下请求不预填卡名；“当前输出”是本次模型实际整理的候选答复，供人工评审内容、工作安排和改路依据。没有把条件分支写入真实原答／掌握／计划记录。

## 1．新程序应先有可跟踪输入

**请求：**“我会求导，刚接触梯度下降。用 f(x)=x² 帮我看懂它到底怎么一步步走，不想一上来被考。”

**当前输出：**“这次先把一个更新步看清。f′(x)=2x 表示当前位置的上升方向，梯度下降用 xₜ₊₁=xₜ−ηf′(xₜ) 向反方向移动。取步长 η=0.25，从 x₀=2 出发，第一步得到 2−0.25×4=1；第二步得到 1−0.25×2=0.5。这里函数、求导和更新规则各承担不同工作：求导提供当前位置的方向，步长决定走多少，更新得到下一位置。你可以先看完整示范；愿意自己接着算时，用同一规则算 x₂ 后的下一步。若现在只想听解释，我们先把这段说清即可。”

**方法与复核：**S05 范例而非先冷测，实际借用可跟踪步骤；需要局部承担才借 S07。x₃=0.25。请求只需看懂过程，不自动要求一般收敛证明、额外模拟或长期测验；若追问步长为何有效，再按新工作分析 0<η<1 的全初态收敛范围。本例的函数结论可直接代数核验，教学收益未验证。

## 2．动态请求不被压成三张已编译卡

**请求：**“给定 xₜ₊₁=xₜ+0.5uₜ，uₜ=2.4(1−xₜ)，x₀=0。我看得懂每个式子，但为什么整体会来回变化？帮我连起解释和简单模拟。”

**当前输出：**“控制器把误差 1−xₜ 变成输入，对象再把输入变成下一步状态。代入后，一步更新是 xₜ₊₁=xₜ+1.2(1−xₜ)。所以 x 的前三次更新是 0→1.2→0.96→1.008：超过目标后，下一次输入反向，状态又回到目标另一边。用 eₜ=1−xₜ 表示误差，递推为 eₜ₊₁=−0.2eₜ，负号解释交替，绝对值 0.2 解释幅度缩小。可以运行状态表，将每行状态和误差核对到这条递推。这个结论依赖现在的线性、无延迟模型；如果加延迟，需要更改状态历史并重分析。”

**方法与复核：**原索引回读 R06／R07／R10；整体接口与动态作用是当前工作，X06 仅在式子与表／图映射有需要时借用。这里是解释教学，AI 已提供递推式，不宣称学习者自主建立递推。探针实际运行同一 q=1.2 的代码，与闭式核对；一般范围在教师参考中有论证，模拟不是一般证明。无需先编译三张动态卡才可以解释。

## 3．恢复入口不足不抹掉关系工作

**请求：**“我理解合并总量与人数，但忘了公式。12 人均值 70，18 人均值 90，帮我接着完成；可以查关系。”

**当前输出：**“你允许从关系重建，我们直接按总量走：第一组总量是 12×70=840，第二组是 18×90=1620，合并总量 2460、人数 30，因此总体均值是 82。公式就是把这几个量的关系写在一起。这个解答现在属于给出的示范；如果后面目标要求你自行重建，可以保留同样的资源条件，再观察由你完成的合并关系。”

**方法与复核：**关系包只借实际需要的恢复／重建部分，不加闭卷债务。当前直接帮助展示了整个解答，不能把正确参考保存成学习者已完成的推理。若真实原答正确重建可接受；有组总量却除以组数时才确认分母意义并修该关系，单次算错不能确定结构全部缺失。

## 4．学习选法先用有区别的条件

**请求：**“我算公式没问题，却搞不清什么题该用哪种权重。想通过几种情况看明白，资料可以看。”

**当前输出：**“先比较权重究竟由什么定义。10 人均值 80、30 人均值 60，合并全部人的均值时，总量按人数展开，结果为 65。若课程明确两部分成绩各占一半，分数同样为 80 和 60，总成绩就是 70，人数并不改写评分规则。如果只给两组均值而不给人数，合并均值没有唯一数值，需要补条件。关键是先认出要合并的对象和已规定的计量／评分关系，然后把权重映射进去。”

**方法与复核：**选择包、D09／D10 的条件比较；这是开卷教学，已提供对照和方法，不能称无提示自主选择。后续目标若要求自行识别，另用合格竞争任务，说明已知近期线索；若只要求这次看懂，不加选择考试。三种参考均有内容依据，不能一律判 70 错，也不能把人数缺失当人数相等。

## 5．条件更新先查系统是否错

**请求：**“封闭练习规格规定 mean 的 v1 空列表返回 0、v2 返回 None，非空都取均值。我在 v2 答 None，参考却写 0；这是我要改观念吗？”

**当前输出：**“按你提供的 v2 规格，None 是正确答案，参考的 0 与当前版本冲突。应先核实并修正这份参考及受影响的评分；原答要保留。v1 返回 0 的规则仍在它的版本内成立，非空列表的均值规则也没有改变。若没有版本信息，空列表应返回什么还不能唯一判断。”

**方法与复核：**条件更新包，先执行系统参考纠错分支，旧合法域保留。走查没有真实评分记录，因此这里只交应采取的修复，不称实际撤销过评分。此为虚构规格，不是现实 API 声明；不能强迫用户先改错答，也不能宣布旧规则全部擦除。

## 6．一般构造保留理论上限

**请求：**“已允许引用半正定惩罚下唯一解的共同核判据。对任意 A，我的目标是证明最小秩并构造 Q，不满足于算两张矩阵；预算不要求额外记忆测试。”

**当前输出：**“保留一份完整论证：先说明 Q 必须约束 A 看不到的方向，再证明最小秩下界并给达到下界的构造。令 k=dim ker A。若 rank Q<k，Q 限制在 ker A 上不可能单射，产生非零公共核方向，违反给定判据，故 rank Q≥k。取该核的标准正交基矩阵 N，令 Q=NNᵀ；对核中的非零 d，dᵀQd=‖d‖²>0，因此该构造满足判据，秩为 k，达到下界。A 满列秩时 k=0，零矩阵也合法。你若希望自己完成构造，实际教学时可先只给目标与允许判据，把这里的 N、Q 留在教师参考中，在具体卡点才提供支持。”

**方法与复核：**可直接完整任务，也可借关系包整体论证；允许判据不额外考记忆。这里是完整解释候选，构造由 AI 已给，不能称用户独立构造；自主用途准备必须分开当前题面与参考。一般论证经数学审查，三个具体秩一矩阵及仿射分支经有限探针核验；有限检查本身不证明一般定理。预算变化不把一般目标改成两个算例。

## 7．只缺未来条件时停止追加

**请求：**“这是一个假设：当天解释已经合格，目标还要求一周后使用。现在继续问能不能直接证明一周保持？”

**当前输出：**“现在继续问只能得到当天的更多表现，不能产生一周后的证据。保留当前合格解释，提出目标内的后续使用检查，并由计划安排；如果期间发生相关复习或反馈，后续结论按实际接触条件解释。当前会话可以结束。”

**方法与复核：**不选新卡，不新增第二套复习队列，不冒称计划已排入。即时教学完成、未来条件未观察分别报告。
