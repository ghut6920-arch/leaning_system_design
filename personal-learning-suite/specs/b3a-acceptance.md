# B3a 有限验收

日期：2026-10-03。对应 N00 第十二节、D02 第五至九节、D04 第四至七节、D06 第七节和 D11 的 B10-01/02/04/08/10/11。以下是各情境的评估切片，不代表完整 B10 或 V1—V4 已通过。

| 验收面 | 可观察结果 | 实际范围 |
|---|---|---|
| 条件与样本 | 选定初答／修订；帮助只限被代做操作；备用未展示不污染；同事件一个样本 | 所给时间线、标注操作和完整声明；不识别隐藏视觉泄露 |
| 资格与判断 | 按要求和关键操作核任务调用、前置、参考、证据条件；支持／资格双轴；未知不判失败 | 专业操作评分由模型提供；程序不核学科真伪 |
| 授权与重要复核 | 主体、决定、对象、判据、结论、预算、有效声明；空触发列表不能绕过反证或重要用途 | 仅 fixture 配置；模板 unbound；无真实身份与时钟失效机制 |
| 冲突与重评 | 同原答同条件相反判断须回依据，同 id 修订也不能绕；原答可重用，无新表现 | 冲突理由由 AG3 声明；不自动恢复专业限制或改目标 |
| 时间 | 只核目标内时间；使用最近相关接触；已过日期不补造缺失事实 | 当前观察保留，目标时间用途不足保持未知／待查 |
| 有限诊断 | 观察、替代解释、反证、不同安排分支、预算、停止／重开；无价值或零预算不加观察 | 暂定解释；不建画像或直接安排 |
| 保存与异常 | 同一 SQLite CAS/幂等入口；保存后重开；失败回滚；暂停、限制、删除迟到阻断 | 不重写原答、样本、目标、需求或计划；外部副本不受 SQLite 删除控制 |
| Skill 前向 | 未给预期答案的独立请求能按实际帮助范围判断并结束当前充分工作 | 人工材料候选分析；不能称真实学习或运行宿主验证 |

[行为测试](../tests/test_b3a_assessment.py)和[检查脚本](../scripts/check_b3a.py)在隔离临时空间执行；[行为报告](../validation/b3a-runtime-report.json)及[原始输出](../validation/b3a-runtime-output.txt)记录实际结果。[独立前向输入](../validation/b3a-forward/input.md)及[实际原输出](../validation/b3a-forward/output.md)不替代专业授权或事实。

模型专业包由 [SK04](../src/skills/learning-assessment/SKILL.md)、[AG3](../src/agents/AG3-assessment.md)和[本地接口](../contracts/assessment-b3a.md)交付；[授权模板](../templates/routine-scoring-grant.json)须实例化并绑定后才可执行。本轮只在人工 fixture 中检验授权，Skill 未安装，四角色未绑定真实宿主。

验收后可使用此接口为 C0 提供评估条件和有限判断；实际教学、正式计划及多 Agent 宿主能力按各自批次处理。跨记录删除后复杂能力范围的专业重评、递归旧依据兼容及用途恢复依然需要对应责任的当前合法结果，不根据程序通过补造已完成状态。
