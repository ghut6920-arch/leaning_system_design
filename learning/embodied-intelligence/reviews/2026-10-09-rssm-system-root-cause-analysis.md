# RSSM 备课薄弱处的系统归因：研究、设计、Skill 与执行

日期：2026-10-09。分析对象是“备课动作条件 RSSM 教学方案”的 ultra 多 Agent 候选，以及现行通用框架和对应正式研究／设计。本文解释上一轮绝对质量评估中的薄弱处，不重新评比模型，不实施修订，不采用候选为真实课程，不改变学习记录。

方法：RootCauseAnalysis／Fishbone，按研究基础、正式设计、通用落地、学科实例化、协作审查和实际验证六类追溯。优先级依据问题所处位置和影响范围；没有受控因果实验，不编造贡献百分比。

## 1. 结论与问题定义

**主要问题在具体认知目标的选择、材料的教学功能实例化，以及审查如何判断这两者的质量。现有研究与设计并非没有深层认知要求；现行 Skill 也不是只剩文件和证据规则。本次已经出现真实、较强的 Encoding 和 Post 工作，但体系尚不能稳定保证“目标选得充分、材料把关键理解教透、学习者真正接得住”。**

准确的问题是：这份准备在“给定 RSSM 的序列推导、有限预测接口与规划审计”上较强，在结构取舍、参数学习的具体作用、不确定性改变行动的辨识性展示上较薄；入口到完整理论和综合任务的实际适配仍未知。不能把它说成没有备课、没有策略调用、没有整体工作或已经发生了学习失败。

上一轮评估依据见[绝对质量评估](2026-10-09-rssm-ultra-absolute-quality-review.md)。该评估区分原范围合格、提高理解目标后需要补强和真实教学未验证。缺少神经网络训练、论文复现、闭卷恢复、长期保持或远迁移，均不能自动认定本次违规：候选明示了不承担这些目标。

## 2. 从哪里到哪里：可观察的传递链

```text
用户提出宽主题和深度备课要求
  → 认知设计把近期整体选为“给定模型的系统论证与规划审计”
  → G1–G5主要落在对象、时序、ELBO、prior rollout、有限规划与证据用途
  → 策略按这些工作实例化，材料围绕固定 Gaussian toy 贯通
  → 教师参考与数值核验将给定模型内的正确性做得很细
  → 审查发现错误和示范限制，修错／限定用途后接受当前候选范围
  → 可以交付有界试教候选，但较宽的模型设计与学习机制理解并未同等落实
```

这条链的文件表现可以确认。它说明缺项如何在上下游相容的情况下保留下来；不证明模型有某种主观动机，也不证明多 Agent 是缺项的原因。

认知设计第1–2节将作品定为《雾中小车 RSSM 系统论证与规划审计》，第4节按此选择方法，第5–6节再给材料和工作契约：[认知设计](../prep/rssm-test-20261009/01-cognitive-design.md)。其中 G3 有训练语义连接，G4 有不确定性接口，不能说这些目标完全不存在；薄弱处是理解要求和展示方式的展开不均衡。

## 3. 各层责任，不能混在一起

| 层 | 已有的内容 | 当前不足及归因 |
|---|---|---|
| 研究报告 | 结构属性、多维深度、中间机制、合法条件变化、示例与支架、保留学习者加工；Post 区分关系、分化、抽象、条件化和迁移 | 足以支持针对性的补强。研究本身是构件证据与设计综合，不能自动生成任意学科的优质课程，也未证明整个 AI 导师组合有效 |
| 正式设计 | 用途与目标依据、近期完整规格、复杂整体工作、材料活动共同准备、深度动态调整、卡片实例化、四类验证 | 相当充分。跨学科规范仍依赖教师作专业判断；需要把“用途是否被近期目标充分承接”和“示范是否充分承担所称功能”落到当前单元的判例与反例 |
| 通用 Skill／Agent | 先备全本次主线、实际读完整策略、具体认知工作、完整参考、支持返回、连续教学和专业核验 | 不能判为研究内容整体丢失。当前实例对规则的解释仍允许较窄、相容的目标一路通过；需要针对质量盲点的指导与实质检查，不是再抄一遍原则 |
| RSSM 具体备课 | 合法长链推导、同 h/z 对象的连续示范、具体问题、开卷整体组织和条件选用 | 最直接的改进位置：结构选择、学习作用、示范辨识性和呈现跨度。目标与材料的专业质量不能靠卡号和完整性证明 |
| 协作与审查 | 真实分工；审查读了材料、任务和参考，实际修了内容／接口错误 | 修错有效。主要沿既定候选目标验收，较少用用户用途反向质疑该目标是否选得充分；多个角色并不自动产生不同的认知设计 |
| 实际教学与效果 | 候选明确未教学，未形成学习者原答或掌握判断 | 属于待验证层。用户本来要求只备课，未试教不是执行违令；但目前不能凭准备文件认定动态深度与真实学习收益已建立 |

## 4. 最主要的归因：目标内充分，不等于用途上充分

### 4.1 具体目标的质量是上游决定

“部分可观测环境中的动作条件 RSSM——从序列变分推断到多步预测与闭环规划”可以实例化成多种合理单元：解释给定模型、推导并审计系统、理解结构取舍、分析模型怎样学习，或进一步实现和实验。它们的必要材料不同。

本次选中了较强的“推导与审计”单元，随后相应目标、策略、材料和题目彼此匹配。这不是把已约定的神经实现目标偷偷降成问答；这些是尚未被采用的系统建议目标。然而，“匹配自定目标”不能单独回答“这份目标是否充分服务用户希望建立的认识”。

正式目标方案已经要求标出课程明确要求、用户用途、系统建议和待澄清，检查最终工作与近期能力覆盖。现行[目标规则](../../../personal-learning-suite/src/skills/learning-goals/references/goal-design.md)及[完整备课规则](../../../personal-learning-suite/src/skills/learning-teaching/references/design-whole.md)也要求用途与知识关系。因此缺的不是新增目标字段或目标责任人，而是**本次对用途到理解要求这一专业选择的实质验收更弱**。

“知道部件是什么”与“能说明为什么选这些部件”，“能证明训练目标成立”与“能说明数据怎样改变预测模型”，都是可以分别选择的认知工作。给出高级公式并不会自动承担后者。

### 4.2 审查闭环主要围绕已选目标

[本次审查](../prep/rssm-test-20261009/08-audit.md)的 P1 定义包括“目标中的关键工作、材料或接口缺失”。它确实进行了内容与教学审查，不能说只检查文件。其最终通过也限定为给定候选范围，没有保证全面优质教学。

问题是：当较宽的理解用途在目标选择中只得到部分展开时，后续“材料满足目标、问题调用目标、参考足以审目标”仍可能全部成立。缺少的认知连接没有成为这一轮的失败条件。

最清楚的例子是 A03：审查已经看出所有候选未来方差相同，知道该例不展示不确定性改变动作排序。处理是说明有限用途，而不是增加一个能展示该关系的合法对照。这个处理在原目标下可以成立；若希望单元更充分教会不确定性对决策的意义，就还应改善材料。

**限定声明防止误教，不能替代关键关系的教学。**两项工作都需要，但是否补例要由目标和用途决定，不能强制每个随机模型示例都改变动作排序。

## 5. 四个具体薄弱处，逐项追溯

| 观察 | 研究／正式设计／Skill 已有支持 | 本次实际情况 | 判定及应改位置 |
|---|---|---|---|
| h/z 角色解释强，结构取舍解释弱 | Encoding 研究第5、7–8节；Encoding 方案第三节的模型评议与方法构造；现行 encoding 的竞争模型／结构入口 | M1/M2说明历史必要性、h/z 的时序与信息作用；缺少集中比较不同结构怎样满足需求的材料 | 属于理解目标与领域实例化可补强；不是原 G2 时序目标已失败，也无需证明 RSSM 普遍最优 |
| ELBO 推导强，参数学习作用示范弱 | 机制中间过程、时间状态、跨层接口、理论与实际相互连接均已有规定 | M3有最大化下界和重参数化说明；M4固定 f/p/q 后计算训练目标与使用轨迹，没有具体展示参数随训练信号改变 | 有训练语义，不能说完全缺失。若承诺理解模型怎样学习，需补有界参数变化示范与相应解释；不必大型训练 |
| 方差传播与平方期望正确，关键决策对比不够有辨识性 | 研究要求合法变化与诊断差异；材料规则要求内容适合其用途 | M4的各候选未来方差相同；方差项改变绝对成本而不改变排序。正文和 A03已承认 | 正确示例服务了分布传播，尚不足以具体展示不确定性可能改变选择；补不同合法预测条件的对照，不冒称原 toy 的结果 |
| 入口到完整推导与综合工作的跨度未验证 | 研究第9–10节；Encoding 方案第四、五节；C0 的前置、帮助和分支要求 | Q0检查一跳信息／索引，随后接完整 M3/M4，再到五类连接的 W1；有 B3 等实际支持，但概率前置是假设 | 是适配风险，不是已发生的学习失败。Q0不能证明 Jensen／条件期望前置；试教时分段呈现、按具体困难给已备桥接，保持同一主线 |

原材料定位：[M2/M3/M4](../prep/rssm-test-20261009/03-core-materials.md)，[Q0/W1/整体任务](../prep/rssm-test-20261009/04-learner-work.md)，[教师参考](../prep/rssm-test-20261009/05-teacher-reference.md)，[支持分支](../prep/rssm-test-20261009/06-support-branches.md)。

不应把上述问题合成“Encoding 深度不足一个等级”。本次关系精确性、形式推导、信息边界和整体接口较强；设计理由、学习作用的具体机制展示和目标选择的外部充分性较薄。

## 6. 策略调用为什么没有自动把课变深

认知设计记录实际读取了 S05、S08、R04、R06、R10 及 retrieve-relation、select-method 的完整包，含正文、条件、限制及证据；该子 Agent 的可读命令记录也显示相应文件读取。现行库有60张编译 Encoding 卡及4个 Post 包，见[选法规则](../../../personal-learning-suite/src/skills/learning-strategies/references/selection-adaptation.md)。本次不是没编译、只写卡号或只用第一道题。

但策略是操作资源，不包含对 RSSM 该教哪些联系的自动答案：

- S05 可以示范一条给定模型的正确路线，也可以示范如何作结构选择。输入目标和素材不同，认知效果覆盖也不同。
- R06 在本次主要追踪动作、h/z 和新观测传播；它不会自动增加参数学习过程。
- R10 的接口连接较充分，同时按目标合法保留了网络训练、优化器和更完整规划算法的黑箱。
- R04 主要区分重建／预测／控制证据及信息用途，没有自动要求不同方差的行动对照。
- S08 已备按组件渐隐，但未实施；不能由预备分支推出学习者已能少帮助完成。

因此，应检查“这张卡在本题究竟让哪项关系变得可理解、让学习者做了什么”，而不是再以更多卡片和调用记录补救。现行规则已经表达这个原则，下一步需用实际不足的材料与反例校准其执行。

## 7. Post-Encoding 有设计，但自主工作的覆盖与原范围一致

本次 Post 有真实内容：W1接管新前缀的连续接口，整体作品组织序列推导、预测、选择和反馈；A/B/C比较在线可行性、离线合法用途与泄漏；U/V材料讨论不同证据能支持的结论。不能把它贬为仅换数字或全由AI代做。

它主要是**给定模型、允许资料及有限候选中的关系整合与选用**。模型族、公式、候选费用表和不少参考已给出，学习者没有承担自主选模型、训练网络或设计完整实验；也不要求算完新的 joint-root。教师参考包含这些深层说明，不代表相应操作已留给学习者。

Post 研究明确区分题干提示方法后的执行与自主选用，正式 Post 方案也按原目标选择工作。现行处理没有把开卷整合冒称闭卷恢复，也没有把模型吸收新观测冒称学习者图式更新，这些做得正确。

若用途确实需要更高的模型评议或实验解释，应先补相应目标，再备一个范围明确的比较／鉴别任务。例如指出给定证据缺哪项、设计一项能区分解释的观察并说明可能结果；不把“再写一遍已给说明”充当新增认知工作。纯接口入门则可以合法维持原范围。

## 8. 多 Agent 解决了什么，为什么还留下这些问题

| 职能 | 本次有效贡献 | 仍须加强的判断 |
|---|---|---|
| AG1式认知设计 | 给出G1–G5、整体作品、完整策略实例与主要工作 | 从用户用途和内容反推目标是否充分；明确哪项结构／学习／决策理解属于近期主线，哪项有理由延期 |
| AG2式材料准备与内容核验 | 可靠推导、同对象示范、算术核验、完整参考与多解边界 | 正确性之外，示范是否具体承担所称教学功能；关键对照是否真的展示待理解的差异；有不足时回提目标／材料调整 |
| AG3式审查 | 修样本与均值、joint/条件root、时间信息、伪造经验表述及整体接口问题 | 保留目标内资格审查，同时单独指出目标建议与用户用途之间的覆盖不足，不直接改写用户用途或原判据 |
| AG0式整合／呈现 | 统一版本、修首回复停点、保证已有下一段内容 | 区分已备材料与可接管认知操作，实际观察后调用桥接；不把Q0成功当完整前置就绪 |

四个角色的现行文件已经有目标、教学、材料和评估责任，见[AG1](../../../personal-learning-suite/src/agents/AG1-design-planning.md)、[AG2](../../../personal-learning-suite/src/agents/AG2-materials.md)、[AG3](../../../personal-learning-suite/src/agents/AG3-assessment.md)。缺的不是再设一个“认知负责人”。

本次实际协作改进了正确性，但大部分工作接受同一份上游目标。四个角色围绕同一个较窄目标各自把工作做完整，不能保证有人再追问“这个目标本身够不够”。这一点适用于单 Agent 顺序兼任，也适用于多 Agent。专业核验的价值有文件证据，协作对认知质量的净因果优势仍无受控证据。

[协作正式方案](../../../docs/designs/AI个人学习系统_工作包8_多Agent协作与共享状态_设计方案_v0.md)本来就支持各方回提目标问题、相容职责兼任、减少无信息委派和不以增员为默认修复。应落实这些反馈，不能以新增会签人数代替依据。

## 9. 研究与设计到底是否不足

有两种不同答案：

1. **若问“为什么没把机制、条件、认知工作写进规则”，不能主要归罪研究／正式设计缺失。**已读原文相当明确，现行 Skill 也保留了关键要求；当前薄弱处主要发生在内容实例化和专业验收。
2. **若问“这些资料能否保证任何单元都高效、深刻并动态适配”，目前不能。**研究报告明确把整套决策流程列为启发式综合，不是经学习收益优化的导师；正式方案把高上限与可靠实施条件分开，并要求真实验证。领域经验、材料质量判例、适配证据和长期运行校准仍需积累。

这不是用“研究仍需验证”逃避具体修复。结构对照、训练作用桥接和材料功能检查已经有足够设计依据，可以针对性改进；而最佳呈现跨度、帮助撤除速度和长期收益不能只凭文件决定。

[验证正式方案](../../../docs/designs/AI个人学习系统_工作包10_验证计划与设计收口_设计方案_v0.md)明确区分 V1内容与评价、V2真实执行、V3学习表现、V4复杂度价值。当前准备主要提供 V1和执行方案，其他层保持未知。只反复评备课，不能测到真实适配；本次只备课是用户明确要求，不是框架擅自漏执行。

## 10. 纠正方向与优先级

本文提出修订方向，未执行。优先级是定性排序，没有贡献权重。

### 第一优先：校准用途、理解要求与材料功能

由现有 AG1／SK01／SK03 在原教师安排内补清：本单元服务什么工作；为了完成它需要理解哪几条关键联系；哪些已由讲解具体承载；哪些必须由学习者使用；哪些本次有理由延期。目标已经可靠时直接复用，不每轮重新备课，不要求列所有理论问题。

两种检查分开：**任务是否满足已选目标**；**系统建议的目标是否充分承接本次用途和承诺**。发现后者不足时先回提目标设计，不事后用新标准倒判学习者。

### 第二优先：用实际教学反例修补 Skill 的执行指导

在现有 design-whole、encoding、domain-checks及教师实例中强化实际判例：

- 算对了方差且有边界说明，但若目标要解释为何影响行动，主例仍可能缺必要展示。
- 给出完整训练目标推导，但若目标要解释模型怎样学习，还需让必要参数变化与预测关系可理解。
- 部件角色清楚，但结构评议目标需要需求与结构取舍的连接。
- 备好庞大参考和整体题面，不等于未知基础的学习者能一次接管所有新增连接。

已有规则够用的地方直接改实例，不再堆同义禁令。现有教师实例已包括视频语义、反馈稳定性、一般证明与构造，不能说库中完全没有深层好课；应补这类“形式完整且内容正确，但所称教学功能仍较弱”的失败判例。

### 第三优先：把协作审查的反馈真正回到目标和材料

认知初稿之后，材料方和审查方可指出目标覆盖及功能问题；AG1处理影响，AG0整合。不要把认知设计一旦完成解释为不可回改，也不要把所有分支串成审批关卡。单模型可以顺序做同样的专业检查。

### 第四优先：验证真实呈现和接管，而非再生成一堆方案

保持同一合理单元主线，观察学习者怎样理解材料、怎样承担连接、帮助改变哪项操作、能否回到整体。陌生基础提供实际解释和示范；符号障碍补符号；已能组织整体则减少重复。无需预先制造错误、固定测每个概念或撤掉全部资料。

当前不优先重写全部研究、不全量再编译卡库、不新增固定Agent、不增加数据库／JSON字段、不改Python API。只有真实发现原主张、责任或运行接口不足时才扩大修订。

## 11. 怎样检验上述归因，而不让归因变成另一份自证

| 待检验解释 | 有界检查／比较 | 可推翻或限制此解释的结果 |
|---|---|---|
| 上游理解目标展开不均衡是主要可改位置 | 保持模型、资料与角色配置，先固定少量用途相关理解要求，再重备相应材料；按原件比较具体联系 | 原目标已有同等明确联系且原材料充分展示，则此项归因应撤回／缩小；固定目标后仍薄弱则更多定位到材料能力 |
| 材料的功能性展示不足 | 用合法对照检查目标关系；例如在明确的新模型里比较均值点评分与完整期望，或在固定q/h的局部条件下追踪prior参数变化 | 新例引入过多额外前置、不能服务当前目标或已被原例等效承担，就不保留该新增 |
| 原审查更容易通过目标相容的薄课 | 给审查两份都正确且完整、但某一目标关系的展示不同的材料；不靠文件数和字数判断 | 审查能稳定定位并要求修复该关系，则问题更多在原题目标／材料选择，而不是审查指导 |
| Q0后到M3/M4/W1可能跨度偏大 | 按主线实际试教，观察具体卡点、允许支持后的恢复和整体工作；未发生困难不强造 | 学习者能合法组织长链且无需额外支持，则不能据篇幅认定跨度失败；若仅符号困难，应只修表示 |
| 多Agent可能不是当前首要杠杆 | 在相同用途、理解要求和参考保障下比较顺序兼任与当前分工，记录质量及成本 | 目标／材料固定后分工仍稳定发现重要遗漏，可支持保留该分工；目前结果不足以单独归因推理级别或人数 |

这些是后续可执行验证建议，本轮未发起新模型实验或正式学习。材料改善与学习收益分别判定，不虚构学习者反应。

## 12. 证据强弱与本轮边界

- **已核实：**研究、正式方案和现行Skill含相应认知规则；具体G1–G5、所选策略、固定toy、主要题目与支持已经写出；A03被审查识别且用途被限定；候选明确未教学。通过原文件及可读线程事件核对。
- **强解释但未做受控因果验证：**自选目标与后续目标内审查，使较窄的认知展开在多角色相容的情况下保留。不能把观察链说成已测出因果贡献比例。
- **待验证：**这些补强对用户理解的实际收益、Q0后的适配、最佳帮助程度、多Agent的净价值。
- **没有证据支持：**模型推理资源不够、某模型品牌天生不能教学、Agent越多效果必然更好、AI因规则害怕解释、研究科学结论整体错误、实际学习已经失败。
