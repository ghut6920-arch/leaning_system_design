# Encoding：建立或修订当前目标需要的关系

依据 D05 第二至七节、D04 共同教学、D07 边界；内容适配与顺序同时转译 R01 第4—10、12—14节，必要时按 [来源清单](../../../../resources/source-registry.json) 回原文。正式专项约定决定适用范围，研究中的卡数、流程与新例建议按目标采用。此规则不是统一深度等级，也不读取学习者脑内模型。

区分目标要求、当前教学展开、本次承诺范围。目标来自 GoalSpec，当前展开随材料、原答和帮助调整，本次范围受共享预算限制。预算不足保存证明／代码的连续产物与未完成连接；原要求不降为“听懂”。可靠活动直接执行，已有足够证据直接引用，简单映射不额外要求机制、图或迁移。

## 根据内容准备当前展开

未准备单元先用 [内容准备](design-whole.md)读清对象、关系、条件和整体用途。按当前所需组件给够用输入；有限尝试适用于已有可用前提、任务有界、后续讲授可靠，并能改变安排或帮助理解目标关系的情况。没有必要先制造错误模型或等待答错再提供解释。仅因学习者是“初学”或“专家”，不能假定每项组件都不会或已懂。

课程／单元首次呈现前，先设计本次要形成的知识联系及理解要求，再备好支持它们的核心输入、示范、主要任务与具体问题及参考；相应 Post 工作沿同一目标一起准备。当前表格帮助作内容选择，不是逐项必修清单，也不能把“按需展开”解释为只备第一题、其余主线逐答临时编排。动态调整改变支持和展开，稳定主线及整体连接复用。

按design-whole实际接入SK06与完整策略包，落实对象→关系／条件→学习者关键加工→可核查产物。程序内容优先让规格、状态转换和不变量可跟踪，按目标安排理由、对照和整体应用；每个新操作后重复一个近例不能自动成为完整Encoding。完整解释可先连贯展开，不需要为每个定义设置问答停点；普通反馈后沿原单元接已备下一连接，收束按单元目标和真实停止条件判断。

分开内容参考结构、目标要求、关于学习者的暂定解释、实际呈现的外部产物／支架。教师画的框架帮助定位对象和关系；能否使用这些关系看学习者具体工作，不能从图的完整度断言脑内表征。不同但合法的证明、图或实现可以满足同一目标。比较前先区分表达差异、假设差异和真实错误；开放问题保留有依据的竞争解释及未知，不补成唯一真相。

| 当前内容主要要求 | 适合准备的输入与表征 | 关键工作与限制 |
|---|---|---|
| 术语、符号或任意约定 | 准确定义、语义对象、简短对应例 | 在目标语境中对应和使用；不强求这些约定的内部机制 |
| 类别、联合条件与边界 | 判定条件、合法近例／非例或条件表 | 区分必要、充分、背景组合及替代路径，接受、拒绝或说明信息不足；概率线索保留基准率和不确定性，不强作必然，也不能反写条件概率 |
| 关系、机制或依赖 | 带前提的关系图／式子、可靠推断示范 | 区分类属、部分、函数依赖、相关、因果及学习前置；需要机制时连接实体／活动／状态变化。观察、干预、反事实各自说明依据与保持项，未知中介不编造 |
| 动态过程、反馈与时序 | 明示模型、状态、初值、时间步／尺度；必要方向表、曲线或小模拟 | 追踪变化和边界；图或模拟不能替代理论条件，负反馈极性不保证稳定 |
| 程序、算法或技能步骤 | 规格、对象／状态轨迹、完整或部分范例、边界依据 | 完成步骤及关键理由、检查不变量；核心代码由 AI 写出后不记独立实现 |
| 数量、数学证明或构造 | 变量／单位／对象域、合法推导和整体参考 | 推导、反例、存在性或构造按目标承担；有限数值不证明一般命题 |
| 多表征对应 | 共享对象／变量，单位、坐标、固定条件、时间与边界的对应 | 明确保留、丢失、新增的信息；区分有来源的新资料与待验证假设。箭头不自动给出函数，工具作图不替代目标映射 |
| 抽象与跨例选择 | 按目的对齐角色、关系和条件；选择能暴露错用或漏用的案例 | 同类比较找共同结构，近邻比较辨界，同题异解比较选择条件；表面变化与结构变化分开，跨领域必要知识先补，方法标题不能代做自主选择 |
| 竞争模型与方法构造 | 可相容候选、各自预测、能区分的观测或合法变式及评价标准 | 正向推演与逆向诊断分开；多个解释同样符合数据时允许不可辨识。按目标提出鉴别办法、算法或惩罚结构并论证，不能把新颖或数值成功当正确 |
| 综合与功能性压缩 | 局部输入／输出／条件／性质及层间接口；保留必要条件的简洁结构 | 接回整体预测或产物；检查变量、单位和时间尺度是否相容。需要压缩时用压缩稿恢复目标推理，摘要短或子图齐不证明整体可用 |

同一内容可以兼有多个结构。挑当前有作用的关系和材料，不按表逐项教学或走六类卡的固定顺序。黑箱保留输入、输出、成立条件、目标依赖的性质及内部未知；接口足以支持目标就暂不展开，目标要求内部解释／修改或接口已不足时再展开。涉及主因排名，先确定比较的是效应、必要性、瓶颈还是可操纵性，无依据不编权重。

按具体理解要求检查展开是否均衡：角色／时序说明不自动完成结构取舍；训练目标的合法推导不自动展示参数变化怎样改变预测；正确计算不自动解释所需选择条件。目标需要其中哪条连接，就准备可跟踪的依据和对应认知工作；目标没有需要时不全部追加。示范改变了哪些关系、哪些仍是黑箱须与主线相容，见 [备课质量实例](preparation-quality-examples.md)。

## 选择输入、示范与学习者承担的工作

把教师准备的结构落实到实际内容：可靠题面、对象域和条件；合法变化／保持；AI 现在提供什么；学习者需要完成什么；可接受的合法多解／拒用／信息不足；哪些具体表现会改变安排。教师参考不是逐字复现模板。

| 当前依据 | 执行选择 | 后续如何调整 |
|---|---|---|
| 必要定义／对象尚无可靠输入，或明确请求解释 | 先给够用说明和带语义例子；需要整体位置时先给有限框架 | 能开始使用就进入连贯工作；仍认不出对象时补必要组件 |
| 步骤路线陌生且示范可靠 | 给完整连贯范例，再按需要留部分步骤／理由让学习者承担 | 对已可用操作减少帮助；不要先让学习者逐项猜未知步骤 |
| 有相关依据，目标工作还未观察 | 直接目标任务或会改变下一步的有限检查 | 合格则保留或结束；具体障碍出现后转相应教学 |
| 局部已可用，支架仍代做目标工作 | 只撤去相应支持，或回更完整任务 | 观察被撤去的工作；失败不抹掉其他有效部分 |
| 局部正确，整体仍失败 | 回完整产物查接口、映射、顺序和方法选择 | 修组织与连接；不自动继续向更底层补基础 |
| 当前目标已够用，或反复无新信息 | 收束；必要时换有依据的表示／活动 | 不为显示深度增加题数、机制或远迁移 |

充分讲解可以先作为纯教学输入，不必立即加一道验收题。目标仍需实践时，留给学习者一个自然关联的操作与解释；有支持的成功按实际条件解释。完整范例→部分承担→自主工作是可选择路径，不是人人必过的阶段。已有可靠作品可跳过示范；一次成功也不强迫全部撤支持。

## 动态调整与返回

当前展开可以分别增加关系细节、条件覆盖、综合范围、形式严谨性或自主承担，也可以减少无关信息、恢复帮助、换表示或保持整体分段。明确哪项新表现促成调整、什么结果后够用；不以慢答、字数、题数或图复杂度判深度。

理论与实践围绕同一对象和条件连接。可以从定义／模型进入实现和观察，也可以从具体案例、已有代码或可靠异常进入结构比较、抽象和模型修订；选择能表达当前关系、符合已有前提的一种入口，不固定理论先行或具体先行。来回转换时标明同一变量、条件、尺度及新增假设，分别核推导、程序行为和观察能支持的结论。若独立实现本来是目标，提供规格与必要概念，完整实现按帮助需要选择时机；不能用跑通替代证明、方法选择或真实使用效果。

目标要求一般证明、模型评议或方法构造时，直接保留相应连贯工作；若已有合格产物就审查，不先把高目标拆成基础问答。只缺符号或允许引用的引理时补该项，保留关键论证；深层参考必须足以审查整体，没有可靠依据就限制该用途并补齐。按需参考 [教学实例](teaching-examples.md) 的逆向模型分支和一般证明／构造案例。

进入局部前保留父任务、原产物／原答、卡点、替代解释、已有支持、局部够用、返回连接及同一预算。够用即返回。局部成功后父任务仍失败，检查组织、选择、映射和诊断；不自动继续同一前置链。同题切换继续同一 PerformanceEvent，不新增独立样本；看完解释、撤去材料或换模型不抹掉帮助。

需要策略时经 SK06 读取完整必要资源与本次配置；S07／X02 对应同次关键补全时只有一次实际表现，借用部分各自标清。没有适用卡可直接用可靠活动，不凑卡数。关键内容／参考疑误限受影响用途交 AG2；非标准合法解交核验与评估；已有原答足够可直接重评，不要求再答。
