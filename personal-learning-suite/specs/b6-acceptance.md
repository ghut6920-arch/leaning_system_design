# B6 工作网络有限验收

日期：2026-10-03；依据 N00 第十二、十四节，D09 第五、六、九节及 D01 第九至十一节。共享协议仍为 `pl-contracts/0.1.0`，局部适配 `pl-network/0.1.0`。本批只使用显式虚构记录。

本批选用本地 Python 受控串行宿主，四个逻辑角色加载实际角色及 Skill 文件，通过宿主签发的能力对象调用工具。操作系统锁限制一个工作区同时存在的宿主实例。专业准备和返回按工作单执行，学习者展示由当前 AG0 执行入口完成。没有独立模型常驻、后台调度器、无人值守续跑或并行展示。

| 验收面 | 可观察结果 |
|---|---|
| 实际绑定 | 四角色可查询加载的规则及工具范围；JSON 角色名、伪造对象、另一宿主能力及已关闭能力均不能执行 |
| 工作单 | 提出、收到、接责、部分接责、拒收分开；缺接收者授权保持未就绪；未接部分由发送者跟进 |
| 最小上下文 | 仅返回工作单授权范围及依赖；重要评估定位原任务、原答和帮助；不复制全档案 |
| 专业返回 | 返回产物保持候选阶段，说明处理与未处理范围、限制、下一责任和触发；调用成功不等专业采用 |
| 多结果未决（2026-10-04 修复） | 同工作单的不同显式结果分别可查；正反 ID 顺序均不能让旧采用结果隐藏新候选；幂等不重复，部分采用／重核／拒绝继续保留跟进。结果自身、旧工作单引用或独立专业产物受限时单列待复核，无关合法结果继续可见 |
| 采用 | 仅相应专业责任采用当前合法、兼容依据；不能以结果采用自动改目标、评分或正式计划 |
| 版本与控制 | 先检查删除／暂停／限制，后查授权与兼容；过期结果需重核；旧幂等回执不解除限制 |
| 串行专业调用 | 复用 B5 允许动作及原专业服务；工作单不能扩大接收者权限或复制共享总预算 |
| 接管 | 原子增加 execution_epoch；同活动旧入口展示和执行均拒绝；接任保持父产物、原答、帮助及实际断点 |
| 统一展示 | 专业角色不能直接向学习者显示；只输出可靠 learner_packet／有限学习者视图，教师参考不随技术回执外显 |
| 删除 | 清理同一 SQLite 中工作单、候选、执行记录及已记录依赖；受影响能力终止，迟到载荷不入库、不从摘要复活 |
| 失败与重开 | CAS 冲突／事务失败不虚构保存；已保存前缀可查；重开演示只读，不能重导入删除内容或重放链 |
| 简单路径 | 已有可靠活动及常规授权继续直接执行，不强制调用四方；未决不使用户无限等待 |
| 回归 | B1—B5 行为、B0 静态来源指纹／链接、主入口 Skill 检查均保持可复验 |

检查脚本保存逐项原始输出、宿主／Python／SQLite／适配版本、通过／失败／错误／跳过数量。本地通道绑定不认证自然人身份，不把 `verified_for_fixture` 升为 `host_verified`。直接调用旧开发脚本、直接写共享文件、外部聊天与模型上下文不属于宿主管道保障；七个 Skill 仍是开发源。V1—V4、真实学科学习效果和四角色组织净收益留 B7。
