# 同一工作的选法与适配

依据 D07 第二至八、十二节，D05 第二、四至六节，D06 第四至七节及 D04 第四至六节。规则支持当前决定，不是固定每题流程。

## 先确认需要怎样的决定

以 SK03 已明确的具体工作为输入，例如“根据人数与组均值构造总体均值”，不要以“增加深度”或卡名代替工作。分开已有表现支持的障碍、目标内尚未观察、初学无可靠输入和证据已足够；只有第一项可直接称为已有缺口。诊断仅在不同结果会改变安排时必要，交 SK04；必要支持无论结果都相同时可直接支持。

已有可靠活动满足当前目标、用途、材料、帮助条件和预算时复用。只有真实候选差异、反复适配成本、来源变化或跨次维护价值才重新选法。不为交付格式硬造第二个候选、固定选两三张卡或遍历六分类；分类只是检索导航。

新课程／单元或旧安排缺认知主线时，按 [单元准备](../../learning-teaching/references/design-whole.md)实际选法，完成工作→材料／操作→参考与反馈→整体连接。先检查对象理解、关系解释、条件判断、局部到整体和目标需要的选用／更新分别由谁承担，再定位相关候选，不把整单元统一为“讲解后改数字”。已有配置可复用的前提是其实际用途、认知工作和完整主线仍合格；仅有旧材料不满足这一前提。

## 从具体工作发现候选

把自然请求落实到内容和工作。例如“公式会，遇到题不知道用哪个”首先涉及选择条件；“负反馈为何还会振荡”涉及动态模型与稳定性，不能仅以“复习”或“深度学习”搜索。当前信息够用就准备活动；只有会改变安排的未知项才需要补问。下表转译 D07 第四、七节，并补 R02／R03 的动态与跨层入口；是候选导航，不能凭一句请求确诊缺口，也不是自动最优排序。

| 当前具体工作或有依据的障碍 | 值得回读的候选／直接路径 | 先排除什么；怎样改路 |
|---|---|---|
| 陌生事实／关系还没有可靠输入 | 直接解释、结构定向、典型例；有定向价值才借 O01，指称不清可借 I01 | 未学过的未知不叫恢复失败；不必先猜。已有材料够用就直接采用 |
| 术语、符号或对应位置挡住当前关系 | S01；需要就地对应借 S02，需要完整意义分段借 S03 | 熟悉说法能做而符号不熟，先修对应；只补必要组件，随即回关系，不背完整词典 |
| 新程序／推导无可跟踪路线 | S05 完整范例；已有上下文而步骤不稳借 S07，理由链不稳借 X02 | 先准备可靠路线。两卡若是同一有理由的补全，只做一次；范例追踪不等于独立执行 |
| 支架正替代目标要求的自主组件 | S08 按具体组件渐隐 | 看该组件的新例表现，撤相应支持；失败可恢复，不按轮数撤全部帮助 |
| 已知前提到结论缺合法连接 | encoding/R02 桥梁推断，或 X02 约束理由 | 两端不可用先补允许输入；类比只能启发，不能当证明。补桥后回整体论证 |
| 必要／充分、联合条件或适用边界混淆 | R04；D02、D04、D06 的合法对照 | 区分漏读、定义约束、概率趋势与未知。未知可留空；改变条件不能同时破坏案例合法性 |
| 从共同变化直接推出因果，或候选模型尚不可区分 | R05；有可理解候选与鉴别依据才借 O05 | 自洽解释不是实证；检查共同原因、反向作用等。没有鉴别信息就保留竞争解释 |
| 已有具体错误命题需要可靠替代 | D08；已有暂定模型与可信结果才借 X09；Post 条件更新 | 不制造误概念。先查系统参考；定位原推断、证据及替代关系，而不是反复复述“你错了” |
| 因表面相似错用，或表面变化导致漏用 | D03、I09；角色映射困难借 D01、I08 | 陌生来源域先换源例／补背景。表面线索在某些任务可能真有诊断性，不能全部删掉 |
| 执行会做，目标还要求自行选择／拒用 | D09、D10；post/select-method | 检查方法名、题组、邻题与工具默认是否代选。提供方法后只观察剩余映射／执行，保留原先选择未知或失败 |
| 局部机制正确，但多步或跨层结果接不上 | S09、R10；局部已可靠且确需可重建压缩才借 X10 | 先查接口的变量、单位、条件与时间尺度；给整体预测，不靠子题总数判整体。不无限展开所有黑箱 |
| 有时间传播、反馈、延迟或稳定性工作 | R06 追踪状态；回路确实存在才借 R07；跨层接口借 R10 | 无方程不编数值、周期或稳定性；负反馈极性不保证稳定。静态状态表够用可先用表，定量比较才准备可靠模型／运行结果 |
| 语言、式子、图分别熟悉，映射或推断冲突 | X05、X06；已有外图需关系审查时借 X04 | 查坐标、单位、定义域、恒定条件和时间尺度；排版差异可能等价。工具作图不代替目标映射，给出冲突后回原判断 |
| 目标要求抽象、构造或新例验证 | X07、I10；跨情境确属目标才借 I04；也可直接完整目标任务 | 先有够用实例／前提；样例回测不证明全称定理。仅需应用时不另加构造、远迁移或证明债务 |
| 已学内容暂时取不出，或后续关系／整体工作尚未完成 | Post 的恢复与关系入口；必要时借 encoding/R02 | 区分未输入、访问、关系和任务负担。给允许前提后能继续，就保留推理；仍有具体关系障碍再最小回 Encoding |
| 新证据、版本或条件改变原判断 | post/conditional-update；必要时借 D01、D02、D06 | 先定位更新原因。系统参考错先纠错；两版本各有合法域时都保留；条件未知不自动取最新 |
| 当前要求已满足，或只缺未来时间条件 | 复用充分证据并结束；必要需求交 SK05 | 不再选卡。现在追加题不能产生未来保持证据，卡片完整训练建议不自动扩课程目标 |

允许一次工作覆盖多行，也允许不用卡。已有合格证明、完整代码任务或开卷比较可直接使用；卡片只补实际需要的部分。新候选没有可解释的增量时继续原方法；第一条路线失配时看下一节的具体可观察分支，不靠固定失败次数换卡。

## 读到可实例化的正文，再检查准入

读 [策略索引](../../../../resources/strategies/strategy-index.json)，用上述候选的原 ID／资源键核对名称与来源；不要求自然请求先匹配库中的原句。索引或辅助器没有文本命中时，回到具体工作表及原库目录，不能据此判“没有策略”。

- `compiled=true`：读取 `bundle_path` 对应的完整 JSON。Encoding 包读两载体全文、共同约束、前置／排除、必要操作、反馈、停止／返回及证据边界；Post 包还须读 `source_excerpts[].content_markdown` 和 `evidence_refs`，顶层 `content_markdown` 只是压缩说明。
- `compiled=false`：按该项 `source_refs` 打开 [R02 原卡库](../../../../../docs/research/02_Encoding微操作与提问库.md) 的完整卡段与文首／文尾，及 [R03 JSON 库](../../../../../docs/research/04_Encoding策略库.json) 对应 `/operations/...` 的正文、证据 ID 和来源表。配合 [共同约束](../../../../resources/strategies/common-constraints.json) 的后续正式规范覆盖，读懂实际目的、前置、风险、深化与验收，再判断本次借用。R02／R03 是同一库的两载体，不算两份独立证据；source_id 的 R02 与原卡 `encoding/R02` 也要区分。
- 无适用卡：仍可从可靠内容设计直接讲解、查阅、示范或完整目标工作。若当前课程材料也不足，说明所缺内容并补核验，不拿卡的研究文献代替学科参考。

未编译项经上述回源、内容核验和适配，可成为人工教学的实际方法；辅助器的 `needs_source_review` 仍不是可提交的已编译配置。需要程序路径时由开发维护生成并检查资源包，不要求每段学习先编译余下全部卡。通用模板的研究支持与本次题面正确、活动适用、真实收益分别判断。

当前注册库的60张Encoding卡全部为compiled=true，并有4个完整Post包；上面的回源路径只供来源争议或未来新增未编译资源。教师备课引用实际读过的资源键、版本／指纹、所借操作和本题实例，不需要新增用户表单。全文中的深化建议按正式目标借用，不机械追加闭卷、远迁移或延迟任务；但原目标需要的关系整合和选用必须在实际任务中落实。

同次已读且指纹相同的共用规则、研究段落和来源正文可跨包复用；新包特有的目的、前置、风险、操作及约束仍需读清。先备一个单元，只定位其所需资源，不预载全部64包；普通反馈不重复这轮备课和核验。减少重复读取不会减少实际认知工作或省略未读约束。

命中标题后仍须读完整必要约束，核对以下内容：

- 方法直接处理哪项尚未完成的工作；说不清实际变化则不选。
- 必要前置、准确材料、可靠参考和反馈是否可用；未知不当满足。预测、发明或误概念反驳缺可靠纠正时，改直接输入或暂缓。
- 输入、标题、邻题、工具默认、已有提示是否代做拟观察的关键操作；教学可继续，独立用途需限定或换合格任务。
- 准备、执行、反馈、核验和收束是否符合当前承诺；不能删必要反馈后仍称等效，不能自行扩预算。
- 停止、中断和返回是否能保留可核查产物；复杂整体可停在中间论证，不强拆成独立小题。

返回当前可用、补齐指定条件后可用或本次不适用，并指出限制哪项用途。程序仅核这些声明；真实学科内容、线索和专业依据仍由相应责任确认。

合格候选间优先比较目标工作覆盖、结果是否可解释、可靠材料和产物复用、相称成本。用户偏好可决定同样合格的呈现，不替换目标本来要求的证明、构图或实现。研究条目数、评级、字数和主观深度不能合成最优分数；没有可靠优劣依据时说明实践选择理由并保留可替换性。

## 把方法交成当前任务与可观察分支

SK06 说明采用哪部分及为什么，SK03 用可靠学科内容把槽位填实：当前对象与条件、已经给出的输入、留给学习者的操作、具体正确参考、关键困难时如何支持，以及返回哪一个整体产物。稳定目标和材料用原引用；给学习者只需呈现当前可用的解释／示范／工作，不先展示一整份配置表。

实际读卡不证明目标选得充分或材料兑现了功能；策略不会自动补出领域的结构取舍、学习机制或决策联系。实例化后按 [材料功能核验](../../learning-materials/references/domain-checks.md)回看实际内容，必要工作未进入目标时回AG1，已入目标但展示不足时修材料，不以再调用更多卡替代。功能已经有合格材料承载时复用。

例如“修复反馈系统理解”不足以执行；可以是“给定无延迟离散模型和变量含义，对照两种增益，解释相同负反馈极性为何对应不同误差轨迹”。已经提供误差递推式时，余下工作是稳定条件推断，不能再称学习者自行建立了递推式。准备代码／曲线时同时留核验参考，代码存在不等于运行通过。

| 实际发生的表现 | 下一步的具体改变 |
|---|---|
| 熟悉说法下能做，符号版失败 | 对齐指称与单位，再回同一关系，不先重讲概念全章 |
| 给允许前提后能推理／实现 | 继续整体工作；按目标决定是否另需独立恢复，不把此前恢复算成功 |
| 前提可用仍无法连接 | 修一段可靠理由链／接口，够用后回原产物；父任务仍失败就重审组织或额外负担 |
| 明示方法会做，混合案例中选错 | 比较适用条件、拒用与信息不足；教学后换合格选择任务，已有暴露不清零 |
| 局部步骤正确，端到端结论错误 | 检查输入输出衔接、遗漏联合条件与全局约束，保留正确局部；不堆更多孤立题 |
| 新例表面改变就错／套错规则 | 分开源知识访问、角色映射、实际新增前置及结构差异，选对应支持 |
| 参考、模拟或反馈可能错误 | 先停用受影响内容和评分，交内容核验；确认用户可能原本正确 |
| 同样帮助仍无新信息／预算不足 | 改输入、表示或工作范围，或收束；说明保留与失去的用途，不再同类追问 |

首次需要连贯实例时参考 [方法与 Post 实例](../../learning-teaching/references/method-post-examples.md)。它们说明内容选择和正常反馈分支，不能当作每次必做的题数、套路或真实学习记录。

## 组合与部分借用

按实际材料、关键操作和可观察变化判断组合。S07 的步骤承担与 X02 的理由约束不同；若两者落实为同一处有理由的补全，合成一次活动，记录各自借用部分与未采用部分，只一份原答和一次事件。多来源不会新增独立样本；同一卡用于不同必要工作也不能仅按 ID 去重。

每个后项须增加尚未完成的目标工作。已完成的环节跳过；完整目标任务已涵盖恢复和推理时不再例行加图或总结。无提示选择本身是目标证据时先保存该表现，再给方法；允许查阅且仅需整合时可直接给前提，不规定检索先于生成。

说明前项会泄露后项什么操作、允许资源及时间条件是否相容。并排比较后的正确不能补记自主选择；隐藏答案不能撤销已经发生的暴露。只借卡片的示范或支架部分，就写实际采用范围和不等效处；卡片完整训练的延迟、新例和撤提示不自动成为额外课程债务。

`MethodConfig` 引用完整来源及修订，并把每个运行包必要条件映射到当前事实。必要条件变化时重新检查用途；改数字或措辞可以保留结构，也可能增加新前置，不能默认为等价。当前活动继续沿 D04 保存初答、帮助和修订，不复制一套策略执行记录。

## 替代、退出与局部返回

进展看目标操作、条件、连接或提示依赖的可观察变化；字数、连续答题和信心不够。没有统一失败次数。已有失配、反证或负担足以改变决定时立即调整；无新增信息的同类追问停止。替代须说明真正改变的表示、线索、操作、反馈或条件，以及保留和损失的证据用途。

暂时访问失败而给允许前提后能继续时，保留帮助后的推理；恢复本身未属目标就不强加闭卷债务。给前提后仍有具体关系障碍时，提出最小局部 Encoding 候选，保留父产物、卡点、已有支持、替代解释、够用条件、返回连接和预算。局部够用即回父任务；局部成功而父任务仍失败，重查组织、映射或诊断，不能无限下钻。

退出配置不必结束教学，可靠直接解释、合法查阅或目标任务仍可用。预算结束、用户暂停、方法无进展、材料争议和证据充分分别收束。仅缺未来时间条件就结束即时追加；沿原 `LearningNeed` 附方法代价与替代，由 SK05 处置，不能创建第二条“做某卡”债务或宣称已排程。
