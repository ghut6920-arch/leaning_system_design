# 具体问题：共同完成同一份接口说明

版本1；备课审查用。以下题目尚未向用户发作正式教学任务，不要求现在回答。允许一直查看学习材料，文字、表格、式子任选，不要求写程序。

## W1. 有支架地修订接口注释

沿材料 C 的保序逐帧轨迹，接口说明里有人写了这段注释：

> 8张图像经过逐帧处理后成为8行特征。既然输出仍属于这些原帧，图像信息就没有损失；逐帧处理时需要打乱顺序，再从特征值识别每行是哪一帧。

请保留其中成立的部分，修改不成立的连接。分别用本例中的一个具体事实说明：处理单位与行顺序怎样关联；来源对应与图像内容保留怎样关联。可以只写被你改动的两三句话，不重抄表格。

这段修订会直接成为 W2 的“逐帧编码说明”。如果你已能在整体说明中完成它，可以并入 W2，不另交一题。卡住可说具体哪两个对象分不清。

提交后若还在等待，可圈出自己用了哪一条流程约定、哪一条数值事实；做完即可停，回复到达后回到这里。

## W2. 将说明接到真正的接口交付

继续同一份说明，原输入和模块契约沿材料 A/B/C：

| 接口 | 要交出的组织与形状 |
|---|---|
| 视频模块 | `[B,C,T,H,W]=[2,3,4,2,2]` |
| 逐帧图像模块 | `[N,C,H,W]=[8,3,2,2]` |
| g的输出 | `[N,D]=[8,2]` |
| 序列模块 | `[B,T,D]=[2,4,2]`，同一视频内按原时间排列 |

已有的视频分组说明可直接复用，路线和shape也可查材料。现在补足一份能交给接入人员使用的说明：相机输入怎样分别成为视频输入和逐帧输入；逐帧结果怎样成为序列；哪些操作只改组织，哪一步改变可保留的图像内容；依据什么保证每个结果放回对应帧。

接入人员可能收到以下三个记录。B/T、批次、g和目标接口均相同；标签是外部记录，不占D。请把它们作为同一说明的条件分支处理，不交三份独立作业。

**记录 A**：已确认输出一一对应输入，行顺序仍是甲1至甲4、乙1至乙4。没有每行标签。

**记录 B**：输出行被换过位置；整行特征与可信来源标签同步移动，标签覆盖这批全部八帧且无重复。记录如下：

| 当前行 r | 特征 | 可信 `(b,t)` |
|---:|---|---|
| 0 | `[61,62]` | `(1,1)` |
| 1 | `[11,12]` | `(0,2)` |
| 2 | `[81,82]` | `(1,3)` |
| 3 | `[11,12]` | `(0,0)` |
| 4 | `[71,72]` | `(1,2)` |
| 5 | `[41,42]` | `(0,3)` |
| 6 | `[21,22]` | `(0,1)` |
| 7 | `[51,52]` | `(1,0)` |

**记录 C**：数值行与B相同，但来源标签、置换表、保序保证均未交付；仍知道它来自同一批两段各四帧，g仍是一帧一行。接入规范要求每行来源可追溯。可以查看教学表，但不可把这套人工数值规律当成真实数据自带的帧编号。

请在整体说明中回答这些接入问题：

1. A没有标签时能否交付？说明你实际依赖的条件。
2. B怎样把**全部八行**安排给序列模块？可列甲、乙分别需要取哪些当前行，也可写一个覆盖所有行的放置规则；说明直接改shape哪里会违背契约。
3. C能否确认每个现有结果行的来源？仅凭shape和特征值，在一般输入下能否保证正确来源？如果另有合法处理路线或可信依据，请说明它支持什么、还不能支持什么。不要把“无法保证”写成“所有数值一定错”。
4. A或B成功交付后，可以声称恢复了什么？可以由这些向量确定甲1原蓝色值吗？请给依据。

一份说明可采用以下骨架，也可自行组织：

> 相机输入……；视频接口……；逐帧接口……；g改变……而来源对应依赖……；序列交付遇到A……，B……，C……；交付结果可以保证……，不支持……。

骨架提供表达位置，没有填入这些条件的结论。原目标允许资料，本任务是开卷整体应用与候选条件选择；刚看过示范的影响保留，不声称广泛无提示迁移。

提交后若还在等待，可只标出说明中一处“来自模块约定”的依据与一处“来自来源记录”的依据；做完即可停，回复到达后回到这里。
