# 开始、恢复与收束

这是 SK00 的日常文件路径，遵守 [共享契约](../../../../contracts/shared-contracts.md)的含义。使用所在课程的真实资料；开发夹具、方法研究结果和大纲建议不属于个人学习事实。

## 辨认用途与授权

持续学习读取所在目录的控制、当前状态和计划引用，再加载 AG0 与当前专业 Skill。稳定活动不反复读全库；重要复核、冲突、内容变化或未覆盖方法才回相关原件。一次性讲解直接完成，用户要求纳入课程时才走其持久记录路径。

“开始学习”或已授权的启动提示词表达了开展相应教学的意图；旧“仅导入”状态不是永久禁教。按实际请求更新本次可做范围，保留此前未发生学习的事实。宿主权限仍需真实可用；缺程序授权对象不等于用户没授权人工教学，也不能伪造已绑定的程序授权。

## 从内容到本次入口

先区分请求尺度。**课程／单元启动**先引用或形成课程粗地图及本次连贯安排，按 [多尺度计划](../../learning-planning/references/multi-scale-plan.md)接上近期整体，再用 [内容准备](../../learning-teaching/references/design-whole.md)备好主要材料、示范、实际任务／问题和反馈依据；不能把它退化成临时开始一道小题。**一次性解释**按请求范围直接讲，不硬加测验。**已有安排恢复**沿原主线、实际帮助与断点继续，充分部分复用；只有旧安排缺当前整体连接时补那部分，不重建全课程。

学习单元沿同一理解目标和整体工作跨轮保持，按内容准备的认知工作、实际选法及连续推进要求执行。旧活动只有局部题时复用事实但补齐单元安排；新单元必读SK06所需选法和Post功能，不能以已有旧范例跳过。用户说“继续”是沿主线推进；正常教学不等待这句才展示下一份已备内容。

1. 确定当前内容和用途。新课程只取粗地图及近期片段；系统建议的近期目标按 [目标规则](../../learning-goals/references/goal-design.md)回对用途及必要知识联系，不只检查题目是否满足自定目标。已有有效且适用目标沿用。方向清楚、正式判据未落实时，可以先开展可靠限定探索，正式通过保持未裁定。
2. 用 [SK03 内容准备](../../learning-teaching/references/design-whole.md)从目标所需的理解及联系设计本次主线；[SK02](../../learning-materials/SKILL.md)落实主线核心输入、示范、备用帮助、具体问题与教师参考的用途核验。复杂任务备足整体审查依据，普通活动只备必要分支，不要求所有未来内容。
3. 根据已有事实选入口：相关真实作品先检查；缺必要对象说明或请求示范时先 [Encoding](../../learning-teaching/references/encoding.md)输入；前提够用、错误可定位且后续讲授可靠时可保留短尝试；已有合格活动直接执行。未知基础不自动触发测评。
4. 第一条教学回复简短说明本次目的、主要内容及最终工作，随后展示一段建立对象和关系的讲解、恰当范例／表征或已备任务；后续核心内容已有实际依据，按节奏呈现。图、式、代码按功能选；静态够用不强做动画，没有实际展示的材料不写已呈现。
5. 按 [C0](../../learning-teaching/references/c0.md)根据真实表现反馈、使用支持并调整，再接主线内已备的材料或工作；局部补充后回同一产物。只在需要学习者贡献或真实停止条件成立时等待／收束；纯讲解不为了制造证据安排必修小题。

时间、设备和先验只补影响可行性的缺项。缺确切预算可开展已授权、随时可停且主线已备的有限输入／探索，时间保持未知；不承诺完整证明、实验、付费调用或整门课程。不能以预算未知省去本次主要内容设计。三问、两张卡、固定间隔或统一深度阶梯均不作门槛。

## Post 与选法

先明确当前要恢复、协调关系、自主选用还是条件更新，读 [Post 功能入口](../../learning-teaching/references/post-encoding.md)。提供允许前提后能继续的，保留帮助并继续；前提可用仍不能连接时，保留父任务、卡点、替代解释、局部够用条件和预算，有限 Encoding 后返回。

需要重新选法时读 [SK06](../../learning-strategies/SKILL.md)及候选完整正文；缺编译包可按规定回原卡，不能凭标题执行。整合不固定由检索解锁，模块往返不重置暴露，不新增父任务或第二份复习队列。

## 反馈与必要保存

按课程记录约定保留实际任务版本、原答／作品位置、关键帮助及先后、修订、必要时间与停止点。有文件能力时原答先保存并读回再反馈，AI 整理稿另存派生位置。无工具或保存失败时，先保留当前可得原话／原版本，交出明确标为待保存的原答正文或现有作品定位，再给反馈；原答与反馈分开，缺失的正文不据摘要补造，不等用户手工保存后才继续普通帮助。正式复核仍需取得合法可回查原件；不能把待保存说成持久记录。没有原答可记实际讲解／展示，不能生成表现事件。

代码、证明和报告引用实际定位与版本；整体作品持续维护，AI 与用户贡献可辨，修改前保留复核需要的用户版本。普通反馈不逐题改目标、发计划或造回执。简单反馈说明具体结果、必要依据与下一动作；复杂论证按需要展开。可选等待动作复用已有任务，不提前泄露待检答案，不增加必修负担。

人工保存用单入口顺序写入并读回，不具有 SQLite 事务或跨聊天锁。失败区分实际发生、已保存、待保存，控制／版本变化后重读再决定；无文件能力交出待保存内容和位置，由有能力者确认。

## 继续与跨模型接任

常规继续先读限制和有效安排，再定位目标／判据、有效判断与材料用途、原答／父产物、帮助时间、断点和未决责任。预算变化后重定范围，稳定部分复用；重要跳过、整体结论和评分争议必须回原始依据。

| 上次停止原因 | 这次具体处理 |
|---|---|
| 预算结束或正常分段 | 接可信父产物尚未完成的连接，复用已完成部分，保留整体标准 |
| 突然中断，无摘要 | 从最后确认事件和现存草稿恢复；未记动作未知，仅补影响入口的缺项 |
| 同一帮助无进展或诊断有反证 | 重审任务、接口和解释或换路，不重复原提问与无限下钻 |
| 内容／判据争议 | 相关用途和确定评分仍受限，核验后按依赖分别恢复；无关可靠工作可继续 |
| 当前目标条件已有充分支持 | 结束重复投入，按有效安排进入下一项；只跟进目标内必要未来条件 |

接任短记录表达当前版本、父产物、实际帮助、未完成连接、限制、资源、下一步和停止条件即可。换模型不重置暴露，摘要不增加样本；普通恢复不全章重测。

当前会话可顺序兼任职责；其他执行者按实际授权与宿主能力交接。确认旧执行停止该活动面向用户教学、新执行明确接任后再继续提示；文件锁或代次不等于关闭旧聊天，无法保障时用单入口。收到、接责、专业采用、进入计划是不同事实，兼任无需模拟通信回执。发起责任跟进未接部分，用户不负责催四个 Agent。

## 控制、纠错与收束

- 为什么这样学／看依据：解释本次工作与目标、已有支持的关系。拟检查自主选择时，先说明观察什么能力，保留具体判别线索；用户要求先看完整理由或参考时满足，并将之后被代做的部分转为帮助后的教学，不以保护测评为由拒绝其有权查看的内容。
- 少讲一点／不用图／换文字：形式不是目标时，用同用途合格表示，保留条件与对应关系；若从公式构图、写代码或跨表征转换正是目标，说明该部分暂未覆盖，可提供支持后继续其他合格工作，不暗改判据，也不把一次偏好写成固定学习类型。
- 暂停立即停止新增任务，保存已有产物；继续可解除用户暂停，仍有效专业限制保留。缩时只缩承诺，正式目标不暗改；超出授权的用途、范围取舍或新增投入交用户决定。
- 要答案或示范可以提供，保留帮助前原答并改变后续证据解释；跳过检查可继续合格教学，未取得的能力证据未知。下一活动确实依赖该未裁定结论时，说明限制并提供不据此作重要跳过的受限路径，不能默认该能力已具备，也不惩罚其选择。
- 异议先定位疑点与原答，限制相关确定结论：AG2 核内容，AG1 核判据影响，AG3 重评，AG0 修复实际误导，计划职能处理安排。沿内容链和要求链回查，原答够用直接重评；材料、历史判断、教学影响和计划分别恢复，系统错误不变为用户欠课。
- 查看按请求定位，避免附带教师参考；导出只取指定合法范围及必要条件，仅摘要时说明不足以独立复核。删除先停用，再清理可控原件、摘要、派生与临时副本，按剩余支持保留／收窄／撤销；不从迟到结果、指纹或旧上下文复活，实际控制边界如实报告。受删内容已在上下文时停止该依赖，以剩余合法资料建立后续上下文，不能虚称宿主历史已清除。
- 够用、暂停、预算结束、无有价值新观察或必要依据缺失时收束。交出真实完成、条件化支持、未完成连接、停止原因、恢复点及同一必要需求的实质去向；未安排明确写未安排。无目标要求的保持／迁移不新增债务，计划日期不算学习发生。
