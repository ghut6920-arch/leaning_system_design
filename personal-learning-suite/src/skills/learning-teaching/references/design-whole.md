# 关键设计与连续整体产物

AG1 对目标内关键 ActivitySpec 负责；AG2 核内容，AG3 核证据用途。设计候选、声明检查、专业采用、执行和目标支持分别成立。自报 AG1 或 design 模式不扩大授权。

## 先把内容准备成可教的安排

依据 D02 第三／八节、D03 第四至七节、D04 第二／四节、D05 第二至六节、D06 第二至五／七节及 D08 第二／四／五节；R01 第5、7、9—10节、R04 的任务匹配和 R05 第4—5、9、12—13节限定内容、顺序及证据解释。已有可靠安排可复用，已有作品可直接分析；未准备单元由教学方先完成下面的实质判断，不把填字段当备课。

### 课程／单元启动：先备好本次主要安排

用户要求开始课程或一个学习单元时，在第一次教学展示或提问之前，先完成本次学习的主要内容设计。课程粗地图说明方向与整体用途，本次安排落实近期要形成的理解、核心材料、主要任务及问题、反馈与下一连接。准备充分指本次主线可以连贯执行，不是只备好第一道题。一次性解释按其实际范围直接完成；已有合格安排或完整作品按原件恢复，不重新冷启动。

**单元由理解目标划定。**一段学习围绕同一组待建立／使用的关系、条件和整体工作组织，可以跨多轮、跨会话；聊天轮、当前题、一次反馈和预算中断均不自动成为新单元。课程启动先确定一个能说明用途、主要连接和完成条件的近期单元，再决定本次推进多少。引用课程目录或将若干字段合成一份短答，不能代替这个判断。真正只需一个事实的目标仍可很短；预算未知时也可分段，但保留单元终点与已准备的后续连接。

**从理解要求选择内容与工作。**先继承目标及允许资源，读清对象、概念、关系、条件和整体用途，再明确此次需做到准确辨认／使用、关系解释、条件判断、一般推导、综合实现或实验解释中的哪些工作。按需注明关系方向、中间连接、适用边界、时间变化或图式／代码对应。它们是具体内容要求，不是统一深度等级。Encoding 为建立这些关系准备输入和示范；Post 为目标需要的恢复、区分、整合、选用、应用或更新准备工作，两者可在同一主线中交替，不固定先后。

把目标要求接到“要建立／使用的知识联系 → 实际材料及其教学功能 → 留给学习者的具体工作 → 参考与反馈 → 整体返回”。例如目标需要判断条件变化，只有定义和重复计数不够；目标只要求术语对应，则不追加一般证明。理论要求由目标决定，当前展开与本次覆盖可以随表现及资源调整，不能因短答易执行而改写原要求。

**以认知工作检验备课。**在现有目标／计划中说清学完要能够作出的判断：解释哪条关系、依据哪些条件、怎样把局部接成整体，以及当前为什么值得建立这些认识。每份主要材料和任务都要对应实际加工：辨认对象、追踪转换、补合法理由、比较诊断差异、保持不变量、条件选用、推演或综合；说明AI已提供什么、学习者仍需承担什么、参考如何核对。讲解可以直接提供完整理解基础，不能机械要求每个概念都答题；但只换数字、轴号或措辞的操作不自动覆盖解释、选法和整体目标。若原目标需要这些工作，必须在同一主线中备实际内容和任务，不能全部写成未知或“将来可观察”。

**把目标选择与目标内准备分别检查。**先按 [目标规则](../../learning-goals/references/goal-design.md)回对原用途与正文，确认系统提出的理解要求及合理暂缓；再检查材料和任务是否充分承担这些要求。已有目标仍适用时复用。给定模型的计算／审计合格，不自动代表结构取舍、学习作用或设计能力已准备；发现用途所需连接未入目标时交AG1处理，材料功能不足时与AG2补齐，不用新增限制声明掩盖目标内必要输入缺失。

材料正确性和实际教学功能按 [材料核验](../../learning-materials/references/domain-checks.md)分别确认。必要关系应在具体解释、推导、示范或合法对照中可跟踪，题面应留下目标要求的关键判断；这不要求所有对照都改变结论、每个概念都答题或所有课都增加训练／实现。典型“正确且齐全但功能不足”的处理见 [备课质量实例](preparation-quality-examples.md)。已有说明确实承担该功能即可复用，不为凑实例再造材料。

**备课阶段实际接入策略。**新课程／单元、旧安排缺认知工作或需要改路时，读取 [SK06选法](../../learning-strategies/references/selection-adaptation.md)，按具体工作定位策略索引，再读实际采用的完整Encoding卡包；同时读取 [Post功能](post-encoding.md)，决定该单元需要哪些恢复、整合、选用、应用或更新，读所选完整Post包。不能因尚在“新学”就跳过必要的Post，也不能只读概述后笼统声称调用策略。稳定安排已完成这些工作可复用，不逐题重新遍历库。

采用的资源在已有教师安排中保留资源键／正文位置、实际读过的版本或指纹、借用操作、本题如何实例化及反馈／返回。直接教学可以不借卡，但须给出同样具体的内容依据、认知工作和选择理由；有合格卡仍只凭默认“示范→改数字”覆盖整单元，不能交付。源版本与实际正文读取是调用证据，卡号、文件存在或compiled标志不是；人工文件不必为了记录调用创建MethodConfig数据库或审批回执。60张卡已全量编译，按需选取，不要求一次读全库或固定采用数量。

本次安排复用现有目标、材料、活动和计划，可在原计划中用短说明及链接组织，至少落实：

- **主线与终点：**本次学什么、为什么从这里开始、要理解哪些知识及联系，形成什么工作或产物；小活动属于哪里，完成后接到什么。仅写“随后按情况实践”仍缺下一连接。
- **可用核心输入：**确切片段或实际写出的讲解、连贯范例及按功能选择的图／式／代码。主线必需内容在展示前取得用途所需核验；只有书目、待制作清单或“需要一张图”不算就绪。多模态成品须检查其实际内容与行为。
- **主要任务与问题：**提前备好本次需要的实际题面、数据、条件、允许帮助，以及可接受答案／合法多解和反馈依据，说明它们各自承担什么理解工作。纯讲解无需问题；需要连续证明、实现或综合解释时保留同一整体产物，不以逐项问答数代替。
- **支持与改路：**准备会改变下一步的必要支持，说明出现什么表现后跳过、补充、换表示或返回哪一连接。意外困难可出现后再补材料，不需要穷举所有回答或逐轮话术。
- **范围与结束：**本次资源边界、完成／停止条件、未覆盖要求与恢复点。保持、陌生应用等未来要求只在目标需要时保留其条件与后续触发，不假称本次已经支持。

**预算未知仍须有主线。**可选择已授权、有可靠输入、范围明确且随时可停止的一段学习；预算保持未知，不虚构分钟数或承诺整课完成。需分段时保留近期整体及返回点，不能把“开始学习”改成一道自立短答再宣称主要安排已完成。

AG1 组织主要安排，AG2 落实核心材料和参考，AG0 确认可执行后呈现，AG3 按目标及实际帮助解释表现；同模型可连续完成，不增加审批。核心部分尚未就绪时先补齐；只有原用途的明确子范围可靠时，说明本次暂覆盖哪里及未完成连接再开始，不掩盖材料缺口。

首次教学回复简短交代目的、主要内容及最终工作，随后实际展示第一份输入／示范或合格任务。教师已备的后续问题和答案按用途逐项呈现，不一次倾倒全部材料，也不只回复课表或“准备好了”。检查自主选法时，路线说明不代做待检查的选择；用户要求完整依据可转教学。

### 沿已备主线持续教学

学习者已经授权开始该单元，普通作答后给必要反馈，并在同一回复接上已准备的下一份材料、解释或有认知价值的整体工作；局部成功不将整段课收束成“正确，下一步可以……”。在需要用户原答、作品、选择或可行入口信息时等待；其余授权内的讲解和材料展开由教师推进，不把“继续／是否继续”设成每道题后的开关。一次回复可连贯覆盖若干必要关系，再留下自然关联的工作；按理解、负担与资源调节，篇幅、题量和“忙碌”均不作质量标准。

用户说“继续”时先沿原单元及作品恢复；若原安排只有局部题，复用已发生内容和原答，先补齐单元认知主线、必要策略及后续实际材料，再推进，不重新从第一题开始或更换父目标。说“看懂了，推进”可减少支架或跳过重复检查；未完成的目标内连接在后续整体工作中自然承担，不强制用一串微测验补偿。

反馈后有局部障碍时，补的对象、理由或对应必须回同一作品；已经正确部分保留。到单元目标内工作足够、用户暂停、预算实际结束、依据不足或无有价值进展时才收束。未知预算不等于每题强制停止，亦不据此虚构剩余时间。纯解释满足请求可结束；用户明确要求只反馈则只反馈。跨单元的新要求、额外费用或设备操作仍按原授权边界处理。

原答及关键帮助先可靠保留；规则、目标、参考和已选策略稳定时复用。单元断点或重要变化再合并必要索引，不把每次普通反馈当作重建目标、控制、计划与整套状态的阶段结束。来源或代码确需核验时做实际检查，不能把重复文书当作认知工作。

### 收束保留目标内工作，并接到实际用途

把材料已经展示、教师解释已经交付、学习者完成的关键操作和目标获得的支持分别说明。AI给了完整路线、推导或逆映射，可以结束这一讲解段；它不自动完成原来要求学习者组织／解释的工作。收束用简短说明交代学习者已完成的部分、教师补充的部分、尚未完成的连接和下一可执行位置，不向用户倾倒评估表。

目标内确需而尚未完成的认知工作，沿原目标和整体作品交SK05，落实到已备的自然应用、原作品修订或明确的暂缓条件。仅写“未知”“将来可观察”“继续时再想下一题”不足以完成交接。后续工作实际调用所缺的连接，允许资料条件沿原要求；不机械要求复述已给答案，不新增固定复习债务，也不把教师整理稿当用户能力证据。用户只要讲解、暂停或改变用途时保留相应边界，不无限追加检查。

首次作单元整体支持结论、重要跳过或关键未完成取舍时，读取 [AG3职责](../../../agents/AG3-assessment.md)及SK04所需整体评审规则（稳定已读内容可复用）。按原任务、原答和实际帮助核每项关键工作，再由AG1维护安排、AG0执行；单模型可顺序兼任，普通局部反馈仍无需全员会签。读角色文件、履行职责和启动独立Agent是不同事实，不为了凑齐角色自动增开模型。

理论与实际应用围绕同一对象及接口准备。当前工作纸面即可开展时不因环境未知停教；近期用途若需要实现／观察，提前取得一份规格明确、可执行并按用途核查的小输入、代码和参考，保留何种工作交学习者承担。教师运行、用户运行、实现、测试选择及实际模型效果分别记录。后续消费者可先作为黑箱给明确输入输出与成立条件，按目标需要展开；不把形状恢复、信息保留或程序通过直接解释为真实动态建模已学会。

### 把本次主线落实到内容

**沿原资料读清一个有限单元。**明确它解决的用途、实际对象、必要定义、关键关系、条件／边界和应形成的整体产物。保留定义／证明／程序的必要上下文。目录与主题名只能定位候选；不能仅由“学习视频张量”生成名词测验。

**辨认当前所需前置。**哪些必须由学习者现在完成，哪些允许教师提供或查阅，哪些与本次无关可暂缓。缺对象含义就补对象，缺规则就给必要规则，步骤组织陌生且有可靠路线时提供连贯示范；用户请求解释／示范时直接提供。“初学”本身不要求所有定义重讲或整套示范。相关经验不明但不影响输入，可边学边观察；已有可用前提时，也可用有界尝试接后续讲授。已有作品足以判断的部分直接复用。只有几种起点会导致不同活动时才补诊断。

**准备材料与可核验范例。**现有可靠材料足够就使用；缺项交 SK02／AG2，具体指出缺哪条关系、条件、范例、图式映射或完整参考。按 [领域与对象核验](../../learning-materials/references/domain-checks.md)核必要内容；图和代码应有可检查的实际成品与行为。材料与教学可以一起准备，但教学设计不替代内容核验。

形式取舍与呈现不清时，按 SK02 的 [材料功能](../../learning-materials/references/materials-workflow.md)及 [实际实例](../../learning-materials/references/materials-examples.md)取得当前入口、备用支持和教师参考；将它们接到当前学习者操作，不能只交“待制作的图／框架”。合成现有对象的短视图及复杂目标展开见 [目标实例](../../learning-goals/references/goal-worked-design.md)，该视图不另存能力或需求。

| 内容准备的需要 | 当前可用材料／操作 | 留给学习者的工作 |
|---|---|---|
| 还不知道对象与整体用途 | 有限任务地图、必要定义、带语义标注的例子 | 定位对象及连接，使用已提供信息；不要求从空白自行画完整框架 |
| 步骤组织陌生，有可靠路线 | 连贯完整示范，再按已有表现提供部分范例 | 逐渐承担对应步骤、理由或选择；观看不等于独立执行 |
| 条件或适用边界是关键 | 合法对照、近例／非例、信息不足情境 | 据条件接受、拒用或指出未定 |
| 结构／变化难以看见，或转换本来是目标 | 静态图、关系表、公式／代码轨迹；动态操作确有增量时才用交互 | 解释映射、预测变化或转换；AI 画图不代替目标构图 |
| 目标需要综合实现、证明或论证 | 原完整任务、正确性锚点及必要中间支持 | 保留连续产物，完成关键连接／接口；不改成孤立题的通过数量 |

**把准备结果交成同一份可执行视图。**引用现有目标、材料、活动和计划，交代生效范围与预算、当前依据及未知、为何这样开始、实际输入／示范、学习者剩余工作及允许帮助、可靠反馈锚点、会改变安排的分支、够用／停止与父任务返回。可以是一段话连同一份材料，不强制新表单。执行者需要的依据与学习者当前应看的材料分开；教师参考、诊断线索和选题理由不自动展示给正在作自主选择的学习者。

本次主线的必要内容正确且可用、主要工作及问题已有具体依据、反馈／返回可执行、范围与授权支持，准备就够用。不要求提前备好全课程或所有分支；远期与意外分支未就绪不等于可以把本次主要材料及问题留到每次回答后临时决定。准备反复无新增信息时汇总具体缺项与影响，停止循环索要方案。

执行后依据实际表现调整主线中的支持、顺序、深度和覆盖，说明哪项内容或新表现促成改变。稳定部分直接复用；局部够用回原工作，整体已足够则结束。仅有小活动的旧安排在课程／新单元启动时补齐必要连接，已有连贯安排的日常反馈不重新备课。正常实例见 [教学实例](teaching-examples.md) 的“首次单元的完整备课”。

首份局部贡献只说明其实际调用的操作，不能证明后续不同推导或表征的前置已可用。较长示范可沿同一父任务分段呈现；必要符号、规则和表示对应直接给足，在需要关系判断或整体组织处再交回工作。预备新增操作及对应支持，已有表现支持的组件少讲或跳过；未知基础不强制全量诊断，也不因一跳正确就一次撤掉全部支持。跨度是否合适由实际使用和支持后的返回检验，不能仅凭材料篇幅判定。

需要把原则落到正常课堂时参考 [教学实例](teaching-examples.md)；示例是教师设计依据，不是必须给每个学习者的固定课程。

## 保留完整任务

目标要求一般证明／模型构造／长代码时，教师须有足以审完整工作的依据；只有局部参考就标整体实施条件缺失，可靠局部可另在原目标子范围内教学，不降整体标准。

完整产物保留在原件，初答与修订分开。整体审查须覆盖目标的前提、接口、对象域／分支、结论或实现约束；不能以各小题通过、数值运行、模板外观、字数或新颖证明一般正确性。合法不同路线、反例和有依据的拒用交具体内容核验与重要复核。

活动 `metadata.b4.whole_required=true` 时，列整体义务和确切 `whole_reference_refs`。引用的 MaterialUse／SourceFragment 必须有当前 `verification.content.whole_coverage` 声明：supported、覆盖 target_operations 与 obligations、合法原件 anchor_refs。程序检查声明和依赖，专业正确性仍须相应责任实质核验。`review_whole` 返回连续原件和真实帮助的 AG3 重要复核候选，不直接判整体通过。

设计通过之后仍须 C0 核当前 MaterialUse 的具体活动修订绑定、执行授权、配置与预算。活动修订后材料用途需要对应核验；设计保存不能替代 AG2 更新。现有证据短路径使用 `reuse_evidence`，调用 B3a 复验既有采用判断；依赖受限、陈旧或目标时间不满足时交已有原答检查，不自动新测验。
