# B4 实现与独立复核记录

日期：2026-10-03；所有程序输入、答复、帮助、授权、费用和时间均为人工夹具。复核支持开发行为和规则转译，不支持真实个人学习效果或完整 B10／V1—V4。

## 核查责任与实际产物

主代理负责专项执行器、计划交界修正、契约和交付整理。独立代理 `teaching_tests` 提供教学测试／演示初稿，`planning_impl` 提供计划运行器／测试初稿；主代理继续完成其余实现、复验失败及接口修正。独立代理 `b4_requirements` 核路线、正式资料及两个运行器，并进行只读代码复核和 Skill 前向候选试用。各代理共享文件，但最终复核未修改项目；测试与后续修正的作者并非完全独立，结果按此限定解释。

共享对象与 `pl-contracts/0.1.0` 沿用 B0；数据库、原件、控制、授权、采用、CAS 与幂等沿用 B1；材料用途沿 B2b；资格、帮助／接触时间与 Judgment 检查沿 B3a／B3 联合修复；同题事件和收束沿 C0；B3c 策略配置仍独立复验。不创建第二套对象定义、掌握账、复习队列或数据库。

## 发现与修正

1. 整体活动不能自行把 `whole_required` 设假。AG1 当前 GoalSpec 的 `teaching_scope` 承载目标级义务；整体参考须绑定当前目标、判据、操作与义务。缺项停止对应范围，局部子任务不得取消整体目标。
2. 进入局部后返回必须引用进入之后的新原答／修订，保持同一事件和样本；局部范围不能在嵌套中重新扩大。返回点明确相同，父任务与整体支持仍需后续实际观察。
3. 证据复用不能采用候选 GoalSpec 或过期／受限 Judgment；B3a 实际检查选定响应点的帮助与最近接触。昨日反馈不能被较早事件时间掩盖。
4. 计划执行准备不能跳过 C0 或专项的实际门禁；保存的同预算 C0 累计时长形成耗用下界，不能重置为零再次安排完整额度。
5. 简单需求关闭允许 AG0 的合法 routine_scoring，保留 AG3 重要复核边界；关闭目的与原材料用途分别检查，必须给原 `material_context`。
6. 三分钟比较曾受浮点误差影响，金额与时长比较保留小容差；正常合并后的终结需求不继续列入活动计划的 live need_refs，从而允许合法缩时。
7. 最终独立复核复现：AG0 缩时减少主动时间却可新增费用／等待／系统工作。修正逐个比较三类非用户成本，不许超过原 allocation；资源增投交 AG1 正式重排。
8. 最终独立复核复现：整体要求可映射成局部要求后合并，导致待办消失。当前限定同目标要求 ID 恒等映射，目标需求必须完整包含源要求；不同 ID 专业等价关系留给后续设计。

后两项先添加负向用例，在修正前实际观察到错误 committed；[修正前原始输出](b4-planning-boundary-before-fix.txt)保留 2 个测试、4 个失败子情境（合并与三类成本），最终行为结果见[完整报告](b4-all-runtime-report.json)。受拒绝请求必须不改原需求／承诺。

## Skill 前向观察

[实际代理输出](b4-skill-forward-output.md)使用加权均值人工案例：已供给总分后仍除以组数，提最小 Encoding 候选、保留帮助条件和同一事件，局部够用即回父任务。只有算例不能承诺一般证明；未知完整成本不能声称三分钟可执行；仅缺未来目标条件时结束当前教学并交同一需求候选，无回执不写已安排。它没有新增学习者答复、判断、记录或正式计划；不是实际教学效果验证。

两个 Skill 标准结构检查结果另见[校验报告](b4-skill-validation.json)。相对依赖沿套件布局，七 Skill 未安装。实际显示、学科真伪、身份、成本和微缩教学等效不由这些检查证明。
