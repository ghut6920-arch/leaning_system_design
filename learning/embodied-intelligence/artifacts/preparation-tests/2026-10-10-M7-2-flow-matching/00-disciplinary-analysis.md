## 1. 保留原用途：这个桥要接到哪里

课程 M7.2 的原用途是理解“噪声到数据路径、条件向量场、期望回归、ODE／Euler、时间方向”，并完成 2D conditional FM、比较步数带来的采样误差与成本；它连接 M1 的导数／期望、M3 的回归训练、M6 的条件分布，后接生成动作头和 DiT。建议学时 10 小时只是原大纲候选，不能视为用户已采用的本次预算。当前学习记录停在 M0；这不证明学习者已具备 M7 前置，也不构成拒绝本次备课的理由。

这个单元的核心问题是：只有条件数据样本、无法直接计算复杂数据密度和正确生成速度时，怎样构造可采样的局部监督，训练一个共享速度预测器，并在不知道目标样本的推理阶段把随机噪声推送到所需条件分布？

难点不只是求出一条直线的导数。逐对数据给出的速度可能冲突；训练时知道的数据端点在生成时未知；网络预测的是当前位置的局部速度，采样器才把速度积成轨迹。理解这些关系，才能辨认“速度标签／边缘场”“训练／生成”“数学生成性质／实际学得好”“模型误差／积分误差”。删掉其中任意一条，仍可以抄出代码，但无法解释它为什么是生成模型或哪项实验结论可信。

本次必须建立完整连接：数据与噪声 → 可抽样的中间状态和速度监督 → 期望回归 → 共享边缘速度场 → ODE／Euler → 条件生成分布 → 误差与成本解释。连续性方程用于教师的理由核查；完整测度论、全套 OT、SDE、likelihood 计算及 CFG 留作明确接口或后续，不悄悄替代原用途。

## 2. 对象、约定及两种“条件”

统一采用 t=0 为噪声、t=1 为数据。图像／视频或动作的物理时间另用 k；离散积分步另用 n。生成时间 t 是人为的概率路径参数，不能读成“机器人走了 t 秒”。一个 action chunk 可整体成为 x，其内部 k 轴不会被积分循环的 n 轴替代。

| 对象 | 本单元含义 | 已知与未知 |
|---|---|---|
| c | 推理时可用的任务条件，如类标、观测或目标 | 数据集提供 (x₁,c)；生成时 c 已知 |
| X₀／ε | 从简单先验抽取的噪声随机向量 | 训练和生成都能抽样；此处 N(0,I) |
| X₁ | 数据端点随机向量，分布 q(x₁∣c) | 训练可抽数据；新生成时不知道它 |
| X_t=(1−t)X₀+tX₁ | 独立端点配对的训练插值 | 同一对端点构成一条路径；跨样本构成概率路径 |
| U=X₁−X₀ | 该插值的样本导数 | 是训练监督；不是已经求出的边缘速度 |
| u_t(x∣x₁) | 给定特定数据端点的条件速度 | 线性路径且 t<1 时为 (x₁−x)/(1−t) |
| p_t(x∣c) | 固定任务条件、把具体端点平均掉后的中间分布 | 一般只有样本，密度积分不易计算 |
| v*(x,t,c)=E[U∣X_t=x,t,c] | 固定 x、t、c 后对兼容端点的条件均值 | 本单元需要的边缘场；仍以任务 c 为条件 |
| vθ(x,t,c) | 网络给出的速度向量 | θ 是可训练参数，输出维数与 x 相同 |
| Y_t | 从新噪声初始化后解 ODE 的生成轨迹 | 不带训练数据端点 X₁；一般不重走某条配对直线 |

“endpoint-conditioned”是按特定 x₁ 构造教师的路径／监督；“task-conditioned”是网络在生成时以 c 为输入。CFM 名字中的 conditional 不自动表示任务条件训练。未带 c 的 CFM 也可训练无条件模型；带 c 的网络也仍须把具体端点边缘化。

原论文 FM 的生成理由及 CFM 梯度等价分别位于 §3.1/Theorem 1 与 §3.2/Theorem 2；MIT 2025 讲义把 Euler、边缘化和 CFM 分别定位到 §2.1/Algorithm 1、§3.2/Theorem 10、§4.1/Theorem 18，任务条件位于 §5.1.1 式 (63)–(64)。[原论文 v2](https://arxiv.org/html/2210.02747v2)，[MIT 讲义 v2](https://arxiv.org/html/2506.02070v2)。

## 3. 为什么逐样本导数能成为生成监督

以下是根据给定定义独立展开的推导。它不把来源的结论换成口号，也不要求学习者先证明全部分析定理。

### 3.1 从端点到监督

固定一次抽取的 x₀、x₁，对 t 求导：

\[
x_t=(1-t)x_0+tx_1,\qquad
\frac{d x_t}{dt}=x_1-x_0=u.
\]

这里“固定”只用于求该对端点的路径导数；总体训练中 x₀、x₁、t、c 都按规定抽样。对给定 x₁，X_t∣x₁ 是 N(tx₁,(1−t)²I)，在 t<1 时可由 x₀=(x−tx₁)/(1−t) 消去初始噪声，因此

\[
u_t(x\mid x_1)=x_1-\frac{x-tx_1}{1-t}
=\frac{x_1-x}{1-t}.
\]

代入 x=x_t 得 u_t(x_t∣x₁)=x₁−x₀。生成网络不把 x₁ 当输入，监督构造却可以使用训练端点；这不是偷看推理答案。

本课线性公式取端点残余噪声为零。原论文 §4.1 式 (20)–(23) 使用 σ_min>0，对应 x_t=[1−(1−σ_min)t]x₀+tx₁、u=x₁−(1−σ_min)x₀。本课程 σ_min=0 的改写需标注：条件密度在 t=1 退化为点质量，不能把含 1/(1−t) 的式子直接在 t=1 代入。t 连续均匀抽样时端点是零测集；代码用样本导数 u，Euler 在 t_n=n/N、n=0,…,N−1 求场。在本文 Gaussian 主例中，边缘分布在端点仍平滑且 oracle 场有连续延拓。

### 3.2 为什么是“当前位置的条件均值”

设 S=(X_t,t,c)，m(S)=E[U∣S]。任意可积候选 f(S)：

\[
f-U=(f-m)+(m-U).
\]

条件期望中的交叉项为

\[
E[(f-m)^\top(m-U)\mid S]=(f-m)^\top E[m-U\mid S]=0.
\]

于是总体风险

\[
L_\mathrm{CFM}(\theta)
=E\|v_\theta(S)-U\|^2
=E\|v_\theta(S)-m(S)\|^2
 +E\|U-m(S)\|^2.
\]

右侧第一项是本路径相应边缘场的 FM 风险，第二项是目标的条件方差总量，与 θ 无关且非负。故优化方向在总体期望下相同；有合法微分交换时两者参数梯度相同。它不表示单个样本的 loss 相等、每个随机梯度相等，或训练误差应当降至零。CFM 中存在不可消去的标签方差；网络容量不足、有限数据、优化未收敛时也未必得到精确 m。

使用条件：U 有有限二阶矩，f 平方可积；路径／端点耦合／t 采样及监督不依赖当前 θ；两目标对相同 S 分布定义；梯度可交换期望（例如合适可积支配条件）。如果采用 θ 依赖的端点配对或路径、只比较不同加权风险、或改用了另一种损失，不能直接借这条等价。原论文 Theorem 2 另以正密度表达目标，Appendix A 给出积分与微分交换的充分正则假设；这些是数学条件，不等于学习者必须先通过实分析考试。

为什么不是对所有 u 直接平均？因为网络要预测固定 x,t,c 处兼容端点的速度；抽样概率随 x,t,c 改变。用所有端点的无条件均值会抹掉位置信息。

### 3.3 条件均值为什么推动整个概率分布

对光滑测试函数 φ，利用插值的导数、链式法则与可交换的期望：

\[
\frac{d}{dt}E[\phi(X_t)\mid c]
=E[\nabla\phi(X_t)^\top U\mid c]
=E[\nabla\phi(X_t)^\top m(X_t,t,c)\mid c].
\]

右式正是速度 m 推动分布时的弱形式质量守恒关系；存在密度与相应正则性时，它写成

\[
\partial_t p_t(x\mid c)=-\nabla_x\cdot[p_t(x\mid c)m(x,t,c)].
\]

若用同一初始分布解 dY_t/dt=m(Y_t,t,c)，且相应 ODE／输运问题有适当存在唯一性，就得到 Y_t 与 X_t 的各时刻分布相同。相同的是分布，不能推出每个 Y_t 都等于某一条训练配对线，或网络每次直接选好训练数据端点。固定 c 及新噪声后，ODE 轨迹确定；换初始噪声仍可产生多样样本。

## 4. 代表任务 A：一条数据产生一次可核的参数更新

代表任务保留数据来源到参数变化的中间步骤，避免从“给定 target”直接跳到优化结果。

固定任务类 c=1，设此类数据均值 μ=(2,0)、标准差 0.5。一次合法数据抽样 x₁=(3,−1)，独立噪声抽样 x₀=(−1,1)，t=1/4：

\[
x_t=(0,\tfrac12),\qquad u=(4,-2).
\]

为了让局部求导可见，只研究当前查询点的二维可训练输出偏置 b，不冒充完整网络。旧 b=(2,0)，使用二维坐标均值 MSE：

\[
\ell(b)=\tfrac12\|b-u\|^2=4,\quad
\nabla_b\ell=b-u=(-2,2).
\]

学习率 η=0.1：

\[
b'=(2.2,-0.2),\qquad
\ell(b')=\tfrac12[(2.2-4)^2+(-0.2+2)^2]=3.24.
\]

可见链条：具体数据与噪声产生 x_t 和 u；旧预测与监督的差产生梯度；梯度更新改变下一次在同一查询处的预测。若先对 t 求导却把 x₀、x₁ 当成随 t 变化，就不是这个训练目标。若使用范数平方而不除维数，旧损失为 8、梯度为 (−4,4)；学习率与更新亦应相应改变，不能混用归一化。

这个子例只证明给定局部目标的计算。完整网络 b 可能被替换为共享的特征映射，参数同时影响许多查询点；单次 loss 下降不能证明总体风险下降或样本生成正确。也不能把本次的 u 当作该查询的精确边缘场：由下一节解析 oracle 可得 v*((0,.5),.25,1)=(96/37,−22/37)≈(2.594595,−.594595)，并不等于 (4,−2)。这正是样本监督与条件期望之别。

## 5. 代表任务 B：完整的 2D 条件 Gaussian 桥

选择依据：它同时提供可采样数据、任务条件、路径、解析边缘场及完整 ODE 解，使训练误差与积分误差有不同参照。它覆盖单元主链但每类单峰，因此不能单独承担“同一条件下多峰生成”的认识；下一节专门改变这个条件。

### 5.1 同一设定贯穿数据、训练与生成

\[
c\in\{0,1\},\quad P(c=0)=P(c=1)=\tfrac12,\quad
\mu_0=(-2,0),\ \mu_1=(2,0).
\]

\[
X_1\mid c\sim\mathcal N(\mu_c,\sigma^2 I_2),\quad
\sigma=.5,\qquad X_0\sim\mathcal N(0,I_2)
\]

且给定 c 后 X₀ 与 X₁ 独立。训练抽取 c,x₁,x₀,t，构造 x_t,u；共享网络输入 x_t,t,c，输出二维速度。生成从新 x₀ 开始，在每一步以当前状态、t、c 查询网络；不提供 x₁。训练无需展开 ODE 的每一步即可构造监督。这里 class label c 仅是任务条件的玩具接口，不等价于视觉／语言条件编码。

由独立 Gaussian 的和：

\[
X_t\mid c\sim\mathcal N(t\mu_c,Q(t)I_2),\qquad
Q(t)=(1-t)^2+\sigma^2t^2.
\]

令

\[
A(t)=\frac{\sigma^2t-(1-t)}{Q(t)}
=\frac{1.25t-1}{Q(t)}.
\]

计算联合 Gaussian 的均值及协方差：

\[
E[U\mid c]=\mu_c,\quad
\operatorname{Cov}(U,X_t\mid c)
=[t\sigma^2-(1-t)]I_2,\quad
\operatorname{Cov}(X_t\mid c)=Q(t)I_2.
\]

因此解析边缘速度是

\[
\boxed{v^*(x,t,c)=\mu_c+A(t)(x-t\mu_c)}.
\]

这是一项自拟设定的解析求解。Gaussian 条件均值公式也可通过配方或正交残差推出；它不是来源论文报告的训练实验。

### 5.2 精确 ODE 解及“直线不推出直线”的反例

对新 z∼N(0,I₂)，令

\[
\boxed{Y_t=t\mu_c+\sqrt{Q(t)}z}.
\]

初值 Y₀=z；其导数为 μ_c+[Q'(t)/(2√Q(t))]z，而 Q'/2=σ²t−(1−t)，正好等于 v*(Y_t,t,c)。端点 Y₁=μ_c+σz，分布恰为目标 Gaussian。

取 c=1、z=(−1,1)：

| t | Q(t) | 精确 ODE 位置 Y_t |
|---:|---:|---|
| 0 | 1 | (−1,1) |
| .25 | .578125 | (−.260345,.760345) |
| .5 | .3125 | (.440983,.559017) |
| .75 | .203125 | (1.049306,.450694) |
| 1 | .25 | (1.5,.5) |

初末点连线的中点是 (.25,.75)，与精确轨迹 t=.5 的位置不同。因此每条训练插值是直线，不推出边缘 ODE 轨迹是直线。概率路径只是各时刻分布，未规定必须保留训练随机配对的逐粒子身份。

### 5.3 Euler 的可预期结果

设 N 步、h=1/N、t_n=n/N：

\[
y_{n+1}=y_n+h\,v^*(y_n,t_n,c),\quad n=0,\ldots,N-1.
\]

本例可写 y_n=t_nμ_c+R_nz，其中

\[
R_0=1,\qquad R_{n+1}=R_n[1+hA(t_n)].
\]

因此 Euler 终点是 μ_c+R_Nz，理论坐标方差为 R_N²。以下数字是按该有限乘积实际计算的教师核查，不是用户运行，也不是学习表现：

| N／每样本场求值次数 | R_N | 终点坐标方差 | 对目标 .25 的绝对方差误差 |
|---:|---:|---:|---:|
| 1 | 0 | 0 | .25 |
| 2 | .2 | .04 | .21 |
| 4 | .34054054 | .11596786 | .13403214 |
| 8 | .41478455 | .17204623 | .07795377 |
| 16 | .45568309 | .20764708 | .04235292 |
| 32 | .47736357 | .22787598 | .02212402 |
| 64 | .48855529 | .23868628 | .01131372 |
| 128 | .49424510 | .24427822 | .00572178 |

N=1 的 oracle 速度在 t=0 是 μ_c−y₀，一步把所有点送到 μ_c。模型场完全正确仍会方差塌缩；因此少步样本集中不必是网络没学到分布。N 增加在本例改善误差而成本线性增加，但不能把此特例的单调行为当成所有模型、指标、步数的定理。

对于平滑场及相应稳定条件，Euler 一步截断误差为 O(h²)、固定时域全局误差为 O(h)；这控制的是积分近似。换 N 不改变已训练的 θ。若 vθ 偏离 v*，增加 N 只趋向更准确地求解错误场的 ODE，不能自动修好模型。

### 5.4 有效的误差分离与实验解读

下游实验应保留同一批初始噪声和类标。四类量各有不同用途：

1. held-out CFM risk：对新抽的 (x₀,x₁,t,c) 测网络与样本 u 的 MSE，含不可约方差，不以“非零即失败”判断。
2. held-out field MSE：E||vθ(X_t,t,c)−v*(X_t,t,c)||²，直接检查解析可知的边缘场学习误差；须写均方是否按维数归一化。
3. oracle Euler vs oracle exact：比较同一噪声的终点、均值、协方差，识别纯数值误差。2D paired RMS 为 sqrt(E||y_E−y_exact||²)=√2|R_N−.5|；若按坐标归一化则为 |R_N−.5|。
4. learned Euler vs 高步／适应性 learned reference：近似检查当前网络的积分误差；与 oracle exact 的终点差混合场误差和积分误差，不能直接命名为模型误差。

高步 learned reference 本身也有残差，需保留收敛范围。均值／协方差指标在 Gaussian 主例有意义，但一般分布不能由两矩唯一确定。墙钟时间受硬件、向量化和批大小影响；场求值次数 N 是当前 Euler 的可比计算代理，测时另记环境。按类报告可防止 pooled 分布掩盖条件失效。

## 6. 必要相邻案例：同一个 c 下的多峰

固定同一任务条件 c，改变数据为

\[
q(x_1\mid c)=\tfrac12\mathcal N(\mu_-,.25I_2)
+\tfrac12\mathcal N(\mu_+,.25I_2),\quad
\mu_\pm=(\pm2,0).
\]

每个 component 的路径仍有 Q(t) 和 A(t)。给定当前 x,t 后的 component 权重是

\[
w_\pm(x,t)=
\frac{\exp[-\|x-t\mu_\pm\|^2/(2Q(t))]}
{\sum_{j\in\{-,+\}}\exp[-\|x-t\mu_j\|^2/(2Q(t))]}.
\]

于是

\[
v^*(x,t,c)=\sum_{\pm}w_\pm(x,t)
[\mu_\pm+A(t)(x-t\mu_\pm)].
\]

实际算 t=.5、x=(.5,0)，Q=.3125、A=−1.2；w_+≈.9608342772，v_+=(2.6,0)、v_-=(−3.8,0)，所以 v*≈(2.3493393741,0)。但该 c 下的终点均值 E[X₁∣c]=(0,0)。

这一差别支持具体结论：CFM 回归的是当前位置／时间条件下的局部速度均值，不能等同于一次性输出的终点均值。不同初始噪声经位置相关的场推动，理想模型可以保留分布的多峰；固定 c 的直接 MSE 终点回归只给均值。对称点 x=0 的速度为 0 不表示全部轨迹聚到 0；在连续噪声中精确落在该点的概率为 0，且其邻近场不同。

这是解析辅助对照，尚无本文件中的混合数据神经网络训练证据。不以 Gaussian 主例的两类 pooled 双峰代替同一 c 下的双峰，不由理想边缘化结论保证有限网络一定学好模式权重。

| 同一需求／候选 | 它保留或付出的东西 | 何时可选／何时结论不足 |
|---|---|---|
| 直接终点 MSE 回归 c→x | 输出 E[X₁∣c]，一次求值，无生成随机性 | 单值／均值预测是需求时可能合适；同 c 多种合法动作需要抽样时会丢分布，不能说所有回归模型都不能生成 |
| mixture density／显式 Gaussian 头 | 直接预测分布参数并抽样，不需 ODE；须选成分、协方差参数化和似然 | 已知低维简单分布时可更便宜；高维复杂结构难度不同。本例 Gaussian 可直接解析抽样，FM不是最经济必选 |
| 自回归条件模型 | 概率分解、顺序抽样；取决于 token／维度组织 | 序列条件与离散表示合适时有用；与连续 FM 的并行速度预测、积分成本是不同取舍 |
| diffusion／score 路线 | 可用 Gaussian 路径及去噪监督，采样有 ODE／SDE 多种选择 | FM 与 diffusion 的路径或模型可有交叉，不把“一个确定／一个随机”当作绝对区分 |
| CNF 最大似然训练 | 同样可用 ODE 变换，但训练要处理积分／密度变换等成本 | 需要 likelihood 目标时可能有理由；本单元 CFM 不需训练时逐步展开 ODE，并不意味全部训练成本消失 |
| 改端点耦合为 OT 或其他配对 | 改变概率路径和监督分布，可改变场复杂度；配对本身有成本 | 需明确算法和证据。独立配对与最优耦合不能混称 |
| 提高采样阶数或 N | 在已有场上减小积分误差，增加求值／实现成本 | 场学得足够好且积分误差占主导时有益；场误差主导时需回到训练／表示／数据 |

一个直接可核的 OT 反例：在 Gaussian 主例 c=1，独立配对的二次位移成本 E||X₁−X₀||²=||μ||²+2(1+.25)=6.5；合法耦合 X₁=μ+.5X₀ 有同样端点分布、成本 ||μ||²+2(.5−1)²=4.5。存在更低成本的合法耦合已足以否定“独立配对必是 OT”，无需在本单元证明全体耦合的最优下界。原论文所谓 conditional OT 的条件 Gaussian 问题，不应扩写成独立噪声和总体数据分布之间已取得 OT 耦合。

## 8. 基于资料的专家实践重建

| 专家线索／实际位置 | 要作的判断与理由 | 新手可能省略的接口 |
|---|---|---|
| 论文把 0／1、x₀／x₁ 反向命名 | 先定端点含义再求导；时间反向需整体换符号与初值 | 只抄公式，混用 DDPM 的数据 x₀ 和本课噪声 x₀ |
| 监督中出现 x₁，推理函数签名只有 x,t,c | 区分标签生成与网络输入，检查端点有没有泄漏 | 把“conditional”理解成生成时已知要去的样本 |
| 多个端点能解释同一中间 x | 以 posterior 权重求局部条件均值，不做无条件平均 | 直接把 u 或 E[X₁∣c]命名为边缘场 |
| 相同 θ、不同采样 N | 分离学场与解场；oracle 参照可隔离积分错误 | 少步失真就说模型训练失败，更多步变好就说学得更好 |
| 训练 loss 不为零 | 查不可约目标方差、容量和评价分布 | 用 CFM 非零直接否定 FM，忽视风险常数 |
| 指标只给 pooled 均值／图看起来双峰 | 按 c 看分布，固定同 c 的多峰对照 | 类条件失效被 pooled 双峰掩盖；两矩匹配被当分布完全匹配 |
| 曲线或样本声称 straight／OT | 查逐端点路径还是边缘 ODE、独立耦合还是全局成本 | 从局部直线推出一步精确或全局 OT |
| 低维 action chunk 采用速度头 | 查 x 形状／单位、c 的信息时点、生成 t 与物理 k | 把积分步当执行步，离线采样好就断言闭环有效 |

这些是有学科理由的候选困难，不是本学习者已经存在的误概念。真实表现需另收原答并结合已给帮助判断。
