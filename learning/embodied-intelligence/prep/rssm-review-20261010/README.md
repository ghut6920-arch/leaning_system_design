## 本次主线与整体工作的意义

主线为：可用信息与历史需求 → 动作条件 h/z 与过滤 → 序列变分目标及参数学习 → 无未来观测的先验展开 → 分布成本 → 首动作执行、新观测、再过滤和再规划。最终 W 在同一模型族的新条件下组织这些连接；它要求理由、条件、接口和证据判断，允许查阅公式，不等同从零设计 RSSM、闭卷恢复或真实控制实验。

完整教师示范 E 的每个后续接口已经备好。B1 交回下界与历史条件理由；B2 交回共享轨迹的矩与成本连接；B3 在整篇骨架中接手组织；W 再要求缺失观测适配、参数版本管理、新起点规划、观测后修订与证据选择。它们是可选支持路径，不能用逐题成功数代替整体工作，也不设置逐题“继续”开关。

## 重点审查的三件事

必要语义已有实际载体：真实状态/观测/历史/belief 与模型 h/z；给定轨迹的确定性与边际随机性；filtering 变分族与 smoothing posterior；同时间 KL 与历史外层期望；参数学习的中间梯度链；conditional/marginal 方差与协方差；动作条件噪声对期望成本的影响；闭环与实验边界。

不同维度分别处理：信息输入与分布输出、状态过滤与梯度训练、latent 与动作搜索分布、一步目标与多步训练/预测/评估/控制、认知要求与实际帮助、条件覆盖与工作量。审查中已补足动机环境到自拟 E 模型的对象过渡，避免把潜坐标冒充物理位置/速度。

跨度已落实为实际材料和题目：一般推导前有单变量桥；矩与成本前有完整演算；整体组织前有部分接手；W 的观测缺失与新规划不靠复制教师答案完成。个人适配和学习效果仍需正式实施后的真实贡献检验，本次不预判。
