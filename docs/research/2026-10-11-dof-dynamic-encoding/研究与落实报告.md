# 自由度分析与动态 Encoding：研究依据、WM 备课证据与最小落实方案

日期：2026-10-11，Asia/Shanghai。版本：研究与落实建议 v1。

本报告回应“是否有必要、应沉淀成什么”的问题。依据项目原始研究与设计、当前 Agent／Skill 源规则、WM 学习项目最新两条 KV Cache 备课聊天及成品、相关历史审查与真实 M0 学习记录，并定向核验相关原始文献。三名子代理分别核查备课历史、现行实现和原始研究；这是分工核查，不是盲评或教学实验。

文中【R／I／W／H】编号对应末尾可定位来源。下列修订是可供实施的建议，本次没有修改教学规则、运行代码、课程目标或真实学习状态，也没有启动正式教学。

## 一、结论：需要沉淀能力，增量主要在方法显化、调用接通与真实验证

**两种能力都有必要，但不需要分别新建一个 Skill，更不需要把四个视角固化为四阶段课程。**自由度分析帮助研究“哪些变化会改变专业判断”；动态 Encoding 帮助教师依据真实表现决定“现在怎样帮助学习者形成或修订必要关系”。两者解决不同问题，可以协同，也可以分别使用。

| 决策 | 建议 | 当前依据强度 |
|---|---|---|
| 是否沉淀自由度分析 | 是，作为 AG2／SK02 可选择的专业研究方法 | 有现有职责、研究依据和具体备课实例；四分法本身仍是设计综合 |
| 是否要求每课完成四层 | 否，按原用途和内容选择有价值的视角 | 原研究、设计及两份备课自身都不支持通用四阶段 |
| SK03 应做什么 | 把专业关系转成必要输入、认知工作与可观察表现 | 现行职责已经如此，需加强具体实例和不可绕过性检查 |
| 是否沉淀动态 Encoding | 是，作为现有 Encoding 的证据约束适配机制 | 研究和现行规则已包含大量内容，v1 提供了较完整的执行示例 |
| 现在能落实到哪里 | 备课原则、运行原则、条件触发入口、少量行为走查 | 不必等真实试学才明确这些原则 |
| 什么必须以后校准 | 诊断判断是否合理、追问是否值得、支持是否有效、何时返回与撤支持 | 最新 KV 备课尚无真实作答，不能据此断言效果 |

对用户所提方向，建议作四处校准：

1. 将“递进的四种研究视角”改成“**可组合的四种研究视角**”。专业判断常常从一开始就决定该研究哪些变量；它不必等前三层完成后才出现。
2. AG2 不能只按已经写下的单元目标决定是否深入。还应检查**原学习用途、内容结构和代表任务**，避免一个过窄目标把重要关系提前排除。正式目标取舍仍由 AG1 负责。
3. AG2 与 SK03 有责任分工，但应允许往返。SK03 找不到可理解的中间解释、合法对照或真正的学习者工作时，要回问 AG2。
4. 动态 Encoding 的运行原则可以现在接通；需要真实记录校准的是具体判断及收益，不能把“以后验证”理解为目前只写备课支持表。

最值得做的事，是让现有专业分析和有限诊断规则在需要时确实进入工作，而不是继续增加一套平行术语与表单。

### 2.2 本次可以推断什么

目前有四种性质不同的证据：

- **规范证据**：研究、设计和源规则写了什么，说明系统希望具备什么能力。
- **成品证据**：备课实际交出了哪些专业关系、材料、任务和支持，说明明确条件下能够生成什么。
- **执行证据**：真实面对学习者时实际展示、追问、帮助、修订了什么。最新 KV 两包尚无此类证据。
- **效果证据**：学习者在相应帮助条件下是否更能完成目标工作，是否值得所花时间。最新 KV 两包同样没有。

教师 toy、手算、链接检查和专业审查可以支持有限内容正确性，不能把后两类证据补出来。另一方面，没有效果证据也不妨碍现在修复明显的内容或调用缺口。

## 三、为什么需要自由度分析：它补的是固定结构内理解的盲区

### 3.1 原研究支持哪些构件

项目 Encoding 研究已经区分条件、关系、变化、反事实、竞争解释与整体接口；学科分析研究要求从专业问题、理由、合法替代及条件变化取得实质内容。它们同时反对统一深度阶梯，也要求用学科整体反查代表任务是否过窄。【R01、R03】

定向核验的外部研究支持采用有意义的变化和对照，但没有验证本项目四视角的固定次序。Marton 与 Pang 的原研究将变化与保持安排进具体学习材料，支持关键差别值得被精心设计；研究任务和条件不能外推成所有专业学习必须经过同一变化顺序。[原研究](https://www.frontlinelearningresearch.org/index.php/journal/article/download/16/99?inline=1)

Schwartz 等人的物理学习实验比较先告知再练习与对照案例中的发明后讲解，说明任务安排可能影响结构理解和迁移；其中有明确案例、引导与后续讲解，不能推出新手应当自行发现一切，也不能推出开放设计始终优于直接教学。[作者稿](https://aaalab.stanford.edu/assets/papers/2011/Practicing_versus_inventing.pdf)

因此，四视角适合作为**本项目组织专业研究的启发式**。它们的价值须落在发现了什么重要关系，而不是冠以一个已获验证的统一学习理论名称。

### 3.2 WM 历史确实存在它要解决的问题

RSSM 与 Flow Matching 历史审查显示：系统能把给定模型内的推演、计算、接口和题解做得很细，但结构为何这样选、换条件后怎样联动、怎样设计或检验方法，未必同等充分。其原因不必全部归于缺少某种认知策略，也可能是系统先选了较窄用途，再在窄范围内完成所有核查。【H03、H04】

自由度分析可以提醒 AG2 跳出“把给定结构讲对”的局限，追问：这个结构解决什么问题，哪些东西本可不同，为什么当前条件支持这个选择，改变后有什么代价。不过，若问题实际是符号未说明、输入对象混乱或缺少一段连续示范，增加方案比较并不能修好它。

### 3.3 最新 A／B 已经交出有价值的关系

**A 的容量抵消关系。**在层数和头维不变、同类未共享缓存载荷比较、暂不计额外开销的条件下：

\[
M_{KV}=2L H_{kv}d_h sBT.
\]

令 KV heads 从 24 变为 6，每元素字节由 2 变为 1，缓存长度翻倍，并发从 2 变为 8：

\[
\frac{M_{new}}{M_{old}}
=\frac6{24}\times\frac12\times2\times\frac82=1.
\]

本报告独立重算结果为 1。局部八倍压缩收益被长度和并发扩张抵消，最终载荷不变。这不是“多列了几个参数”，而是把优化收益与最终服务规格接起来。候选检查点是否可用、质量是否合格、量化开销和软件兼容性仍需另有依据。它首先是明确模型下的乘积关系，不能冒称已估计的统计交互效应或真实系统性能结论。【W03】

**B 的系统组合关系。**机制稿展开了分页与调度、分页与量化、共享与驱逐、offload 与并发／长度、chunked prefill 与 decode 指标之间的联系，讨论中间机制和失效条件。这比重复容量公式更接近真实专业取舍。【W06】

这些发现足以支持现在沉淀研究方法；尚不足以断言“四视角提示”比既有方法稳定更好，更不能证明学习者已经能自主发现这些关系。

## 四、自由度应该沉淀成什么

### 4.1 建议定位：AG2 的“专业变化与约束分析”

可保留“自由度分析”这个简称，但明确它指**专业对象的合法变化、约束及判断后果**，不表示变量数学独立，也不等于学习者拥有多少选题自由。

| 研究视角 | AG2 真正要回答的问题 | 值得交接的内容 | 常见误用 |
|---|---|---|---|
| 选择空间 | 哪些结构、表示、方法、条件或证据解释可以合法变化？谁能改变它？ | 候选及可变边界，例如服务配置可调、头结构依赖合法检查点 | 罗列所有参数；把固定检查点结构当运行开关 |
| 条件后果 | 变化成立需要什么？哪些性质保持，哪些结论改变或失效？ | 有前提的推导、反例或条件对照 | 每变一项就宣称所有结论失效；只列变化不说保持 |
| 结构联动 | 多项变化怎样通过接口、资源或反馈共同影响结果？ | 抵消、相容／冲突、瓶颈转移、共同可行条件 | 把变量多或公式长当深度；只给独立收益清单 |
| 专业判断 | 在什么目标、证据与约束下可以选择、拒用、设计或验证？ | 有条件建议、证据缺口、区分性检验、回退依据 | 默认存在唯一最优；把排除一个候选写成全域不可能 |

四种视角不构成成绩等级。即使完整讨论了四种视角，若关键推理全由教师提供，也可能只有有支持的重建；只研究一个条件边界，也可能需要独立而严谨的证明。**内容复杂度、知识覆盖、学习者自主程度和证据强度应分别判断。**

### 4.2 何时调用、何时停止

AG2 从“原用途＋初步目标＋对象结构＋代表任务”判断是否有值得研究的变化：

- 目标要求选方案、改结构、解释失效、迁移条件或设计检验时，通常值得深入。
- 目标是机制理解时，只展开真正承担解释的变化；不因为没有工程设计任务就自动排除。
- 数学的条件辨别、历史的证据解释、语言的语境替代，也可能需要这些视角。此处的“可变”不都意味着能做因果干预。
- 单一术语、单位约定或明确事实的直接解释，可以不调用整套分析。
- 既有研究已足够、追加变化不会改变解释或教学决定时，直接引用并停止。

若研究发现当前目标遗漏原用途必需的联系，AG2 向 AG1 提出具体缺口和建议取舍。它既不能自行把一节课扩成完整课程，也不能因为目标草稿没写某条关系就将它永久排除。【R03、I01】

### 4.3 交付物应是一项有内容的关系，不能是四栏填空

建议在原学科分析稿中，用短段落或小表留下：**专业关系是什么；依据和成立条件是什么；什么变化会改变判断；它对本次理解或选择有什么价值；尚未核清什么。**充分的旧材料可以直接引用，不要求另建文件。

例如 AG2 可交接：

> KV 载荷取决于保存头数、表示字节、实际存活请求及各自已处理长度的共同规格。头数／精度的局部收益可能被长度／并发增长抵消。该式只核相应载荷，不推出延迟与质量；头结构候选必须合法可用。若本单元要判断服务方案，最终规格的共同核算具有教学价值。

这一段给 SK03 的是专业依据和用途线索，没有预定要出几道题。

### 4.4 SK03 的转化：先确定学习者剩余工作

同一项专业发现，可以支持不同教学安排：

| 当前目的 | 合理安排 |
|---|---|
| 让学习者理解为什么局部收益不能直接外推 | 教师完整解释一条抵消轨迹；可以止于解释 |
| 让学习者在新规格下使用该关系 | 给可靠公式和语义，留下新规格核算、范围限定与解释 |
| 让学习者审计整体提案 | 将相关参数、前提和约束放回同一方案，留下识别不相容承诺的工作 |
| 让学习者作有条件的专业设计 | 提供必要候选与资料，留下取舍、选证、回退和新证据后的修订 |

SK03 应明确：教师已提供什么；学习者实际要连接、决定或验证什么；输入是否已经代做了目标判断。讲义标题、箭头、默认代码、选项和教师参考提前展示，都可能构成帮助。【I02、I03】

**A 恰好用 E／C／I／D 四组承接用户本次要求，是合理的专门设计；不应把它直接复制成通用课型。**其 README 已明确四层是本次指定观察维度。B 也将既有支持作为输入，重点留下综合与判断，没有要求从基础重新闯关。【W02、W03、W05】

### 4.5 AG3 的审查重点：目标工作是否真的不可绕过

B 首轮有一个具体反例：材料声称需要联合两处远距证据，但 R17 可以仅凭温度不合格否决，R18 可以仅凭资格不合格否决。正确答案“两批都不允许”并不要求联合两项证据。审查后，在同一案例加入 R19，肯定结算必须连接“本季度合格”与“29°C”，才补上目标工作。【W07】

这不是说短路推理本身不合法，而是说**短路否决不能单独证明目标要求的联合能力**。合理修复可以发生在原案例中，不必再增加一个高阶任务。

AG3 因而应围绕具体内容询问：若不使用声称要学的关系，是否仍能凭明显线索、简单计算或复制示范完成？若能，可能需要改输入、改工作或限定该表现的解释范围。审查对象是有意义的认知工作，不能用“四视角覆盖率”替代。

## 五、动态 Encoding 是否有必要：需要，但已有设计基础比表面上更多

### 5.1 它解决的是固定支持分支无法可靠应对的歧义

动态 Encoding 的最低含义是：**学习者的新表现能够改变教师实际提供的解释、表示、示范、对照或任务支持；后续表现又能修正先前判断。**如果无论说什么都得到同一段提示，换了称呼仍是固定脚本。

它也不是每次回答后都要“诊断脑内结构”。学习者可能只缺一个词，可能使用不同但合法的表达，可能看到了参考中的错误，也可能明确要求完整讲解。良好的适配包括直接解释、维持原路线和停止追加观察。

支架研究把随表现调整、帮助渐隐和责任转移作为相互关联的特征，同时指出不能脱离学生反应单独判断教师支架。这支持同时观察教师行动和学习者后续工作，不能用“备有支持材料”替代适配已经发生。[原综述](https://link.springer.com/article/10.1007/s10648-010-9127-6)

项目原 Encoding 研究更直接地提出：保存父目标，依作答提出暂定缺口，必要时区分备选解释，提供帮助并返回整体；还明确该组合是设计综合，不能由此声称系统已经自动诊断。【R01】

### 5.2 最新 A 提供了较好的运行示例，B 并非完全没有

A 的“缓存是前缀的可能性地图”是**虚构学习者表达**。支持稿至少保留三种解释：

1. 把当前 query 的 attention 权重叫作缓存。
2. 认为高层 V 能无损恢复全部历史。
3. 实际在描述另一种会更新或压缩状态的算法。

这三种情况需要不同回应：对象对齐与同 KV／不同 query 的数值对照；未来查询与信息保留的边界反例；或者核查实际算法接口。其价值在于同一句话不被直接塞进一个错误标签。A 也明确：已有作品能区分就不用新题；若不同解释导向同一个可靠补充，可以直接讲；仍不能区分就保留表达未清，不虚称知道脑内模型。【W04】

B 已有触发信号、替代解释、具体支持、代做范围和返回位置，还要求局部正确而整体失败时检查接口与参考错误。A 相较 B 的明显增量，是把竞争解释、区分观察、不同支持和修订连成一个完整示范。不能据此断言 B 完全静态，也不能断言额外一句提示造成了全部差异。【W08】

### 5.3 真实 M0 记录说明需求存在，也暴露了过诊断风险

学习者曾正确定位、指出信息不足，随后明确表示不理解“恢复依据”“两条路线”“视频模型输入”和“帧身份”。照片说明后，其修订仍将逐帧编码、打乱顺序和信息不变混在一起。【H01】

这支持一个具体判断：局部答案正确，不能代替对象和关系已可用；真实回答可能暴露教师压缩过度、指称不明或示范缺桥。它不能证明学习者有一个稳定、普遍的误概念，更不能证明任何新诊断方法已修好问题。

这些原话本身已足以触发补充说明，不需要先安排一串测验来证明“确实不懂”。后续该观察的是补充后的接口工作能否推进。若学生能做局部、整体仍失败，先重查连接和原判断，不继续机械地下钻基础。

## 六、动态 Encoding 应沉淀成三部分

用户区分备课与运行是必要的；进一步建议把“现在能规范的运行原则”和“尚待校准的诊断效果”分开。

### 6.1 备课：准备高影响困难及可用材料

沿核心主线，选择那些**容易影响重要关系、且不同解释确实需要不同帮助**的困难。材料应实际可用，例如带对象的图、同条件对照、必要定义、短数值轨迹或有边界的反例。

不要求穷举学生错误，不要求每条困难凑两个解释，也不将“可能出现的困难”写成个人状态。部分分支在没有真实回答前无法预见，正式教学可以临时核查和生成；AG2 只需对新增的专业内容负责，不重研整份课。

### 6.2 运行：以当前决定为目的的适配循环

下表是判断关系，不是每次都必须完整执行的七步表单。

| 当前要做的判断 | 可采取的动作 | 可直接跳过或停止的情况 |
|---|---|---|
| 原话在说什么、任务和参考是否可靠 | 对齐对象、阶段、条件；检查表达省略和合法另类解释 | 已清楚且正确，继续或收束 |
| 目前是否需要帮助 | 依据原答、作品和用户请求确定影响当前工作的卡点 | 缺定义或明确要示范时，直接提供必要输入 |
| 不同解释会不会改变帮助 | 仅保留对下一步有实际差异的合理候选 | 都需要同一项短而可靠的补充，直接补 |
| 有什么最低成本的区分依据 | 先用已有作品；必要时问对象指称或给最小对照 | 不能可靠区分，保留未知；不强选原因 |
| 实际改变什么 | 选择解释、表示、例子、对照、任务粒度或帮助程度 | 没有新增价值，保持原安排 |
| 新表现支持了什么 | 看所补关系是否可用、是否违背先前预测；必要时改判断 | 有帮助的成功不回写成原先独立掌握 |
| 能否回原工作 | 回同一方案、解释、证明或代码的未完成连接 | 用户只要解释、暂停、投入结束或继续无增量，可收束 |

“最小辨别”中的最小，应理解为**足以改变当前决定、成本相称**，不是形式上一定一道题或一定只改一个变量。有时自然作品的一句话就够；有时任务本身已经提供了分歧预测。诊断观察还可能产生教学作用，不能把观察后的成功假装成未经帮助的原始状态。【R02、I05】

### 6.3 真实校准：不要过早固化一个“诊断算法”

现阶段不宜写死错误类别到策略卡的一一映射、统一置信阈值、固定追问轮数、所有单元共用的撤支持门槛。必须观察的包括：

- 暂定解释有没有被后续表现推翻，教师是否愿意修订。
- 区分观察究竟改变了哪项教学决定，还是只多问了一轮。
- 被选择的支持是否补上目标关系，有没有代做原本要观察的操作。
- 学习者是否能从局部帮助回到整体，还是停留在复述局部范例。
- 相对可靠的直接解释，额外诊断是否值得其等待、交互和认知负担。

这不是要求找到不可观察的“真实脑内标签”。早期可检查的是解释与已有事实是否相容、预测是否有区分力、后续工作是否支持所选帮助；若仍多解，就保持多解。

### 6.4 一个拟议的执行实例

以下是设计演示，不是新发生的学习记录。学习者说：“量化少一半字节，速度就快两倍。”

- 若原作品已明确限定纯带宽传输、其他开销可忽略且有效带宽不变，这可能是其条件模型内的正确推论。教师保留它，帮助说明外推边界即可。
- 若其把推论用于端到端延迟，可直接把传输、计算、反量化和排队放回整体，指出仍缺哪些测量。
- 若原话没有说明范围，而这个区别确实影响下一步，先澄清比较的是哪个时间量；不立即判“误解量化”。

返回点是原方案中的性能承诺和验证项。修改这一项比重新讲完整量化章节更贴合当前需要。后续若依然出现错误总延迟判断，再查看是否是瓶颈、口径或整体接口问题。

### 8.2 可直接采用的核心表述草案

**AG2 方法草案：**

> 依据原用途、对象结构和代表任务，选择研究合法替代、条件后果、多因素联动及目标约束下的判断。交出有依据的专业关系，说明哪些变化与保持真正影响本次理解或选择。四者是可组合视角，不是固定阶段或覆盖指标；已有分析充分就复用。发现目标草稿遗漏用途必需关系时回提目标责任方，不自行扩大课程。

**SK03 转换草案：**

> 将有价值的专业关系转成必要输入和当前目标要求的学习者工作，明确教师已提供及学习者仍须完成的判断。选择解释、示范、对照或连续任务，不按研究视角逐项出题。若学习者可以绕过目标关系完成，或材料已代做关键判断，调整实际内容或限定该工作的用途；必要时回问 AG2。

**动态执行连接草案：**

> 面对含糊或出乎预期的回答，先核对象、条件及题面／参考，保留合法解释。仅当不同合理解释会改变支持时，按有限诊断规则使用已有证据或必要的区分观察；否则沿已有充分依据继续教学，确需支持时直接提供所需帮助，当前工作已够用则返回或结束。依据新反应修订判断和实际支持，保留帮助条件，够用即返回原工作。重要能力结论按 SK04 处理，普通可回退帮助不逐次会签。

这些草案应替换或合并相邻重复表述，不应原封不动再叠到多个入口。

### 8.3 轻量交接与记录

备课关系记在原学科分析／认知设计中；备用材料记在原支持稿；实际适配记在既有原答、帮助与父任务事件中。必要时留一段可追踪记录即可：

> 原答／作品位置；影响当前工作的卡点；尚存解释与依据；这次为何直接帮助或辨别；实际提供了什么、代做了什么；后续反应及解释修订；回到原作品哪里。

没有改变教学安排时不强制新增诊断笔记。预设分支不能写成已经观察到的误解；同一回答经过帮助后的修订不能增加为独立学习样本。诊断不另造长期心理画像，也不因此新增复习债务。【I05、R02】

## 九、落实顺序与验证：两条线不同步，但都要跨过“写出来”

### 9.1 自由度：先把研究方法写实，再检查能否按需调用

先将四视角及已有实例整理到 AG2 使用的参考中，保持内容优先。随后用新的备课请求验证：不在用户提示里再次点名“四层”，系统能否在确有需要的专业问题中发现重要联动；面对简单目标，能否合理不展开。

比较重点是**发现的关系是否改变解释或教学决定**，而非篇幅、变量数、四栏齐全率。可先做同模型、同用途、同材料权限和相近预算的成对备课；差异有意义再复现。生成有随机性，一对结果不能给出稳定因果优势。

### 9.2 动态 Encoding：先接运行入口，再做行为走查，随后进入真实记录

行为走查可以用少量明确标为虚构的情境检查：

| 情境 | 应观察的行为 |
|---|---|
| 同一句话对应不同对象 | 只在支持会不同且证据不足时澄清；不能关键词判错 |
| 缺一个定义或用户要求完整解释 | 直接讲解，不以诊断为前置关卡 |
| 学习者答案与参考不同但可能合法 | 查题面、条件和参考；允许修正教师 |
| 局部均正确，整体方案失败 | 查接口与联动，不追加同类基础题 |
| 支持后反应不符合预测 | 修订暂定解释与支持，不固守最初标签 |
| 已足够、无信息增量或用户暂停 | 返回或停止，不为跑完流程继续追问 |

这些走查证明的至多是规则可被执行和逻辑上能够处理分支；虚构学习者表现不能当作教学效果。

真实试学时，复用选定单元和已有材料，观察自然出现的困难，不为收集诊断样本故意制造障碍。至少需要能回查原答、实际帮助、后续反应及整体返回，才可谈一次适配是否发生。保持／迁移只在目标需要时观察，不默认安排额外测试。

### 9.3 四类结果分别报告

| 要回答的问题 | 可接受证据 | 不能作为替代 |
|---|---|---|
| 专业关系与材料是否可靠 | 合法推导、实际来源、反例、明确规格的计算及内容审查 | 文件齐全、教师答案流畅 |
| 能力是否被调用并影响教学 | 无特别点名下的备课；真实或明确虚构的行为轨迹，分别报告 | 源文件包含关键词 |
| 学习者在目标条件下能否工作 | 原答与作品、帮助范围、返回整体后的表现 | 自述看懂、教师代做、局部答对 |
| 额外机制是否值得 | 相应任务结果与时间、等待、追问、负担和连续性 | 单独统计通过率、分支数或调用次数 |

单次真实观察可以揭示误判、无效追问或返回失败，适合改进；要声称净收益，则需要合理比较。对照应是充分而可靠的直接讲解／示范／练习，不能故意拿贫乏教学作基线。若同时加自由度分析、扩大备课预算并强化动态支持，即使结果改善，也无法分清是哪项变化所致；资源有限时先分别验证两条线。

### 9.4 何时继续沉淀，何时删减

若自由度分析不断发现原用途所需、原先遗漏的关系，并改善解释或任务，可以逐步扩充跨主题实例。若只是每课多写四段而教学决定不变，应删减重复流程。

若动态机制会选择不同且合适的支持，能够承认反证并回到整体，再逐步总结稳定模式。若分支总导向同一说明、追问没有改变决定、学习者反复只复述教师稿，优先简化或改材料。不能用“诊断不足”要求无限更多真实数据，也不能靠再加规则掩盖效果不明。

## 十、综合判断

用户提出的方向基本成立，最需要修正的是“递进”可能暗含新等级，以及“现有能力”和“新增能力”的界限。

**自由度分析适合现在沉淀为 AG2 的可选专业方法，并由 SK03 转成有实质工作、负担相称的教学；动态 Encoding 适合现在接通已有有限诊断与适配规则，同时把判断质量和净收益留给真实学习校准。**

两者共同的完成标准是：专业分析有没有带来重要认识，教学有没有据此发生有理由的改变，学习者有没有在相应帮助条件下完成所需工作。四个标题、更多支架或更厚审查材料，都不能独立回答这些问题。
