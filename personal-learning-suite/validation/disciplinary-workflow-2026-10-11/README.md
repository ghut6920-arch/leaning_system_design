# 学科研究与教学转换：本次验证

2026-10-11，通用指令维护验证。此目录不保存真实学习者表现，不进入课程进度。

- [工程完整性](integrity-result.json)：研究／设计、runtime、契约、资源与课程原件保护，规则链接和公共manifest；[核查脚本](check_release.py)可重复运行。
- [Skill格式](skill-format-results.json)：安装环境的quick_validate实际输出，格式有效不证明执行效果。
- [B0静态核查](b0-static-report.json)：复验既有来源、契约与角色／Skill结构；不把未执行的运行情境升级。
- [反向审查的先定问题](forward/phase1-before-product.md)：独立子Agent只先取得原用途与专业定义，保存问题后才取得候选成品。
- [成品反向审查](forward/phase2-product-review.md)：检查两份候选并区分原用途缺项、正确局部、充分文字和未核图成品。
- 教学实际输出：[有限单元](forward-teaching/A-有限单元.md)、[直接解释](forward-teaching/B-直接回答.md)、[局部学科交接修复](forward-teaching/C-局部交接与处理.md)。
- [教学试用的读取与决定记录](forward-teaching/读取与决定记录.md)：实际来源范围、指纹、策略借用与顺序兼任边界。
- [前向试用结果](behavior-review.md)：实际输出、根代理按内容复核及有限结论；不是关键词／标题匹配测试。

保护基线在 [protected-baseline.json](protected-baseline.json)。用户既有未提交README与两份WM备课也按当时原件保护。规则修订没有安装原生Skill或改变共享schema；真实教学、学习增益和协作净收益未测。
