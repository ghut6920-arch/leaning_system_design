2026-10-09。状态：备课候选，供审查；正式教学未执行。由同一模型顺序承担 AG1/AG2/AG3 职能并自查。用户基础、时间、设备均未知；不依据其他学习记录。以下要求是本次主题的设计提案，没有写入真实 GoalSpec 或学习进度。

## 先确定需要形成什么认识

核心问题是：**只有历史观测和动作时，怎样形成可用于决策的当前状态表征；怎样用同一个动作条件模型，分别完成有观测的推断、无未来观测的预测和收到新观测后的再决策？**

单元终点是一份连续的《RSSM 推断—预测—规划协议说明》。它包含带理由的序列目标推导、训练与想象的信息边界、数据流接口、一次有限规划和新观测后的修订，以及结论能支持到哪里的说明。不是六个名词各解释一次，也不是观看完整范例后照抄代码。

课程粗定位：POMDP 的历史与信念 → 动作条件潜在状态模型 → 序列变分学习 → 多步模型使用 → 闭环决策。后续若要学习 Dreamer 的 actor/critic、策略梯度、离散 RSSM 或真实机器人，可从这些接口进入；本次不把它们列为欠课。完整神经训练、基准任务复现、一般闭环稳定性证明和长期保持均不属于本次必交。

## 六项相互连接、分别判断的认知要求

| 要求 | 学完要作出的判断或操作 | 必须建立的联系 | 在整体作品中怎样核对 |
|---|---|---|---|
| C1 对象与信息 | 同一当前观测为何可对应不同隐藏情况；区分环境状态、潜在状态、历史、belief、状态样本 | 历史提供额外约束；模型表征是学习的近似，不能自动等同真状态或完整 belief | 用两个合法历史解释观测歧义；标出在线时刻可用信息 |
| C2 推断与表示 | 解释 h、z、prior、posterior 的角色；沿一步更新追踪动作和观测进入哪里 | h 的递推包含先前随机样本；函数确定性与边缘分布的不确定性不同；q 是近似推断机制 | 因子分解与数据流一致，指出 p 和 q 的信息边界及确定性所指条件 |
| C3 序列变分学习 | 从联合分布和 q 路径分解推出 ELBO，并解释每一步为什么合法 | Jensen、对数乘积、期望、条件 KL；重建和动态一致性各承担什么 | 连续推导有外层历史期望、正确 KL 方向；区分 ELBO、加权训练目标、MSE 特例 |
| C4 多步预测 | 从截止时刻的信念连续滚动 prior；区分条件一步预测与自由多步预测 | 中间潜在状态须积分或采样；没有未来观测不能使用 q 校正；均值代入与期望不同 | 同一时轴上写两步 rollout；给出不泄漏未来的评价协议；说明误差传播与 overshooting 边界 |
| C5 闭环规划 | 在给定模型和目标下比较候选动作序列；执行首动作后重新观测、更新并规划 | 动作条件预测 → 未来收益分布 → 有限优化 → 执行 → 信念更新 | 初始候选评分、新观测后的起点和第二轮选择连贯；不把开环序列搜索当完整 POMDP 最优策略 |
| C6 整体核查与条件更新 | 发现信息泄漏、接口错位或条件改变，修复整段协议；说明结果的证据限度 | 推导、算法接口、数值算例、离线指标和真实控制结果相互约束且不互相替代 | 在同一作品中定位问题、修订理由和影响范围；保留旧条件下仍正确部分 |

C1/C2 是 C3/C4 的语义前提；C3 说明训练信号，**不逻辑保证** C4 的多步效果；C4 的模型使用为 C5 提供估计，**不逻辑保证**实际闭环收益。C6 检查这些接口，不用各项平均分抵消关键缺口。

## 不把不同维度绑成一条“理解深度”

| 维度 | 本次怎样展开 | 不允许的混绑 |
|---|---|---|
| 概率对象 | 真状态 x、学习潜变量 z、递推记忆 h、分布、样本、均值分别命名 | z 就是真状态；一个样本就是完整信念；h 确定就没有不确定性 |
| 信息与时间 | t 先看 o_t，再执行 a_t，得到 o_{t+1}/r_{t+1}；训练数据中可见不等于在线预测时可用 | 有整段录像就能在预测过程中读未来；过滤 q 等于平滑后验 |
| 数学严谨性 | 一般序列 ELBO 保留完整理由；数值辅助只核具体算式 | 跑通数值算例等于证明序列目标正确 |
| 表征与实现 | 分布参数/随机样本、batch/time/latent 轴、函数输入输出对应 | shape 对了就语义对；参数张量就是一次状态采样 |
| 模型效果 | 分开后验重建、条件一步预测、自由多步预测、收益预测、控制回报 | 重建好或 loss 降了就能规划；随机潜变量已经校准全部模型不确定性 |
| 自主承担 | 示范、允许公式、局部理由提示、整体组织分别记谁完成 | 看懂或执行教师代码算自主推导/实现；隐藏参考恢复独立性 |
| 成本与范围 | 预算保持未知；可以停在连续作品的一个接口 | 为了短答而把一般推导改成复述；为了“完整”要求立即训练大模型 |

关系精确性、解释完整性、边界判断、时间推演和跨表征对应分别观察；没有合成深度总分。理论上限、当前展开和本次推进范围也分别决定。

## 前置怎样处理

必须可用：条件概率的含义、期望、KL 定义、Jensen 的一句形式、求和与乘积的展开、概率分布与采样的区别。它们可由材料直接提供；不要求先闭卷测过。高斯数值示范允许使用更新公式和计算器。代码阅读只需认识函数输入/输出与循环；独立 Python/PyTorch 实现不是本次门槛。

GRU 门公式、CNN 内部、CEM 的概率收敛证明保留为黑箱，给其输入/输出与限制。只有拟修改它们、接口不足或实际困难定位到内部，才展开。未知经验不写成“新手”“基础薄弱”。

## 从示范到整体工作的跨度

1. **输入**：解释对象与时间；交完整因子分解/推导和可复算的闭环轨迹。AI 提供路线和数值参考。
2. **有限承担**：Q1/Q2 在已有对象中追踪信息并补关键合法理由。这里减少的是无序搜索，不删语义和条件。
3. **接接口**：Q3 改一个观测、完成后验与下一轮评分；Q4 在已有规格中修复一段混合协议，承担选择和组织，保持网络黑箱。
4. **整体使用**：Q5 更新噪声条件；Q6 用自己的组织交连续协议说明。允许引用公式，撤去的是教师已经连好的整体答案。

不要求每一阶段必做全部问题。有可用整体作品可直接 Q4/Q6；局部会但整体接不上，查时轴、分布/样本、接口和目标，而非退回整章概率基础。拟观察的选择被讲解代做时仍可教学，限定那部分自主证据。

正式启动后正常反馈直接接下一份已备输入或同一作品任务；只在需要学习者贡献、求助、暂停或有效停止时等待。本次所有题目与首回合均仅为审查稿，不向用户索答。
