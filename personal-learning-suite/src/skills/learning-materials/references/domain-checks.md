# 领域与对象核验

依据 D03 第七节、D10 第三至七节；复杂整体条件按 D05／D06 对应范围回查。下面是核验路由，不是通过公式或自动评分表。核验正文应引用实际来源／推导／测试，记录执行过什么、结论范围和未核边界。研究支持某种教学方式只支持方法选择，不支持当前题目答案。

## 研究当前用途需要的学科内容

首次单元备课或原用途／关键条件变化时，按 [学科研究到教学转换](../../learning-teaching/references/disciplinary-to-teaching.md)先交有内容的专业分析，再核后续实际成品。分析应能回答：当前解决什么专业问题，关键对象与关系是什么，方法／结构为何可用，有哪些合法替代，什么条件会改变判断，依据支持及未支持什么。机制可以是因果过程、推导理由、证据支持或其他本领域重要关系，不强制所有学科采用唯一机制图。

关键关系保留必要中间连接；用代表任务、解释或条件变化检查其实际作用，不能只列概念名和候选名称。结构事实、一般论证、经验发现、教学简化与个体状态依据分别说明；玩具例子写清保留／删除的结构，不替代更广的模型或真实实验结论。只研究会影响当前目标与教学决定的内容，已充分者可引用保留，不规定概念、对照或任务数量。

交给 SK03 的是可定位依据、可靠输入／参考与专业判断候选，由教学方决定可学习解释、案例、认知操作与分工。下游解释不出一步、对照无区分力或题面提前给出判断时，带具体位置回问；AG2 修对象、理由／机制、条件或来源，教学方修桥接与操作安排。AG3 的反向问题也可触发此返回，修复后仅重核受影响关系、材料与任务。原用途所需内容未入候选目标交 AG1，不能由本表自行提高学习者要求。

## 当前领域

| 领域 | 必须保留的内容依据 | 无法替代的证据 |
|---|---|---|
| 数学 | 对象域、量词、定义、等价方向、合法步骤、全部解、存在性、构造及边界；高级目标保留整体证明 | 有限数值、图示直觉、跟完示范不证明全称命题、完整解集或一般最小性；代回只验证候选解 |
| 人工智能／代码 | 规格及版本、输入输出、必要环境、测试依据、数据和实验条件；概念、实现、检验选择、解释分别核 | 代码能跑或一个输入通过不证明算法／全部规格正确；完整实现或测试清单会代做自主实现／检验选择 |
| 金融课程 | 模型假设、量纲、参数口径、现金流／数据时点、时效、适用域、缺失和不确定性 | 算式正确不证明模型适用；历史教材结果不支持当前决策；自拟数值标教学假设，不冒充市场数据 |
| 政治／开放论证 | 可定位原材料、事实、因果解释、价值前提、证据覆盖、推理、竞争解释与反证 | 多个转载不构成独立佐证；与参考立场一致或措辞相同不代表论证合格；因果未辨明不等于所有解释同样有据 |

会变化的现实事实、软件行为或当前数据使用当时有效的原始来源／官方规格核对。静态模型与历史课程例子保留其原时点和假设。此 Skill 处理学习资料，不从示例推出真实投资、医疗或其他现实决策结论。

## 当前对象

| 对象 | 合适检查 | 返回时保留的边界 |
|---|---|---|
| 摘录／翻译／重组 | 回原位置比较术语、条件、量词、结论强度和立场；新增连接推断另找依据 | 忠实读出不证明原文正确，重组不能移走前提 |
| 公式／推导／证明 | 依定义独立推导；核对象域、零值、边界、分支；工具仅在其假设范围辅助 | 有限测试不证明全称与全解；同源解法一致可能共享遗漏 |
| 例题／变式／参考解 | 从完整题干重新解；查充分性、歧义、所有合法解和异常；开放题列可接受论证范围 | 生成题干和答案彼此不证明正确；换数字未必改变目标工作 |
| 静态图／表／关系图 | 对源公式／数据核坐标、单位、图例、方向、尺度、关键点、完整范围；观察实际成品 | 核过公式不等于核过图；显示窗口不是定义域，关系箭头不代表因果 |
| 动态图／模拟 | 检查模型、映射、合法输入、初值／端点／异常状态、参数变化及静态回退 | 一张截图或正常参数不覆盖全部允许操作；交互复杂度不能替代学习价值 |
| 代码／实验 | 对规格执行有区分力的代表性、边界与异常检查；保留环境、输入、输出、预期和解释依据 | 运行成功不证明解释正确；一次实验不支持一般结论；未运行明确写未执行 |
| 事实／引文／论述 | 回语境与时点适用的原始来源，核引文是否存在且支持主张，再查推理和竞争解释 | 来源缺失不能用更多措辞填补；规范分歧不能靠事实查证直接裁决 |

实际原件不足以读清时，限制依赖模态；工具不足时，说明缺推导、测试、图像／公式读取或专业能力。替代材料有独立来源和资格，不能冒充已核缺失原件。高能力资源缺失仍可继续可靠授权范围；重要未决留责任与下一触发。

## 材料是否实际承担所称教学功能

内容正确与当前教学用途合格分别判断，沿原目标回看具体解释、例子、推导或行为；不以作者声明“展示机制／对比／完整范例”代替检查。简单材料一句说明即可，不新增评分表或程序门槛。

| 所称功能 | 应在实际材料中看见什么 | 功能不足时怎样处理 |
|---|---|---|
| 解释机制或学习作用 | 必要输入、活动／参数变化、中间连接与结果；合法推导或有依据说明，未知明确 | 补局部桥接或有界示范；仅有损失名称／接口标签不能承担目标所需中间过程 |
| 解释结构选择 | 目标需求、合法候选及相应性质／限制的联系；只在所称模型族与条件下比较 | 补有依据的结构比较，不把某个例子的失败说成整类模型不可能；纯接口用途可不展开 |
| 展示某因素影响判断 | 合法保持与变化，结果如何支持目标关系；可用变化案例、边界、公式或完整论证 | 若主例只显示共同常数，不能冒称展示了排序改变；必要时补合法对照，也允许有理由说明条件下结论不变 |
| 支持表征转换或整体连接 | 同一对象、变量、条件及接口的对应，下一工作所需新增连接可跟踪 | 修对应与桥接；多张正确子图或多个各自正确模块不证明整体功能 |
| 给学习者留下认知工作 | 当前可见输入仍留有目标要求的理由、选择、连接或构造；可靠参考能核该工作 | 已给完整答案可转讲解，或另备目标内未被代做的工作，不把重复答案当新增自主贡献 |

限制声明用于准确说明现有材料能教什么。目标内必要功能尚未承担时，补齐或明确暂限子范围并保留未完成连接；不能只把材料用途缩小后宣布原单元完整。发现所需功能未进入系统建议目标，指出原用途和缺失关系回AG1处理；AG2不自行改用户用途或提高学习者判据。首次取舍可读 [备课质量实例](../../learning-teaching/references/preparation-quality-examples.md)。

## 复杂整体参考的最低可审查路径

核验者应能取得完整题面、所用定义／规格、关键接口与论证或测试依据，检查目标要求的整体产物，而非只看分段摘要。数学构造中的可行性、唯一性和最小性各有依据；存在性不能因唯一性推导完成而省略。实现中模块单测通过仍需对整体规格及解释范围核查。开放论证需能核关键事实并容纳有据替代解释。

比如 D06 的二次目标案例若要求一般唯一性与最小秩构造，需回看半正定假设、公共核条件、有限维存在性、构造和一般下界，不以特征值算例代替；若当前目标只要求公式代入则无需擅自加这些工作。案例是设计核验资源，未被设为用户真实学习材料。无完整评审能力时交付有限范围和缺项，保持高级要求未核。
