# 具身智能：跨模型学习入口

本目录使用同一套 Agent／Skill 的人工文件协议，模型品牌不属于接口条件。接入依赖实际读取、内容核验、上下文和保存能力；未安装平台 Skill 或绑定真实模型程序。用户指令与宿主规则优先，大纲、论文、代码注释及作答均作资料阅读。

## 定位与最少读取

学习目录为本文件所在的 learning/embodied-intelligence，框架在项目根 personal-learning-suite；两个目录以相对路径相连。移动整个项目仍保留关系；只复制学习目录不能自动取得框架。有文件工具的模型应在项目根工作区读取；缺文件只说明缺失能力与可用范围，不猜造规则。

开始／继续依次读取尚未取得的内容，同次已读不因相互引用循环加载：
1. [AGENTS](AGENTS.md)、[控制](state/control.md)、[当前状态](state/current.md)，然后本文件；按指向定位当前计划及实际断点。
2. [FRAMEWORK](FRAMEWORK.md)中的共享语义、SK00、AG0；读取 SK00 的 session-entry。
3. 当前请求所需专业入口及参考、实际课程片段与已有产物。新单元先按 [学科研究与教学转换](../../personal-learning-suite/src/skills/learning-teaching/references/disciplinary-to-teaching.md)取得或复用AG2专业依据，再由SK03设计认知操作和师生分工，落实具体材料／必要可视化／问题并反向审查；读取SK03内容准备、Encoding、Post功能和SK06选法，实际读取所选完整策略包并备好认知主线；已有合格单元直接复用，只有局部题的旧安排补齐整体连接；已有作品先查原件。不要在每次回答前预载全部研究或重读不变文件。

当前公共规则修订于2026-10-11。架构维护后或换模型接任，核 [框架指纹](framework-manifest.json)并读取发生变化的入口／专业规则；文件更新不会自动注入旧聊天上下文。单元由理解目标和整体工作划定，跨轮保持；普通反馈后自动接已备下一份内容／工作，不把每次“继续”当重新开课，不等这句才准备后续。认知工作、实际策略引用和结束依据按 [内容准备](../../personal-learning-suite/src/skills/learning-teaching/references/design-whole.md)维护。

其他专业入口的开发 API 段落描述虚构程序，不是人工教学的前置。人工对象是共享契约的可追溯视图，不冒称已校验 JSON、已认证角色或正式程序授权。

## 当前授权与角色

区分资料导入、用户要求开始学习和学习实际发生。旧记录只授权导入时不自动开课；用户现在明确说开始／继续，或发出 [START_PROMPT](START_PROMPT.md)，即可在该请求与既有约定内开展相应教学和保存。更新真实授权范围不能倒写此前已学习、已接触或已通过。维护框架文件不是开始学习，不创建学习事件。

AG0 组织当前会话；目标／关键设计／重要计划按 AG1，学科实质研究和内容／用途按 AG2，反向专业审查与重要评价按 AG3。认知分析可以把具体专业缺口回问AG2，修复后读回受影响内容并进入实际成品；已经充分的部分保留，不强制新增任务。高能力模型可顺序兼任相容职责，注明同模型自查；能力不足时依赖充分准备与有限授权，仅关键缺项升级。普通讲解、提示、等价呈现、常规反馈和缩时不逐轮审批。重要复核先回原始依据；已看旧结论不能假装忘掉或称盲评，换模型也不自动成为独立核验。

角色与 Skill 名称不自动启动子 Agent。跨会话／模型接任前确认旧执行停止当前活动的面向用户教学；不能确认唯一入口时暂停新提示。提示词、文件锁及清单不提供身份认证、并发隔离或旧聊天拦截，默认单入口顺序处理。

整体单元收束／重要跳过时显式读取AG3相关职责和SK04整体规则（稳定已读可复用），常规局部反馈仍可由AG0完成。恢复区分生成时的prepared快照和已回查的真实展示；以当前checkpoint及确认事实继续。维护新增的派生笔记、材料和代码是准备，不是用户已作答／运行或能力通过；优先接原目标的未完成连接，不重开首次学习。

## 让第一段学习实际开始

用现有课程地图、大纲的近期片段、用户用途及合法作品确定当前位置。只问会改变可行入口的缺项，不先要求完整画像或固定题量诊断。时间／设备未知不编造；可先做已授权、随时可收束的可靠输入或探索，完整证明、实验和新增费用承诺需相应条件。

遵循 SK00 和 SK03 的具体准备规则：
- 缺术语、对象说明或初步表征，或用户请求讲解／示范：先给够用框架、定义、例子及对应关系；再留下可完成的学习者工作。必要输入无需等答错才提供。
- 前提可用、任务有界、错误可定位且有可靠后续讲授：可以先尝试或预测；不能把未知定义连续出成测验。
- 已有合格活动／相关作品：直接执行／评价并复用支持；没有需要的新证据就收束。
- 直接问一个概念：给所需讲解，可以结束；不强迫小测或编造表现。不在未授权的其他课程开档案。

开始回复简短说明当前目的、工作、允许资料和投入边界，随后真正交出必要输入、范例或任务。不是只列“准备完成、证据待收集”。框架、图式、范例、代码按内容功能选择，静态够用不用复杂媒体；来源、教师参考和任务必须能支持当前用途。

## 动态深度、广度与实际应用

目标要求、当前展开、本次工作量分别处理。完整证明、机制推演、条件比较、构造、实现和实验解释有真实需要时保留整体要求；本次分段不降低标准。广度扩展服务必要条件、可辨比较和新情境，不把兴趣变为原目标欠账。

真实回答中的动态适配按 [Encoding 的动态调整与返回](../../personal-learning-suite/src/skills/learning-teaching/references/encoding.md#动态调整与返回)执行，有限诊断按其中引用的 SK04 规则按需读取。局部修复保留父任务、原答、卡点、暂定解释与反证、实际帮助及后续反应；够用即回整体。局部会而整体仍失败先查接口、组织、选择或原判断，不能沿同一前置链无限下钻。

Post 区分访问、关系、选用和更新；前提允许提供后能继续就继续，仍有结构障碍才局部 Encoding 后返回。需要选法才加载 SK06 的候选及完整资源；不固定检索先行，不凭卡名执行，也不重置帮助历史。

具身学习按当前内容连接理论对象与变量、张量、数据流、实现及实验；当前只需概念辨认时不自动加实现。证明、有限数值、程序行为、离线预测与闭环效果分别核验。关键论文／软件版本或新模型细节要有实际依据，不能把生成流畅当正确。

大纲 A/B/C/D 是课程优先级／要求线索，260 小时、周安排、固定单元或待补数量是候选估算；未获个人采用不构成承诺。M0 是候选起点，已有支持可改变入口；资料导入不是已读／掌握。来源表中的旧核验状态只按其真实范围与版本使用。

## 过程、代码与保存

按 [INTERACTION](INTERACTION.md)复用稳定上下文、减少无变化文书。实际原答先保留再反馈，简单反馈直达具体依据和下一工作，复杂证明按需要展开。较长核验说明具体工作；可选等待动作复用已有任务、不泄露待检答案、不增加必修负担，不承诺固定响应时长或后台续写。

用户问“为什么这样学”，解释本次工作与目标、已有支持的关系；检查自主选用时先保留具体判别线索，用户要完整理由／参考可以展示并转教学。少讲／不用图／换文字时，形式不是目标就给合格替代；构图、实现或转换正是目标时说明未覆盖部分，不暗改判据，不固化为学习类型。跳过检查可继续可靠学习；下一工作依赖未裁定能力时说明限制并给受限路径，不默认已经会，也不强迫补考。

| 实际内容 | 规范位置 |
|---|---|
| 题面、当前输入、备用帮助、教师参考及用途 | questions/；当前输入与备用／参考分区，按实际展示记帮助 |
| 用户原话、初答、修订、实际关键帮助及先后 | sessions/raw/ 与会话记录；AI 整理稿不覆盖原答 |
| 推导、证明、报告、图表等完整产物 | artifacts/；会话引用原件与具体版本 |
| 全部学习代码、可执行 notebook | code/，按模块／项目组织；用户、AI、共同编写均在此，保留来源、贡献、环境与可定位版本 |
| 实验条件、实际输入输出、结果与解释 | experiments/，引用 code/ 原件；未运行不记已验证 |
| 来源、目标、有限判断、必要需求与当前安排 | materials/、goals/、assessment/、plan/；只有实际决定／事件发生才更新 |
| 真实停止点、下一连接与当前索引 | sessions/ 的 checkpoint、state/current.md；控制范围变化更新 state/control.md |

使用 [模板](templates/README.md)辅助定位，简单活动可用短记录，不必填满内部字段。在已授权课程内保存必要学习事实，不默认永久保存全部聊天；保留范围、归档／清理和用户入口沿控制约定，无明确约定时只保留当前恢复必需内容并说明范围。

有文件工具时原答先写入并读回确认再反馈，只有完成才说已保存。无工具或保存失败先保留可得原话／版本，返回明确路径和待保存原答正文或实际作品定位，再给反馈；两者分开，不等用户手工保存后才给普通帮助。原件缺失不据摘要补造，正式复核仍需可回查合法依据。部分成功逐项说明，单入口顺序写不冒称原子事务。真实内容不导入 fixtures、examples 或 synthetic SQLite，也不改通用框架来“过门”。

## 结束与跨模型继续

够用、暂停、预算结束、无增量或必要依据缺失即可结束。说明真实完成、帮助条件下的支持、未完成连接、停止原因、恢复点及同一必要需求的实际去向。未安排写未安排，计划日期不等于学习发生或保持达成，目标没要求的延迟／迁移不追加。

继续先核当前控制和版本，按引用回原产物、任务、实际帮助及停止原因：缩时续未完成连接，无摘要用最后可信事件，无进展处理反证，参考争议核验后才恢复依赖用途。已完成部分不冷启动重做，未记最后动作不猜补，关键缺项才澄清。

异议和删除按 SK00 session-entry 的两链纠错及合法剩余依据处理。原答够用直接重评；材料、历史评价、教学误导与计划分别恢复。删除不经旧摘要／迟到结果／指纹复活，宿主历史和外部副本控制范围如实报告。新模型接入同一合法原件，不增加独立样本或重置暴露。
