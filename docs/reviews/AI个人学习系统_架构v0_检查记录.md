## 三、关键异常场景的纸上走查

各行依次检查触发、责任与行动、保存的信息及后续去向。场景可组合，不要求额外增加十二套运行模块。

| 编号与触发 | 责任与处理 | 保存什么 | 返回或后续去向 |
|---|---|---|---|
| A01 基础不足：任务缺关键前提 | 中层定位并在授权内给局部支架；改变目标依赖时交高层 | 原答、缺失前提的证据、帮助、暂定诊断、父目标 | 局部 Encoding，随后回到原目标的新任务；必要时缩小范围 |
| A02 同错反复：不同题中重复同类错误 | 中层暂停单纯加练；高层重审题目、来源、诊断和已用反馈 | 错误表现、已试策略、反馈依据及反证 | 更换活动或补建关系；资源不足时调整承诺范围 |
| A03 提示下会、独立不会 | 中层分别记录，高层按需要复核重要能力判断 | 两种条件的原答、提示内容和任务暴露 | 保留有帮助表现，补独立调用检验；不自动登记为独立掌握 |
| A04 原题会、新情境不会 | 先区分识别、映射、执行与新情境前置；重要诊断变化交高层 | 新任务改变了什么、作答、已给条件和备选解释 | 选择条件辨析、局部补缺或应用练习；必要时拆分目标 |
| A05 材料冲突：来源结论不兼容 | 中层标记争议，高层确定核验依据和影响范围 | 来源、版本、冲突命题和依赖任务 | 未解决前暂停相关评分；解决后修订受影响教学、判断和计划 |
| A06 用户指出题目或评分错误 | 暂停争议判断，按内容纠错责任复查 | 原题、原答、异议、旧评分及修订理由 | 撤销错误派生判断，保留历史语境；必要时补测 |
| A07 临时缩时或请求示范 | 中层执行暂停、示范和范围内调整；改变承诺范围时交高层 | 新约束、已给帮助、已完成部分、未完成项 | 记录预算结束或转回教学；示范后需另取得合条件的独立表现 |
| A08 跨天复习积压 | 高层在共同预算中比较关键依赖、证据缺口与目标价值 | 候选任务、取舍理由、延期部分和新范围 | 必要纠错与检验挤占可选新学；不能维持原范围再无限追加 |
| A09 中断或更换 Agent | 新执行者先读取交接；授权或结论冲突交责任方处理 | 当前目标、最后证据、帮助、未决项、返回位置 | 恢复明确下一步；关键上下文缺失时先做最小确认 |
| A10 延迟失败或旧错复发 | 中层区分访问、关系与条件问题；高层修订重要诊断 | 实际间隔、线索、版本、正确与错误侵入 | 补检索、局部 Encoding 或边界辨析；证据反向改变后续范围 |
| A11 无法取得可靠答案 | 中层保留未知并上报；高层决定依赖范围 | 缺失依据、争议内容、已核验部分 | 暂停相关评分和超出授权的判断；继续不依赖争议的活动 |
| A12 用户改变目标或纠正个人记录 | 用户决定新目标，系统说明影响；高层修订范围与重要结论 | 修改内容、理由、受影响任务及剩余证据 | 按新目标重新安排；删除证据后不保留不可追溯的确定判断 |

## 四、数学活动与跨学科检查

### 1. 数学核验锚点

主文档四.2 的例子限定于实数域：

- 若 a 不为零，ab = ac 可以推出 b = c。
- 若 a = 0，原等式不能保证 b = c；a = 0、b = 1、c = 2 是反例。a = 0、b = c = 1 则表明 b = c 也可能成立，不能把“不能保证”误写成“必定不成立”。
- y² = 3y 的完整实数解为 0、3；直接除以 y 会遗漏零解。
- (x² − x) / x = 0 的原定义域排除 x = 0；其唯一实数解为 1，约分在此合法。

核验只支持例题的数学正确性。是否适合具体学习者、是否有恰当诊断力、是否促进保持和迁移，仍需实际任务证据。验收前不能暴露上述答案；独立成功必须记录帮助历史和题目暴露。

### 2. 四学科的设计适配

| 学科情境 | 应采用的判据 | 暴露问题后的返回路径 |
|---|---|---|
| 数学：类比解释流畅，但证明存在跳步 | 对象域、前提、量词与推导是否合法 | 补必要引理或推导，再回到原目标独立检查 |
| AI：概念答对，但代码或实验失败 | 概念、实现行为、实验条件与结果解释分别检查 | 定位概念/实现/实验设计问题，修复后换适当配置检查 |
| 金融：公式使用正确，但情境假设失效 | 模型适用条件、数据时间与不确定性 | 用对照情境检验条件选择，不用单次结果盈亏评价理解 |
| 政治：立场明确，但事实或因果依据不足 | 区分事实、解释、价值判断和竞争理论 | 核查来源、补证据或比较解释，不以立场一致作为掌握 |

本表验证共同流程是否容纳不同正确性标准，不构成四学科教学效果证据。
