## 2. 实际输入、抽样与拟合过程

训练 100000 条、held-out 25000 条，均为各 c 恰好半数后打乱。训练／held-out／生成 seed 分别为 20261010／20261011／20261012。给定 c 后独立抽 X₀∼N(0,I₂)、X₁∼N(μc,.25I₂)，μ₀=(-2,0)、μ₁=(2,0)，t 连续 Uniform[0,1)。实际构造 Xt=(1−t)X₀+tX₁、U=X₁−X₀。

shape：X₀/X₁/Xt/U=[100000,2]，t/c=[100000]；Φ=[100000,68]，W=[68,2]。17 个 τj=j/16 的 hat 基函数乘 `[1,x_coord0,x_coord1,2c−1]`；训练输入没有 μ 中心化、oracle 速度或解析场系数。训练标签始终是独立样本 U。

损失为 coordinate-MSE=`mean((ΦW−U)**2)`，即 `(1/(2B))Σ||ΦW−U||²`。从 W=0 用 `np.linalg.lstsq(Φ,U,rcond=None)` 求一次有限经验平方问题的解；没有正则化或声称执行梯度优化器。局部 b 更新与完整共享 W 拟合是两个明确分开的示范。

## 3. 风险、场误差与常数项

所有下表 MSE 均按两个坐标归一化。held-out 独立于训练，oracle 只在评价调用。

| held-out 量 | 实际值 |
|---|---:|
| learned vs U 的 CFM coordinate-MSE | **0.7841924748** |
| learned vs v* 的 field coordinate-MSE | **0.0005578587** |
| oracle v* vs U 的 coordinate-MSE | 0.7836408288 |
| 本批 `.25/Q(t)` 平均值 | 0.7815269999 |
| 总体不可约 coordinate-CFM risk（解析） | π/4≈0.7853981634 |
| 本批残差交叉项 | −0.0000062127 |
| 有限批代数分解的剩余误差 | 1.49×10⁻¹⁶ |

本例每坐标 `Var(U|Xt,t,c)=.25/Q(t)`，连续均匀 t 的积分为 π/4，所以总体 coordinate-CFM risk=field coordinate-MSE+π/4。有限 held-out 的 U 仍随机，样本 t 权重也波动，交叉项不会严格为零；因此不能要求 0.78419 必须等于 field MSE+π/4，更不能据非零 CFM loss 判失败。有限批代数分解加上交叉项后吻合，只核本批计算，不冒充总体梯度的实证证明。

这些数字支持这次模型在本 Gaussian、抽样分布和有限评价上的场近似；不能由一次 OLS 最优点推出任意分布、轨迹区域或真实神经网络都正确。

## 4. 同一个 W、同一噪声批的采样比较

生成输入 z[8192,2]、c[8192]，每 c 4096；所有 N、oracle 与 learned 使用相同 z/c，W 固定。Euler 输入签名为 `euler_sample(field,z,c,n_steps)`，field 为 `(x[B,2],t_scalar,c[B])→velocity[B,2]`。N≥1，N 次当前状态查询与更新，最后 t=1，不额外查询 t=1。每样本 NFE=N 是当前算法的成本代理。

Oracle exact 是解析 Y₁=μc+.5z；oracle Euler 是同解析场的数值积分。learned reference=2048 步，同场 double reference=4096 步。2048 与 4096 的配对 coordinate RMSE 为 **0.0001841599**，二维 norm-RMS=0.0002604414；4096 vs oracle exact 的 coordinate RMSE=0.0063664838。加倍步数变化很小，允许作为本次有限比较参照；它仍非 exact，也不是剩余误差的严格界。

定义：coordinate RMSE=`sqrt(mean((y−ref)**2))`；二维距离 norm-RMS=`sqrt(mean(sum((y−ref)**2,axis=1)))`，对相同二维批次恰好是前者的 √2 倍。表中均为 coordinate RMSE；norm-RMS 原件在 JSON/CSV 中。

## 5. 实际数学与接口检查

8 组关键核验通过，记录保留具体输入／输出：

1. 单条 x₀=(-1,1)、x₁=(3,−1)、t=.25 得 Xt=(0,.5)、U=(4,−2)；b=(2,0) 的 loss=4、梯度=(−2,2)，η=.1 后 b′=(2.2,−.2)，loss=3.24。
2. hat 分区和为 1、最多两项活跃、t=0/1 端点正确，查询 j=4 活跃块为 `[1,0,.5,1]`。
3. 7 个 W 元素的中心有限差分检查 coordinate-MSE 梯度，ε=10⁻⁶，最大绝对差 **4.62×10⁻¹¹**；标量 t 的相邻节点快速插值与完整 ΦW 在若干端点／非节点一致。
4. Gaussian exact 的数值导数与 oracle_field 最大绝对差 **2.18×10⁻¹⁰**，初值／端点正确；π/4 的独立细网格积分为 .785398163392。
5. oracle Euler 终点符合独立系数递推，N=1/4/16/64 方差为 0/.115967859752/.207647081603/.238686275967；N=1 确实全部到 μc。
6. 用 v=−x 检查更新后的状态、恒速场和 v=t 的求和对照；N=4 查询 t 为 0/.25/.5/.75，恰好 4 次，无 t=1 查询，不改原输入 z。
7. 拒绝 12 个非法 N／shape／类标／非有限输入或错误场输出情况；正整数 N 接口才可采样。
8. 同 c 双峰 t=.5、x=(.5,0) 的 w+=(.960834277203)、v*=(2.349339374101,0)，全局终点均值为0；独立配对成本6.5，合法 X₁=μ+.5X₀ 耦合成本4.5。

这些检查分别使用导数、有限差分、精确解、手算常数与行为规格，不用把同一循环再写一遍作为“证明”。完整任意场的误差定理不由这里的有限运行建立。

## 7. 有限结论与未运行范围

本教师示范确实从独立 CFM 标签拟合了共享参数；Gaussian 主例的 held-out 场误差小，同样初始噪声下积分步数增加减小了本次主要端点误差。正确 oracle 的 N=1 也方差塌缩，支持把学场与解场分开；这只是该设定、同一 seed 与当前算法的有限事实。

固定 t,c 的模型仍是 x 的仿射函数，**没有同 c 多峰训练证据**。双峰后验及 OT 成本仅作解析结构对照。没有 PyTorch/神经网络、真实动作 chunk 训练、机器人执行、闭环效果、其他耦合训练、算法速度排行榜、超参搜索或多 seed 重复。显式 Gaussian 头直接抽样在本例也合法，FM 不因课名成为最佳方案。
