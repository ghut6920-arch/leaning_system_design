# 初步学习框架 EMB-MAP-001 / revision1

身份：AI生成教学草图，prepared，非唯一架构、非用户心理状态记录；单模型兼任，无独立复核。用途：让当前具身学习主题、课程能力和张量任务有可修订的关系定位。不以看过图证明学习者形成了表征。

任务锚点：机器人把杯子推到指定位置。观测为相机图像、机器人状态，目标可以来自语言或其他指定条件。策略根据观测/目标产生动作；执行改变环境；新观测形成反馈。世界模型若被使用，则根据历史/状态及候选动作预测未来，为动作选择提供依据。这是常见功能区分，不声称每个策略必须包含显式世界模型。

关系草图：观测与目标 → 表征 → 动作选择/生成 → 执行 → 新观测。世界预测是可接在表征与候选动作上的预测支路，预测产物不等同可执行动作。训练与评估是跨环节的学习/核验过程，不是每次执行都必须在线训练。

课程地图：M0数据/张量接口；M1–M3必要数学、损失、梯度和模型训练；M4视觉表征；M5序列、Attention与条件接口；M6–M8生成、动作条件预测与小实验。数学随任务补，方向和先后仍按实际目标调整，不把大纲候选全量变为强制前置。

当前局部位置：相机视频进模型的数据接口。轴T表示帧、C表示颜色通道；两模块布局[T,C]与[C,T]不同，轴交换须保留每个值的帧/颜色身份，reshape的尺寸吻合不能替代该关系验证。颜色数表是接口关系的缩小例子，而非Python语法课程。

Encoding依据：建立当前目标需要的对象、条件和关系，完整解释可先提供；整体图只是教师支架。后续应让学习者在完整实践中解释/修改数据流，按实际表现调整这张图；不强制先做全课心理表征诊断。

当前展示不附新测验；后续先连贯解释一个真实数据接口示范，再整合实践，不回到连续小题。
