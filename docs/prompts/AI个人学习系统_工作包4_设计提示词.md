# AI 个人学习系统：工作包 4 设计提示词

我正在建立一个面向个人长期使用的 AI 学习系统。工作包 1「整体学习流程与概念架构 v0」已经完成，工作包 2、3 正在另外设计。本轮请聚焦工作包 4「材料选择、输入组织与生成内容核验」，对应架构 v0 的 B3。

我希望解决的核心问题是：**AI 收到我上传的课程与学习材料后，怎样结合学习目标、已有学习证据和现实约束，判断我具体应该学习哪些内容，适合通过怎样的文字、公式、推导、例题、图示或其他形式接触它们，哪些辅助材料值得补充或生成，以及怎样保证这些内容和后续使用依据可靠。**

请交付这部分的中文顶层设计方案，使后续教学设计可以据此继续展开。方案要有明确但可修订的选择，解释关键判断、依据和取舍。材料形式可以自由选择和组合，也可以有理由地暂不增加输入。

系统面向人工智能、数学、金融、政治等学科。既有方向是高能力 Agent 负责关键规划、评估与教学设计，中等能力 Agent 承担主要交互、制作和执行。时间不足时，独立掌握优先，必要时缩小覆盖范围；用户保有对目标和投入的决定权。

## 希望设计解决的问题

以下问题表达需要解决的事情，不是固定目录、步骤或模块清单。你可以重新组织问题，发现更关键的矛盾，并提出更简洁的设计。

- **上传材料怎样成为可定位、可理解、可使用的内容？**怎样辨认其中的知识关系、条件和上下文，形成适当粒度的片段或组合，并处理读取不完整、内容缺失和资料冲突？
- **为什么此刻选择这些内容与形式？**同一主题面对不同目标、已有表现或不确定性时，材料选择怎样改变？何时原文已经足够，何时需要解释、推导、范例、对照或可视化，何时值得寻找补充来源或生成材料？怎样考虑前置、负担、可访问性与预算？
- **材料怎样组织成实际可用的学习输入？**原文、辅助解释、公式、例题和图之间怎样对应；材料应让学习者完成什么工作；怎样与教学活动共同设计，同时保留交互调整的空间？学习用内容、提示、参考答案和评分依据在不同用途下应如何使用？
- **可靠性怎样建立并持续维护？**怎样区分来源身份、内容正确性和当前适合度，核验转述、生成例题、图示及评分参考？来源冲突、生成错误或材料更新后，怎样限定使用、纠正内容，并把受影响任务与判断交给相应工作处理？
- **这部分怎样与其他工作接起来？**从 2、3 获得什么目标与证据信息，向 5、6 提供什么材料与使用依据，与 7、8 怎样协调预算、责任和恢复？反馈如何改变下一次材料选择，哪些细节可以留待后续？

## 设计边界与自由度

具体概念模型、流程、分工、表示方式、材料粒度和选择办法由你论证。材料形式和研究框架都是资源，不要求每项内容配齐所有形式，也不要求将工作包映射为独立 Agent。v0 是当前起点；如有充分理由调整其中可修订的选择，请说明影响。

材料管理需要有主动的适配判断，能提出材料及其教学用途；实际逐轮提问、提示撤除、反馈与策略调度仍由后续教学工作展开。与 2、3 的接口先说明所需信息的含义，避免依赖它们尚未确认的完整结构。

请延续项目已有的证据边界：材料特征不直接等于用户能力；AI 提供的解释不构成用户掌握证据；方法或答案暴露会改变后续表现的含义。生成内容不能只靠未经核验的生成答案或模型彼此赞同来证明正确，内容与评分应能追溯到适合其用途的来源、推导或检验依据。依据不足时允许未知和限定使用，并有可继续推进的路径。

本轮停留在能指导后续设计的层次。需要深入的关键细节可以深入，具体技术选型、完整字段、固定阈值、全量资源库与逐轮教案无需提前确定。请保留各学科不同的正确性要求，也保留有限首期范围和后续简化的可能。

## 交付期待

请用你认为最清楚的结构交付一份连贯、可审查的方案，展示主要信息与流程关系、关键选择为何成立、失败和变化如何处理，以及后续工作据此能接着做什么。重要取舍给出理由、代价和不确定性，区分项目依据、设计推论与待验证假设，并提供可定位的关键出处。

用少量有区分力的情境检查方案是否真的能产生不同材料安排，并体现来源或生成内容出错时的处理。没有真实课程或学习者记录的部分，可用明确标注的假设继续设计，不虚构个人基础、教材位置或学习成效。缺失信息按其对关键决策的影响提出，不必先完成全面访谈。

完成时，我应能沿着「为什么现在学习这些具体内容—为什么采用这种形式—需要我完成什么—可靠依据在哪里—什么反馈会改变安排」检查方案，并知道这部分如何支持后续教学。请在真正影响判断的地方深入，不必为了形式完整而扩展功能或重复原则。
