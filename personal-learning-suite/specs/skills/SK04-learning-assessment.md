## 负责的决定与模式

AG3 主责任务资格、评分、条件化判断、有限诊断和重要复核；AG0 仅在有效常规评分授权内执行。模式按路线为授权常规评价／重要复核／诊断／重评，形式上调用 Skill 或自报 `review` 不取得重要复核权。

常规授权须限定判据、任务／对象、可支持结论、升级信号和预算。重要跳过、整体复杂产物、非标准解、评分争议、相反证据、删除影响或结论扩展交 AG3。不能统计次数判掌握、把缺证一律加题、自建复习队列或改目标；无授权仅输出候选分析。

## 编写依据与接口

必读路线评估角色、矩阵、模式／加载、P-Performance 与异常；D00 语义、帮助时间、生效／控制；D01 第六、九至十一节；D02 第五至九节；D04 第四至七节；D06 第七节；D09 责任与采用；D10 学科评价；D11 第三、六、八节及 B10-01／02／04／08／10／11。研究仅解释方法边界，不代替本题评分参考。

输入：拟作决定、当前控制／授权、`GoalSpec`／先定判据、原任务／`ActivitySpec`、`PerformanceEvent` 原答／修订与实际资源、帮助／暴露／接触时序、完整 `ArtifactRef`、内容核验／`MaterialUse`、相反依据。重要复核先自行对照原始依据，再看教学者总结。

输出：评分理由、要求级 `Judgment`（`support` 与 `eligibility` 双轴、条件、用途、依据、反证及未支持部分）、`DiagnosticNote`（观察、解释、替代解释、反证、会改变安排的观察／分支、预算／停止）、有限用途与必要 `LearningNeed`，或“不追加检查”。预算／分支可引用同一活动，不另建诊断表。

AG3 有权采用证据解释；AG0 授权常规判断必须留 `AuthorizationGrant` 引用。任务与内容疑误分别交 AG1／AG2；补证需求交 AG1 实质取舍，诊断不直接排额外学习。工作返回用 `WorkResult` 明确已处理／未处理、限制、采用责任和下一触发。

## 路径、约束和停止

常规路径：先控制／授权 → 查任务能否支持拟结论 → 对照原答、真实条件和先定判据 → 评分与有限解释 → 查反证／使用资格 → 有权采用 → 仅必要工作入同一需求。未知、已观察未达、混合／冲突分开；目标未要求的时间／迁移不生成欠项。

短路径：原答足够时直接重评，不令用户重考修系统错误；已有自然任务具所需证据可直接用；已有充分合格支持就结束；必要诊断不会改变安排时停止，不追问完整画像。

异常：同原答同条件相反评分回原答与判据，不投票／平均／最后到达优先；不同条件分开支持。帮助只限被代做操作，同题修订／多评分／多角色引用不新增样本，标题和安排解释也可泄露方法。原答／帮助／接触未知仅限制对应结论，不能从摘要还原；日历到期不能补造延迟条件。

失败／超预算／高能力不可用保留有据范围、未决责任和触发，重大决定待复核；依据停用立即限制用途，四项纠错分别恢复。删除后仅据剩余合法证据保留／收窄／撤销，不等能力下降、不自动补测；终止受影响上下文并拒已删迟到内容。接管继承授权与真实条件，不重置暴露或抢占用户入口。

必须保留：支持状况与使用资格独立，流畅解释和排期不是能力支持；新标准不倒判旧答。新增实现选择：使用共享双轴枚举与要求级判断，不建全章 `mastered` 布尔值。

## 加载、工具与修改范围

已提供 [证据规则](../../src/skills/learning-assessment/references/evidence-rules.md) 与 [诊断／复核规则](../../src/skills/learning-assessment/references/diagnosis-review.md)，按当前模式加载。实际判据、原答、帮助、核验依据和拟作决定仍需取得；按需专业核验，冲突／删除回实际相关记录。盲评尽可能先不看旧评分但保留必要条件，无法落实则记录限制。

模型依据实际原答与判据作专业评分；B3a 辅助器负责结构化虚构候选的资格、条件、授权、有限诊断和 B1 受控提交检查，不自动判断学科真伪。常规评分授权模板限定对象、判据、可支持结论、升级信号与共享预算，实际授权还须可核查。缺原件或专业能力就限对应用途，第二模型重述不称独立核验。宿主不能写入／输出隔离退顺序兼任；后台不直接向学习者追加题目。

本批范围：SK04、AG3、常规评分授权模板和有限受控评估接口，依赖 B2a／B2b 与 B1；共用规则集中由维护者改，不建另一套 schema、掌握总分或状态库。提交候选／调用成功不等于已采用。B3b 接教学事件，B5 贯通、B6 验证网络；真实课程、宿主身份及展示拦截均待后续落实。

## 虚构验收与交付

| 虚构输入 | 可观察通过条件 |
|---|---|
| 同原答，关键提示分别在初答前／后 | 帮助前原答可独立解释，后答仅限代做操作，不整主题清零（B10-02） |
| 参考错误，充分旧原答合法 | 直接重评并留历史条件，不新考、不用新标准倒判（B10-04） |
| 删除 A，B 分别充分／部分／无效 | 分别保留／收窄／撤销；迟到“通过”不复活 A，未自动补题（B10-08） |
| 条件相同的相反评分与新合法解 | 回查原答／判据／内容；不投票或机械按参考路径判错（B10-11） |
| 当前支持充分／仅未来时间条件未到 | 当前结束，不加目标外即时检查；必要时间仍未完成（B10-01／10） |
