# 正常教学实例：从内容准备到连贯工作

依据 D03 第六节、D04 第二／四节、D05 第四至六节和 R01 的结构适配及教学演示。用于准备陌生单元或检查教学指引的实例化，不每轮常驻；是自包含假设情境，不是用户原答、独立实验或学习收益记录。数值与模型是教学规格，不能当现实系统结论。

## A. 初学视频张量：先有语义对象，再处理轴

假设本次目标是理解视频数据如何匹配接口，能保持帧、像素、颜色身份做轴对应；此前没有相应表现，允许看范例与用索引说明。不暗加自主编码、闭卷 API 记忆或长期保持。

**内容准备。**整体关系是“视频帧／像素／颜色→数组坐标→模型接口”，当前必要前置是索引和轴的含义。输入采用 `(B,T,H,W,C)`，接口要求 `(B,T,C,H,W)`；这些是本例明示约定，不是所有模型的统一顺序。用有语义的颜色与位置解释，不能只给一串无对象的整数。

**当前输入。**先说明 B 是视频条数、T 是帧数、H／W 是像素行列、C 是颜色通道。本例有1段视频、2帧，每帧1行2列、RGB三个通道：

| 帧 | 左像素 RGB | 右像素 RGB |
|---|---|---|
| 0 | (10,20,30) | (11,21,31) |
| 1 | (40,50,60) | (41,51,61) |

旧形状 `(1,2,1,2,3)`，新形状 `(1,2,3,1,2)`。轴交换是改变坐标的安排，原帧／像素／颜色值保持：

`y[b,t,c,h,w] = x[b,t,h,w,c]`。

**连贯示范。**旧坐标 `x[0,0,0,1,0]` 表示第0帧右像素的红色值11。新接口把颜色放到第3个轴，因此同一值是 `y[0,0,0,0,1] = 11`。相邻呈现表、轴名与这条坐标关系；无需先测维度乘积或每个轴编号。

**留下的工作。**让学习者沿同一视频找到“第1帧右像素的绿色值”的旧／新坐标，并说明哪些身份保持。实际目标若只需读懂此映射，足够后结束；若目标需要完整转换，再由学习者完成各通道的一行值或实现规格，不把示范计为独立实现。

**教师核验与分支。**对应值是51，旧坐标 `[0,1,0,1,1]`、新坐标 `[0,1,1,0,1]`。若对象含义仍不清，指回同一表补“绿色／右像素／帧”的对应；若标签可用但索引错，局部修坐标读取再回映射。已正确时不再轮流考同义轴问题。

需要区别改形状与轴交换时再引入具体反例：第0帧按本例旧顺序连续排列为 `10,20,30,11,21,31`；直接分成三个通道、每通道两列会得到红色 `(10,20)`，正确轴交换的红色应为 `(10,11)`。因此元素数量与目标形状一致还不保证身份映射符合接口；某些退化情形结果相同，也不能推广成普遍可替换。本例的 H=1、W=2、C=3 足以显露差异。

**材料与记录。**完整映射是当前输入，另一种表示或局部释义按需要使用；教师参考不必同时全部展示。保留实际提供的映射与范例，后续成功按实际帮助解释。例子没有真实用户原答，不生成 PerformanceEvent。若以后采用库 API，核其实际规格与版本；这里不以某个库函数名替代坐标语义。

## B. 已有相关基础：把理论条件接到动态表现

假设学习者已有线性递推与曲线读取的合格产物。本次目标是判断负反馈模型在不同参数下的行为，并说明理论与数值观察的范围；不重测每个基础术语。

**当前材料。**给自包含离散模型、固定目标与参数：

`x[t+1] = x[t] + a*u[t]`，`u[t] = k*(r-x[t])`，`a>0`，`k>=0`。令 `q=a*k`、`e[t]=x[t]-r`，则 `e[t+1]=(1-q)*e[t]`。

若推导就是目标工作，只提供定义让学习者完成连接；若本次只比较稳定条件，可直接提供该误差关系作为合法输入。明确时间步、初值及固定参数，不沿负反馈符号直接推现实稳定性。

**连贯工作。**让学习者给出 q=0.2、1.2、2、2.2 时误差的符号与幅度变化，说明怎样从同一关系判断；再按用途查看轨迹或运行小模型与预测比较。已有完整论证者直接评价，不再强制加模拟。

**教师参考。**非零初始误差下，趋于零须 `|1-q|<1`，即 `0<q<2`。`0<q<1` 同号衰减，`q=1` 下一步归零，`1<q<2` 交替衰减，`q=0` 非零误差保持，`q=2` 等幅交替，`q>2` 交替发散。起点 `e[0]=0` 的全零轨迹不能单独支持一般稳定结论。

**调整与整体返回。**算对乘子但图式对应错，就核坐标、符号、初值和同一时间步，补实际对应再回原参数比较；一般条件已论证，不再加孤立数值练习冒充深度。如果目标确实需要考察一拍延迟，改模型后明确新增历史状态与特征方程，不能直接沿用无延迟条件；预算或目标不支持时暂缓该扩展。

**核验边界。**实际代码／图需核输出和合法范围；几个数值轨迹展示现象，一般条件来自上述理论关系。理论判断、程序实现与现实设备效果分别处理。本例不添加机器人执行、费用或外部实验权限。

**按目标才展开的逆向分支。**若当前工作变为“根据轨迹识别参数”，先让学习者比较 `(a,k)=(1,0.6)` 与 `(2,0.3)`：同一 r、初值和固定时间步下，两者 q 都是0.6，因此 x 的完整闭环轨迹相同，仅看这种轨迹不能分别确定 a、k。此处关键工作是说明为什么多组参数相容，而不是猜一个唯一答案。

若目标还要求设计鉴别办法，可让学习者提出并论证新增信息：例如教学模型中暂将控制输入改为已知非零命令 v，得到 `x[t+1]-x[t]=a*v`，在精确测量、同一 a 和时间步且模型条件成立时识别 a，再用原 q 求 k。更换控制输入是新实验条件，不是对原轨迹的等价重画；这里只准备候选实验，不宣称已经观测或在现实设备上验证。一般测量噪声和模型误差仍需另处理。

该分支转译 R01 第8、12节的正向／逆向区分及 D05 第三节的模型评议要求，离散算例由本次教学设计推导。原目标只有稳定性判断时不追加此项。

## C. 一般证明与方法构造：从计算走向约束方向

本例按 D05 第七节情境 C 实例化。假设目标是判断并证明二次目标何时有唯一极小解，进而构造或评议惩罚项。允许引用基础线性代数性质、使用数值工具辅助；一般论证和构造理由仍由学习者完成。已有产物只支持标准 `Q=I` 的计算，不将其当作一般条件的证据。

**可靠模型与当前任务。**`A∈ℝ^(m×n)`、`b∈ℝ^m`、`x∈ℝ^n`、`λ>0`，Q 是 n×n 对称半正定矩阵：

`F(x)=||Ax-b||²+λ*xᵀQx`。

当前给学习者的是模型、对象域、允许引用的性质和任务：“λ>0 是否足以保证唯一极小解？论证一般条件，并说明惩罚需要约束哪些方向。”教师先备下述完整依据；除非转为解释／示范，不直接展示判据再把复述算作自主论证。已有完整合法解者直接审查，跳过教学对照。

**必要时使用的结构对照。**取 `A=[[1,1],[2,2]]`、`b=(1,2)ᵀ`，s=x₁+x₂，d=x₁−x₂。数据项为 `5(s−1)²`，不约束差方向 d。并排准备两个同为非零、秩1、半正定的惩罚，保留差异判断给学习者：

| 惩罚矩阵 | 惩罚作用的方向 | 教师参考 |
|---|---|---|
| `Q₊=[[1,-1],[-1,1]]` | `xᵀQ₊x=d²` | 唯一，s=1、d=0，x=(1/2,1/2)；补上数据未约束方向 |
| `Q₋=[[1,1],[1,1]]` | `xᵀQ₋x=s²` | 不唯一，s=5/(5+λ)、d任意；重复约束和方向，差方向仍自由 |

学习者要把“未受约束的共同方向”接到一般论证，并按目标构造合法 Q；两个矩阵的算例答对只支持相应局部。构造允许多解，核其对称性、半正定性和是否补齐数据项未约束的方向。

**整体教师参考。**令 `H=AᵀA+λQ`。任意 v 满足

`vᵀHv=||Av||²+λ*vᵀQv`。

两个非负项之和为零当且仅当 `Av=0` 且 `Qv=0`；后一等价来自 Q 半正定的谱分解。因此 H 正定当且仅当 `ker(A)∩ker(Q)={0}`。此时 F 严格凸且唯一极小解为 `H⁻¹Aᵀb`。

反之，存在非零公共核方向 v 时，任意 t 有 `F(x+t*v)=F(x)`。极小解确实存在：F 是堆叠矩阵 `[A; sqrt(λ)*Q^(1/2)]`、向量 `[b;0]` 的有限维最小二乘目标；其像空间闭，投影给出极小值。因此沿 v 有无穷多个极小解。必要性、充分性和存在性均落实，得到“唯一极小解存在当且仅当公共核只有零向量”。几个矩阵测试不能替代这项一般论证。

**表现怎样改变教学。**不会“核空间”符号但能解释不变方向，就补术语对应；若只是需要允许引用的半正定引理，提供引理，保留唯一性连接；目标要求证明引理时才局部展开谱分解。会求两个核但不会论证唯一性，回查共同方向与函数不变／正定的连接，不继续堆矩阵计算。一般论证与合法构造已经完成时，按目标结束。

**返回与条件变化。**需要未展示的应用时，可备 `A=[1,0]`、b=2，比较 Q₊ 与 `diag(1,0)`；教师参考分别为唯一解 (2,2) 与 x₁=2/(1+λ)、x₂任意。它检查判据的使用，不代替原目标的一般证明和构造。Q 改成不定矩阵或 λ 改成非正值后，需要重新分析有界性与曲率，不能沿用原判据；只有目标包含该变化才展开。

**预算与理论上限。**时间只够计算，保存当前计算和论证断点，证明／构造仍未完成。若目标本来只要求按给定公式算一次，可靠唯一性性质可作为黑箱，不追加本例证明。这是可核验的教学设计，尚未证明本路线提高真实学习收益。

## D. 首次单元的完整备课

假设请求是“开始学习反馈系统，希望理解为什么纠偏有时收敛、有时振荡；先建立基本认识，再做一般论证和条件变化判断”。个人预算未知；允许看定义、计算器和几何数列引理。沿 B 的离散模型，课程粗地图暂定为对象与闭环→一般稳定条件→模型变化；本次主线是把前两项连接成一份有条件的解释，延迟模型只用来辨认原条件不能直接沿用，不扩成一门控制课程。

**先从目标关系选材料与问题。**Encoding 要建立目标 r、状态 x、偏差、命令 u、执行参数 a、增益 k 与下一步状态之间的联系；本次还需给出一般论证。Post 要整合局部方向与长期行为，并在模型条件改变时拒绝直接套用。辨认变量、算一次变化、一般论证和条件更新是不同工作，不能用前两项的成功代替后两项。

在首份教学呈现前备齐以下主线，按节奏分开显示：

| 已准备内容 | 留给学习者的主要工作 | 核验／返回 |
|---|---|---|
| 定义、模型、闭环关系图；a=1、k=0.5、r=10、x[0]=0 的两步完整示范 | Q1：从模型推得 e[t+1] 与 e[t] 的关系，说明局部纠偏怎样进入下一状态 | e=x-r，乘子为 1-ak；符号陌生时补释义后回同一解释 |
| 允许查阅的几何数列引理；未提前展示的完整教师证明 | Q2：对任意非零初始误差论证何时趋零，并解释 q=0、1、2 及 q>2 的边界 | 按合法推导核一般条件与边界，不由几条数值轨迹宣布证明完成 |
| 对照用轨迹图；带一拍延迟的新模型和明确历史状态 | Q3：解释原一般结论的成立条件；模型变化后判断原条件是否仍能直接使用 | 延迟改变递推结构，原条件不能直接继承；补局部关系后回最终解释 |

首回复先说“本次从同一模型连接纠偏过程、长期行为及适用条件，最终形成一份有依据的解释；可以分段”，随即展示变量、关系图和两步示范，再给 Q1 或继续材料。Q2／Q3 和参考已经准备，不等 Q1 答完才决定它们。轨迹图留到相应预测后展示，避免将图上类别标签当成自主判断；用户要完整解释则转教学并保留帮助。

预算未知不承诺全部完成；临时缩时可停在已保存的推导连接处，保留本次未完成的一般论证及模型条件。用户只要求解释时直接给所需解释，不强制走三问。已有完整合法证明者复用原件，当前只接尚未完成的条件判断；若全部要求已有充分支持，则结束。

同模型顺序制作并核查的完整虚构成品见 [教师安排](../../../../validation/session-preparation-fix-2026-10-05/first-unit/teacher-plan.md)、[实际输入](../../../../validation/session-preparation-fix-2026-10-05/first-unit/input.md)及 [首回复与调整](../../../../validation/session-preparation-fix-2026-10-05/scenarios.md)。这些是维护实例，无真实学习者记录；具体模型、题数和顺序均不作为其他课程的固定模板。

## E. 认知主线、实际选法与连续推进

虚构单元以“按条件把观测数组接到消费者”组织坐标身份、数值处理和通道合成。首回复连贯呈现对象、正常／错置对照、公式与完整流程，再留下整段关系追踪；后台已备消费者变化任务。备课实际读取S05、D02、X05、S09和两个Post完整包，注明借用范围，详见 [教师安排](../../../../validation/strategy-cognitive-fix-2026-10-06/example/teacher-plan.md)。

普通原答后，具体反馈与下一份实际条件材料／整体工作在同一回复中继续；局部错误获得对应支持后返回同一作品。无需逐题“继续”，也不凭局部成功结束单元。请求纯解释、暂停、已有完整作品或资源变化时按原范围调整。实际材料、运行代码和反馈文本见 [学习输入](../../../../validation/strategy-cognitive-fix-2026-10-06/example/learner-input.md)与 [课堂重放](../../../../validation/strategy-cognitive-fix-2026-10-06/example/classroom-playback.md)。此例的参数、题数和策略组合不作为全课程固定要求。
