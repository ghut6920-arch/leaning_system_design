# Post-Encoding：让已有知识在当前条件下可用

依据 [D06 正式方案](../../../../../docs/designs/AI个人学习系统_工作包5_Post-Encoding_设计方案_v0.md) 第二至八、十至十一节，[D07 策略使用](../../../../../docs/designs/AI个人学习系统_工作包6_策略使用规则_设计方案_v0.md) 第四至八节及 D04。研究依据是 R04 任务矩阵、R05 动态研究、R06 逐命题证据台账；八维状态用于分析，矩阵用于匹配，不转为评分或固定流程。

## 从目标需要的工作开始

先用一句具体工作说明确定目标要求、现有支持、当前需要完成什么。可直接从已有推导、代码、案例或合法材料继续；不重考全章术语，不把“学过”当全部可用，也不要求 Encoding 全部验收后才进入 Post。可靠原件已有足够目标证据时可直接结束。

课程／单元启动按 [内容准备](design-whole.md)提前落实本次需要的 Post 工作：恢复什么内容、连接或区分哪些关系、在哪些条件下选用／拒用、要解释或更新什么，以及实际任务、允许输入和可靠参考。它们与 Encoding 共用本次主线，不等第一题答完才决定是否需要综合。目标没有要求的功能不追加；延迟工作只保留目标需要的条件与触发，不假称在本次完成。已有安排直接恢复，不重复备课。

这项功能判断属于新单元备课入口，即使材料尚在首次讲授也要完成；目标需要的功能实际读所选完整包并实例化。近例执行可服务学习，但不能替代目标中的解释、条件选用或跨局部整合。错误被教师纠正后，原目标尚需的连接进入同一后续作品或条件变化任务；尊重跳过／推进请求，不机械追加微测。普通反馈后继续已备主线，不等待“继续”才重新规划Post。

Encoding 产物按实际用途沿用：学科参考／准备锚点、学习者表现证据、当前外部支架、未来恢复线索。一个产物可有多种用途，但“AI 总结完整”不证明学习者能恢复；提供作支架后观察的工作也不能倒算为帮助前完成。

在本次连续任务中，明确学习者将自行连接、选择、拒用或修订的具体位置。给定模型、完整公式或候选表可以保留有意义的整合工作，但不能因此声称已准备自主选模型、构造方法或实验设计；这些属于用途时须有相应新工作与可靠参考。教师参考比题面深的部分，只作支持，不算学习者承担。帮助后的修订与后续实际贡献分别解释，按 [备课质量实例](preparation-quality-examples.md)检查工作是否已由输入代做，不机械要求闭卷。

| 当前需要的具体功能 | 完整资源入口 | 这次要实例化的操作及改路 |
|---|---|---|
| 恢复目标事实、条件、程序或论证入口 | [post/retrieve-relation](../../../../resources/strategies/post/retrieve-relation.json)，按需只借恢复部分 | 明确恢复对象与允许入口；需要时给可靠内容／线索，让剩余工作继续。目标只要求查阅应用就直接查，不强加关系题或闭卷 |
| 连接、区分、抽象、因果／层级或整体协调 | 同一 [关系包](../../../../resources/strategies/post/retrieve-relation.json) 的关系源正文 | 准备关系两端及可靠参考，选下节的一项必要工作。给前提后能推理就继续；仍有具体关系障碍才最小回 Encoding |
| 在实际情境自行找到方法、映射并执行，或有依据拒用 | [post/select-method](../../../../resources/strategies/post/select-method.json) | 准备真实竞争情境；分开识别／源知识访问／映射／执行。提供方法后成功只支持剩余工作，失败可能含新前置 |
| 新依据要求纠错、修订条件或保留版本 | [post/conditional-update](../../../../resources/strategies/post/conditional-update.json) | 定位为什么变化，依据下节六种情况安排输入、比较、修订和后续检查；系统参考先核验 |
| 组合恢复、解释、比较、生成或解题；需要决定顺序 | [post/retrieve-generate-order](../../../../resources/strategies/post/retrieve-generate-order.json) | 说明后项增加什么尚未完成的工作、前提可用性、材料可见与帮助。前提不足可先讲解／开卷；已有前提可先恢复；不固定检索在先 |

四包不是四个阶段。一个完整目标任务可以兼有多种功能；只借实际所需部分，也允许直接讲解、示范、合法查阅或只做一个简单恢复。已有活动足够时复用；需要发现／比较方法再经 [SK06](../../learning-strategies/references/selection-adaptation.md)，不每轮先生成配置。

功能表用于人工教学选取原文工作范围。当前开发辅助器检查所选完整包的全部必要条件，不能因为只借恢复部分就把关系条件标成已满足。简单恢复可直接教学；若需要程序配置而完整包条件不适用，保持为人工方法／待核候选，开发侧另评是否值得增加相称资源，不为通过检查改写本次目标。

第一次采用一个包时读其完整 JSON：顶层说明和前置／排除／条件、必要操作、帮助反馈、停止返回、时间及证据限制，尤其 `source_excerpts[].content_markdown` 的完整设计／研究段落与 `evidence_refs`。只有标题、摘要、索引或 `source_refs` 定位不够。已经完整读过且版本、用途稳定时复用，不逐题重读全部来源。原文旧绝对链接失效时沿 `workspace_relative_path`／source_id 回本项目原件；文献 E 编号、覆盖 P 编号都不是原卡号。

## 把内容与关系工作准备出来

恢复对象可以是名称、命题、成立条件、程序、源例、关键不变量、接口或完整理由链。目标允许可靠重建时，另一条合法证明也可用，不要求逐字复现。复杂目标保留当前论证和整体位置，不改成一串互不相关的小测。

依据关系包的源正文选择当前需要的加工：

| 关系工作 | 准备什么内容；留什么给学习者 | 按什么结果反馈 |
|---|---|---|
| 桥梁连接 | 准确前提与成立条件；学习者补合法中间连接 | 连接是否真能推出结论，缺哪条规则；类比只算启发 |
| 近邻分化 | 共享背景、改变诊断条件的可信正／非例；学习者分类及排除竞争答案 | 区分概念不靠忘掉另一项；允许信息不足，指出缺哪个条件 |
| 跨例抽象 | 合法的角色对应，兼顾表面变而结构同、表面似而结构异；学习者提取有边界规则 | 哪些关系保持、哪些性质不能迁移；少量样例不当全称证明 |
| 整体综合 | 局部可用产物、接口、全局约束；学习者完成端到端论证／预测／实现 | 局部正确而整体错误先查连接和条件，不靠题数替代整体 |
| 因果与层级 | 可靠模型、系统边界及可区分候选／结果；学习者追踪机制或判断证据不足 | 方向、条件、时间尺度、竞争解释；自洽故事与设想实验不当已取得证据 |

只列操作名还不能教。当前安排须交出可呈现的可靠输入／示范、具体学习者工作、学科参考、困难时的支持以及回到原产物的位置。AI 可以直接给完整解释；需要检查某操作时才保留相应自主工作。关系两端来自记忆还是允许的资料分别解释；没有必要为每次开卷比较加一道闭卷前测。

反馈落在实际问题的一层：单项错误给正确对应；前提不够给可用前提；理由断裂解释合法连接；条件误用给诊断边界；选法错误比较适用性；模型冲突核对预测与证据。缺前提会污染后续推理时及时补；有可执行问题表征和后续复核安排时可考虑延迟反馈。具体时机按用途决定，可靠解释不以“先自主答错一次”为解锁条件。

## 自主选用与新情境工作

先看当前目标是否要求自己识别该用什么；若只是执行给定方法，不额外增加选择测验。需要选择时，在不代选的任务条件下观察：能否识别适用知识、是否能访问相应原理／源例、角色如何映射、最后怎样执行。恢复源例和正确映射是不同工作，不把“做过原题”当已会迁移。

准备包含应使用、应拒用或信息不足的有意义情境，而不把所有题放进名为“加权平均／贝叶斯”的题组。标题、邻题、笔记、刚发生讲解和工具默认都可能代选；改变措辞不会取消暴露。给方法后能做时保留执行表现，选择仍按实际原答解释。当前仅在给定候选间比较，不能称已完成广泛无提示选用。

新案例明确改变了什么、保持了什么和新增前置；陌生领域知识不足时先给必要背景或换案例。由源知识找不到、映射错、程序执行错导致的失败，安排相应支持。有限近例的成功不保证远迁移，目标没有更广条件时只表达边界，不制造欠账。

## 按原因更新，保留仍正确的知识

| 变化原因 | 当前教学／修复动作 |
|---|---|
| 系统题面、参考或反馈错误 | 停用受影响教学内容和评分，交 AG2 回核可靠依据；AG3 重评原答，用户可能原本正确；不要先迫使用户改答 |
| 学习者把规则过度概括 | 用合法边界定位原规则何时不成立，给替代关系／联合条件，同时保留旧有效案例 |
| 不同版本／情境各有正确答案 | 对齐新旧条件、来源和用途，按版本使用；版本未知时保留信息不足，不默认最新 |
| 新事实与原结构相容 | 直接接入必要关系，不制造冲突或强行重构整个模型 |
| 竞争解释目前均符合证据 | 比较预测与真正有鉴别力的信息；没有新增证据就保留多个候选 |
| 目标新增要求 | 交 AG1 明确目标变化，AG3 限定旧证据适用范围；旧目标合格表现不倒算错误 |

若要检验更新，观察学习者能否说明依据怎样改变关系／条件并用在目标情境；只有目标需要或旧错复发有依据，才再检查延迟、不同线索或旧场景。即时改答、背会一个反例、禁用所有旧版本或叙述更流畅都不能单独支持持久更新。系统纠错同时处理受影响内容、历史判断与必要错误教学修复，各由相应职责承接，不清掉无关正确历史。

## 最小回 Encoding，随后回整体

恢复失败先保存原答，提供目标允许的可靠前提。供给后能继续，就保留帮助后的推理，限制被代做的恢复；目标不要求独立恢复时没有闭卷债务。供给后仍有明确关系障碍，先排除任务理解、表达、工具或新增前置负担，再重建最小必要关系。

完整答案或理由交付后，按 [收束与承接](design-whole.md)区分教学输入完成与目标操作支持。原目标内尚需的组织／条件判断在同一作品的自然应用中继续承担，当前安排须已有实际输入、工作及参考；不只归档为未知，也不自动追加同题复述。每次阶段转换先明确当前对象、输入条件及消费者要求，再处理映射；数值、形状、角色身份、元数据与表示内容分别核对。

局部工作保留父产物／位置、卡点原答、有效支持、尚存解释、局部够用条件、返回连接、剩余预算和允许帮助。够用即回原证明、代码或目标判断；局部成功不补记此前未提示恢复，也不代替父任务完成。父任务仍失败时重审整体组织、映射、接口或诊断，不无限下钻。

理论目标可以要求严格证明、最低复杂度／秩构造、条件改变后的推理；实际目标可以要求实现、运行与模型边界解释。只有原目标包含这些工作时才展开，工具算例不代替一般证明。首次实例化可读 [方法与 Post 实例](method-post-examples.md)，其中有恢复分支、动态系统、选择、版本及高阶整体工作。

## 时间、收束与后续需要

引用相关学习、练习、帮助／反馈和最近有关再接触，必要时区分初始编码→恢复、恢复→反馈、反馈→后测、相邻练习四种时距；不每次新增四个字段。初学过去 28 天而昨天看了相关完整解释，不是 28 天无再学习保持。帮助只限制实际提供的操作，其他有效历史保留；未知接触保持未知。

近期同条件可靠使用可复用，不因日期经过自动判衰退；延迟检查本身也是练习，失败后的帮助再答带有新背景。睡眠、间隔、次数及行为更新不产生“巩固完成”“再巩固窗口打开”或“旧痕迹擦除”状态。研究组件证据、当前内容正确、任务用途及真实收益分别核验。

区分当前工作完成、目标内支持充分、预算／暂停、无进展、依据争议。重复帮助没有新信息时换路或收束；仅缺未来时间条件时结束即时追加。必要后续需求说明未支持要求、理由／不做影响、父产物、允许入口与可靠材料、完整成本及会改变下一步的结果，沿同一 LearningNeed 交 SK05 决定安排／暂缓／关闭；不另造“做某卡”的复习队列，也不冒称已经排程。
