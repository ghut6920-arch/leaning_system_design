贯穿各模式的时序与对象
at−1 → xt → (ot, rt) → at

x 是环境隐藏状态；真实 belief 是条件分布 βenvt = P(xt | 历史)。模型状态 (h,z) 或其中一个样本不能直接等同这个分布。

h 的确定性指给定上一步模型状态和动作后的函数更新。不同随机 z 历史仍会产生不同 h；“h 确定”不等于它是真状态或跨轨迹固定。

训练与预测为何不是同一件事

标准 ELBO 的重建 / 奖励项与同时间 KL(qt ∥ pt)共同训练模型。后续误差可经 h 递推向以前参数传播梯度，但这不等于直接对无观测的多步 prior 展开加了训练约束。

多步 rollout 是模型用法；latent overshooting 是可选训练关系；离线多步评估与闭环控制评估各自需要实际实验。此图不执行这些实验。

静态回退：不操作也能读清

在线过滤：看到当前实际观测，用 q 得到状态表示，参数固定。序列训练：沿过滤路径计算目标，聚合损失后用优化器更新参数。未来想象：从当前过滤表示出发，对候选动作只沿 p 展开，不能读尚未发生的实际观测。重规划：执行首动作后取得新观测，重新过滤并搜索后续动作。

CEM 更新候选动作的搜索分布；MPC 指规划—首动作执行—观测—再规划的外层循环。两者与 RSSM 参数更新、latent 分布更新分别处理。
