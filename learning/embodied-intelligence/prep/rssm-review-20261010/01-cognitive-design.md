# 认知设计：动作条件 RSSM 的连续理解与整体工作

版本：2026-10-10 v1.1；状态：本次审查用备课设计。本文不采用真实课程目标、不生成学习事件、不修改进度。设计者是本次子 agent；材料、来源和审查分别由其他子 agent 承担，最终采用由主 agent 整合。未读取其他学习记录或旧 RSSM 备课。

## 1. 从本次用途推出终点

用户要求的是“部分可观测环境中的动作条件 RSSM——从序列变分推断到多步预测与闭环规划”。因此近期单元须承接六条必要联系，而非仅教组件名称或给定系统的数值审计：

1. 信息不足为何要求利用历史；输入是否够用与输出是否保留分布是两个问题。
2. 历史、确定性记忆、随机潜变量、filter 与生成 prior 怎样组成动作条件 RSSM；为什么有这些结构及各自的限制。
3. 序列概率模型怎样产生 ELBO；该目标怎样经参数变化影响下一次预测。
4. 有观测的序列推断怎样接到无未来观测的 prior rollout；不确定性怎样随多步传播。
5. 一步学习目标、多步训练、离线多步预测评估及控制效果各自支持什么结论。
6. 预测分布怎样进入候选动作评价；执行第一动作、取得新观测、更新 belief 并重规划怎样形成闭环。

完整父作品 W 是一份可回查的“模型—训练—预测—决策说明”，沿同一受控 RSSM 模型族连续包含：信息与时序契约、结构选择理由、生成与推断因子分解、一般序列 ELBO、局部参数学习解释、未来分布与多步检验、一次 MPC 决策及下一观测后的修订、结论边界。物理位置/速度的观测别名例只说明信息需求；自拟潜模型 E 不宣称已拟合该环境，也不把 d/z 冒充其物理坐标。材料方在 `03-learner-materials.md` 中落实教师示范，在 `04-tasks.md` 与 `05-teacher-reference.md` 中落实 W 的新条件任务与完整教师参考；本设计不把待编文件视作已经就绪。

W 要求在允许查阅已给定义、恒等式和计算器的条件下由学习者完成关键连接；不是闭卷记忆任务。完整实现、真实训练、GPU、机器人操作、长期保持及远域迁移均不属于本次必要义务。算法规格与数据流对应必须能解释，但教师程序运行不算学习者实现，有限数值不算一般证明，纸面规划不算现实控制成功。

## 2. 六项要求与判据

以下要求身份只用于本备课内部定位；要求来源为本次用户请求，内容依据由本次来源 agent 对 PlaNet 原文及变分推断依据核验。它们不是既有课程目标的修订。

| 要求 | 学习者关键操作与可检查位置 | 必要正确性条件 | 不由什么替代 |
|---|---|---|---|
| G1 信息与结构 | W 开头说明相同当前观测为什么可对应不同未来；评议当前观测输入、历史记忆、分布输出及 h/z 分工 | 区分真实状态 x、观测 o、历史 H、真实belief β、模型 h/z；RSSM 的联合状态通常是 (h,z)，z 单独不必 Markov；不称 RSSM 唯一可行 | 背组件名；把随机潜变量直接等同真实隐状态 |
| G2 时序与推断 | 写出生成模型、filter q 和每步操作顺序，追踪一次观测或动作变化 | 统一 a_{t-1} 导致到达 t 的状态，见 o_t 后才选 a_t；q 可用当前 o_t，future prior 不可用未到达的 o；同条潜变量历史递推 h | 单独辨认 p/q；把 h 当固定外部数据 |
| G3 序列学习 | 从 joint、q 和 Jensen/KL 恒等式推导一般 T 的 ELBO，解释重建与 KL 的作用；做合法局部更新并接回预测 | 期望与历史条件完整；KL 是 q_t 对同一步 prior p_t；说明精确模型 posterior 可含未来、所用 q 是 filtering 近似；局部固定量、梯度和预测改变相符 | 计算一个 KL 值；只写“最小化 loss”；把局部梯度说成完整网络训练 |
| G4 多步预测 | 从当前 filter 状态推出两步以上 future prior 分布，解释采样/积分和误差累积，判断可用的评估 | 未来沿 prior 递推 h/z；共享轨迹的 h 与 z 依赖保留；均值 rollout 一般不等于分布预测；rollout、overshooting、评估分开 | posterior 重建；形状正确；一个有限算例证明普遍预测好 |
| G5 分布与规划 | 用规定成本对合法候选动作序列求期望或可靠近似，说明方差何时改排序、何时不改 | 成本、动作费用、horizon、终端/折扣条件明示；比较均值点评价与分布评价；不确定性影响须由合法数值或一般推导承担 | 所有候选同方差却宣称已展示排序变化；把方差自动当 epistemic uncertainty |
| G6 闭环与证据 | 写出执行首动作→新观测→filter→再规划，并据新条件修订结论；匹配下一项检验与支持范围 | 在线 belief 更新不等于参数学习；重规划不保证消除模型偏差；预测/训练/闭环实验的证据范围各自保留 | 说“MPC 会反馈”；把离线误差下降等同闭环回报提高 |

整体判据另列：W 各段使用同一动作约定、潜变量历史、参数版本、预测起点、成本定义和证据条件；不能以六项局部分别正确代替这些接口连接。合法不同推导、不同表示、基于条件的拒用和信息不足均接受。

## 3. 必须给够的语义与一般模型

采用标准时序：到达 t、得到 o_t，构成可用历史 H_t=(o_{1:t},a_{1:t-1})；选 a_t 后环境到达 t+1。奖励可按转移后记录 r_{t+1}，材料若采用另一约定必须在全包一致说明。为避免奖励索引干扰，首份模型可以以观测 likelihood 推导 ELBO，随后明确加入奖励头及其索引。

核心 RSSM：

\[
h_t=f_\theta(h_{t-1},z_{t-1},a_{t-1}),\qquad
p_\theta(z_t\mid h_t),\qquad
q_\phi(z_t\mid h_t,o_t),\qquad
p_\theta(o_t\mid h_t,z_t).
\]

h 是模型的确定性递推记忆，z 是随机潜变量；“确定性”描述给定输入时的更新规则，若历史 z 是随机的，h 的边际分布仍可随机。β_t=P(x_t|H_t) 是对真实隐藏状态的条件分布概念，s_t^m=(h_t,z_t) 是模型联合状态，RSSM filter 提供可用于预测的近似表示，不默认是精确 Bayes belief，也不默认有唯一物理语义。本文不把状态元组与概率分布共用一个b符号。

给定控制序列、初始条件及上述 h 递推，joint 与变分族分别为各时刻 prior×likelihood 的乘积及 filter q 的乘积。所有 h_t 均由该条 z_{<t} 历史决定。序列 ELBO 要实际推导为

\[
\log p_\theta(o_{1:T}\mid a_{0:T-1})\ge
\mathbb E_{q_\phi(z_{1:T}\mid o,a)}
\sum_{t=1}^{T}\log p_\theta(o_t\mid h_t,z_t)
-\sum_{t=1}^{T}\mathbb E_{q_\phi(z_{<t}\mid o,a)}
\operatorname{KL}\!\left(q_\phi(z_t\mid h_t,o_t)\|p_\theta(z_t\mid h_t)\right).
\]

起始 a_0 可明示为已知初始控制或零哨兵，不让符号隐含额外事件。材料须给出 joint/q 比值、Jensen 或 gap=KL 的理由、因子抵消、条件 KL 的形成和外层历史期望，而非直接展示最后一行。q 是合法的 filtering 变分族；生成模型的精确全序列 posterior p(z_{1:T}|o_{1:T},a) 可以利用未来，不能把它同 q 的计算信息集混写。仅在本题明确固定 q/h 时才能用局部高斯 KL 导数，完整神经训练仍含编码器、递推与采样/重参数化路径。

训练机制还需给出够用梯度桥：连续Gaussian时写 z_t=μ_φ(h_t,o_t)+σ_φ(h_t,o_t)ε_t，ε_t来自固定标准分布；重建/奖励误差经decoder及z路径影响生成与识别参数，KL同时约束prior和recognition，h的递推使后时刻项经历史路径回传。不能把KL单称为“训练prior”，也不能把重建单称为“训练decoder”而遗漏识别与递推。数值例只显示固定其他量的一个prior参数更新；闭式q在该小模型中是手设可靠推断接口，不能声称该例已经训练了神经encoder/decoder。将重建完美而prior失配、prior可预测但decoder失配作为两种合法诊断可能，单项loss不能唯一定位错误模块。

需要解释结构取舍：历史用于区分观测别名；分布输出用于保留目标所需多种未来；h 保存跨步可递推信息，z 使模型可表达条件随机未来/不确定状态。确定性 RNN 加分布头也可能表达随机输出，纯随机 SSM 或其他 belief 模型也可用；给定输入/输出接口的不足不是 RSSM 普遍最优的证明。单个 Gaussian 潜变量不自动代表任意多峰 belief。

未来预测从 q_t 或其轨迹表示开始，给定候选 a_{t:t+H-1}，递推 h_{t+k} 与 p(z_{t+k}|h_{t+k})，积分/采样到观测、奖励或成本。不得偷用真实未来 o 做 q 更新。一步 ELBO 通过状态递推可影响长链，但它的训练形式不自动成为显式多步约束。latent overshooting 是可选的多步 latent 一致性训练设计；PlaNet 原文报告最终 RSSM agent 无需该项，不将其设为 RSSM 必备。多步 prior rollout、本次采用的训练目标、离线 rollout 指标和闭环效果是四项不同事实。

MPC 的优化对象是有限 horizon 的候选控制序列或其分布，目标是模型内期望累计成本/奖励；选出后执行第一个动作，取得实际新观测，再 filter 和重规划。q 的在线变化在参数固定时也发生；参数更新须有训练数据、目标与优化步骤。模型动作分布覆盖、likelihood/latent 失配、风险标准和算力限制会影响控制，重规划不构成真实性或稳定性保证。

## 4. 认知维度、帮助、覆盖、工作量分别管理

| 认知维度 | 本单元要观察什么 | 合法帮助与展开如何改变 |
|---|---|---|
| 关系精确性 | 对象、条件依赖、动作时序及 p/q 方向正确 | 直接给符号表和时轴；不降低时序判据 |
| 解释完整性 | 历史需要、结构分工、ELBO到参数再到预测的中间连接 | 给 Bayes/Jensen/高斯公式；保留目标内理由连接 |
| 边界敏感性 | filter/smoother、mean/distribution、train/eval/control 的接受与拒用条件 | 并排对照可以教学；不据其成功称广泛自主选法 |
| 扰动推演 | 动作、参数、观测、方差分别变化时怎样传播 | 保持其他量；有模型才算数值，缺依据可说未定 |
| 跨表征协调 | 概率式、时轴、递推状态表、算法接口指向同一对象 | 图可由教师给；映射要能解释，不强制自己画图 |
| 整体组织 | 把推断、学习、预测、决策、重估接成一份连续 W | 分段保存同一 W，局部帮助够用后回其确切接口 |

帮助条件另记：可见定义/完整范例/中间式/候选方法/参数或数值工具实际代做哪项；帮助后有效操作保留，不把看过完整示范的跟随称为无接触自主。覆盖另记：典型序列、未来无观测、相同观测不同历史、均值相同方差不同、均值不同但方差使排序变/不变、缺失观测或分布转移、合法旧条件。工作量另记：学习者时间与设备未知；本次备课先准备完整路线，正式实施按可停连接分段，不虚构分钟数、不以题数当深度、不自动缩成首题。

| `post/conditional-update`，借真实新增条件后的判断修订与保留旧域 | W完成第一次规划后给新观测；另给无新观测但有训练批次/参数变化；区分应改belief、参数、评价或结论的哪一项 | 不制造学习者旧误解；更新依据来自题设。保留旧条件下原结论，接受新信息不足。参考错先纠参考，不能要求改成错参考；不加未来保持债务 |

未采用第四“恢复/生成顺序包”：本单元已有明确可靠输入→连贯示范→有支架关系→整体条件工作，未涉及要比较检索与生成顺序的决定。不是四包必经阶段。上述Post各功能可融入一次W，不增加多个独立成功样本。

## 8. 示范到整体工作：渐度、教师代做与剩余操作

材料必须先写出完整教师范例 E，包括信息不足反例、统一时轴、一般ELBO及一处合法局部学习、两步以上无观测预测、分布成本选择、执行首动作后接新观测重规划。范例可以分段展示，但每段已有到下一接口的具体内容；高层通用公式与受控小模型是明确的实例化关系，小模型不能定义或替代整个主题。

| 当前段 | 教师提供/代做什么 | 学习者关键剩余操作 | 为什么跨度可控/返回 |
|---|---|---|---|
| E0 定向与完整起点 | 信息集、对象、时轴、当前观测相同历史不同的可信例；h/z/p/q全部必要定义 | 第一个可完成贡献只解释一处动作/观测信息界限或指出别名不足 | 不从未知术语提问；此贡献不裁定ELBO/成本前置，随后直接补相应输入 |
| E1 推断与学习连贯示范 | joint、q、Jensen/gap、逐步条件KL；局部参数固定量/梯度/预测改变 | B1在一般T表达中补一处必要理由与历史条件，判定错误q_t对q_{t-1}式；连到W的学习段 | 先给单变量桥梁再给序列展开；B1不要求同时写完整规划 |
| E2 预测与决策连贯示范 | 两步以上prior轨迹/矩传播、分布成本恒等式；排序改变/不改的合法条件 | B2沿已给filter状态接续未来一步及成本接口，解释不能偷用未来o；区分观测变化与参数变化 | 保留模型规格和计算公式，只交回对应接口；不因B1成功撤掉新操作示范 |
| B3 范例条件的整体重组 | 给同一完整W骨架、E已经展示的状态/观测与可查公式，首段/工具均可用 | 回看范例并组织当前q、未来p、成本与重规划的接口；核对训练/评估证据 | 只作有支架的接口协调，不算新条件适配或独立求得E答案；新条件操作由W承担；失败先查接口，不回头重考全部术语 |

## 9. 交给材料方的具体契约

请以本设计为首要约束自主造一套新内容，不能参考旧学习记录/旧RSSM备课；具体标量参数由材料方选定并核验。

1. 可见材料 M1：部分观測环境与信息别名；定义x/o/H/β_t^env/h/z/s_t^m及动作时轴；至少说明两类合法替代架构及“接口不足≠普遍最优”，并明示动机环境与自拟E模型的对象过渡。
2. M2：一般RSSM、joint与filter q、逐步ELBO推导。初始条件、h的历史依赖与期望写清。加观测/奖励头时保持记录约定。
3. M3：同一范例里局部参数梯度的一步更新，固定量与全网梯度的差别；将更新参数应用到新历史/输入，使“参数学习改变预测”实际可见。主模型另给重参数化、decoder/recognition/prior/递推的梯度路径，说明闭式q示范没有训练所有模块；不能只贴loss标签代替学习机制。
4. M4：从该状态沿prior未来展开至少两步，明确方差/协方差/采样路径。理论分布与数值演算对应；说明条件mean递推的合法特例和一般失效。
5. M5：同一受控范例走到累计成本与MPC；另备明确题设的合法条件对照，用平方成本或其他可核风险标准展示方差改排序和不改排序。两组不得冒充原固定模型自动产生的结果。
6. M6：执行首动作、接新观测、固定参数filter与重规划的完整步骤；对比真正参数训练；给多步训练/评估/闭环证据的条件表。
7. 问题/参考：E完整；B1/B2/B3桥接；W一份连续新条件任务，题面与教师完整答案分区；至少含一种需拒用或说明不足的情境。建议W采用三步序列中第二步传感器缺失的条件：学习者决定q_2=p_2、缺失观测likelihood项省略、同时间KL为零，但z_2仍经h_3影响后项与未来。以此要求学习者适配joint/q/ELBO与数据流，避免仅复制已给一般公式；允许基础Jensen、KL/矩/成本恒等式、模型定义和工具，教师参考初始不展示。已发生完整示范暴露保留，后续成功只解释为允许资料下的新条件适配、理由与整体组织，不称首次自主发明RSSM。参考要审一般序列推导和完整接口，不只验数值。
8. 支持：符号/单变量变分/条件与边际/期望成本/整体接口五个必要分支，给实际可展示解释及返回位置，不只写“再解释”；误差诊断允许多因。
9. 首回复 `06-first-reply.md`：审查用可直接发送的草稿。先简短说明目的/路径/最终作品，再实际交第一份输入与一个自然贡献；此轮不可把该草稿作为正式教学发送或索答。

核心材料与任务全部就绪后，再按用途、关键语义、维度分离、功能兑现、帮助剩余工作和整体跨度接受审查反馈；本认知v1允许据具体反证回改，不用“已选目标”阻挡用途缺项。
