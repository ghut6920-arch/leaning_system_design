## B．动态反馈：找到未编译方法，也交出可用模型

自然请求是“我知道控制器要减小误差，但为什么负反馈还会振荡？能把推导和简单模拟连起来吗？”若当前背景尚不足，先解释状态、目标、误差及一步更新；已有相关基础则从整体比较开始。候选回读未编译的 R06、R07、R10，按需要借 X06；有依据的过度概括还可用 `post/conditional-update`，原本没有误概念则直接教学。

当前内容限定为理想、线性、无延迟、无饱和的离散系统，固定目标 r：

\[
u_t=k(r-x_t),\quad x_{t+1}=x_t+a u_t,\quad a>0,\ k>0.
\]

状态 x、目标 r、误差 e＝r−x 同单位；a 把输入 u 转成一步状态变化，q＝ak 是无量纲量。先给控制器→对象→下一状态→新误差的对应，必要时示范一步：r＝1、x₀＝0、a＝1、k＝0.2 时，u₀＝0.2、x₁＝0.2、e₁＝0.8。输入或控制器饱和不属于本模型，不能无说明移用结论到真实机器人。

本次连贯工作可以是：用这个模型说明误差递推，比较 q＝0.2 与 q＝2.2，为“极性相同、轨迹却不同”给出依据，并用代码检查对应点。若目标仅要求理解，AI 可给完整推导；若目标要求自主建立递推，当前输入只给上述模型和一步例，教师先保留下面参考。

教师参考：eₜ₊₁＝(1−q)eₜ，故 eₜ＝(1−q)ᵗe₀。对任意初始误差收敛到零要求 |1−q|＜1，即 0＜q＜2。q＝1 一步消除误差；0＜q＜1 同号收敛；1＜q＜2 交替收敛；q＝2 非零误差等幅交替；q＞2 的非零误差交替增大。e₀＝0 的特殊轨迹不能证明某参数对任意初态稳定。

最小代码输入可用：

```python
def trajectory(q, steps=8, target=1.0, initial=0.0):
    x = initial
    rows = [(0, x, target - x)]
    for t in range(steps):
        x += q * (target - x)
        rows.append((t + 1, x, target - x))
    return rows
```

实际使用时运行并核对 q＝0.2、1.2、2、2.2 的状态表，再决定静态表是否已够或需曲线。表／图用于检查动态解释，有限轨迹不代替对一般 q 的推导。若映射是目标工作，先让学习者说明哪条曲线应交替／收敛，再展示输出；若只是示范，可以直接展示。

已经能解释局部控制器却解释不了整体时，先查对象增益 a、时间索引与回路接口；这正是 R10 的整体工作，不继续逐个问术语。若增加一个采样步延迟，模型变为 xₜ₊₁＝xₜ＋q(r−xₜ₋₁)，需要给初始历史并重新分析特征方程；不能沿用无延迟的 0＜q＜2。只有目标和预算需要时展开该分支，否则保留当前模型适用边界并结束。

## D．接口版本更新与系统参考纠错

以下是封闭的虚构练习规格，版本事实已直接提供，不对应任何真实软件 API：`mean(values, version)` 在 v1 下空列表返回 0，v2 下空列表返回 None；非空列表两版均返回算术均值。自然请求是“新文档改了空输入行为，我旧实现是不是全错了？”

候选为 `post/conditional-update`，必要时借 D01／D02 的版本对照。直接提供新旧规格和当前实现，让学习者定位需要改的分支，保留非空行为，设计按版本检查的方法；不要求闭卷背版本号。目标只需实现时不扩成整套软件测试课程。

教师参考：v1 的 `[]→0` 和 v2 的 `[]→None` 各自正确；`[2,4]→3` 两版都成立；未指定版本时不能唯一判断空列表的返回。实现可显式区分版本，也可按已约定当前版本只改受影响分支。

若系统先前把 v2 的空列表也判成 0，学习者回答 None，先核规格并撤销受影响错误评分，保留其原答；再处理错误教学是否影响后续实现。不是先安排“纠正用户误概念”。若之后用户把所有空输入一律改成 None，回查 v1 合法域；即时改答不证明后续版本选择稳定。

## E．高阶整体：从唯一性证明到最小秩构造与条件变化

仅在原目标明确包含这些要求时展开。假设学习者已有或允许查阅如下命题：在有限维实数空间，λ＞0、Q 半正定时，F(x)＝‖Ax−b‖²＋λxᵀQx 的无约束最小解唯一，当且仅当 ker A∩ker Q＝{0}。证明和存在性参考见 [教学实例 C](teaching-examples.md)；不重新考命题名字。

自然请求是“能用这个条件自己构造最省秩的正则项吗？限制可行方向后条件怎么变？”当前产物保留为一份证明＋构造＋适用域说明；候选可借关系包的恢复／整体部分、选择包的构造条件判断和条件更新包。直接完整目标任务同样合格，不必给每个步骤配卡。

教师参考一：令 k＝dim ker A，N 的列为 ker A 的标准正交基，取 Q＝NNᵀ。对 d∈ker A，dᵀQd＝‖Nᵀd‖²＝‖d‖²，只有 d＝0 才为零；rank Q＝k。若 rank Q＜k，则 Q 在 k 维空间 ker A 上的限制不可能单射，有非零 d 同时属于两核，违反唯一性条件，故最小秩就是 k。A 满列秩时 k＝0，Q＝0 合法。这个一般下界与构造都要进入目标论证，不用一张数值矩阵替代。

教师参考二：A＝[[1,1,0],[0,1,1]] 的核由 n＝(1,−1,1) 张成。Q＝nnᵀ／3 或 diag(1,0,0) 都是合法秩一构造；取 u＝(1,1,0)、Q＝uuᵀ 也是秩一，却使 Qn＝0，不满足条件。要看的不是“低秩”标签，而是对 A 的不可见方向是否提供约束；其他合法构造也接受。

若学习者暂时取不出旧命题，目标允许查阅就直接给命题，留下下界证明和构造；给了 N、Q 的完整设计后，余下验证不能称其自主构造。局部说明“Q 在核方向非零”仍不能自动支持完整最小秩证明，返回同一论证补合法下界。

教师参考三：若可行域改成非空仿射空间 x₀＋D，则唯一性改为 ker A∩ker Q∩D＝{0}。理由是只有可行差方向 d∈D 需要严格正二次曲率；在该有限维仿射空间上仍是可达到的最小二乘问题。取 A＝[1,0]、Q＝diag(1,0)、b＝2，并限制 x₂＝3，虽全空间的共同核非零，可行方向内交集为零，唯一解为 (2／(1＋λ),3)。这是适用域改变，原无约束定理仍正确，不把它更新成“原定理错了”。

若目标只要求原无约束唯一性，最小秩和仿射分支不成为新增必修。若目标已包含一般构造，预算缩短可停在已核论证的断点并交同一未完成需求，不能用完成两个数值例取代原目标。
