## 1. 单元主线与整体终点

本单元要建立一条连续连接：历史动作和观测不足以直接给出物理状态 → 用确定性递归与随机潜变量组织学习表示 → 用生成模型和因果过滤近似分布训练表示及动态 → 当前观测修正当前潜状态 → 未来没有真实观测时只沿动作条件 prior 推演 → 用预测奖励比较候选动作序列 → 执行首个动作、取得新观测、更新表示并重新规划。

主线选择的理由是 RSSM 的用途来自这些接口同时成立。只识别网络部件、只算一次贝叶斯更新、只背 ELBO 或只展示 rollout 都不能承担“由序列推断到闭环规划”的整体工作。数值桥服务信息边界；神经 RSSM 与 ELBO 仍是本单元主体。这里的近期目标是设计建议，不能当作用户已通过或正式采用的课程要求。

整体作品 W1（建议名称：**RSSM 训练、预测与行动审计**）保留一份连续原件，含六个相互引用的部分：

1. 用统一时间轴、变量表和依赖结构解释生成模型、推断模型及当前信息集合。
2. 由联合分布与变分分布得到序列 ELBO，解释每一项的对象、期望与限制。
3. 用一段训练／部署记录说明过滤、未来 prior rollout、参数学习的不同角色。
4. 对一个固定候选动作序列追踪多步表示与奖励预测，标记没有真实未来观测的位置。
5. 将预测接入一次规划、执行首动作、新观测更新和重新规划，审查错误流程。
6. 用条件对照说明不确定性、误差、表示与控制结论的边界，并修订整体说明。

作品形式允许文字＋式子＋信息表；关系图或流程图可作为辅助，不要求以图代替论证。不要求训练完整神经 RSSM、GPU 实验、闭卷、长期保持或远迁移。可执行演示只作为教师材料／可选消费者；代码运行不等于学习者实现或理论理解。

## 3. 必要语义与数学锚点

### 3.1 统一时间与对象

动作 a_{t-1} 推进到 t；o_t 是到达 t 后的观测，r_t 是到达 t 后取得的奖励。规划在 t 从当前信息出发，候选 A=(a_t,…,a_{t+H-1})，预测奖励为 r_{t+1},…,r_{t+H}。reset 的初始观测若没有 r_1，就省略／mask 初始奖励项，不补造它。`env.step` 返回 tuple 的命名习惯须显式对齐此时间约定。

物理隐态 x_t 是环境对象；z_t 是模型的随机潜变量；h_t 是模型的确定性递归表示；o_t 是可观测信号；e_t 如引入，只是观测编码器的特征。x、z、h、e 不得靠“都是 state”混为一物。模型的 (h,z) 可以用作历史条件表示，但通常不能保证是精确充分统计量或可识别物理状态。

### 3.2 选定的基础 RSSM

固定 h_1／初始化约定；对 t≥2：

\[
h_t=f_\theta(h_{t-1},z_{t-1},a_{t-1}),\quad
z_t\sim p_\theta(z_t\mid h_t),\quad
o_t\sim p_\theta(o_t\mid h_t,z_t),\quad
r_t\sim p_\theta(r_t\mid h_t,z_t).
\]

推断因子为

\[
q_\phi(Z\mid O,A)=\prod_{t=1}^{T}q_\phi(z_t\mid h_t,o_t).
\]

h_t 已压入过去采样 z、动作与相应历史信息，不等于不使用历史。给定实现的一条历史，h 的更新是确定函数；跨不同随机历史，h 也可以有诱导分布。“确定递归”不等于“整体没有不确定性”。q 是因果过滤形式的**近似推断网络**；这不是声称它恰为物理系统或生成模型的精确过滤后验。所选 PlaNet 式 q 不以奖励为输入；别将这一架构选择说成所有 RSSM 不能使用奖励。

生成模型在给定动作序列、固定初始化时取

\[
p_\theta(O,R,Z\mid A)=\prod_{t=1}^{T}
p_\theta(z_t\mid h_t)p_\theta(o_t\mid h_t,z_t)
p_\theta(r_t\mid h_t,z_t)^{m_t},
\]

其中 m_t 标记实际有奖励项的步骤。发射的条件独立及 h 的递归是建模假设；不是物理系统的一般定理。动作通常在训练似然中作为已给定条件，不由该似然单独建立行为策略模型。

### 3.3 序列 ELBO 的完整连接

在合法支持与可积条件下，由引入 q、Jensen／KL 得到

\[
\log p_\theta(O,R\mid A)\ge\mathcal L
=\mathbb E_q\!\left[\log p_\theta(O,R,Z\mid A)-\log q_\phi(Z\mid O,A)\right].
\]

分解为

\[
\mathcal L=\sum_t\mathbb E_{q(Z)}\left[
\log p_\theta(o_t\mid h_t,z_t)+m_t\log p_\theta(r_t\mid h_t,z_t)\right]
-\sum_t\mathbb E_{q(z_{<t})}\left[
\mathrm{KL}\!\left(q_\phi(z_t\mid h_t,o_t)\Vert p_\theta(z_t\mid h_t)\right)\right].
\]

实际可用前 t 项的边缘分布计算对应发射期望；写 E_{q(Z)} 是紧凑而合法的共同记号。KL 外层期望不可无解释省去，因为 h_t 随随机 z_{<t} 改变。h 是确定函数时无需把 Dirac 分布当普通密度另算 h 的 KL。

gap 为

\[
\log p_\theta(O,R\mid A)-\mathcal L
=\mathrm{KL}\!\left(q_\phi(Z\mid O,A)\Vert p_\theta(Z\mid O,R,A)\right).
\]

右端真后验是**完整序列后验**，会受未来序列／奖励影响；q 的因果因子化不把 gap 的对象改成一步精确过滤分布。整段训练数据可用来计算损失和参数梯度；q_t 的前向信息边界仍是当前／过去。未来损失影响共享参数并不等于现场 q_t 输入未来观测。

“重建项”须注明是在 q 下的观测／奖励对数似然，“正则项”须注明是后验与动态 prior 的匹配，不只画成三个无语义 loss 盒子。重参数化或解析 KL 可以解释蒙特卡洛估计，但不要求自主实现梯度。训练改动（KL 权重、free nats、loss scale 等）逐项标实际目的与数学地位；不能把任何实践目标直接写成这里的同一标准 ELBO 恒等式，具体是否仍构成某种下界需另核。latent overshooting 只作可选边界阅读；原 PlaNet 最终 RSSM 不以它为必需，不能当多步 prior rollout 的先决。

### 3.4 过滤、预测和规划的接口

在现场 t：递归得到 h_t，使用已取得 o_t 形成 q_t；未来固定动作预测从当前表示分布／样本出发，反复用 f 和 p(z_{t+k}|h_{t+k})，通过发射模型预测未来观测／奖励。真实 o_{t+k} 尚未取得时，不调用带该真实观测的 q 修正未来。用预测图像再回灌 q 是另一个算法，不能冒称已取得新环境证据。

一般期望式规划目标可写为

\[
A^*\in\arg\max_A\mathbb E_{\text{current }q,\,\text{future }p}
\left[\sum_{k=1}^{H}r_{t+k}\right].
\]

优化／近似评估候选后只执行 a_t^*。到达 t+1 后取得实际 o_{t+1}，重新过滤并求新的候选；未来计划的剩余动作可被替换。原 PlaNet 的 CEM 对每候选使用单条轨迹估计这一目标；教学若演示多粒子平均，必须标为一般化说明，不能写成原实现复刻。CEM、候选枚举或已给候选排序可作规划内部黑箱，只保留输入、目标、输出和估计误差。

内部 fixed-action rollout 与外部 receding-horizon 闭环并存。该 MPC 不等于在一次规划内枚举所有未来观测分支和 contingent policy，也不自动优化信息价值。不因“用了反馈”宣布稳定、不因“取最大预测值”宣布真实环境最优。

### 3.5 不确定性与误差

至少分开：当前隐藏状态的推断不确定性、模型定义的过程／潜变量随机性、有限采样造成的规划估计误差、模型错设／参数不足／分布外导致的预测误差。单一随机潜变量分布不自动代表参数 epistemic uncertainty；粒子多只改善估计，不能自动修复动态模型。

两个不同历史可以得到同一个 o_t，但 h_t／q_t 不同；同一个当前 belief 在不同未来动作下得到不同预测；没有新观测不意味着所有分布宽度单调增长。确定转换也可作用于不确定状态，随机转换也可出现收缩或集中。后验窄、观测重建好、ELBO 高、代码跑通分别不能单独推出模型正确、表示可识别、控制可靠。

| encoding/D02 最小对／单因素隔离 | 在同一时点／模型只改“新观测是否实际取得”，比较 filtering 与 prior；同一候选计划只改“首动作后有没有新证据并重算”，比较固定预测与实际闭环；同一动态／likelihood只改训练loss处理，判断数学地位 | 两侧合法、相同背景可核；不拿不同变量、目标、公式和场景同时变化来冒称单因素。q使用真实观测与q使用自生成图不是相同实验。教学逻辑对照不冒称统计因果实验 | 学习者指出变项、保持项及改变的合法接口，信息不足可接受。误判先核材料；给诊断条件后的成功只支持剩余判断。返回 W1.1／3／5／6；不是每组自动要求第二或第三例 |
| encoding/R06 局部扰动的动态传播 | 给相同当前表示和两条仅一个动作不同的序列，沿 h,z,预测奖励逐步追踪；再给真实新观测，定位从哪一步改变 q 和后续计划 | 先给明确 f/prior 或完整离散转移表。神经模型没有权重参数时只判断依赖／信息，不编具体数值、方向、增幅、稳定性。多步预测不是静态箭头逐个抄写 | 指出第一处变化、随后传播路径、可确定／未知项。离散数值按精确参考核；RSSM按依赖／时间核。追踪够用即回 W1.4—5，不要求长期平衡或统一扰动次数 |
| post/retrieve-relation：关系／整体整合部分 | 从已提供的 p/q、ELBO、过滤与规划接口，完成 W1 的端到端论证和错误修复。恢复对象是必要定义／接口／不变量，允许查阅，不规定检索先于生成 | 关系两端通过材料可用；可靠整体参考需材料 agent 备齐。分别解释资料访问、连接和整体结果。大概念图、自洽故事、局部正确率不代替连续关系 | 能用允许前提连接就推进；仍有某处关系障碍才最小回 Encoding。比如只修“历史随机性→外层期望”，回 W1.2该式；不是重讲全章VI |
| post/select-method：限定候选下接受／拒用 | 用实际记录选择 p rollout、q更新、暂缓判断或重新规划；报告为什么可用／不可用，进行角色映射与后续操作。候选已知，不宣称跨领域广泛自主选法 | q/p条件已可跟踪；中性题名、信息清单、方法候选与最近讲解线索均计入条件。刚示范后的同法练习不能称无近端线索。无真实未来观测时拒用其q是合法回答 | 保存初始选择后按缺项提供定义／方法／映射；给法后只解释后续执行。若材料已泄露选择，限定用途，仍可教，不虚构无提示成功。返回 W1.3—6，不另造“选法卡”复习队列 |

选择排除与未借部分：不使用 O05／D08 来制造未经观察的误概念；不使用 R07 推导未有条件的稳定性；不使用 X10 追加压缩背诵；S07／X02 不另建重复填空，合法推导和局部承担已在同一 W1 工作中安排；R10 的整体功能以 W1＋Post 关系包承担，无需再加同义活动。conditional-update 与 retrieve-generate-order 包此次不采用；不会因库里有四包而安排四个阶段。实际出现版本争议或新条件需要更新时，父 agent 再定位必要资源，原有可靠域保留。

共同限制：这些模板属 H 设计综合；包内研究支持策略家族或具体邻近任务，不证明每个 RSSM 题面有效。R02／R03 两载体不是两份独立证据。研究原文的测量矩阵、卡片数量、撤提示／延迟／新例建议不是统一必做流程。教学可以直接提供必要答案和支持；解释其代做范围即可。成本与时长保持未知，不编预算、神经巩固状态或固定失败次数。

## 6. 分段输入、剩余工作与问题意图

这里的“问题”是备课题意，供材料 agent 写正式题面及教师参考；本次聊天未向学习者提问。主要工作预先备齐，普通作答反馈后接同一作品下一连接；只有真正需要学习者原答／作品／选择时才等待，不设置逐题“继续”开关。

| 段／接口 | AI 必须先提供的可用输入 | 留给学习者的目标工作；问题意图 | 回到 W1 与参考义务 |
|---|---|---|---|
| A 任务与信息入口 | 简短用途、最终作品、时间轴、x/o/a/r/h/z/p/q的必要说明；一对相同观测不同历史的合法叙述 | 在给定对象中解释“当前图像为什么不自动等于状态”和历史表示的作用；不要求凭空猜网络设计。初步题：“哪些信息足以推进模型一步，哪些仍未知？” | W1.1；教师参考需包含物理状态与表示不可识别的边界，不把历史压缩视为精确belief |
| B 精确桥完整示范 | 两隐态动作条件转移表、观测likelihood、初始belief、到达奖励／评价定义、至少一个完整预测与归一化；接固定动作多步prior及首动作后新证据重规划 | 追踪概率质量、观测likelihood与正规化；解释有／无真实观测时操作切换；算例关键归一化可由教师给出，其后的连接仍由学生承担 | W1.3—5的数值附件；桥明确不是神经RSSM、无 learned h、不是ELBO训练实例。避免用已观测奖励暗中泄露隐态；若奖励加入belief，须显式更新条件集合 |
| C 返回 RSSM 表示与双模型 | 完整统一公式、依赖图／表；把桥中的belief作用映射到RSSM近似表示，列不对应处；一条h/prior/q连贯轨迹 | 解释确定性递归和随机潜变量各自作用；在同一轨迹辨认生成／推断与训练／现场。初步题：“历史样本改变后，h确定是否还意味着它跨历史恒定？” | W1.1／3；不能把离散精确belief直接等同 h 或 z；随机历史h有诱导分布 |
| D 序列 VI 与训练 | 联合分布、因果q、初始化／reward mask、Jensen或KL恒等式的允许输入；完整可靠推导和训练实际改动注释 | 用合法理由连接 log evidence 与期望项；解释KL方向、外层历史期望与full-sequence gap；判断某loss是不是当前已推得同一ELBO。初步题：“这两个公式省略／保留了哪个随机对象？” | W1.2；教师完整参考须足以审连续推导；不能只给一个ELBO公式或toy数值 |
| E 多步预测与候选行动 | 当前q表示、固定候选动作序列、无未来真实观测清单、f/prior/奖励接口；至少两步RSSM prior依赖轨迹 | 在不回灌真实未来o的条件下组织h/z/奖励传播；选择可用模块并解释不可用项。动作改变的第一处及后续传播是主要工作，不是仅填符号 | W1.4；数值只有方程参数足够才提供，原PlaNet单轨迹和一般多粒子估计分开 |
| F 闭环与综合审计 | 一次候选评估、所选首动作、到达新观测、再更新和再规划的完整参考；一份混有信息／时间错误的中性现场记录 | 审查该记录，定位最早非法操作并修出连贯流程；说明改变信息如何影响未来动作。比较“看完整候选计划后执行全部”与“只执行首动作后重算” | W1.5—6；材料标题不预告错误类型；合法不同修复路线可接受；MPC不等于观测分支政策树 |
| G 边界收束 | 低后验方差但动态错的合法案例；分布宽度不必单调的有限反例；基础loss与修改loss的明确版本 | 依据条件拒绝“窄＝可信”“预测步长＝误差必然固定增加”“训练loss好＝控制最优”等过度结论；不奖励故意唱反调或故事 | W1.6并核全件；没有校准／分布外实测时保留未知。全件够用即结束；未来保持不在本次目标 |

主线认知顺序先获得可跟踪的对象与完整桥，再回 RSSM 的双模型与训练，最后由预测到行动综合。若用户已有兼容作品可直接审整体或跳过重复示范；起点未知不强制先试错。既有正式用途若只要解释，教师完整输入可满足解释请求；它仍不会被登记为学习者已完成 W1 的自主工作。

## 7. 支架跨度、必要支持分支与够用返回

支架不按固定“三级提示”或轮数撤除。记录实际代做的操作：给符号定义、给概率规则、给中间式、给方法名、给接口映射、给完整组织分别作用不同。全段预算未知；每个分支可暂停在同一原件的未完成连接，不新开单元。

| 触发表现（可观察；不预设已发生） | 最小支持与替代解释 | 局部够用条件 | 返回位置；仍未支持部分 |
|---|---|---|---|
| 熟悉文字能解释，式子指称错 | 对齐z/h/o和a_{t-1}→t；给同一时点一行语义表，先排记号约定 | 能把当前式子的输入／输出和可见信息正确对应 | W1.1／3；不重教整章概率，不把词表抄对算机制理解 |
| 预测与观测更新混同 | 固定同一prior与likelihood，只改“观测实际到来”条件；教师给合法预测与归一化 | 能说明哪一步使用新likelihood，没观测时为何不能做该步 | W1.3—4；帮助代做的初次选法保留边界 |
| 把h当恒定／忽略历史KL期望 | 显示两条可能z历史对应不同h；给其中一条合法KL条件项 | 能说明“条件于历史确定”与“对随机历史平均”分别在何处 | W1.2；不要求实现完整神经递归或全概率测度理论 |
| ELBO gap写成逐步过滤后验或KL反向 | 给完整序列联合／q比值与KL定义，定位被换掉的对象；允许查Jensen | 能合法补回evidence gap及外层期望，保持原正确发射项 | W1.2连续推导；同题改答不作新独立样本 |
| 局部rollout正确，整体行动错 | 检查当前q→future prior→reward→candidate→execute-first→real-o→q接口；保留正确局部 | 能修出从最早错误到重规划的连续流程并解释下游影响 | W1.5—6；不是自动继续加更底层小题 |
| 明示模块会做，情境里选择错 | 保存初始选择；补实际信息清单／候选条件，观察剩余映射 | 能依实际o是否取得作出合法选用／拒用，说明缺项 | W1.3／5；给模块后的执行不倒算未提示选择 |
| 概率算术阻碍关系解释 | 给精确数值／归一化结果，继续解释信息与动作接口 | 关系解释能继续，不受无关算术负担污染 | W1.3—5；计算未独立完成保持明确，不因此判所有关系失败 |
| 程序输出／教师参考冲突 | 停用受影响参考并请内容核验，优先检查系统错误；纸面可靠部分可继续 | 有可核参考且确认条件一致 | 回同一W1受影响位置；不先要求学习者迎合错误参考 |
| 同一帮助没有新增信息／当前负担过高 | 换文字／表／时间轴或收缩当前展开；仍保留整体义务；可以交完整解释后暂停 | 有明确新信息或可恢复接口；否则停止重复 | 保存父作品位置、已给帮助与未完成连接；停止不记达成 |

如果用户说“看懂了，推进”，可跳过重复追踪，把仍未由学习者承担的关键连接放入已备 W1 综合记录自然调用；不安排同题复述补偿。未来如真正开课，先保留原答及贡献定位，再反馈；本次备课不创建 PerformanceEvent、Judgment、学习进度或排程。

## 8. 给材料 agent 的制作契约（可直接采用 revision 1）

父 agent 在认知稿完成后调度材料制作。材料 agent 可按域核验修正内容，不改上述认知目标为“一题／一个toy”。以下是本次成品的必要组成，材料、正式题面、备用支持和教师完整参考须分开定位：

1. **核心讲解原件**：完整覆盖第3节语义与主线A—G，含统一时间轴、两个模型、基础ELBO的连续推导、信息集合、prior rollout和MPC接口。可靠内容可连贯解释，不为互动把每个定义切成问答。
2. **精确离散桥**：两个隐态、动作条件转移、观测likelihood、初始belief、明确评价规则，展示预测→观测更新→未来无观测的多步预测→评估候选→首动作后新证据→重新规划。概率数值可精确核；至少出现非平凡归一化、一个动作对预测的影响、一个实际证据改变后续规划的情形。桥是教学构造，不冒称RSSM本体或论文实验。奖励观察不能暗中泄露隐态而被belief忽略，若有此信息明确建模／屏蔽语境与结论边界。
3. **RSSM 映射及破裂点**：说明精确belief对应的是近似历史条件表示的功能，不是把belief硬命名为h／z；含两步以上h与z prior传播及无真实未来o的明确位置。主线最终回到神经RSSM与训练，不停在离散桥。
4. **连贯范例与主要任务**：实际题面、数据、允许帮助、学习者剩余工作和完整正确性锚点，按第6节接口写。W1整体题有可审完整合法参考／多解；不能交“待做图／以后看情况题”。选择任务中性标题，方法候选与近端提示条件明示，结论不越界。
5. **教师参考与备用支持**：依据第7节备必要分支。标出帮助是否代做选择、理由、变量映射或整体组织；备用但未展示不计实际暴露。整体参考要核完整推导与流程，不能用toy代码运行代替学科审查。
6. **第一条教学回复草稿**：只保存为本次审查稿，简短说明用途、主要内容和最终作品，随后实际给第一份对象／信息输入或完整示范入口；别只列课表。本次聊天不得直接开课。接下来的主要材料已备，但正式执行按需呈现。
7. **可选演示及来源**：如生成可执行学习代码／notebook，统一放本学习目录code/下本次专属模块，保留教师生成贡献、版本和材料引用；纸面主线不依赖用户安装／训练环境。一般多粒子演示与PlaNet原单轨迹区分。域来源以primary为主，数学锚点与程序行为分别核查。
8. **审查证据**：完整检查语义、合法对照、各轴独立调节、支架实际代做范围、整体接口、数值与公式；报告已核／未核和实质风险，不生成个人掌握状态。材料制作完成后回父 agent 做成品审查。

制作自由：可改具体机器人情景、概率有理数、视觉表现、题面次序与细节，条件是关键关系、学生剩余工作和反馈锚点保留。可选择给足完整示范，不需先诊断或诱导猜错；若增加支架，更新被代做范围即可。新增大证明、训练完整网络、远迁移、长期保持、固定课时须另明确用途，不能由策略卡或论文建议自动加入。

接受条件：主线的输入、数值桥、RSSM／ELBO主体、整体任务、完整参考、必要支持与第一回复草稿全部实际存在且可定位；“有提纲”不算成品；材料文字正确但任务替学习者完成所有关键工作，也不算合格认知设计落地。正式采用与正式开课仍是父 agent／用户的下一决定，不由本稿自动生效。
