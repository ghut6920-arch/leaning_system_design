## 1. 为什么保留这条完整主线

原用途要求理解 FM 并完成 2D conditional FM 与步数、误差、成本比较。要完成这项工作，学习者必须连接两个看似矛盾的事实：每条训练插值的导数可以直接计算；生成时却不知道它的训练端点，而且同一当前位置可能有多种速度标签。因此本课的关键桥是“可抽样的样本监督如何经共享回归变成局部边缘场，再由采样器变成分布”。只学插值导数、只追踪 oracle、只运行 AI 完整代码都不能承担这个用途。

本单元终点是一份连续作品《2D 条件 FM：从训练样本到生成分布的解释、实现与比较》。作品包含数据到参数的链、总体回归理由、合法条件输入、N 步采样、可解释的实验及条件取舍，数值、公式、字段和代码使用同一对象。自然分段是这份作品的几个位置，不另设每题“继续”开关。

## 2. 核心对象与教师模型的统一约定

全程 t=0 噪声、t=1 数据。c∈{0,1} 均匀；μ₀=(-2,0)、μ₁=(2,0)，σ=.5。训练 X₁|c∼N(μc,.25I₂)，X₀∼N(0,I₂)，给定 c 后独立；t∼Uniform(0,1)。输入 x_t=(1-t)x₀+t x₁，标签 u=x₁-x₀。新生成初始化 z，与任何训练端点无关。

生产必须分四条参照：

- `oracle_exact`：Y_t=tμc+√Q(t)z，Q=(1-t)²+.25t²；是解析答案，未训练。
- `oracle_field`：v*=μc+A(t)(x-tμc)，A=(1.25t-1)/Q；用于数值参照及场误差评价。
- `learned_field`：实际从独立采样的 CFM标签拟合出来的参数化回归器，禁止拿 oracle 系数或 oracle 速度作训练标签。
- `learned_reference`：同一个拟合参数、同一个 z/c，以更细步长求解所得的近似参照；不是 exact、不是新的训练。

教师训练采用明确的合法简化，避免新增多层网络和优化器前置：17 个时间节点 τj=j/16；分段线性 hat 函数 hj(t)，相邻两个非零，和为 1；s(c)=2c-1。每个 j 的 4 个特征是 hj(t)[1,x_coord0,x_coord1,s(c)]，拼成 68 维 Φ(x,t,c)。共享参数 W[68,2] 输出 ΦW[batch,2]。从初始 W=0 到 NumPy 最小二乘解，是对有限经验 coordinate-MSE 的真实参数拟合；另用 §3 的局部 SGD示范显露一次梯度更新。

这个模型族对固定 t,c 仍仿射于 x。它可服务每类同 σ 的 Gaussian 主例；时间基函数近似也可能带来场误差。它不能充分表示本课同 c 双峰的非线性局部权重；双峰只能作解析结构对照，不能把这个回归器的训练结果称为已学多峰。数据分布、模型族、损失及采样器是可分别替换的层；FM 不要求一定使用神经网络，真实高维网络则有另一个表示与优化问题。

损失统一为 L=(1/(2B))Σb||v_b-u_b||²，与 NumPy `mean((V-U)**2)` 相同。单样本二维损失为 1/2||v-u||²，∂L/∂V=(V-U)/B，∂L/∂W=Φᵀ(V-U)/B。公式中的未按维数归一化风险需要明确除 2 才与实验数字对应；等价与常数结论不受同一整体缩放影响。

## 3. 主线的实际材料与连贯示范规格

材料制作为一份连贯阅读稿，按以下关系段落展开。它可以分次自然呈现，第一段不把全部答案倾倒；审查版允许用户查看全部教师参考，之后按实际暴露解释测试。

### A. 建立问题与训练/生成接口

开头实际表述：“我们有带类标的数据点，想输入类标和新随机噪声，输出该类的分布。训练能看到 x₁，生成不知道它。这节先把一条训练记录追到参数，再说明很多记录为何训练一个当前位置的速度，最后用相同初始噪声检查采样误差。”

同一页给训练流与生成流，箭头注明对象而不是只画流程名。训练：(x₁,c),x₀,t → x_t/u → Φ/W →预测/损失 → W；生成：(z,c),t_n →当前 y_n→同一个拟合W→速度→y_{n+1}。上方直接给 X₀、X₁、t、c、u 的释义。标注 `x₁` 是本任务待生成的数据端点；已知目标坐标可合法成为 c，合法性看推理信息时点，不能以“c含坐标”自动判泄漏。

教师参考：训练标签可用端点不等于推理输入可带端点；固定 θ 后生成函数只有当前状态/时间/可用条件。这里输入应足够让学习者承担后面的组织和解释，不能连续追问尚未输入的定义。

### B. 一条训练记录追到真实参数

连续使用 c=1、x₁=(3,-1)、x₀=(-1,1)、t=.25。算 x_t=(0,.5)、u=(4,-2)。局部可训练输出 b=(2,0)，coordinate-MSE=4、梯度=(-2,2)，η=.1 后 b′=(2.2,-.2)，同样本损失=3.24。每一步旁边只标它使用的前提和改变的对象。

然后接回共享回归器：本查询 t=.25 只有 h₄=1，活跃特征块为 [1,0,.5,1]；W有68×2参数，而不是每条数据另建b。批量经验损失对W求导后，多个输入通过共同W相互影响；NumPy `lstsq` 直接求这个有限平方问题的解，没有声称执行了无数次梯度步。生产给实际拟合前后同一个查询的两向量、W变化摘要和 held-out风险，登记教师运行条件。局部 b例只说明梯度方向，不能冒充完整回归器的一步梯度或总体收敛。

必须接一句：“这个训练标签 u=(4,-2) 仍不是该查询的精确边缘速度。相同 x=(0,.5)、t=.25、c=1 的 oracle 是 (96/37,-22/37)≈(2.594595,-.594595)。为什么一条合法监督不是精确场，才是下一段的问题。”

### C. 从样本冲突补到条件均值与总体等价

实际解释先固定 S=(x,t,c)，再平均能产生该 S 的端点/噪声对。网络看不到该对端点，因此多个标签共享同一个预测。不得把“求所有 u 的均值”当答案；兼容概率随 x,t,c变。

材料展示 f-U=(f-m)+(m-U)，m=E[U|S]；给条件期望的提取规则，逐行写交叉项为何为0，得到 E||f-U||²=E||f-m||²+E||U-m||²。框出不依赖 θ 的后一项，并给有限二阶矩、同路径/抽样/损失、路径不依赖θ及梯度交换的条件。生产用上游原推导，不让步骤只剩“正交原理”名称。

风险分解说明总体最优目标相同、合法交换下总体参数梯度相同；单个u和m不同，所以单样本 loss/随机梯度不等。CFM风险非零既可能是标签方差，也可能混入容量/优化/有限数据误差。不要从本段推到“真实训练必收敛”。

接输运段时直接提供测试函数弱形式及连续性方程的含义：m 使这些中间分布满足相同质量守恒，适当正则/唯一性下ODE在各时刻给相同分布。学习者后续负责把“分布相同”与“每粒子照原线走”分开；不把一个有限图例当一般证明。

### D. 连同 c 的多样性及直线边界

主例 oracle exact 用同一个 z=(-1,1)、c=1，给 t=0,.25,.5,.75,1 的实际坐标，特别是Y_.5=(.440983,.559017)，初末连线中点=(.25,.75)。图的横纵轴都是 x 两维，旁边t标签是生成时间，不把t当图中横轴。两条轨迹图例明确“端点配对插值”与“边缘ODE”；不能仅贴曲线不解释对象对应。

再固定同一个c，数据为等权 N((-2,0),.25I) 与 N((2,0),.25I)。给 t=.5、x=(.5,0) 的后验 w+≈.960834、v+=(2.6,0)、v-=(-3.8,0)、v*≈(2.349339,0)，而终点全局均值=0。当前位置的标签平均不同于一次性终点均值；不同z查询不同位置的场，因此理想运输可多峰。对称点 x=0 的速度=0只说一个点，不说所有轨迹塌到0。不得用两个c的pooled双峰代替类内多峰。

最后给竞争模型的必要输入：直接MSE终点输出均值；显式Gaussian或混合密度头能抽样；FM学习速度后需积分。已知本主例解析Gaussian可以直接便宜地抽样，不能让“选择FM”成为标准答案。

### E. 学场与解场接成可解释实验

Euler t_n=n/N，n=0,…,N-1，N次更新 y_{n+1}=y_n+(1/N)v(y_n,t_n,c)，到t=1；在t=1不评价含1/(1-t)的 endpoint式。主例oracle边缘场在端点可平滑延拓。代码要用更新后的状态，不能反复查询z，不能少一步或把输出速度作为终点。

oracle N=1时 v(z,0,c)=μc-z，故所有点一步到μc，方差0。这是正确场也会出现的积分失真。提供上游 N=1,4,16,64,128理论方差表，再由教师运行复核。在同一噪声批/按c比较理论及样本均值、协方差；小样本误差不得解释为公式失效。

learned实验固定一次拟合参数、同噪声/类标，比较以上N，再用较高N与加倍N检查当前learned reference是否近似稳定，未稳定不称精确参照。同时提供 held-out CFM coordinate-MSE 与 oracle field coordinate-MSE。oracle exact vs oracle Euler隔离积分；learned vs自身reference近似隔离此场积分；learned vsoracle exact混合场/积分差。教师运行没有学习者解释，不登记学习表现。

成本主指标是Euler每样本N次场求值；墙钟时间须随实际环境/批大小记录，未知不承诺几秒。更多N不会改变W；学得差时更多步只更准确解当前错误场。

### F. 回到具身接口

给一个不执行机器人的明确接口：数据动作chunk a₁[batch,8,2]，8个物理时刻 k，每步两维为平面位移(m)。按给定每维尺度归一化后，x₁[batch,8,2]，先验x₀同shape；每样本生成t为[batch,1,1]并广播，任务c由当前相机观测/已知目标得到，示例c表示“左侧/右侧目标”。速度头输出[batch,8,2]，单位为“归一化动作量/单位生成t”；N=16只更新整个chunk16次，输出仍是8个动作时刻。反归一化后动作量单位为m，执行步k按控制周期决定；N不等于8、不指定真实执行周期。

学习者后续负责指出本toy class conditioning到真实观测encoder之间未完成的接口；黑箱保留输入/输出/信息时点。玩具分布吻合不证明动作可执行、成功或安全，闭环效果是另一个有实际设备授权与评价的工作。

### 教师整体参考与合法多解

R1参考为上游 §4与本稿 §2–3B；Φ/t/c共享W应与采样同签名。对参数影响可用梯度式或线性预测差 Δv=ΦΔW说明，不能把每个查询分配独立标签记忆。OLS允许作为合法经验风险优化，不强迫梯度优化器。

R2参考为上游 §3.2，交叉项在固定S下为0，条件方差项与θ无关；除2的归一化一致。反驳单样本相等需明确“总体期望相同”与“随机标签仍有方差”的层级。只引用定理名不满足补理由用途；合法等价推导可用。

R3参考为上游 §5.3。接受Euler正规N步、合格的其他ODE求解器及说明场求值次数；如任务采用高阶求解器，指标成本按实际函数求值，不再自动=N。正式实现证据要有学习者代码原件、实际帮助与行为，纸面规格只支持组织与解释。

R4至少分清oracle纯积分参照、learned自身数值参照、held-out field MSE；样本统计与理论矩分开。learned大N参照不收敛时接受“当前尚不能可靠分离”的判断。CFM非零不可一律叫训练失败；按c呈现避免pooled掩盖条件错配。
