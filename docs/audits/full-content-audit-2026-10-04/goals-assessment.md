# SK01／SK04 与 AG1／AG3 内容兑现审查

日期：2026-10-04。审查者：本次审查子代理；只读公共实现与设计源，仅新增本报告。这里的前向用例为纸上分析，没有真实学习者作答，没有运行评分、存储或教学服务，也没有改动个人记录。

## 判断

**SK01 目标设计与 SK04 评价诊断不需要整体重做。** 两者的运行规则已经保留大量会改变专业决定的内容：材料性质与要求性质、课程粗地图和近期规格、决策相关粒度、前置与返回、局部与综合证据、操作级帮助影响、替代解释、有价值才诊断、诊断停止、纠错与旧证据边界。SK04 的证据规则本身就是这项 Skill 的实质能力，不能因其形式化程度较高而删去。

但有三类不足需要限定加强：

1. **从材料到目标的正向设计指引还可以更明确。** 运行规则能检查目标该有什么，给出了重要分解标准；对如何从一段复杂正文提取对象、关系、条件和整体任务，再形成目标与判据，缺少连贯示例。现有前向试用表明简单异或资料能落地，不能据此确认复杂新课也稳定。
2. **条件化判断到教学内容展开的桥接被拆散。** 原设计的一屏展开单含起点、材料功能、学习者工作、改道和收束；当前主要由 GoalSpec、ActivitySpec、LearningNeed、PlanCommitment 与交付说明分别承载。这种拆分可以成立，运行入口仍需给执行者足够短、完整、可教的合成视图。仅看本次负责文件，无法确认全系统是否已稳定做到；应与 SK00／SK03／SK05 联合核查。
3. **跨学科正确性细节和复杂作品评价的指导、验证较弱。** 原方案明确区分 AI 解释、实现、实验与结果外推，金融模型假设／数据时点，政治事实／因果／价值。精简规则保留通用原则和部分差异，但没有完整展开这些可用检查。应增加按实际目标选用的判据指南及少量复杂实例，避免重做一套领域总分或固定题库。

这些不足不等于需要 Python 自动理解任意学科。设计明确把内容分析、专业评分与诊断解释交给模型，把确定性辅助器限定于声明、引用和条件相容性检查。这个分工合理，应保留。

## 两个新纸上前向用例

这两例只按已加载的 SK01、SK04 两组 references 和 AG1／AG3 路径走查，不依靠设计原文临时补完规则；未假装运行器自动产出内容。

### 用例 A：陌生主题，只有大纲，学习者明确想先建立理解

假设输入：大纲写“张量、视频输入、轴交换、模型接口”；用途是把一段视频按指定轴顺序交给模型。没有学习者作品；用户表示陌生，希望先看解释。大纲没有规定具体接口规格和全部张量语义。

按运行规则可推导：

1. SK01 辨认大纲只能支持范围，不能造正式题目判据；先形成主题与最终输入任务的粗地图，标出缺的接口规格及正文依据。未知不能填零基础。
2. 近期目标应围绕视频对象与轴身份形成可检查工作，不按“四个名词”机械拆成四目标；必要语法可伴随补充，有益背景不做进入门槛。
3. 用户要示范，可以直接进入有可靠限定依据的教学；SK04 不需要先创建诊断。如果示范与符号澄清无论回答如何都会给，就没有理由先发一道测查。
4. 在教师提供语义后发生的学习者工作，应按实际输入和帮助保留；没有自主选择的证据，不能称课前已会或长期掌握。

**能落地的部分：**起点选择、目标边界、停止不必要诊断、证据解释；这些都有明确运行依据。

**暴露的不足：**SK01/SK04 不告诉 AG0 应怎样组织“视频—张量—轴身份—接口”连贯讲解与示范，也不生成必需语义表。这个责任应由 SK03 与 AG2 的材料准备落实。目标规则可增加一个简短内容分析交付示例；不能让 SK04 为解释缺失负责，更不能通过删证据规则解决。

### 用例 B：已有条件清楚、可靠的复杂作品

假设输入：学习者提交完整程序、对应接口规格、独立完成条件说明、测试与实验记录；已核验内容与当前目标条件一致。近期目标要求从输入规格组织转换、正确运行、解释边界和测试取舍，没有新增长期保持目标。另一个旧口头解释事件已充分支持局部概念。

按运行规则可推导：

1. SK01 复用相容目标，保留局部与完整组织要求；不因为新会话就从变量或语法重测。
2. 这是复杂完整产物结论，SK04 读取 diagnosis-review，交 AG3 回完整作品和先定判据。先审原件、真实帮助、规格和结果，再看旧教学总结。辅助器的 compatible 不替学科审查。
3. AG3 检查实际可辨认的选择、映射、执行、边界与组织是否满足判据；合法不同实现按规格审，不机械追参考代码。旧口头证据只支持其已有范围。
4. 若原产物足以支持近期要求，明确不追加检查；若只缺目标要求的测试选择理由，先定位现有记录有无该依据，再只补会改变结论的部分。不得用 len／名称题代替完整作品复核。
5. 某测试脚本若有错误，限制对应结论并回原产物重评；无关有效实现和解释证据保留，系统错误不要求用户重新实现。

**能落地的部分：**复用、整体评审入口、原件核查、替代路线、局部支持、结束与纠错都有明确指引。

**暴露的不足：**复杂作品怎样建立充足判据与如何评价实验外推，仍要求专业模型进行学科分析。当前规则允许并要求这种分析，现有前向试用尚未实际检查其质量。这应补语义前向实例与目标专用判据；不是增加一个自动评分器即可完成。
