# SK01 learning-goals：B2a 目标切片

状态：B2a 已创建开发态 Skill 和虚构候选辅助程序；尚未安装或绑定真实宿主。规格修订：0.2.0；共享协议：`pl-contracts/0.1.0`；目标资源：`pl-goals/0.1.0`。本文件承接 B0 短任务单，原 B0 验收属于历史设计预期；当前实际结果见 B2a 报告。

接口按[共享契约](../../contracts/shared-contracts.md)，出处与冲突按[来源索引](../../resources/source-registry.json)。

## 负责的决定与模式

AG1 主责课程粗地图、近期目标、判据、关键前置和版本；模式按路线为初次设计／变更／澄清，先粗地图再近期细化。AG2／AG3 可读取目标并提出内容／证据影响，AG0 接收有效结果，不加载本 Skill 重写正式要求。

不判学习者掌握、不强制冷启动全面测评，不由会话缩时降低目标。用户决定正式用途、最终范围和新增投入；AG1 在已有授权内维护目标。模式不提供额外权限；无实际授权时只返回候选设计。

## 编写依据与接口

必读路线目标角色、矩阵、通用调用、加载和 P-Goal；D00 共同语义、生效与控制；D01 契约／宿主边界；D02 第三至五、八至十节；D03 来源与要求纠错；D09 采用；D10 用户选择；D11 B10-01／03—05。研究不替代课程要求，通常不读全策略库。

输入：用途与约束、要求来源、`SourceFragment` 内容依据、课程粗地图、已有 `GoalSpec`、相关有效 `Judgment` 与资源／未知项；控制与授权引用贯穿。

输出：`GoalSpec`、目标对应的证据要求、前置依据／`DependencyEdge`、目标版本兼容说明、未决项；实质变更用 `ChangeNotice`。每个目标／前置／判据同时可追到要求来源和内容依据，区分课程要求、个人用途、系统建议与待澄清。定义对象域、关键操作、产物、允许资源、适用情境、必要时间条件，目标未要求的延迟／迁移不制造未知欠项。

AG1 采用目标决定；AG2 返回内容支持范围，AG3 返回评价能观察什么，AG0 返回当前执行缺项。只有会改变承诺的部分再交 SK05 整合。`WorkResult` 说明已处理／未处理、限制和下一责任，返稿成功不等目标正式生效。

## 路径、约束和停止

常规路径：辨识课程表／大纲／正文／作业／解答的作用 → 粗地图与关键最终任务 → 只细化近期范围 → 确定关键工作与证据条件 → 核内容可行性／评价可观察性 → 有权采用版本关系。

短路径：已有有效近期目标且用途与条件兼容，直接复用；用户自述陌生或要示范，可以给可靠限定探索入口，不先要求答错或全面诊断。只缺远期资料不阻止当前有据范围。

异常：要求来源或关键内容有疑误，限制受影响判据并查两条依赖链；实质变更重审旧证据的适用范围，不能用新标准倒判旧答。材料、原答和授权缺项各自限用途。失败／超预算返回可靠子范围、缺项和下一触发，不补造判据；高能力资源不可用保持重要未决，不无限索要完整背景。暂停／删除先控制，受删依据不从摘要恢复；接管只继承原授权，旧目标建议不能覆盖新承诺。

必须保留：目标、教学进展、支持状况与计划执行分开；必要依赖是可检验判断，课程顺序不自动为前置。新增实现选择：B0 用 `GoalSpec` 与引用表达目标模板，字段和语义以共享契约为准，不新造领域总分。

## 加载、工具与修改范围

运行读取[目标 Skill](../../src/skills/learning-goals/SKILL.md)、其目标设计／版本规则、当前合法课程要求及必要内容依据，不常驻全库；出现要求／内容冲突或未覆盖配置回查对应原文。结构化虚构输入和嵌套表示见[B2a 适配接口](../../contracts/runtime-b2a.md)，辅助程序只检查候选，不代替模型设计或专业核验。

需要来源定位／读取、专业内容与任务资格核验、真实授权绑定及串行提交；工具缺失时交未决项，不能把存在性校验当内容成立。宿主不能隔离后台写入／展示则单入口顺序采用，兼任不称独立核验。

本批修改：本任务单、SK01 及精简参考、AG1 目标职能、候选辅助程序及虚构测试、适配接口与验收记录。共享契约字段源保持原版；与 B2b 共用 `GoalSpec`／`SourceFragment`／`MaterialUse`，无需先完整建全课程图谱。
