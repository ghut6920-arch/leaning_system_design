# B3b 有限验收：C0 教学共同核心

日期：2026-10-03。依据 N00 第十二节 B3b、D04 第二至八节、D02 第五至九节、D08 第三至六节及 D11 B10 受控核查。共享协议仍为 `pl-contracts/0.1.0`；专业请求为 `pl-teaching/0.1.0`。

本批实现 learning-teaching 的 C0 有限切片，复用 B1 状态组件和 B2a／B2b 的目标、材料接口。测试目标、授权、预算、题面和回答均为虚构输入。验收检查实际引用、事务、时序、分支、收束和恢复行为，不把声明检查当学科核验或真实学习效果。

| 场景 | 可观察通过条件 | 验证边界 |
|---|---|---|
| 当前可靠简单活动 | 确切目标／判据／材料／参考、授权、预算与任务资格支持当前用途；可直接执行 | 声明与引用检查，学科正确性另核 |
| 任务资格失效 | 只限制受影响的活动用途，不因答对追认合格，不归因用户能力 | 资格与表现分离 |
| 初答、帮助、修订 | 原答可回查且不覆写，实际帮助／反馈及替代操作可定位，顺序与时间事实保留 | B10-02 的事实条件，不含正式能力判断 |
| 关键帮助在初答前／后 | 两种实际时序不同；帮助前原答仍保留，帮助后操作受相应条件限制 | 不得整主题清零；正式 Judgment 留 B3a |
| 备用参考／展示未知 | 未显示的备用材料不记实际暴露，未确认展示保持 unknown | 没有宿主 UI 显示认证 |
| 同题修订、多角色引用 | 一个 PerformanceEvent／independent_sample_id，不多计成功或新样本 | 不提供统计掌握度 |
| 条件不明／时间未知 | 记录已知及未知，不把缺日志记未接触；目标不要求的时间维度不成欠项 | 目标内时间条件与日历分开 |
| 反馈分支 | 根据可定位原答现象作可靠支持并留下学习者工作；结果不会改变下一步时不新增小检查 | 规则／人工前向试用；未实现自动学科诊断 |
| 局部修复与返回 | 保存规范父产物、卡点、够用条件和返回连接；局部够用回同一父任务，整体未自动通过 | 普通 C0 修复，不含 Encoding／Post 专项 |
| 简单活动已足够 | 直接收束；无新目标外必修检查、卡库遍历或复习债务 | B10-01 的 C0 部分 |
| 缩时／预算结束／暂停 | 停新展开，保存实际工作和未连接部分、停止原因；目标／判据不降，未完成不冒称通过 | B10-03；不自动重排计划 |
| 无结束摘要恢复 | 从最后可信事件、规范产物和当前依据继续；未记录动作不补造，不要求整章重做 | B10-06 的受控恢复 |
| 需求待处理 | 原答与父任务引用可定位，相同缺口返回同一需求更新候选；不写需求或处置，提出／接责／安排不混同 | 没有 SK05 实质排程 |
| 内容疑误／非标准解 | 保留原答并限制确定评分，指定 AG2／AG3 及下一触发，其他可靠授权工作可继续 | 不裁定错误或强迫重考 |
| 控制、冲突及幂等 | 删除／暂停／专业用途门禁先于当前动作；旧状态不覆盖；重试不增事件／需求 | 同一 SQLite 的可控行为 |
| 删除后迟到／旧依据继续 | 不从已删除原件、事件、摘要或旧返回恢复正文；合法剩余范围才继续 | 不承诺外部文件／已加载上下文已清理 |
| 证据／诊断越界请求 | 不提交正式 Judgment、DiagnosticNote、重要结论或降低目标的承诺 | 本批未接入 B3a，不替 B4／B6 越权 |

测试应保存承载与协议版本、原始请求／返回、检查者、通过／失败／未执行／无法判定及限制。实际执行入口与报告以本批运行验证文件为准；本规格给出待验证条件，不把未执行分支或既有完整 B10 情境改记通过。Skill 前向试用另留原始输出，结构验证只说明可发现与可加载。

本批可证明受控虚构记录的保存、读取和流程边界；V1 的真实内容正确性、V2 的真实教学兑现、V3 学习者收益、V4 协作增量分别待真实运行。C0 不自动运行已有 B3a 评分／诊断；初答和修订可通过显式交接检查。B4 专项及计划、B5 自动纵向集成、B6 身份与唯一展示入口隔离不属于本批交付。其他批次的实际状态以各自交付与验证为准。

联合修复的资格、配置、材料绑定及响应点测试另见 [B3 互通报告](../validation/b3-interop-report.json)，原批次报告保留历史结果。
