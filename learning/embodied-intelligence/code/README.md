# 具身智能统一代码目录

本课程的所有代码统一放在这里，包括学习者编写、AI 生成、共同修改、教学示例、测试、运行脚本和可执行 notebook。按模块或项目组织，例如 `M0/`、`P1/`、`P3/`；同一项目共同维护，不强制按作者拆成两套代码。

每个项目记录运行入口、依赖和代码来源/贡献。AI 初版、用户原始提交与后续修改保留可定位版本；未使用版本管理时保存不同文件名或快照，不能覆盖作为评价依据的旧版。代码来源见 [来源记录](provenance.md)，需要时继续追加。

sessions/ 保存会话、原答文字、帮助及修订顺序，并引用这里的代码文件、版本和函数/行定位。可执行代码原件与代码快照也放 code/；不再把脚本散放 artifacts/ 或会话目录。聊天中的零散代码若用于教学、运行或评价，保存为这里的文件并说明来源。

artifacts/ 保存推导、概念图和报告；experiments/ 保存实际运行配置、日志、指标和结果，引用 code/ 中的主代码。模型权重、数据和输出不因代码来源规则移入这里。

已有脚本的移动对照见 [路径迁移](path-migrations.json)。旧会话与题面中的历史路径按此表解析，原历史记录不改写，迁移不改变代码内容或已有帮助事实。运行通过不等于学习者独立实现。
