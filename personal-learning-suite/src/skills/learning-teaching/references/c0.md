# C0：有限活动、真实帮助与收束

本运行说明转译 D04 第二至八节、D02 第五至九节及 D08 的需求／预算／恢复约束，依据登记见 [source-registry.json](../../../../resources/source-registry.json)。共享对象只在 [shared-contracts.md](../../../../contracts/shared-contracts.md) 维护；当前请求与实现限制见 [teaching-b3b.md](../../../../contracts/teaching-b3b.md)。编码和 Post 专项、完整证据判断与计划分别留 B4／B3a，不靠本说明产生已执行声明。

## 准备与活动设计

用当前有效目标及判据、范围和已有事实说明：本次让学习者完成什么，以便决定继续、帮助、有限修复还是结束。基础未知写未知；不为填活动字段推测失败原因。正式判据未落实时可以做有边界的阅读／示范候选，不作正式通过判断。

ActivitySpec 至少让执行者知道实际题面、版本、可见输入、关键操作与产物、允许资源、备用帮助、教师参考、反馈锚点、多解／信息不足的处理、关键分支、局部调整权、预算、退出以及父任务返回。上游可引用的内容不重复建立另一份规范来源。

陌生单元或尚无具体活动时，先读 [内容准备](design-whole.md)；需要建立／修订关系时用 [Encoding](encoding.md)按当前对象与结构选择材料。不能仅用目标标题和字段清单代替已准备活动。开始呈现有限用途、当前位置和必要输入，让学习者能够进入实际工作；说明用途的细度按是否正在观察自主选择决定。

课程／单元启动还须核对本次主要安排已经连贯可执行：目标内理解及联系、核心输入／示范、主要题面与反馈参考、支持返回、结束和下一连接均有实际依据。一题的 ActivitySpec 合格不自动证明本次备课完整。准备要求集中在 design-whole，先完成后再发布首份教学内容；日常恢复和纯解释按原范围处理，不新增程序字段或会签。

一次活动结束与单元结束分别处理。默认在必要反馈后沿design-whole接单元内下一份实际内容／整体工作；只在需要学习者贡献或有效停止条件成立时等待。已授权正常推进不逐题询问“继续吗”，学习者的“继续”不改变父目标、已发生事实或策略历史。认知工作未覆盖时明确留在同一主线，不以局部正确数或文书收束替代。

讲解、完整范例、框架或图都可以成为当前输入。缺必要定义、对象含义或步骤组织时直接给；基础未知但不影响输入时边学边观察。若不同回答不会改变所需帮助，先给该帮助。现成产物直接使用，不强制先诊断。纯教学输入也可收束，不为记录 PerformanceEvent 补造原答或硬加问题。

下表同时检查教学任务是否适用与拟作的证据解释。教学输入和参考也须可靠，任务应支持当前工作、前置负担应适当；尚无正式判据只限制正式通过判断，不豁免内容正确性。示范可以代做目标操作，此时明确作为输入或有帮助学习；独立性、暴露和间隔等按拟作结论限制，不阻止提供必要信息。只有需要取得尚未支持的目标证据时才另用合格任务，并由实际目标与计划决定是否现在需要。

发布教学任务或作评价前，按用途分别检查五件事：

| 资格面 | 当前需要核对什么 | 不满足时 |
|---|---|---|
| 调用目标操作 | 产物是否需要学习者完成目标判断；抄写或猜选项能否绕过 | 改活动或限定能支持的范围 |
| 输入未代做 | 题干、标题、例子、颜色、编号、默认项及安排解释是否已给方法／关系 | 转为具体有帮助教学，保留实际暴露 |
| 前置负担 | 符号、工具、读取与步骤是否引入未声明前置 | 换形式或提供允许的局部支持；不直接归因父目标 |
| 内容与参考可靠 | 当前版本、对象域、条件、推导／测试与合法多解是否已有本用途所需核验；有核验路径不等于核验完成 | 停用依赖疑误内容的讲解／任务及确定评分；可靠部分可继续，交 AG2，必要时交 AG1 |
| 证据条件 | 资源、暴露、训练关系、目标实际要求的时间／情境是否相容 | 限相关用途；保留其他可观察工作 |

B3b 程序辅助器检查引用和声明，不能独立证明任务内容正确或发现所有未标注的语义／视觉泄露。人工教学仍须实际核对内容、呈现与参考；AG2 的内容核验与用途核验必须支持当前活动，远期资料未齐不阻止已准备范围。准备往返没有新信息时汇总具体缺项、用途影响、可行替代与责任方，停止重复索完整方案。

## 原答、帮助与反馈

每次表现保存实际题面／版本、原答或原始产物、学习者与 AI 的贡献、实际资源、可见材料及必要上下文。AI 整理稿不能替代原答；修订追加，不回写成初答。同一表现兼有学习和检查用途只记录一次，多个评分者或模块不能增加独立样本。

时间线保留初始输入、初答、实际帮助／反馈和修订的顺序。引用或记录事件时间、初学及最近相关练习／反馈、已知再接触；只有时距影响解释时才增细计时。外部接触不明保持 unknown，不能根据缺日志断言未接触。备用解答和后台参考未展示不计实际暴露；展示未确认保持 unknown。

帮助按替代了哪项操作解释。例如提供公式后，之后的自主计算仍可保存，公式恢复／选择未被观察；提供一个反例后，修订可体现利用反馈，但该反例的自主设计不能归学习者。方法被标题或安排说明提前给出同样记录。完整示范、意外展示、换 Agent 与同题重算不重置暴露。

反馈定位原答现象，给有依据且与现象相称的支持，再留下可观察的修订、说明、比较或操作。简单事实错误可以直接给事实；任务可能有缺陷时先回查参考。原答与参考不同不等于学习者错，合法新解或反例须保留并移交相应复核。

| 当前观察 | 合理教学分支 | 保留的限制 |
|---|---|---|
| 前提暂不可用，关系是否可用未知 | 提供允许前提，观察剩余推理 | 不反推自主恢复前提，也不清零之后的推理 |
| 步骤断裂，可能是关系、符号或执行问题 | 改读取形式或支持必要连接，让学习者完成剩余部分 | 呈现调整若泄露关系也记录帮助 |
| 条件遗漏或方法选择失败 | 有需要时作能改变下一步的条件比较／有限观察 | 方法由 AI 给出后，只保存相应帮助下执行 |
| 实际产物和参考冲突 | 暂停该处确定评分，回查原答、任务与内容 | 不持续要求改到参考一致 |
| 原活动已经完成所需工作 | 直接确认具体工作并收束 | 不追加目标外理由、保持或迁移要求 |
| 相同路径无新信息或已有反证 | 换有依据且预算内的路径，或结束并移交 | 不无限追问、不以慢答推断一般能力 |

含糊、未预期或与原判断不符的反应，按 [Encoding 的动态调整与返回](encoding.md#动态调整与返回)核对象、条件、题面／参考并调整实际支持。需要区分会改变帮助的合理解释时，直接读取 [SK04 有限诊断](../../learning-assessment/references/diagnosis-review.md#有限诊断为当前决定服务)；普通正确反馈、同一可靠帮助和已经够用的工作仍直接推进或收束。当前软件可保存观察与分支理由，但不生成正式原因诊断。重要决定缺证时保持未决，不用额外题目掩盖缺授权或缺核验。

将同一产物中自然相连的操作与必要解释合成可完成的工作，避免每个术语或微步骤都造成一次往返。学习者卡住时可立即求助，不要求先交完整批次。反馈先明确具体正确处、问题与下一连接；必要复杂核验说明待核范围。稳定目标、参考和授权复用，仅在内容或条件变化时重查；记录原答／帮助和关键断点，不逐题重写整套目标／计划，也不虚称后台稍后保存。

## 局部修复与父任务

进入修复前保留同一父产物的位置、实际卡点原答、已有帮助、仍可能的解释、局部够用条件、返回连接与剩余预算。人工文件模式可用原件引用和短段落，不要求学习者填内部字段。实际调用 B3b 时这些含义对应 ParentTask 的父活动、parent_artifact、blocker、entry_basis_refs、alternative_explanations、local_sufficiency、return_connection 与 budget_ref；简单活动可明确不适用，不能只存父任务标题。

局部工作达到父任务所需程度即返回同一未完成产物，保留实际帮助、接触与原答。原题可以用来修订，但已暴露关键答案后不能当作新独立证据。父任务仍失败时保留局部成功，检查综合组织、识别、新前置或原解释，必要时收束；不靠子项打勾宣称整体通过。

证明、代码或综合报告以连续规范产物保留，本次分段只改变推进位置。完成连接、未完成连接及其关系须可定位；B3b 的简单任务切片不提供复杂整体评审。

## 收束、需求与恢复

收束记录实际完成／未完成、原答位置、帮助和条件、父产物与下一连接、停止原因、受限用途、必要责任和触发。预算须容纳必要反馈与收束；只剩收束时间则停止新展开。缩时仅改变当前范围，不能降低正式目标／判据或自动把所有未做项排到明天。

本次活动完成与目标能力结论是不同决定。仅未来必要条件尚未满足时可以结束当前教学；未纳入目标的保持／迁移不建立欠账。已有合格原答可直接交评估，不重复考。人工教学在有效授权、可靠判据与真实原件具备时按 [SK04](../../learning-assessment/SKILL.md)作相称评价，重要或争议结论按其复核边界处理。B3b 程序辅助器本身仅保存教学事实／候选，不自动产出正式 Judgment 或 DiagnosticNote；这是该开发服务的职责边界，不是人工教学的评分禁令。

LearningNeed 仅表达目标内必要工作：目标和要求、尚缺内容、已有事实、现在考虑的理由、不做影响、必要条件与时窗、原答／帮助／材料／父任务引用。相同缺口更新同一需求；不按答错次数或卡片创建平行队列。发出未获回执写待接收，收到但未承担写未接责，接责未处理写待处理并给责任和下一触发。没有有效 PlanCommitment 不能显示已安排；B3b 不代 AG1 作计划处置。

恢复时先读当前有效范围、目标／判据、材料用途、限制与授权，再定位原答、帮助／接触时间和父任务断点。无结束摘要从最后可信事件继续，缺失动作保持未知；只补会改变起点的信息，不重复已保存工作。依据停用或删除先限制相关用途，历史摘要不能恢复已删内容；剩余判断的保留／收窄／撤销交 B3a。

参考更正须分别处理材料可靠性、历史判断、实际教学误导和安排相容性；内容修好不自动恢复其他三面。对用户纠正错误反馈应说明具体更正及仍成立范围；原答足够时移交直接重评，不强迫重考修系统错误。高层不可用时继续不依赖争议且有授权部分，或结束并保留责任触发。
